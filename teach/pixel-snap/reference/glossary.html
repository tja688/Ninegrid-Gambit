Reference

术语表

本课与后续课统一用这些词。撞到陌生词先回这里。

Vertex snap（顶点 / 几何吸附）

在顶点着色器里把裁剪空间坐标折到像素格。改变的是方块画在哪，不改变纹理内部怎么采样。你们的 TableNineSnapClipToPixelGrid 属于这一类。

UV / framebuffer snap（采样吸附）

全屏 blit 时用量化后的 UV 去读颜色缓冲：floor(uv * res) / res。每个屏幕像素都被迫对齐低分辨率格。旧的 SelectiveLook Pass1 属于这一类。

SDF（Signed Distance Field）

TMP 字形 atlas 存的是到轮廓的距离，不是「实心黑白位图」。边缘锐利度靠距离场的连续采样产生 AA。TMP 文档。

Subpixel position（亚像素位置）

物体落在两个屏幕像素之间。Pixel art 用 nearest 时常见后果是闪烁/抖边；文字用 SDF 时则需要亚像素来保持边缘平滑。

Pixel Perfect Camera

URP 组件：按 Reference Resolution / PPU 控制 ortho 与可选的 Pixel Snapping。官方参考。注意：其 Pixel Snapping「不改 Transform」，是渲染时对齐。

Scanline（扫描线）

全屏后处理暗线/栅格。轻度时文字通常仍可读；糊的元凶几乎总是 snap，不是 grille。你们的 Pass2 仍可打在文字上。
