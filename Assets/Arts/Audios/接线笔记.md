## 1. 匹配策略摘要

**游戏风格**：2D 像素风航海肉鸽，核心体验是「收绞盘 → 发射巨锚 → 液压锻造」。音效应偏 **机械、金属、 nautical**，打击感要 punchy，UI 可略带 8-bit/复古感。

**素材库优先级**：

| 来源 | 用途 |
|------|------|
| 游戏已有 `Assets/Arts/Audios/` | BGM、锚链核心音效（已部分接线） |
| CleanFall_Assist | 抓钩/Grapple 全链路、战斗 stinger、UI pop |
| 龟龟潜海记 Sounds | 海洋 ambient、岛屿 BGM、UI 面板、金币、过渡 |
| 地狱酒店音频素材 | 中文命名实用 SFX：木头/金属/勾选/切换/错误 |
| CIGA 音频素材 | UI confirm/negative、奖励、警报 |
| GDC 2026 包 | 高品质 one-shot：whoosh、金属拖拽 loop、工厂 ambient、卡扣 |
| 8-bit | 主菜单 BGM `Airship Serenity` |

**文件命名规则**：`{编号}_{AudioKey}.{ext}`，与 `AudioKey.cs` 枚举 ID 一一对应。

**AMP 接线类型**：

- **SFXObject**：绝大多数 one-shot（默认 volume=1, pitch=1）
- **MusicTrack**：`BgmBattle` / `BgmBoss` / `BgmRoute` / `BgmMainMenu` → `loopMode=Loop`, 走 `MusicManager`
- **Loop Clip**：`AmbientBattle` / `BgmIsland` / `AmbientForge` / `LoopChainTaut` / `AmbientOcean` → `loopMode=Loop`, 走 `SFXLoopManager`

1. **搬运**：将 staging 全目录复制到 `Assets/Arts/Audios/SFX/`（BGM 放 `Assets/Arts/Audios/` 根或 `Tracks/`）
2. **Unity Refresh**：MCP `refresh_unity`，确认无 import 错误
3. **AMP 资产生成**：对每个 clip 创建 `SFXObject` asset 于 `Assets/Arts/Audios/AMP/SFX/{AudioKey}.asset`；BGM 创建 `MusicTrack` 于 `AMP/Tracks/`

6. **验证**：Play Mode 中触发各系统事件，Console 无 missing cue 警告

**Builder 快捷路径**：可扩展 `GameAudioCueDefaults.ClipFileMap` 后运行菜单 `GameAudioCueDatabaseBuilder` 批量生成。
