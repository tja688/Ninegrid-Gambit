## 一、设计决策摘要

### 1.1 交互范式变更

| 维度 | V0.2 原型 | V0.3 目标 |
|------|-----------|-----------|
| 道具使用手势 | 点击 / 粗粒度释放区 | **拖拽 → 指向反馈 → 松手 Confirm / 空白 Return** |
| 飞刀等指向卡 | 场地进入 KnifeTargeting（规划） | **ItemTargetingSession + Board TargetingAssist** |
| 内核契约 | `UseItemCommand(itemUid)` 为主 | **`UseItemCommand(itemUid, selectedCardUids?, selectedOption?)` 一次成型** |
| 内核改动 | — | **无**（表现层收集 payload，Confirm 才发 Command） |

### 1.2 核心原则（不可破）

1. **本地 vs 回放**：Drag / 高亮 / Selected 预览 = LocalFeedback；Confirm 后才 `UseItemCommand`；`ItemUsed` 后走泳道 C `ItemUsePerformance`。
2. **盲目乐观**：UI 可灰显非法目标作提示，但**不挡松手**；非法 Confirm 由表现层拦截（不发 Command），内核 `ActionRejected` 作兜底。
3. **防白丢卡**：内核在 `UseItem` 后会消耗道具，即使 `SelectedCards` 解析为空。表现层 **空白/非法松手必须 Return，绝不发 Command**。
4. **输入锁**：`IsInputLocked` 时 Session `Cancel()`，道具回手，场地 Assist 还原；观演期拒绝一切指针交互（含 Hover）。

## 二、架构组件

### 2.1 三层分工

```text
ItemCardInteractionFsm     手势主人：Idle → Hover → Drag → Confirm | Return
        │
        ▼ BeginDrag / UpdatePointer / TryConfirm / Cancel
ItemTargetingSession       协调器（非第三套手势 FSM）
        │
        ├── ItemUseProfileResolver   从 defId / effect JSON 推导 profile
        ├── ViewRegistry             CardUid → 演员、合法目标集
        └── BoardInteractionFsm      TargetingAssist 子态（Normal 抑制）
```

### 2.2 ItemUseProfile（表现层数据结构）

```csharp
// 示意 — 落盘：NineGrid.Presentation/Interaction/ItemUseProfile.cs
enum ItemUseProfileMode
{
    ApplyZone,      // 无指向：炸弹、治疗、盾、宝箱 — 拖入释放区即可
    SingleTarget,   // 单卡指向：飞刀、火球、破甲锤…
    MultiPick,      // 多选：交换卡（释放区 + 点选两张）
    OptionOverlay,  // 选项：stat_boost（Confirm 前/后弹 Attack/Armor/Hp）
}

class ItemUseProfile
{
    ItemUseProfileMode Mode;
    CardKind AllowedKind;       // Monster / Unknown / …
    int RequiredCount;          // 1 或 2
    bool ExcludeElite;
    bool ExcludeBoss;
    string[] OptionIds;         // stat_boost: Attack, Armor, Hp
}
```

**解析来源（V0.3）**：`ItemUseProfileResolver.Resolve(defId, effectJson?)`  
首版可硬编码 + 抄 `RandomAgent`（`Assets/Scripts/NineGrid.Core.Tests/Simulation/RandomAgent.cs`），后续可扫 `effects.json` 的 `SelectedCards` / `SelectedOption` / `AllMonsters` / `Player` target atom。

### 2.3 ItemTargetingSession API

```csharp
// 示意 — 落盘：NineGrid.Presentation/Interaction/ItemTargetingSession.cs
interface IItemTargetingSession
{
    bool IsActive { get; }
    ItemUseProfile ActiveProfile { get; }

    void Start(int itemUid, ItemUseProfile profile);
    void UpdatePointer(Vector3 worldPosition);
    bool TryConfirm(out int itemUid, out int[] selectedCardUids, out string selectedOption);
    void Cancel();

    event Action<IReadOnlyList<int>> EligibleTargetsChanged;
    event Action<int?> FocusTargetChanged;
}
```

**职责边界**：

- 不处理 press / drag 阈值（归 `ItemCardInteractionFsm`）
- 每帧解析指针下 `cardUid`，通知 Board Assist 切换 `Eligible → TargetHover → TargetSelected`
- `MultiPick` 模式：释放区落点后进入点选子阶段，收集满 `RequiredCount` 才允许 Confirm

## 三、FSM 状态图（V0.3）

### 3.1 ItemCardInteractionFsm

```text
Idle ──enter──► Hover ──drag──► Drag ──┬── profile+合法 ──► Confirm ──► UseItemCommand
  ▲               │                   ├── 空白/非法 ──► Return ──► Idle
  │               │                   └── Watching ──► Cancel Session
  │               └── ItemCardInteractPerformance
  └────────────────────────────────────────────────────────────────────────────
```

**Confirm 分支（按 Profile）**：

| Mode | 松手条件 | Command |
|------|----------|---------|
| ApplyZone | 指针在 `applyZoneCollider` 内 | `UseItem(uid)` |
| SingleTarget | 指针在合法目标卡上 | `UseItem(uid, [targetUid])` |
| MultiPick | 已点满 N 张（swap=2） | `UseItem(uid, [a,b])` |
| OptionOverlay | 释放区 + 已选 option | `UseItem(uid, null, "Attack")` |

**已落地文件**：`Assets/Scripts/NineGrid.Presentation/FSM/ItemCardInteractionFsm.cs`  
**待改**：接 Session、`UseItemCommand` 三参数、按 profile 分支 Confirm/Return。

### 3.2 BoardInteractionFsm（待落地）

```text
【Normal 子态 — Session 未激活】
Idle → Hover → Selected → (Hold) → Cmd(Attack / Pickup / ClickEmpty)

【TargetingAssist 子态 — Session 激活，Normal 抑制】
每张场地卡代理：Inert → Eligible → TargetHover → TargetSelected
  - 不发 Attack/Pickup/ClickEmpty
  - 仅本地反馈；目标由 Item FSM Confirm 时写入 Command
```

**与旧 V0.2 差异**：删除独立 `KnifeTargeting` 节点；飞刀 = `SingleTarget + Monster` 的一种 profile。

### 3.3 SelectionOverlayMode（不变）

- 仅服务内核 `PendingChoiceKind`（奖励三选一、房间选择）
- **不包含**道具棋盘指向
- 宝箱卡：`UseItem` → `RewardOffered` → overlay 走 `SelectRewardCommand`（第二条 Command 链）

## 六、时序（解锁态 · 单目标道具）

```text
1. 用户 Drag 起手
   → ItemFsm: Hover→Drag
   → Session.Start(uid, profile)
   → ProfileResolver.Resolve(defId)
   → BoardFsm: Normal 抑制, Assist 启动
   → CardTargetEligiblePerformance.PlayEligible(...)

2. 用户移动指针
   → Session.UpdatePointer(world)
   → Assist: TargetHover / TargetSelected 切换
   → ItemCardInteractPerformance.UpdateDrag(..., hasValidTarget)

3a. 合法目标上松手
   → Session.TryConfirm → [targetUid]
   → ItemFsm: Confirm → PlayConfirm → Send UseItemCommand(uid, [target])
   → Session.Cancel, Board Assist 还原
   → 输入锁 → ItemUsePerformance 回放

3b. 空白松手
   → Session.Cancel
   → ItemFsm: Return → PlayReturn
   → 不发 Command
```
