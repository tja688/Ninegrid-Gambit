# 多层级代理约束收敛驱动控制 · 范式设计

> 状态：设计定稿（待实现） · 作者：策划/主程 grill 对齐产出 · 日期：2026-07-15
> 目标域：局内战斗卡牌位置控制（场地变化 + 手牌/卡组布局 + 表演编排）
> 本文替代当前"世界空间竞争写入 + 间接完成判定"范式，根治其位置控制类 bug。

## 问题陈述（Problem Statement）

当前局内战斗的卡牌位置控制 bug 频出，根因不是某个具体缺陷，而是范式本身：

- **卡牌活在世界空间，靠竞争写入同一个 `transform.position` 移动。** 补牌飞行（drain/explore）、大盘旋转 hop、攻击 lunge、换位等多个异步流程各自直接写同一张卡的世界坐标，彼此用 `KillMotion` 抢占。
- **"完成"靠间接条件判定。** 到达阈值 + 预算耗尽软着陆 + 取消令牌三件套拼凑出"就位"，没有一个必然可观测的完成事件。
- **跨流程交接靠握手。** `TryReleaseFlightForHop`、替身 `GroundSlotDealDecoyTracker` 追坐标这类"暂停/恢复/坐标交接"逻辑，是时序相关、概率性、极难复现的 bug 温床。

后果：卡牌闪烁、跳变、卡住、穿模、"演独角戏"（一方到位另一方还在半路），且这类 bug 依赖时序，难查难复现。

需要一套新范式，同时守住两条**不可让的验收铁律**：

- **铁律1（必达就位）**：涉及复杂编排的表演，其收束时间必须绝对可预设、可计算、可动态分配预算；到承诺时刻必然精确就位，误差不可超过 0.2s，否则表演崩溃。
- **铁律2（丝滑无跳变）**：任何位置控制不得出现强制对齐/瞬移/跳表；全程曲线、速度连续、优雅。

## 解决方案（Solution）

把"世界空间竞争写入 + 间接完成判定"替换为**多层级局部空间约束收敛**：

- 每张卡自带一条**固定深度、永不换父**的变换塔（Transform 嵌套）。世界位置 = 各层 local 叠加自动合成。不同语义的运动（格位移动 vs 特效位移）落在不同层，物理隔离，永不互相抢写。
- 每一层的 local 目标用**带速度连续的五次多项式轨迹**收敛：从"当前 local 位置 + 当前 local 速度"出发，在 `t = sourceTime` **解析地精确命中**目标（位置到位、末速度归零）。到点必达（满足铁律1），中途重定向时以当前位置+速度重解新曲线，C1 连续（满足铁律2）。
- "系统/表演器"不再 `new` 物理父节点抓卡，而是退化为**逻辑编排大脑**：计算汇聚点、算长尾预算、向参与卡的某一层下发（目标 local + sourceTime）指令、做优先级仲裁。
- 跨对象同步（"A 打 B 时两者必须同时就位"）由**全局节拍栅格 + 就位栅栏**保证。
- "谁能驱动谁"的仲裁由**租约（lease）机制**决定：同步表演独占（卡, 层, 时间窗），异步表演无租约、可被后发先至、可被同步租约带速度征用。

一句话本质：**局部空间嵌套（沿用 AE 空节点思维）+ 固定不长的塔（去 SetParent 换父 bug）+ 每层带速度精确到点的五次曲线（同时满足两条铁律）+ 系统当大脑而非手 + 租约仲裁并发。**

### 数学依据

设 B 父约束 A、C 父约束 (B-A) 系统。C 保证 A 必然与 C 重叠，当且仅当：B 使 `A−B→0`，C 使 `Φ(A,B)−C→0`，`Φ(x,x)=x`，且 C 的移动可追踪/可补偿/足够慢。本质是"内部自由度被 B 消除，整体平移自由度被 C 消除"，最终 `A=B=C`。有限层级可严格归纳——这正对应"每卡固定深度父链"（A2），动态换父会破坏归纳前提，故被否决。

## 用户故事（User Stories）

1. 作为玩家，我希望卡牌在补牌、旋转、换位、攻击时全程丝滑无跳变，以便获得优雅的视觉体验。
2. 作为玩家，我希望"A 打 B"这类战斗表演中双方精确同时就位，不出现一方演独角戏、另一方在空中陪演。
3. 作为玩家，我希望大幅度位移的卡牌飞越盘面时压在最上层、不穿模，到达时干净落位。
4. 作为策划，我希望能为每个表演预设、动态计算其收束时间（源时间/预算），并按前置长尾链分配下游预算。
5. 作为策划，我希望把"两卡融合"这类多卡协同表演，通过统一编排大脑算好各卡就位预算，让它们精确撞在一起。
6. 作为策划，我希望为每次表演请求声明"同步/异步"，同一位移能力在不同场景可分别表现为强承诺或随手打断。
7. 作为策划，我希望怪物多跳（三跳、四跳）可选择"逐跳可见（串行多 beat）"或"只看终点（合并单 beat）"两种投影策略。
8. 作为程序，我希望格位移动与特效位移落在不同层、永不互相 KillMotion 抢写，从根上消除竞争写入 bug。
9. 作为程序，我希望卡牌永不换父，"换格"退化为改 local 目标重收敛，从根上消除 SetParent 交接握手 bug。
10. 作为程序，我希望"完成"是一个必然可观测的局部事件（五次曲线到点或栅栏对齐），不再依赖到达阈值/预算/取消令牌拼凑判定。
11. 作为程序，我希望对象跨域迁移（牌库→手牌→场上→战斗→回库）时带速度连续交接，边界不破铁律2。
12. 作为程序，我希望净土场景（纯手牌/纯牌库/纯战斗）用自成黑盒的简单驱动器，不背负复杂域的重武器。
13. 作为程序，我希望同步表演能独占某卡某层一段时间窗（租约），期间拒绝异步写入与其他租约。
14. 作为程序，我希望异步表演可被同步表演随时带速度征用，征用瞬间 C1 连续、无跳变。
15. 作为程序，当两个同步表演争抢同一 (卡,层,时间窗) 时，我希望得到明确诊断报警而非无声穿帮。
16. 作为程序，当"必达承诺"的收敛被后发先至抢占、承诺无法兑现时，我希望立刻收到诊断日志，而非事后对着穿帮画面猜。
17. 作为程序，我希望排序/可见性作为离散事件通道特事特办，其切换时刻挂靠在收敛完成事件上，使跳变发生在位置已就位的瞬间而不可见。
18. 作为程序，我希望收敛基元写成可作用于任意标量维度的通用形式，将来把缩放/透明度接入收敛体系时只是多实例化一个通道。
19. 作为程序，我希望初版用变长帧时间驱动收敛（0.2s 容差足够），并保留升级到固定步长逻辑帧的门。
20. 作为程序，我希望墙角（预算 vs 距离不可调和）时默认用"冲刺"策略（纯五次基线，零额外代码），并保留将来挂"过冲回勾"策略的增量门。
21. 作为程序，我希望串行队列/StepProjector 作为上游编排层，仅通过"带 commitment 标签的有序 Step"这一唯一契约与执行层交互。
22. 作为程序，我希望每层空节点固定命名并提供 Editor Gizmo 可视化各层 local 偏移，使问题一眼可查。

## 实现决策（Implementation Decisions）

### 一、地基：固定层级塔（A2）

- **决策 A（固定层级 vs 动态嵌套栈）**：选**固定层级**。语义分层编译期定死、父子关系永不变，卡永远是最内层叶子。否决动态嵌套栈（每请求 `new` proxy + `SetParent` 插拆链）——其换父拓扑竞争是当前握手 bug 的同构体。
- **决策 A2（共享框架 vs 每卡私有塔）**：选**每卡私有塔、永不换父**。"格位"退化为一个目标 local 坐标，不是父节点；换格 = 改收敛目标重收敛，零 `SetParent`。
- **补刚体感**：整环旋转等需要"整齐划一"的动作，让所有环上卡对应层用**同一条时间曲线、同一 startTime、同一 sourceTime** 收敛 ⇒ 每帧进度 `u` 相等 ⇒ 视觉刚体同步，底层仍是 N 条独立、无共享父的收敛。
- **性能**：每卡多挂 3~4 个空 Transform，量级 ~250 节点、深度 4~5，脏标记传播 O(深度)，无感。
- **可读性**：每层空节点固定命名（如 `_L1_BoardFrame`/`_L2_SlotFrame`），提供 Editor Gizmo 画出各层 local 偏移。

### 二、塔的分层（复杂域）

从外到内固定五层，位置 = 各层 local 叠加：

- `L0 CardRoot`：世界锚，永不动，uid 挂此。
- `L1 BoardFrame`：整盘运动（全局抖屏/盘面位移），平时恒等、留空。
- `L2 SlotFrame`：**格位重定位层**——旋转/换格/hop/drain/explore 全在此收敛。复杂域主战场，就位栅栏只盯此层。
- `L3 EffectFrame`：**特效位移层**——lunge/受击/击退/融合牵引，末态回零。
- `L4 CardVisual`：叶子 sprite 本体，缩放/翻牌/闪烁在此。

- **L2 与 L3 物理隔离**：格位收敛写 `L2.localPosition`，特效冲刺写 `L3.localPosition`，两个不同 Transform，永不互相 KillMotion；世界位置自动叠加。这是消灭"lunge 与 hop 抢同一 `root.position`"的根本手段。
- **预留插层原则**：层数与语义编译期定死，层可留空不驱动，但**不可事后插队**（插层需重挂所有卡的塔）。复合运动（如"绕另一张卡公转"）若将来需要，须现在预判是否在 L2/L3 间留层。

### 三、收敛基元：带速度连续的五次多项式

- **决策（基元选型）**：选**有限时长五次多项式轨迹（Hermite/最小 jerk）**。否决弹簧/SmoothDamp（渐近、无有限完成时刻，破铁律1）；否决硬截止快照（跳变，破铁律2）；否决 OutCubic 重定向（目标变时速度跳变，破铁律2）。
- **形态**：给定 `p0, v0, p1, v1=0, T`，解析唯一的五次曲线，`τ=1`（t=源时间）时位置精确命中、末速度归零。**到点必达是解析等式，不靠 epsilon、不靠快照。**
- **同层抢占/重定向（后发先至）**：新指令来时，用**卡当前 local 位置 + 当前速度**作为新曲线 `p0,v0`，重解到新 sourceTime。速度连续（C1）。**"硬取代"只取代目标(target+sourceTime)，绝不取代当前位置与速度。**
- **在静止 local 帧内收敛**：父层运动被父层自身消化，子层的 local 目标是静止的 ⇒ 五次曲线全程平滑，丝滑不依赖"追移动目标"。
- **通用维度**：基元写成可作用于任意标量维度，将来缩放/透明度接入只是多实例化一个通道。
- **墙角策略（预算 vs 距离不可调和）**：初版用 **X 冲刺**（纯五次基线，零额外代码，中段速度尖峰）。**Y 过冲回勾**作为纯增量的 `ICornerReshapePolicy` 叶子策略，注入点唯一、几十行、可回退、不锁死；X/Y 上层架构完全一致。

### 四、协调：全局节拍栅格 + 就位栅栏

- **权威调度时钟**：当前不存在（`DiagBeatClock` 只是日志计数）。需新建驱动表演的权威调度时钟。
- **决策（跨塔协调）**：选**全局节拍栅格 + 就位栅栏**，并预留依赖 DAG 接口（长尾在 DAG 上向下游传播预算）。指令挂到 beat 上，同 beat 共享 `sourceTime`；"必须全员就位"时刻是一道 barrier，调度器保证栅栏 beat 上所有收敛 sourceTime ≤ 栅栏时刻。铁律1 由"五次到点 + 栅栏对齐"共同保证，不靠观测、不靠快照。
- **决策（时钟步进）**：初版用**变长帧时间**（`Time.deltaTime`，sourceTime 用墙钟秒）。0.2s 容差远大于掉帧抖动（几十 ms），固定步长逻辑帧为过度工程。保留升级门：将来换 dt 来源即可，五次基元不改。

### 五、分域治理 + 域边界交接

- **决策（分域）**：承认"没有银弹"。**净土域**（纯手牌布局、纯牌库布局、纯战斗 lunge——域内不会被第二系统并发重定向）用自成黑盒的简单驱动器，不挂调度器、不进栅栏。**复杂域**（场上卡）用栅格 + 栅栏重武器。净土域是"塔退化到 1 层且不接受外部重定向"的特例，与复杂域共用同一 `ConvergenceCurve` 基元，只是使用姿势不同。
- **决策（域边界交接协议）**：定义统一交接结构 `HandoffState { localPosition, localVelocity }` 与接口 `Evict()→HandoffState` / `Admit(HandoffState)`，**全域一致（净土也不例外）**——这是唯一需要全域一致的接口。
- **先 C 后 B（平行线，非岔路）**：
  - **C 阶段**：全域冷启动冷结束，`Evict()` 的 `localVelocity` **恒填 0**（这是现状真相，非偷懒）。行为 = 今日现状，零新 bug。
  - **B 阶段**：某边界要丝滑打断时，**只改那一个域的 `Evict()`** 吐真实速度。接口签名一字不改。
  - **关键前提税**：交接口从第一天就带 `localVelocity` 字段。付了 = 平行线（逐边界升级）；不付（做成只带 position）= 岔路（届时改所有域接口）。
- **四象限交接裁决**见下节租约。

### 六、系统 = 逻辑编排大脑（非物理父节点）

- **决策**：表演器**不 `new` 父对象、不 `SetParent` 抓卡**。它是逻辑编排器：计算世界汇聚点、算长尾预算、向参与卡的某层下发（目标 local + sourceTime）指令、做优先级仲裁。
- "父子约束收敛"照常发生，但"父"是卡自己身上的固定层，不是表演器临时造的物理节点。SetParent 彻底消失。
- 用户原始"层号（7/12/99）"正名：那不是 Transform 深度，是**控制优先级 / 租约身份**（与"空间合成深度"是正交的两个维度，此前被压成一个词"层"）。
- **融合示例流程**（无 SetParent、无握手）：融合表演器算中点 P → 检测 B 正在 L3 播长尾 → 给 A 的 L3 下发"到 P，sourceTime 长"、给 B 下发"长尾结束后快速消费到 P" → A/B 各在自身 L3 用五次曲线收敛到同一世界点（各自反算 local 目标）→ 共享到达时刻 ⇒ 同时到点撞一起 → 融合表演器释放控制权（非 SetParent 放回）→ 回库表演器接管 L3 下发"向上飞出"，速度连续交出、无跳变。

### 七、并发仲裁：租约（Lease）机制

- **核心洞察（三角降维）**：`输入锁自由 / 必达就位 / 后发先至硬取代` 三者只能同时要两个，但这是 **per-表演** 的，不是全局单选。每个表演自己声明放弃哪一个：
  - **同步表演**：要「必达就位」+「锁」，放弃「输入锁自由」。终点可见、预算死、未完成不谈下一步。
  - **异步表演**：要「输入锁自由」+「后发先至」，放弃「必达就位承诺」。可随手打断（如旋转中途被换位拉走，无人在意中间态）。
- **机制**：同步表演 = 向调度器申请 **lease**，独占某卡某层一段时间窗，期间拒绝一切异步写入与其他租约；到期（承诺兑现）释放。异步表演 = 无租约，尽力写，可被后发先至或被租约征用。
- **四象限裁决**：
  - 异步 vs 异步 → 后发先至，随便换。
  - 同步(持承诺) 被 异步 抢 → **异步被拒**（锁挡住）。
  - 异步(无承诺) 被 同步 抢 → **同步直接征用**，靠交接 B 带速度 C1 接管，无跳变。（"输入锁自由"的最强形态）
  - 同步 vs 同步 争同一 (卡,层,时间窗) → **设计错误，报警**（纪律 B）。
- **决策（守锁策略）**：选**纪律 B（承诺标记 + 抢占报警）**。给参与栅栏的必达收敛打 `committed` 标记；后发先至抢占带 `committed` 且承诺未兑现的目标时，**不阻止抢占（保住自由与简单），但立刻抛诊断日志/断言**。把设计纪律从脑子里搬进代码变成可观测护栏。罕见场景可局部升级为纪律 C（承诺即锁、抢占排队）。
- **决策（租约粒度）**：**按层独占，非整卡**。融合租约锁 L2 期间，L3 受击闪避仍可异步演（不同层物理隔离、世界位置自动叠加）。
- **决策（同步/异步标签归属）**：**贴在每次表演请求上，表演器给默认值**（`Play` 带 `commitment: Sync/Async`）。同一位移能力融合时同步、随手滑动时异步，不绑死在表演器类型。

### 八、可见性 / 排序：离散事件通道

- **本质矛盾**：`sortingOrder` 是整数阶梯，物理上无法平滑插值——它是唯一从根本上无法遵守铁律2 的通道。
- **决策（排序定位）**：选**方案 A**——排序是离散事件通道，不进收敛体系，但其**切换时刻挂靠在 L2 收敛的 sourceTime/完成事件上**：收敛开始抬到飞行层，完成事件触发时掉回目标排序。因位置此刻已精确就位，排序跳变发生在卡静止贴合目标位的瞬间，肉眼几乎不可察。
- **决策（飞行排序粒度）**：初版用**全局飞行层**——"动起来就必然飞"，任何大幅位移中的卡统一抬到远高于盘面的飞行序（多卡同飞用 uid/出发序微偏移）。领域系统内有自己的显示规则。否决逐对象动态比较（初版不值得）。

### 九、串行队列 / StepProjector：上游编排层

- **生态位**：串行队列是**编排层**，坐在调度器之上，是执行层（塔/曲线/交接/栅栏/租约）的**意图供给者**，不是执行层的延伸。
- **唯一契约**：输出**带 `commitment` 标签的有序 `Step[]`**。它完全不需知道塔、曲线、租约的存在。
- **多跳投影策略**（"某表演 A 场景异步、B 场景同步"的物理归属地）：
  - **策略 S（串行多 beat，多跳可见）**：N 跳投影成 N 个 Step，每个是一个同步租约，逐跳精确落格、看得清。用于需让玩家看清跳数的机能（如虚空牌组怪物多跳的威慑/可读性）。
  - **策略 C（合并单 beat，只看终点）**：N 跳投影成 1 个 Step，只给终点，中间格不承诺，执行层作"换目标的异步"连续划过。用于中间态不重要、要最丝滑时。
- 现有 `BoardPresentationStepProjector` 已在切 Step，新范式只需**多贴 Sync/Async 标签 + 多一个多跳 S/C 投影选择**，是小增量、非重写。



## 测试决策（Testing Decisions）

好的测试只验外部行为、不锁实现细节。本范式的可验证外部行为集中在**数学基元**和**调度语义**，它们是纯逻辑、可脱离 Unity 渲染在 EditMode 下测。

- **五次曲线基元（核心，必测）**：
  - 到点必达：给定 `p0,v0,p1,T`，在 `t=T` 时 `p==p1`（误差 < eps）、末速度 ≈ 0。
  - C1 连续重定向：收敛中途换目标，采样"换目标前一帧速度"与"换目标后一帧速度"连续（无阶跃）。
  - 墙角冲刺（X）：极小 T + 极大距离时，曲线仍在 `t=T` 精确到点，不 NaN、不越界失稳。
  - 通用维度：同一基元作用于标量/2D/3D 行为一致。
  - 先验参考：`Assets/Scripts/Cards/Tests/DealFlightMathTests.cs`（纯数学基元的 EditMode 测法范式）。
- **栅栏 / 调度语义（必测）**：同一栅栏 beat 上多条收敛，其 sourceTime 均 ≤ 栅栏时刻；到栅栏时刻全部报告已完成。
- **租约仲裁（必测，纯逻辑）**：四象限裁决——异步被后发先至替换；同步持锁拒绝异步；异步被同步征用产出带速度的 HandoffState；同步撞同步触发报警回调。这些不依赖 Transform，可用假的时钟 + 假的通道对象测。
  - 先验参考：`Assets/Scripts/Cards/Tests/ShuffleIntoDeckPresentationScannerTests.cs`、`BoardPresentationStepProjectorTests.cs`（纯投影/扫描逻辑的测法）。
- **StepProjector 投影策略（必测）**：多跳输入分别在 S/C 策略下投影出 N 个 / 1 个 Step，且 commitment 标签正确。扩展现有 `BoardPresentationStepProjectorTests`。
- **交接协议（必测）**：`Evict()→Admit()` 往返；C 阶段速度恒 0、B 阶段速度透传，接手方初速正确。
- **不建议做的测试**：不测"看起来丝滑不丝滑"（主观、属演出调校，靠 PerfLog + 人眼验收，见 battlelog-analysis skill）；不测具体 Transform 层的世界坐标数值（属实现细节）。

## 范围外（Out of Scope）

- **净土域内部驱动器的重写**：手牌/牌库/纯战斗黑盒沿用现状，仅补 `Evict/Admit` 交接口（C 阶段填 0）。不在本范式初版重做其内部布局逻辑。
- **缩放 / 旋转 / 透明度进入收敛体系**：初版仅**位移**纳入收敛 + 栅栏（通道 A）。非位移通道暂留现状 tween 黑盒。基元预留通用维度门，将来增量接入。
- **固定步长逻辑帧时钟**：初版变长帧足够（0.2s 容差），不建。
- **墙角过冲回勾（Y 策略）**：初版仅冲刺 X，Y 作为未来增量。
- **依赖 DAG 完整实现**：初版栅栏 + 节拍栅格即可，仅预留 DAG 接口，不全建。
- **纪律 C（承诺即锁排队）**：初版用纪律 B（报警）；仅罕见冲突场景按需局部升级。
- **逐对象动态飞行排序比较**：初版用全局飞行层。

## 补充说明（Further Notes）

- **本范式最大的认知转变**：真正的代价不在架构（架构一次建成、处处留升级门），而在两件长期、增量、由内容诉求驱动的功夫上——**逐边界磨演出**（让速度连续在每个具体边界真的好看）和**逐表演贴标签**（Sync/Async、多跳 S/C）。"丝滑是磨出来的，不是选出来的"。
- **一路留门总览**（每个决策都是平行线而非岔路，可后续增量升级，不推翻架构）：
  - 墙角 X → Y：换叶子策略函数。
  - 交接 C → B：改单个域 Evict 吐真速度（前提：接口第一天带速度字段）。
  - 变长帧 → 固定步长：换 dt 来源。
  - 位移通道 → 全通道收敛：多实例化通用基元。
  - 纪律 B → C：局部承诺加排队。
  - 栅栏 → 依赖 DAG：预留接口生长。
- **建议实现起点**：最小可跑核 = **五次曲线基元 + 固定塔（L0~L4）**。先让一张卡在固定塔的 L2 上用五次曲线丝滑精确落格，再逐步接入栅栏、租约、交接、StepProjector 标签。
- **对齐关系**：与现有诊断体系（BattleLog/CoreLog/PerfLog，见 `.cursor/skills/table-nine-battlelog-analysis/`）契合——纪律 B 报警、就位承诺时刻、beat 对齐等都应写入诊断 sink，延续"诊断先行"哲学。
- **当前范式的病灶存档**（被本范式取代的对象）：`GroundSlotDealFlightCoordinator`（世界空间竞争 + 握手）、`GroundSlotDealDecoyTracker`（替身追坐标 = 外部观测）、`CardDeckTween.ChaseAnchorAsync/TrackQuadraticBezierAnchorAsync`（指数追踪 + 预算软着陆间接判定）、`TryReleaseFlightForHop`（暂停/恢复/坐标交接握手）。
