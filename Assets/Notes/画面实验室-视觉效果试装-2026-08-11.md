# 画面实验室：视觉效果试装（2026-08-11）

> 过程笔记（非权威）。程序集登记见 `docs/code-map/README.md` 程序集一览。
> 目标：提供一批可**一键装配 / 一键还原**的程序化画面强化，供人对比体验后挑选实装；实装由后续 AI 另票落地。

## 怎么玩（热键速查）

进 Play 后（Editor / Development Build 自动生效，正式包不含）：

| 键 | 作用 |
|----|------|
| **F9** | 一键装配全套 ⇄ 一键还原原版画面（总开关） |
| **F10** | 循环全屏 Look：原版 → CRT 显像管 → 烛光酒馆 → 辉光绽放 → 深渊地牢 → 老式胶片 |
| **F11** | 循环全屏 Look 强度：100% → 70% → 40% |
| **F6** | 机关卡光环环绕 开/关 |
| **F7** | 氛围浮尘与余烬粒子 开/关 |
| **F8** | 卡面流光 开/关 |

装配后屏幕右上角有状态叠层；未装配时开场提示 12 秒后消失。F1（伤害日志）、F12（作弊面板）不受影响。

## 效果清单与设计意图

### 全屏 Look（5 个并行变体，F10 对比）

实现：`NineGridFxLabFeature`（Renderer2D 第三个 Feature，事件 600，排在 TableNine Selective Look 之后——扫描线会跟着 CRT 曲面弯曲，风味正确）。着色器 `Assets/Arts/VisualProfiles/NineGridFxLabLooks.shader`（9 Pass）。所有参数在 `NineGridFxLabFeature.ApplyLookParams` 一处集中调。

1. **CRT 显像管**：桶形曲面 + 圆角遮幅 + 径向色散 + 竖向 RGB 荫罩 + 晕影 + 亮度闪烁/滚动亮带。像素画 + 显像管是天配。
2. **烛光酒馆**：暖色白平衡 + 暗部琥珀提升 + S 曲线 + 暖棕晕影（边缘乘暖色而非压黑）+ 多频正弦烛光呼吸。贴合牌桌地牢酒馆的题材气质，最耐看的一档。
3. **辉光绽放**：半分辨率软阈值 Bloom（预滤 → 高斯 H/V → 加色合成）。白字、火焰特效、金币、余烬粒子（HDR 色）会自然泛光。
4. **深渊地牢**：去饱和 + 冷影调 + 对比提升 + 动态胶片颗粒（暗部更重）+ 重晕影。压抑向的 roguelike 氛围。
5. **老式胶片**：干褐褪色 + 12fps 门抖 + 间歇竖向划痕 + 尘斑 + 帧闪烁 + 颗粒。回忆/剧场感。

### 世界级模块

- **机关卡光环环绕（F6）**：`FxLabTrapHalo` 定期扫描场上 `CardPresentationKind.Trap`，卡面根下挂「呼吸底环（组内 order -60，卡后）+ 轨道火花粒子（order 55，卡前，沿卡缘公转）」。颜色按 defId：离开=翠绿、烈焰=橙红、治疗泉=水青、复活石=紫、其余=暖金。背面朝下 / 死亡 / 离场自动摘除。
- **氛围浮尘与余烬（F7）**：`FxLabAmbientDust` 在主相机视野挂两套 ParticleSystem——半透明暖白浮尘（慢漂 + noise）与稀疏加色余烬（HDR 橙，上升）。配合辉光 Look 余烬会发光。
- **卡面流光（F8）**：`FxLabCardFoil` 给手牌/场上卡的「卡框」「主图标」精灵各挂一层同精灵加色覆盖层，`NineGridFxLabFoil.shader` 做斜向彩虹流光扫过 + 32PPU 像素闪点；顶点走与 `TableNineSpriteHitFlash` 同一套几何 Pixel Snap（`TableNinePixelSnapVertex.hlsl`），运动中不与底精灵错位；每卡相位随机错开。

贴图（软圆斑/四芒星/光环）与材质全部运行时程序化生成（`FxLabRuntimeAssets`），零新增美术资产。

## 装配与还原语义

- **F9 关**：渲染 Feature 不入队任何 Pass（零 GPU 开销），三个模块 OnDisable 拆净所有生成物——画面即原汁原味。
- **彻底移除（交给实装 AI 或人工）**：
  1. 菜单 `NineGrid/画面实验室/移除全屏渲染特性 (还原 Renderer2D)`；
  2. 删 `Assets/Scripts/VisualFxLab/`；
  3. 删 `Assets/Arts/VisualProfiles/NineGridFxLab*.shader`；
  4. 撤掉 `docs/code-map/README.md` 程序集一览的对应行。
- Renderer2D 上的 Feature 是仓库预装的（`Assets/Settings/Renderer2D.asset` 第三项 `NineGrid FxLab Looks`）；误删后可经菜单 `安装全屏渲染特性` 重装。

## 实装挑选备注（给后续 AI）

- 全屏 Look 参数集中在 `NineGridFxLabFeature.ApplyLookParams`，逐 Look 常量 × `LookStrength`；要实装某个 Look 时把它抽成正式 Feature/设置并砍掉热键即可。
- 卡面流光若实装，建议改为按稀有度/卡种选择性挂载（当前 showcase 为全卡挂载、卡框 0.55 / 主图标 0.32 强度），并从轮询扫描改为接入卡生命周期事件。
- 机关光环若实装，建议接 ADR-0040 的 Persistent Visual State（`owner+slot+state`）替代轮询扫描；颜色表挪进内容绑定。
- 粒子氛围的排序：浮尘 UI/260、余烬 Main/140、光环底环组内 -60、火花组内 55——实装时按「通层排序值」约定复核。
