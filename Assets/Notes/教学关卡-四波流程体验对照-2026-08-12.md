# 教学关卡：四波流程体验对照（过程笔记，非权威）

最后更新：2026-08-12。权威见 [ADR-0042](../../docs/adr/0042-tutorial-level-module.md) 与 `docs/code-map/presentation.md` `Tutorial/` 行。

## 入口

| 路径 | 行为 |
|------|------|
| 主菜单「开始游戏」→ 人物选择「出发」 | 存档无教学完成标记 → 自动先进教学，通关后**自动转正式开局**；有标记 → 直接正式开局 |
| 主菜单「教  学」按钮（开始游戏下方） | 任何时候可重进教学，完成后回主菜单 |
| 复位首次标记（Dev） | 删 `persistentDataPath/NineGridSaves/slot_tutorial_profile.es3`，或 eval `NineGrid.Flow.Tutorial.TutorialProgressStore.ResetCompleted()` |

教学战败：正常失败结算回主菜单，**不**记完成标记，下次开始游戏仍进教学。

## 第一波：基础互动（8 张教学机关）

铺场阅读序（格 1→9）：欢迎 / 发牌 / 旋转 / 攻击 / （你）/ 血量 / 安全 / 补牌 / 进阶。

- 预期：开局常规卡组入场表演，8 张机关按上述顺序铺满；点击相邻机关攻击（6 血、不反击），每次互动全场转一圈
- 击破第 1 张 → 补出「教学·补位」（看，补牌来了再破一张）+ 旋转
- 击破第 2 张 → **换波**：残余机关集体移除（清关同款退场），补发第二波 8 张（带发牌飞行动画）
- 不应发生：机关反击伤人；换波时能点卡（主线互斥应拒绝输入）

## 第二波：怪物机制（7 机关 + 小小莱姆）

阅读序：怪物出现 / 行动计数 / 每互动减一 / 归零开火 / 右键详情 / 击破调位 / 击破怪进下一课 / **怪物（格 9）**。

- 怪物：`monster.melee_3`（普通近战、行动计数 5、攻 1 血 4）
- 预期：怪物卡角显示行动倒计时，每次互动 −1；归零且你在其正交邻格时挨 1 点打；右键可开详情
- 机关**无限补位**：抽牌堆空了自动补「教学·机关（随便击破）」
- 击破怪物（+5 金）→ 换波
- 不应发生：怪物在范围外仍打到你；补位卡断供导致无从互动

## 第三波：道具使用（5 机关 + 飞刀 + 恢复药水 + 练习靶）

阅读序：道具出现 / 拾取 / 拖用 / 飞刀选目标 / 用完两件进下一课 / **飞刀（格 7）** / **药水（格 8）** / **怪物（格 9）**。

- 预期：点相邻道具卡入手牌；手牌拖到场地使用；飞刀需选定怪物（6 伤直接秒练习靶）；药水拖出直接喝（回 10）
- 防卡死：飞刀没用而全场无活怪 → 自动往抽牌堆顶补一只练习靶（击破一张机关就会补出）
- 两件道具**都用掉** → 换波（残余机关+怪清场）
- 不应发生：飞刀无目标可选卡死；只用一件就换波

## 第四波：清关与变卖（7 机关 + 离开机关）

阅读序：大门 / 变卖 / 结算 / 跑路 / 贪心 / 撤退 / 层主 / **离开机关（格 9）**。

- 离开机关：复用 `trap.leave`（门 / 魔免 / 离开，6 血只吃交战伤害）
- 预期：击破离开机关 → Core 正常清关（残余机关清场不兑金）→ 「教学完成！」提示 → 转正式开局或回主菜单
- 不应发生：击破普通教学机关触发清关；完成后再点开始游戏又进教学

## 内容清单

- 教学卡组 `deck.tutorial`：29 张 `trap.tutorial.*`（6 血 / 无攻 / rarity None / 无效果装配；图标待填充——`sprites.mainIcon` 全空，走模板兜底）
- 复用：`monster.melee_3`（教学怪 / 练习靶）、`help.throwing_knife`、`help.healing_potion`、`trap.leave`
- 卡面描述每张 ≤16 字；改文案直接改 `Assets/Arts/ContentVisual/cards/trap_tutorial_*.json`（记得同步 StreamingAssets 镜像）

## 已知取舍（体验后可调）

1. 换波用「清关清场」同款移除表演（不兑金、无赏金），没有专属换波特效/音效
2. 波间无大字幕（第 N 课提示靠卡面描述本身）；如需可加简要解释 Notice
3. 教学怪按正式数值参战：玩家战士初始属性足以碾压，但连续吃打仍可能战败（视为正常教学挫折）
4. 第一波补位卡也计入「击破两张」——玩家打掉补位卡同样推进换波
