## 3. 硬语义一览（实现必须遵守）

| 技能 | 语义 |
|------|------|
| **远程武器** | 玩家打该怪时，怪**不反击**；齐射仍按宿主远程模式 |
| **提速** | 本卡对玩家造成一次伤害 → 其他怪物 **倒计时 −1** |
| **神圣决斗** | 标记挂**玩家**（先玩家状态，注释预留日后 buff）；与持有者**玩家主动交战**后记下；之后玩家主动点**其他**怪开战 → 对玩家 2 伤；持有者**翻面或离场清标记**；怪齐射打玩家**不算**战斗 |
| **天涯若比邻** | 场上时，怪物技能的「是否相邻」判定**直接满足**；与战斗/射程无关 |
| **潜伏近战** | **仅正面**生效；每互动 5 且正交邻接 → **打一下**（强制按宿主攻击形式）→ **再翻面**；翻到背面后本技能失效，**等外部翻正**后才继续计互动次数。同卡跳杀：己方这次翻成背面时「处于正面」不成立 → **不叠跳杀刀** |
| **起来** | 使一张其他怪物卡双向 `[翻面]`（QT 随机即可）；玩家侧仍只能背→正 |
| **休养** | `[[翻面后]]` 若正面 → 攻+1、甲+2 |
| **刺客领袖** | 本卡**正面**时，怪物**打出到格**发射为背面；发射后不管；领袖不在场/非正面后新牌默认正面；已在场背面**不**自动翻回 |
| **逃避** | `[战斗后]` 仅在格 1/3/7/9 中有**非己卡牌**的格里随机 Swap；全无则不触发 |
| **死亡召唤** | 被移除时，**复活石（机关）** 打到**原槽**，抢在常规补牌前 |
| **死亡之主** | 他怪被移除时同上；**自己死不补**复活石 |
| **快递** | 每移动 **5** 次；正交邻格**道具卡** ↔ 战斗卡组一张怪物；道具卡 = 旧帮助卡口径，**不含**怪/机关 |
| **「相邻」**（快递/链接准备等未写正交时） | **一律正交** |
| **烈焰沸腾** | 每互动 5 次，烈焰造成伤害再 +1（叠层；默认可叠加） |
| **链接战术** | 常驻邻接光环攻 +1，离开消失（**非**每移叠层） |
| **历战** | 对齐 `bloodthirst` 语义 / 正式 id·显示名 |
| **斜角近战** | 距离 1 对角（权威已改，与现网一致） |
| **近战7** | 权威表漏普通近战；正式挂载应补；QT 测决斗时可带开火宿主 |

**内容依赖**：复活石 = 机关卡（`机关卡.md` / `机关技能.md`·复活亡者）；烈焰 = 既有机关/内容 id（仓内现多走 `help.flame`，接线时按机关权威对齐，勿把机关当道具清掉）。
