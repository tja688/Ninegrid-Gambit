# 弹道特效库：「谁打了谁」projectile 播放器与 8 个预设（2026-08-12）

> 过程笔记（非权威）。代码现状见 `docs/code-map/presentation.md`「程序化弹道播放器 projectile」段；长期契约见 [ADR-0040](../../docs/adr/0040-vfx-cue-binding-persistent-state-workbench.md)。
> **本文是给「表演编排接线 AI / 人」的交付说明书**：这套东西是什么、怎么发射、每个预设长什么样、怎么做变体、怎么把伤害反馈对齐到命中帧。

## 一、这批东西是什么（为什么做）

玩家反馈最多的问题：战斗里**看不清是谁打了谁**——伤害来源只有卡牌/遗物自身缩放一下，
伤害数字直接浮现在目标头上，中间没有任何「从 A 飞到 B」的视觉因果。

本次给 VFX 系统新增第四种播放器 **`projectile`**（前三种：`sprite-sheet` 素材翻页、
`gold-flight` 金币程序化、`particle` 程序化粒子），用**运行时程序化装配**的方式提供
「源 → 靶」的完整弹道演出，每条弹道 = 三段可见因果：

```
起手光（源位置，可选）→ 弹头飞行 + 粒子拖尾（清晰轨迹）→ 命中爆点（靶位置）
```

- **8 个弹道预设**：魔法飞弹 / 飞刀直射 / 火球 / 虚空法球 / 电光急蹿 / 骨刺三连 / 毒液抛射 / 金色流光。
- **零美术依赖**：弹头 Sprite 与拖尾贴图全部复用 particle 库的程序化贴图（柔光点/像素/星芒/圆环/碎片），
  加色发光走既有 `NineGrid/VFX/ParticleAdditive` shader；起手/命中爆点直接复用 particle 预设库的 27 个预设。
- **命中时刻回传**：每次发射经 `VfxCueResult.PresentationPlan` 拿到「首达/末达」秒数，
  编排侧可以把飘字、扣血、音效**精确对齐到弹道命中帧**（解决"数字先出、弹还在飞"的错位）。

**技术选型说明**：与 particle 库同理——本项目是 URP 2D Renderer + Sorting Layer 排序的像素卡牌，
VFX Graph 不参与 2D 排序层也无法运行时组图；弹头用 SpriteRenderer（可控朝向/拉伸/变色），
拖尾用 Shuriken 的 `rateOverDistance` 世界空间发射（弹头飞过自动留下粒子轨迹，密度与速度无关），
完全落在 ADR-0040 播放器契约内。

## 二、怎么发射（给接线 AI / 人的操作手册）

### 已就位的 5 个 cue（声明 + 绑定齐全，发射即生效）

| Cue ID | 默认弹道 | 语义 |
|---|---|---|
| `vfx.projectile.attack` | `projectile.arrow_shot` 飞刀 | 攻击者 → 受击者的普攻轨迹 |
| `vfx.projectile.effect` | `projectile.magic_bolt` 魔法飞弹 | 「效果对某某造成伤害」通用默认 |
| `vfx.projectile.skill` | `projectile.fireball` 火球 | 怪物技能弹道 |
| `vfx.projectile.trap` | `projectile.spark_zip` 电光 | 机关弹道 |
| `vfx.projectile.relic` | `projectile.gleam_streak` 金色流光 | 遗物触发 → 目标 |

绑定在 `Assets/Resources/VFX/vfx_bindings.json`（`authoringStatus=aiDraft`，待人工调参确认）。

### 发射一行代码

```csharp
using NineGrid.Flow.Presentation;

// 源/靶世界坐标：用 PresentationOutputProjector.ResolveCardWorldPosition(uid)
// 或 ResolveBoardSlotWorldPosition(slot) 取快照。
var result = ProjectileVfxCues.PulseFromTo(
    ProjectileVfxCues.ResolveCueId(sourceDefId, cause),  // 按 trap./relic./skill. 前缀四类分诊；普攻直接用 Attack
    "EffectTriggerPulseBeatHandler.TryApply",             // 诊断来源
    sourceDefId,                                          // cardDefId（内容定向覆盖用）
    cause,                                                // skillId
    sourceWorldPosition,                                  // 源（谁打的）
    targetWorldPosition,                                  // 靶（打到谁）
    diagnosticUid);
```

内部即 `TriggerPulseHub.PulseVfx` + `VfxSpatialContext(源, targetPositionSnapshot: 靶)`，
护栏合规（业务禁直调 `IVfxSystem`，`VfxStructureGuardTests` 盯着）。

### 把伤害反馈对齐到命中帧（这套系统的核心价值）

```csharp
if (result.Outcome == VfxCueOutcome.Played && result.HasPresentationPlan)
{
    float hitDelay = result.PresentationPlan.FirstArrivalDelay; // 首发命中（秒）
    float allDone  = result.PresentationPlan.LastArrivalDelay;  // 末发命中（多连发时更晚）
    // 编排侧把飘字 / 扣血卡面提交 / 命中音效排期到 hitDelay 之后，
    // 弹还在飞时画面保持"蓄势"，命中一瞬反馈齐发。
}
// 未播成功（Unbound/Suppressed/...）时 Plan 无效 → 按现状立即出反馈，不阻塞主线（发即完成，可降级）。
```

注意：弹道是**装饰层**，不占 Batch-ack 主线（ADR-0040）；对齐只影响装饰节奏，
锁步推进照旧。伤害先在 Core 结算完、表演层只是把可见反馈排到命中帧。

### 预览方式（不用接线就能看）

- Play Mode 下 `NineGrid/视觉特效/VFX 绑定调试工作台` → 静态绑定库 → 选 `vfx.projectile.*` → 预览。
  预览没有源/靶坐标时自动退化为「原点向右前方 3.6 单位」的演示飞行，8 个预设都能直接试看。
- 想在棋盘真实位置试：任意 Editor 脚本 / `execute_code` 里调 `ProjectileVfxCues.PulseFromTo` 传两张卡的世界坐标。

## 三、预设总表与逐个说明

尺寸参照：卡面约 3.8×4.9 世界单位、格距 5×5.5（相邻格弹道 5~7.4 单位，对角约 7.4）。
所有预设按「独立型、卡面中心 → 卡面中心」调参。

| 预设 ID | 一句话 | 轨迹 | 速度感 | 为谁设计 |
|---|---|---|---|---|
| `projectile.magic_bolt` | 蓝紫发光弹头 + 光尘尾 + 星爆命中 | 微弧线加速 | 中速 (10u/s) | **通用效果伤害默认**，最百搭 |
| `projectile.arrow_shot` | 白亮拉伸弹头 + 稀疏碎屑尾 + 火花命中 | 直线出手快 | 极快 (17u/s) | 物理攻击 / 飞刀 / 箭矢 |
| `projectile.fireball` | 橙红光团 + 火星尾 + 爆燃命中（20 粒大爆） | 低弧线压向目标 | 慢而重 (8u/s) | 烈焰套 / 灼烧类主击 |
| `projectile.void_orb` | 暗紫自旋球 + 暗烟尾 + 虚空爆散 | 高抛缓落俯冲 | 最慢 (5.5u/s) | 决斗套 / 暗系 / 诅咒 |
| `projectile.spark_zip` | 白青光点 + 电花尾 + 脆响火星 | 锯齿摆动 3 周期 | 最快 (20u/s) | 机关 / 雷电 / 速攻 |
| `projectile.bone_shard` | 骨白旋转碎片 ×3 错峰齐射 + 骨屑命中 | 各自带随机小弧 | 快 (12u/s) | 骷髅主题（`deck.skeleton_legion` 等） |
| `projectile.venom_glob` | 黄绿液团 + 沿途滴落 + 毒雾泼溅 | 最高抛物线 | 慢 (7u/s) | 虫群套 / 中毒 |
| `projectile.gleam_streak` | 暖金光点 + 星尘尾 + 金光爆点 | 柔和 S 线 | 快 (13u/s) | 遗物 / 道具触发 |

**观感设计逻辑**（做新变体时延续）：

- **速度 = 力量语言**：越重的攻击越慢（火球/毒液高抛），越轻快的越直越快（飞刀/电光）。
- **轨迹 = 来源语言**：物理直线、魔法弧线、能量摆动——玩家扫一眼轨迹形状就知道伤害类型。
- **命中爆点必须有**：轨迹告诉玩家「谁打的」，爆点告诉玩家「打到了」。8 个预设全部配了命中爆点。
- **配色对齐既有语义色**：血 #CB3834、甲 #5E7E74、烈焰橙红、虚空暗紫、虫群黄绿——与粒子库/飘字同源，别自创色。

**逐预设调参方向**（真源在 `VfxProjectilePresetLibrary`）：

- 嫌看不清轨迹 → 加 `TrailPerUnit`（密度）或 `TrailLifetime`（余辉更长）；嫌糊 → 反向。
- 嫌没力量感 → 命中爆点 `ImpactScale`/`ImpactCountOverride` 加码；或换更重的 Impact 预设（如 `particle.flame_burst`）。
- 想要"蓄力再射" → 绑定 `startOffsetSeconds` 加起手延迟，配合 MuzzlePresetId 起手光。
- 多连发 → 绑定 `fps` 直接改弹道数（1~8），`StaggerSeconds`/`TargetJitterRadius` 在预设里调错峰与散布。

## 四、变体创作指南（外人怎么轻松做差异化）

三层复用，从便宜到贵：

### 1. 绑定层（改 JSON，不动代码）——90% 的需求停在这层

四个旋钮 + 内容定向 + 变体池：

| 绑定字段 | 弹道语义 |
|---|---|
| `materialKey` | 预设 ID（`VfxProjectilePresetIds`，卫生校验会查表） |
| `fps` | **弹道数量覆盖**（1~8 齐射；0=预设默认） |
| `scale` | 整体缩放：弹头、拖尾、弧高、散布、爆点全部等比 |
| `speed` | 时间倍率：飞行更快/更慢，拖尾爆点同步 |
| `tintR/G/B/A` | 整体乘色（做主题变体的主力） |
| `startOffsetSeconds` | 起手延迟（蓄力感） |
| `timeBase` | `scaled`/`unscaled`（暂停场景演出用 unscaled） |
| `variants[]` | 变体池：加权随机 + 避免连续重复，`fpsTrim`/`scaleTrim` 微调 |

**内容定向覆盖**（同一 cue、不同卡不同弹道）——加一条带 selector 的绑定行即可：

```json
{
    "cueId": "vfx.projectile.skill",
    "selectorSkillId": "skill.flame_boiling",
    "note": "沸腾之焰专属：大火球",
    "enabled": true,
    "playerId": "projectile",
    "spatialOwnership": "independent",
    "materialKey": "projectile.fireball",
    "scale": 1.3,
    "timeBase": "scaled",
    "authoringStatus": "aiDraft"
}
```

五维 selector（cardDefId / skillId / roomId / itemDefId / contentId）按最高特异性解析，
基础行兜底——**给一张卡做专属弹道 = 加一行 JSON**。

**tint 变体速查**：`magic_bolt` tint 绿 = 毒弹、tint 红 = 血魔法；`arrow_shot` tint 青 = 冰刺；
`bone_shard` tint 暗红 = 血骨。像素/发光形状通吃乘色。

### 2. 预设层（改 `VfxProjectilePresetLibrary`）

复制相邻预设改参数即可；新增预设要同步 `VfxProjectilePresetIds`（常量 + `sAll` 数组），
漏了会被 `PresetLibrary_MatchesContentPresetIdTable` 测试当场抓住。
起手/命中爆点字段直接填 particle 库 27 个预设里的任意非 loop ID（跨库复用，`ImpactTint` 染色）。

### 3. 形状层（改 `VfxParticleTextureBank`）

弹头与拖尾贴图与粒子库共用五种程序化形状（SoftDot/Pixel/Spark/Ring/Shard）；
新形状加枚举 + Bake 函数，弹道和粒子两边同时受益。
想换真美术贴图时优先候选：`Assets/Arts/Images/PixelartCardTCG/PNG/CardEffects.png`（PPU 16，光斑星芒图集）、
`Assets/Plugins/Feel/MMTools/.../MMParticles/`（16 张专业粒子贴图）。

## 五、运行语义与边界（接线时须知）

- **坐标**：源 = `VfxSpatialContext.PositionSnapshot`、靶 = `TargetPositionSnapshot`（本次新增，均不进绑定主键）。
  缺靶坐标不报错，退化为向右前方 3.6 单位的演示飞行（工作台预览依赖此行为）。
- **排序**：独立型 `Main` 层，弹头 order = 5000 + 预设 delta（默认 3），发光层 −1、拖尾 −2、爆点按 particle 预设自身 delta。
- **空间**：独立型接纳时固定源/靶世界位快照，挂 `VfxIndependentSpatialRoot`，**宿主死亡不中断**——
  卡牌命中瞬间死亡碎裂，弹道和爆点照常放完（位置是快照，不追踪目标移动；快速批次里目标已位移时命中点即发射时的位置）。
- **多连发**：首发精确命中靶心（可读性），后续发在 `TargetJitterRadius` 内散布 + 弧高抖动，错峰 `StaggerSeconds`。
- **失败语义**：未知预设 ID → `BackendFailure`；缺 materialKey → `Unbound`；全部进 VFX 诊断与工作台，不抛入玩法。
- **性能**：每次 Pulse 一个根 GO（≤8 发 × 弹头 2 Sprite + 拖尾 1 系统 + 爆点），播完即毁，15s 失效兜底；
  拖尾 `maxParticles` 上限 256。量级与 gold-flight 同策略。
- **卫生门禁**：弹道绑定预设键由 `VfxBindingCatalogHygieneValidator.ValidateProjectilePresetBinding` 校验
  （`missing-material` 级）；projectile 只支持 Pulse，挂 `stateBindings` 会报 `missing-player`（player 不支持 State）；
  工作台断链筛选经 `VfxBindingProjectilePresetRules`。
- **EditMode 测试注意**：飞行数学纯代码驱动（Tick 推进），测试可确定性断言位置/命中；
  拖尾/爆点粒子在 EditMode 不自动模拟，完成判定走「末达 + 余辉窗口」的时间兜底，别断言粒子数。
