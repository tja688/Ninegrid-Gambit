## M2 投影器

- 纯数据 `LivingUiContentProjector`：载体采样 size → content `localScale` / `localPosition` / `visible`
- `BoundaryReactive`：`scale = saturate((sizeRatio - stagger·span) / (1 - stagger·span))`，stagger 来自局部位切比雪夫归一化
- `PartialFollow`：贴边 `local ± 0.5·Δsize`，不缩放
- Envelope → `TransitionPlanner` 每载体流动下限
