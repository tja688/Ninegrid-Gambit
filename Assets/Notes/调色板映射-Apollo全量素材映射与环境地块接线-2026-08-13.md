## 可用脚本（scripts/）

| 脚本 | 用途 |
|------|------|
| `palette-map-apollo.py` | 全量映射主工具。`--dry-run` 核对 / `--pilot` 出对比图 / `--run` 就地覆写；`--rules` 追加区域规则；`--only` 过滤子串；`--report` 出 CSV |
| `gen-region-rules.py` | 从卡 JSON（deckId + 动画目录）生成 `region-rules.json`；共用目录自动回退中性 |
| `region-rules.json` | 生成产物（30 条），供 `--rules` 消费；内容变更后重新生成 |
| `palette-compare.py` | 原图\|映射后 并排对比图，输出 `.scratch/palette-map/compare/` |

环境：`py -3.12`（装有 numpy + pillow）。标准流程：

```
py -3.12 scripts/gen-region-rules.py
py -3.12 scripts/palette-map-apollo.py --dry-run --rules scripts/region-rules.json
py -3.12 scripts/palette-map-apollo.py --run --rules scripts/region-rules.json --report .scratch/palette-map/run-report.csv
```

## 经验记录

- **Oklab 最近色 + 权重**是关键：明度权重 1.15 保住像素画明度结构；色度权重 1.30 让近中性色
  优先落灰阶，避免头骨/石头出现蓝绿杂点。纯 RGB 距离会把暗部映得很脏。
- **区域加权取温和值（0.8–1.25）只掰"摇摆色"**：太激进会把固有色也拉偏（比如骷髅白骨被
  拉成紫色）。目的是氛围偏重，不是整体调色。
- **共用素材必须回退中性**：同一帧目录被过渡卡组和主题卡组共用时（本次 5 个目录），
  强行套区域色会让同一素材在不同上下文中不一致，回退中性最稳。
- **仅映射可见像素**（alpha>0），透明区 RGB 不动，避免边缘 halo 变化。
- **接线避免动场景 YAML**：本仓库表现层惯例是代码自愈（找不到就 AddComponent），
  跟随此惯例把皮肤组件挂到 `GroundFieldView.Awake`，零场景 diff。
- **槽位底板是 9-slice 拉伸**（1.9×2.45，transform ×2），新地块无九宫边框时 Unity 按
  FullRect 整体拉伸即可，但 meta 的 `spriteMeshType` 必须从 Tight(0) 改 FullRect(1)。
  同物体挂有点击碰撞盒，禁止用 transform 缩放来配尺寸。
- **数据驱动查引用**：怪物 id→sprite 没有映射表，全靠卡 JSON 的 `animations.slots[].path`
  显式指路径；查"谁引用了这批帧"要扫 `Assets/Arts/ContentVisual/cards/*.json`。
