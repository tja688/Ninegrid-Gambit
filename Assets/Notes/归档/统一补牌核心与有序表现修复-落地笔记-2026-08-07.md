## 已落地的核心

- `BoardStabilizationSystem` 以 Core `BoardModel` / `DeckModel` 判断欠补位，统一覆盖开局、击杀、非击杀移除、捕熊触发和敌方行动收尾等路径。
- 每个稳定化切片至多执行一轮 `FillEmptySlotsAction`。Fill 内触发的新空位不会在同一批内被隐藏追算，而是在上一批 Present ack 后形成下一独立切片。
- `BoardStabilizationScheduler` 在 `BattleTimeline` 上串行推进 `Resolve → Present → ack → stable check`，直到 Core 报稳定。
- 融合/重组牌由 Core 的 `deferRefill` / 稳定化排除集合管理，稳定完成后恢复牌堆顺序；表现层不再临时改牌堆。
- 旧 `DrainRefill` / `FusionRefill` 专用 scheduler、command、planner 和 aftermath 已删除。
