## 给策划的一句话结论

**能玩、能打完 3 层 × 9 关的垂直切片已经成立**：九宫格战斗、发牌补牌、旋转、帮助卡、大部分怪物与技能、通关奖励、房间二选一（商店/金币/宝箱/温泉）、遗物与经济闭环都在正式流程里跑通。

**内容完成度上帮助卡最齐（27/27），遗物缺口最大（22/58）**；导师卡 / 玩家技能习得、酒馆、商店删卡、职业选择、遗物丢弃等文档流程**尚未接入正式对战**。

### 1.2 帮助卡（27/27 — 文档全量落地）

Catalog 与 `Assets/Docs/九宫牌局/07-数据/帮助卡数据.md` **一一对应**，DSL 均可解析。

**正式流程获取途径**（均可实际抽到 / 买到 / 奖励到）：

- 通关三选一池 `help.choice`（白 65% / 蓝 30% / 金 5%）
- 关后轻车熟路白色三选一 `help.white.choice`
- 商店六选一 `shop.helpCards`（扣金币，`PhaseSystem.SelectReward` 按 Price 扣费）
- 宝箱类帮助卡开出的遗物三选一
- 精英/层主击杀洗入（蓝箱/金箱/金币/属性提升等）
- 开局小丑初始包（恢复药水×3、普通宝箱×1、飞刀×3、属性提升×1）
- 怪物技能间接生成（如喷火 → 烈焰、献身 → 烈焰等）

**红色帮助卡**（金色宝箱卡、烈焰）：不进常规池，可通过遗物/技能/怪物效果加入 — 逻辑已存在，正式局可遇到。

## 四、半落地 / 壳 / 与设计有偏差

| 项目 | 设计 | 当前实现 | 严重度 |
|:--|:--|:--|:--|
| **暴力卡** | 玩家总攻击翻倍，与怪物战斗一次后复原 | 下一次对怪 **战斗伤害 ×2**（`DamageMultiplier Once`） | 中 |
| **烈焰** | 场上相邻伤血 + 使用伤血 + 关末未使用移除 | 仅 **使用时** 对玩家 4 伤并移除（`help.flame.use`） | 高 |

| **渴望** | 血量上限 +10 + 恢复翻倍 | 仅恢复翻倍规则，**无 +10 上限** | 中 |

## 附录 B：审计方法说明

1. **文档枚举**：`Assets/Docs/九宫牌局/07-数据/*.md`、`04-技能/*.md` 等标题级条目。  
2. **Catalog 枚举**：`TableNineContentCatalog.cs` 中 `Help/Relic/Skill/Monster` 注册与 `AddRewardsAndRooms` 奖池。  
3. **可达性**：是否进入 `help.choice` / `shop.helpCards` / `relic.*_chest` / 击杀池 / 初始卡组 / 房间逻辑。  
4. **流程**：`MainGameLoopManagerSingleton` 状态机 + `PhaseSystem` 命令门禁 + `PendingChoiceKind`（当前仅 `Reward` / `Room`）。  
5. **DSL 完整性**：EditMode `DefaultCatalog_ValidateCatalog_IsValidWithNoPendingEffects` 通过 → 已注册 effect 无 Pending。
