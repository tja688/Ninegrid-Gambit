## 1. 背景

### 1.1 策划侧

新版本卡牌四大类：**玩家卡 / 怪物卡 / 道具卡 / 机关卡**。游戏内用卡组区分（`deck.player`、遭遇子卡组、`deck.help`、`deck.relic`）；本轮正式补上 **机关分类 + `deck.trap` + 机关技能**。

策划表（9 张，均 HP6 / ATK0 / Armor0）：


| 卡    | 技能   | 稀有  |
| ---- | ---- | --- |
| 滚石   | 滚石碾压 | 常规  |
| 攻击图腾 | 攻击提升 | 常规  |
| 护甲图腾 | 护甲提升 | 常规  |
| 恢复图腾 | 恢复提升 | 常规  |
| 倒刺   | 尖刺   | 常规  |
| 捕熊陷阱 | 猛夹   | 常规  |
| 治疗泉  | 恢复水  | 特殊  |
| 烈焰   | 烈焰高温 | 特殊  |
| 复活石  | 复活亡者 | 特殊  |


开局规则（策划）：常规机关开局随机 X 张入战斗卡组；特殊仅靠技能打入。**本轮不做开局注入**（另票）；只保证技能 / 编辑器 / QuickTest 能打出并验收。

### 1.2 仓内现状（Grill 摸底）


| 项          | 事实                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------- |
| `CardKind` | 无 `Trap`；复活石以 `**kind: Monster` + `trap.*` 前缀**伪装                                              |
| 卡组         | 无 `deck.trap`；复活石 `deckId` 空 → 编辑器「(未分组)」                                                      |
| 卡面         | `Assets/Prefabs/机关卡标准模版.prefab` **已做好、零引用**；运行时机关走怪物壳                                          |
| 效果池        | 仅道具 / 遗物 / 怪物技能；`tpl.trap.*` 落入「其他」                                                            |
| 正式机关       | 仅 `trap.revive_stone`（互动 6 次 → 同格特 5）                                                          |
| 「老机关感」内容   | `help.rolling_stone` / `help.bear_trap` / `help.flame` / `help.healing_spring` 仍是 **HelpCard** |
| 远程武器       | 核心是 `RuleId.CounterAttackBanned`（可静默挂），不是必须挂 `skill.ranged_weapon`                             |
| 爆弹等        | `AllMonsters` → 硬过滤 `Kind == Monster`；迁 Trap 后若不放宽则打不到机关                                       |
| 清关         | `HasEnemyOnBoard` 等按 Monster；前缀豁免散落在死亡之主 / 刺客领袖模板                                              |


问题：分类未一等公民、Help 与机关权威分叉、交互靠前缀特例、专用模版未接线。

## 2. 设计裁定（Grill 共识）

### 2.1 身份

- 新增 `**CardKind.Trap`**（同步 `CardPresentationKind` 同序同值、选壳、投影、Infer）。
- 单一 `**deck.trap`**。
- `**EffectContainerType.Trap`（或 TrapSkill）** + 编辑器「机关技能」桶（`tpl.trap.`*）。
- 内容 id：`trap.*`；一卡一文件（Arts → StreamingAssets）。

### 2.2 双桶（避免散落 `if Trap`）


| 桶             | 成员          | 用途                                |
| ------------- | ----------- | --------------------------------- |
| **可交战 / 可受伤** | `Monster    | Trap`                             |
| **真怪物**       | 仅 `Monster` | 文案/模板「怪物卡」、遭遇报名、死亡之主/刺客领袖、图腾加成对象等 |


集中入口：Core helper（如 `IsBoardCombatTarget`）+ `TargetResolver.MonstersOnBoard`（或等价改名）+ `PhaseSystem.Attack` / `BoardIntentLegality` / `GroundCardHitProxy`。  
模板里 `targetKind=Monster` **保持精确匹配**（自然排除机关）；`excludeTargetDefPrefix=trap.` **退役**。

### 2.3 其它不变量


| 项        | 裁定                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 清关       | 机关**不挡关**（场上 / 抽牌里的 Trap 均不算「还有敌」）                                                                         |
| 击杀经济     | 打死机关**无赏金**                                                                                                |
| 默认特性     | Spawn/装配静默 `CounterAttackBanned`；Source 固有/`trap.`*；**不**挂远程武器技能、检视不显示为技能                                  |
| 攻击模式     | 全员 `attackPattern: "无"`（不进敌方行动报名）                                                                          |
| 数值默认     | HP6 / ATK0 / Armor0（策划后改自行改表）                                                                              |
| 图腾互 buff | 邻格**其它机关不加**（只真怪 + 玩家，按文案）                                                                                 |
| 发牌身份     | 机关是**卡**：进敌侧发牌池 → DrawPile → 补格占格（与怪同路占格，但清关/赏金按上表排除）                                                      |
| Help 迁徙  | `help.rolling_stone` / `help.bear_trap` / `help.flame` / `help.healing_spring` → Trap 权威后**删除** Help 项并清引用 |


### 2.4 九技能落地语义


| 卡        | 语义（实现必须遵守）                                                             |
| -------- | ---------------------------------------------------------------------- |
| **滚石**   | 移到格 3 时：格 6 上**怪 / 道具 / 机关**都可清；**非精非主仅约束真怪**；**不自移除**（只能被玩家或其它合法效果破坏） |
| **攻击图腾** | 邻格真怪+玩家 ATK+1，离开失效（`activeWhileAdjacent`）                              |
| **护甲图腾** | 邻格真怪+玩家 Armor+1，离开失效（同上）                                               |
| **恢复图腾** | **本卡移动/旋转落地后**判定一次：邻格真怪+玩家各 **Heal 1**（真回血，非临时 Recovery）；其它时机不触发       |
| **倒刺**   | **本卡**每移动 1 次，邻格真怪+玩家各伤 1                                              |
| **捕熊陷阱** | 邻格补牌：真怪→10 伤；道具→移除该卡；**机关→不影响**；然后自移除（一套触发一次）                          |
| **治疗泉**  | 同恢复图腾触发时机，但 **仅玩家 Heal 1**                                             |
| **烈焰**   | **本卡**每移动 1 次，若正交邻玩家则对玩家 1 伤；满 3 次自移除                                  |
| **复活石**  | 既有：玩家互动 6 次后自移除，同格打出特 5；本轮做 Kind/deck/container 迁正                     |


### 2.5 本轮明确不做

- 正式开局「随机 X 张常规机关入战斗卡组」。
- 改策划数值表（除非实施中发现阻塞）。
- 用 Safe Mode / worktree / 旁路克隆。

## 3. 技术落点（实施时对照）

### 3.1 必改集中点（双桶 / 清关 / 经济）

- `TargetResolver.MonstersOnBoard`（及 `AllMonsters` / `RandomMonster`）→ 含 Trap（可伤目标）。
- `PhaseSystem.Attack`、`BoardIntentLegality`、`GroundCardHitProxy` → 可普攻 Trap。
- `DeckSystem.HasEnemyOnBoard` / `HasEnemyInDrawPile` / `IsNodeCleared` → **仍只认真怪**。
- 击杀赏金路径 → **跳过 Trap**。
- 静默 Rule：Trap Spawn/装配统一入口加 `CounterAttackBanned`。
- `CardChassisPaths` + `ResolveFacePrefab` → 机关模版。
- `ContentSystem.ToContainerType`、编辑器 `EffectTemplateOriginCategory`、`ResolveEffectTemplateCategory`（`tpl.trap.`*）。
- `RewardSystem` / `NodeDeckOptions.AddEnemyCard`：允许 Trap 进入敌侧发牌池（QT 与日后开局票共用此能力）。
- 复活石 JSON + death_summon / lord_of_death Spawn `kind`；刺客领袖 / 死亡之主去掉 `trap.` 前缀。

### 3.2 QuickTest

- 扩展通道预设 `**trapContentIds`**：`BuildNodeDeckOptions` 之后、`StartNode` 之前 `**AddEnemyCard` 注入**（走正式 Deal 链）。
- **与现有 `skillIds` 并存、互不影响**；`\0` 不占用。
- `\1`–`\9` 各注入一张（见下表）；旧技能通道保留。
- 通道确认后更新 Living Note（交互 → 预期反馈）。


| 码    | 注入机关 | 现有技能通道（保留） |
| ---- | ---- | ---------- |

| `\2` | 攻击图腾 | 互动向        |
| `\3` | 护甲图腾 | 翻面向        |
| `\4` | 恢复图腾 | 批次1·打伤联动   |
| `\5` | 倒刺   | 批次1·成长移动   |
