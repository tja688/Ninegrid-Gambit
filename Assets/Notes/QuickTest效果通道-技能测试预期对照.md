# QuickTest 效果通道与顺劈斧弹道粒子测试对照

> **最后更新**：2026-08-18  
> **核心原则**：  
> 1. **正式版打包隔离**：`\` 快速测试入口与局内快捷键处于 `#if UNITY_EDITOR || DEVELOPMENT_BUILD`，正式发布包（Release Build）按键完全无响应。  
> 2. **通道精简收拢**：仅保留 `\0` 快速测试通道，开局玩家 HP=99、金币=999，其余规则、发牌、交互 100% 走正常完整游玩流程。  
> 3. **局内快捷测试**：仅在通过 `\0` 进入的快速测试中，支持按数字键 `0`–`9` 实时切换战士初始遗物「顺劈斧」触发时的程序化弹道粒子效果。

---

## 1. 入口与作弊规则

- **入口**：主菜单长按 `\` 键（Backslash），弹出提示后释放直接进入 `\0 快速测试`（或按数字键 0 确认）。
- **局内状态**：
  - 玩家生命值：99 / 99（每关自动维持/重置）
  - 玩家金币：999
  - 角色攻击力：正常角色数值（不再强制修改为 5）
  - 怪物与机关：正常卡池与关卡内容，不再动态挂载怪物技能或注入多余陷阱。

---

## 2. 顺劈斧程序化弹道粒子测试矩阵（数字键 0~9）

战士初始遗物为**顺劈斧**（`relic.rotten_cleave_axe`），效果为：攻击敌人时，对目标正交相邻格子的敌人造成 1 点顺劈伤害。

在 `\0` 快速测试对局中，按键盘上方数字键 `0`~`9` 或小键盘 `0`~`9` 即可实时切换顺劈斧发射的弹道粒子：

| 按键 | 弹道预设 ID | 预设名称 | 视觉表现与特征 |
| :---: | :--- | :--- | :--- |
| **0** | `projectile.magic_bolt` | **魔法飞弹** | 蓝紫发光弹头 + 光尘拖尾 + 星爆命中（低弧线弹道） |
| **1** | `projectile.arrow_shot` | **飞刀直射** | 白亮拉伸弹头极速直线 + 稀疏碎屑尾 + 火花命中（极速高冲击） |
| **2** | `projectile.fireball` | **火球** | 橙红光团低弧线 + 火星拖尾 + 爆燃命中 |
| **3** | `projectile.void_orb` | **虚空法球** | 暗紫球体高抛缓落 + 暗烟拖尾 + 虚空爆散（重力高抛感） |
| **4** | `projectile.spark_zip` | **电光急蹿** | 白青光点锯齿急蹿 + 电花拖尾 + 脆响火星命中（折线穿行） |
| **5** | `projectile.bone_shard` | **骨刺三连** | 骨白碎片旋转齐射 + 骨屑命中（三发散射） |
| **6** | `projectile.venom_glob` | **毒液抛射** | 黄绿液团高抛 + 滴落拖尾 + 毒雾泼溅命中（粘液滞留） |
| **7** | `projectile.gleam_streak` | **金色流光** | 暖金光点柔和 S 线 + 星尘拖尾 + 金光爆点（神圣/遗物标准感） |
| **8** | `projectile.fireball` | **火球 (强化)** | 烈焰主题重击强化弹道 |
| **9** | `projectile.spark_zip` | **电光 (疾驰)** | 雷电主题疾驰强化弹道 |

### 验证步骤
1. 主菜单长按 `\` 键后松开，进入游戏（提示 `\0 快速测试`）。
2. 查看 HUD：玩家生命值为 99，金币为 999。
3. 战士攻击一名正交相邻存在其他怪物的目标怪。
4. 观察左上角遗物栏的顺劈斧图标：顺劈伤害触发时，立即向相邻受害者射出弹道粒子。
5. 随时按键盘数字键 `0`~`9`（Unity 控制台会打印 `[QuickTest] 顺劈斧测试弹道切换为 [X]: ...`）。
6. 下一次攻击触发顺劈时，顺劈斧会立即发射新切换的粒子弹道。
