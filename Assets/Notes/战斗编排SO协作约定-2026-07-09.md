# 战斗编排 SO 协作约定（2026-07-09）

> 范围：Cards 表现层战斗编排。本轮**不接** Core `AttackCommand` / `PresentationBatch`。

## 心智模型（硬契约）

| 层 | 资产 | 管什么 | 谁管理 |
|----|------|--------|--------|
| 单卡反馈 | `CardEffectSO` | 只与自身有关的 one-shot（闪白、死亡缩放等） | `CardEffectManager` |
| 战斗编排 | `BattleEncounterProfileSO` | 玩家×怪物起舞 timing / 击退系数 / 回调策略 | `FieldBattleManagerSingleton` |
| 基础容器 | 场景 `CardAttackBasic*` Timeline | 人手调的 DOTween Animation/Timeline | 场景 Rig，SO 不替代 |

**熊怪例子**

- 熊怪挨打闪白、死亡缩放 → 熊怪卡上 `CardEffect`
- 熊怪与兵大哥对砍时后仰更大、受击点更晚、反击前摇不同 → 新建 `BattleEncounterProfileSO` + Catalog 条目
- **不要**把战斗 timing 塞进熊怪 `CardEffect.Hit`
- **不要**为了变体去改 Rig 场景魔法数或 Adapter 硬编码

## AI 编排流程

1. 确定 `BattleIntent`：`Attack` / `AttackLethal` / `CounterAttack` / `CounterAttackLethal`
2. 取双方 `ManagedCard.DefId`（通配 `*`）
3. `BattlePresentationRouter.ResolveBindParams(catalog, intent, playerId, monsterId)`
4. `CardAttackBasicAdapter.PlayBasicAttackAsync / PlayBasicCounterAttackAsync(bind)`
5. 禁止直接改 `CardAttackBasicDirectionRig` 私有字段或 delay 启发式常量

## 点击交战默认编排（组合，非新 Intent）

`FieldBattleManager.TryHandleBattleClick` / `RequestBasicAttackAtSlotAsync`：

1. 播 `Attack` 或 `AttackLethal`（吃 Catalog / SafeFallback）
2. **未击杀** → 接播同一怪物的 `CounterAttack`（再走一遍 Catalog，独立 Profile）
3. **击杀** → 清格 + 外圈旋转；**不**播反击、**不**在未击杀时旋转

不要新建「AttackThenCounter」Intent：反击变体/调参改 `Counter*` Profile 即可自动进点击链路。  
DevTest：`Keypad1` 仍只测纯反击；`Keypad8` 仍武装下次玩家击杀。

## 路由优先级

1. 精确 `(intent, player, monster)`
2. `(intent, player, *)`
3. `(intent, *, monster)` ← 怪物特殊手感落点
4. `(intent, *, *)` 默认
5. SafeFallback（打 Error，系数安全默认值 + 强制终态 Guard）

## 带锁参数

- 怪物受击击退系数：`[1.0, 3.0]`
- 玩家受击（反击）击退系数：`[0.3, 1.0]`
- 越界由 Profile `OnValidate` / `ToBindParams` clamp

## 终态安全

`BattleFinalStateGuard`：播前快照 → 播后/取消 Kill tween → 回格位锚点 → rotation identity → `RefreshDisplayMode`。  
超时软补间会硬 Snap，避免 tween 被杀后错位。

## LEGACY 提醒

`FieldBattleManager` **仅击杀后**外圈旋转仍是伪战斗路径，**不是**正式规则；正式规则待接 Core Batch。
