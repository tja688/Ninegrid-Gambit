# RES_属性管线

> 本文档定义有效属性的计算管线。每次需要属性值时**从头重算，不存中间值**。
> 所有"攻击""血量""护甲"等虚构名见 [[虚构对照表#一、资源层（RES）]]。

---

## 化身属性管线（RUL_011）

适用于：化身（玩家操控单位）

```
有效值 = 基础值 → 持久修正 → 条件修正 → 临时修正
```

### 阶段 1：基础值

| 属性 | 来源 |
|:--|:--|
| 攻击 | 职业初始配置 + `EVT_ITEM_025`（属性提升道具）永久加成 |
| 血量上限 | 职业初始配置 + `EVT_ITEM_025` 永久加成 |
| 基础护甲 | 职业初始配置 + 被动装备属性 |

### 阶段 2：持久修正

| 来源类型 | 示例 |
|:--|:--|
| 被动装备属性 | `EVT_RELIC_003`：攻击+1 |
| 套装加成 | `EVT_RELIC_002+003+004`：攻击额外+2 |
| 技能永久加成 | `EVT_PSKILL_002`：血量上限+10 |

### 阶段 3：条件修正

满足特定条件时生效的加成：

| 条件类型 | 示例 |
|:--|:--|
| 血量阈值 | `EVT_RELIC_042`：血量<50% 时攻击+2 |
| 套装检测 | `EVT_RELIC_002`：同时拥有 A+B+C 时基础护甲额外+2 |

### 阶段 4：临时修正

限次/限时效果：

| 效果类型 | 示例 |
|:--|:--|
| 战斗限次 | `EVT_ITEM_006`：攻击翻倍，战斗一次后复原 |
| 单次免疫 | `RES_009`：下一次伤害变为 0 |

## 敌方属性管线（RUL_012）

适用于：敌方单位（AI 操控单位）

```
有效值 = 基础值 → 持久修正 → 条件修正
```

### 阶段 1：基础值

- 来自 `[[EVT_敌方单位模板]]` 中定义的原始属性

### 阶段 2：持久修正

| 来源类型 | 示例 |
|:--|:--|
| 光环技能 | `EVT_SKILL_039`：相邻单位攻击+1 |
| 复仇累计 | 因其他单位被移除而获得的永久加成 |
| 自身永久成长 | `EVT_SKILL_004`：战斗时攻击+2（叠加） |

### 阶段 3：条件修正

| 条件类型 | 示例 |
|:--|:--|
| 位置条件 | `EVT_SKILL_002`：[场上] 处于槽6时攻击+2 |
| 相邻条件 | `EVT_SKILL_013`：处于化身相邻时触发 |

---

## 显示规则

- 面板/卡牌上显示的属性为 **有效总值**（管线最终输出），非裸值
- 敌方单位显示含技能加成（光环 + 复仇累计），实时反映
- `RES_006`（当前护甲）为主显示值，`RES_004`/`RES_005` 在调试面板可见
