# RES_资源定义

> 本文档定义游戏中所有数值资源（货币、生命、攻击、护甲）的纯机制规则。
> 虚构名通过 `[[虚构对照表#ID]]` 映射，本文不出现世界观词汇。

---

## RES_001：通用货币

### 获取公式

| 来源 | 数量 | 触发事件 |
|:--|:--|:--|
| 敌方单位从战场移除 | +5 / 个 | `removeCard` |
| 关卡结束时未使用的辅助道具 | +10 / 张 | 通关结算 |
| 使用特定道具（编号 `EVT_ITEM_015`） | +50 | `onUse` |
| 通关后跳过道具选择 | +10 | 界面操作 |
| 跳过被动装备选择 | +20 | 界面操作 |
| 放弃已装备的被动装备 | +20 / 件 | 界面操作 |
| 在消费场景中出售道具 | +10 / 张 | 界面操作 |

### 消耗

- 消费场景中**购买**辅助道具（价格见 `[[EVT_帮助卡模板]]`）
- 被动装备 `EVT_RELIC_017` 效果：每 5 货币抵消 1 点护甲伤害

### 规则

- 货币不设上限
- 跨关卡累积保留

> **虚构层**：当前称为 [[虚构对照表#RES_001]]，可替换。

## RES_002：化身生命值

### 定义

- **当前值**：实时生命值，归零触发失败状态（`[[虚构对照表#FLOW_009]]`）
- **上限值**：最大生命值，通过被动装备或技能永久增加，获取上限时**等量恢复当前值**

### 归零判定

```
if 当前值 ≤ 0 → 触发游戏结束
```

### 上限增加途径

- 被动装备提供（如 `EVT_RELIC_004`：上限+2）
- 技能习得时提供（如 `EVT_PSKILL_002`：上限+10）
- 道具使用提供（如 `EVT_ITEM_025`：上限+2）

### 规则

- 最低为 0，不可为负数
- 跨关卡保留当前值和上限值

> **虚构层**：当前称为 [[虚构对照表#RES_002]]，上限称为 [[虚构对照表#RES_007]]。

## RES_003：化身攻击力

### 定义

- 决定对敌方单位造成伤害的基数
- 参与 `[[虚构对照表#RUL_005]]` 计算

### 计算公式

参见 `[[RES_属性管线#化身属性管线]]`：
```
有效攻击 = 基础值 → 持久修正 → 条件修正 → 临时修正
```

### 基础值来源

- 化身职业初始配置（见 `[[PRO_职业]]`）
- 道具 `EVT_ITEM_025` 永久加成

### 规则

- 最低为 0，不可为负数
- 跨关卡保留

> **虚构层**：当前称为 [[虚构对照表#RES_003]]。

## RES_004~006：护甲系统

### 三层模型

| ID | 层级 | 定义 | 计算/初始化 |
|:--|:--|:--|:--|
| `RES_004` | 基础值 | 静态属性值 | 被动装备 + 技能永久加成 |
| `RES_005` | 有效值 | 关卡初始化的基准值 | 基础值 + 被动装备 + 套装 + 技能 |
| `RES_006` | 当前值 | 可消耗的护甲资源 | 关卡开始 = 有效值 |

### 护甲消耗规则

受伤害时：
```
护甲损失 = min(当前护甲, 原始伤害)
血量损失 = 原始伤害 - 护甲损失
当前护甲 -= 护甲损失
```

### 当前护甲获取途径

- 关卡开始：初始化为有效护甲值
- 被动装备效果（如 `EVT_RELIC_009`：[使用道具时] +1）
- 道具使用（如 `EVT_ITEM_011`：+5）

### 规则

- 所有护甲值最低为 0
- 当前护甲不跨关卡保留（每关重新初始化为有效值）
- 基础护甲跨关卡保留
- 数据层必须将三层作为**独立字段**存储

> **虚构层**：三层分别称为 [[虚构对照表#RES_004]]、[[虚构对照表#RES_005]]、[[虚构对照表#RES_006]]。

## RES_008：伤害减免

### 定义

- 多来源累加的固定减伤值
- 在 `RUL_005` 中**最先**参与计算

### 公式

```
原始伤害 = max(0, 攻击力 - 伤害减免)
```

### 来源

- 被动装备提供（如 `EVT_RELIC_031`：伤害减免+1）
- 敌方技能提供（如 `EVT_SKILL_044`：敌方单位受伤-1）

### 规则

- 多来源累加
- 当前无来源时 = 0

> **虚构层**：当前称为 [[虚构对照表#RES_008]]。

---

## RES_009：单次伤害免疫

### 定义

- 满足条件时，下一次受到的伤害变为 0
- 仅免疫**单次**伤害，对多段伤害只免疫第一段

### 触发源

- 技能 `EVT_SKILL_062`：常驻，受伤害时触发，不可叠加
- 道具 `EVT_ITEM_002`：使用时赋予
- 被动装备 `EVT_RELIC_018`：每关卡首次护甲归零后赋予

### 规则

- 不叠加（多次获得时只保留一次）
- 触发后消耗

> **虚构层**：当前称为 [[虚构对照表#RES_009]]。
