# EVT_遗物模板

> 纯机制定义。所有虚构名映射见 `[[虚构对照表#5.4 被动装备名映射]]`。

---

## 被动装备数据结构

每件被动装备由以下字段构成：

| 字段 | 说明 | 示例 |
|:--|:--|:--|
| 属性 | 常驻数值加成，无则为"无" | 攻击+1、基础护甲+2、血量上限+6、无 |
| 效果 | 事件触发或常驻效果 | `[使用道具时] 恢复 2 血量` 或 `伤害减免+1` |
| 品质 | 白/蓝/金 | 白色 |
| 定位 | 主标签，副标签 | 道具，恢复 |

---

## 效果分类

| 效果类型 | 格式 | 示例 |
|:--|:--|:--|
| 事件触发 | `[触发前缀] 动作` | `[使用道具时] 恢复 2 血量` |
| 常驻 | 无前缀，直接写动作 | `伤害减免+1`、`所有敌方攻击-1` |

---

## 定位标签体系

主标签 + 副标签格式（如 `道具，恢复`）。单维度只写主标签。

### 主标签

| 标签 | 含义 | 计数 |
|:--|:--|:--|
| 道具 | 围绕道具使用触发 | ~5 件 |
| 护甲 | 围绕护甲属性 | ~11 件 |
| 属性 | 纯数值或按属性计算 | ~5 件 |
| 杀怪 | 击杀敌方后触发 | ~8 件 |
| 经济 | 影响货币 | ~4 件 |
| 血量 | 围绕血量属性 | ~10 件 |
| 位移 | 影响网格位置/旋转 | ~5 件 |
| 恢复 | 提供血量恢复 | ~3 件 |
| 纯属性 | 纯数值无触发 | 1 件 |
| 条件爆发 | 满足条件大幅加成 | 1 件 |
| 成长 | 数值逐步增长 | 2 件 |
