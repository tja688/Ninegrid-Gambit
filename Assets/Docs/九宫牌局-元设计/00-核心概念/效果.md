# 效果

## 一句话定义

**效果**是游戏中一切"发生什么事"的原子描述单位。任何改变游戏状态的行为——造成伤害、恢复血量、增减属性、加入/移除卡牌、旋转棋盘——都以"效果"的形式定义和解析。

---

## 效果的本质：三段式结构

每条效果在逻辑上由三个部分构成：

```
触发时机 + 条件 + 动作
```

| 组成部分 | 含义 | 示例 |
|:--|:--|:--|
| **触发时机** | 效果在什么时间点/事件下启动 | `[战斗时]` `[使用时]` `[每关卡开始时]` `每移动3次` |
| **条件**（可选） | 触发后需满足的额外条件 | "若格6为怪物卡" "当前血量低于50%" |
| **动作** | 实际产生的游戏状态变化 | "造成6点伤害" "恢复10点血量" "攻击+2" "移除本卡" |

> **"效果"不关心来源**。无论是遗物触发的、技能生效的、还是帮助卡使用的，效果结构完全相同。来源信息由 [[效果类型隔离规范#一、效果类型元标签（第一道防线）|类型元标签]] 携带，不影响效果自身结构。

---

## 效果与"技能""遗物""帮助卡"的关系

**效果是原子，其他概念是容器。** 效果本身没有名字，它被不同的容器承载：

```
技能（名称）          ──容纳──▶  1 个效果
遗物（名称 + 属性）    ──容纳──▶  1 个效果
帮助卡（名称 + 品质）  ──容纳──▶  1~3 个效果
```

### 具体关系图示

| 容器类型 | 容器有什么 | 里面装了什么 | 举例 |
|:--|:--|:--|:--|
| **技能** | 名称（如"丐帮同心"） | **1 个效果** | `每移动5次，将一张乞丐怪物卡洗入战斗卡组` |
| **遗物** | 名称 + 属性 + 品质 + 定位 | **1 个效果** | `[使用帮助卡时] 恢复2点血量`（废物利用机） |
| **帮助卡** | 名称 + 品质 + 价格 + 体系 | **1~3 个效果** | 效果1 `[场上]…` 效果2 `[使用时]…`（滚石） |

### 关键区分

- **"技能"不是效果，技能是一个拥有名称的效果容器。**
  - "丐帮同心"是技能名，它包含的效果是"每移动5次，将一张乞丐怪物卡洗入战斗卡组"
  - 日常说"丐帮同心的效果"——这是正确的说法，意为"丐帮同心这个技能所包含的效果"
  - 日常说"怪物技能效果"——这是冗余说法，等于"怪物技能容器里的效果" = "效果"

- **"遗物"不是效果，遗物是一个拥有属性和效果的装备物品。**
  - "废物利用机"是遗物名，它包含的效果是"[使用帮助卡时] 恢复2点血量"
  - 遗物还可能提供无触发条件的常驻属性（如木剑 `攻击+1`），常驻属性**不是效果**——它没有触发时机，只是数值加成

- **"帮助卡"不是效果，帮助卡是一个拥有品质和价格、承载1~3个效果的消耗品。**
  - "滚石"是帮助卡名，它包含两个效果：场上移动触发 + 使用时自移除

## 效果的四个来源类型

效果按承载容器分为四种类型，解析规则详见 [[效果类型隔离规范]]：

| 类型标签 | 承载容器 | 容器特点 |
|:--|:--|:--|
| `【类型遗物】` | [[遗物系统\|遗物]] | 被动装备，永久持有，事件触发 |
| `【类型怪物技能】` | [[怪物卡]] 绑定的[[游戏开发项目/九宫牌局/04-技能/技能系统\|技能]] | 绑定怪物生命周期，默认可叠加 |
| `【类型玩家技能】` | [[玩家卡]] 习得的[[游戏开发项目/九宫牌局/04-技能/技能系统\|技能]] | 永久被动，同类不可叠加 |
| `【类型帮助卡】` | [[帮助卡]] | 消耗品，使用/触发后移除 |

---

## 效果的两类子型

效果按触发方式分为两种：

```
效果
├── 事件触发效果：有 [触发前缀]，满足事件/条件时触发一次
│   例：[使用帮助卡时] 恢复2点血量 、[战斗时] 攻击+2
│
└── 常驻效果：无触发前缀，获得后无条件持续生效
    例：伤害减免+1 、所有怪物卡攻击-1 、互动距离不受限制 、所有恢复效果翻倍
```

| | 事件触发效果 | 常驻效果 |
|:--|:--|:--|
| **有无触发前缀** | ✅ 有 `[使用时]` `[战斗时]` 等 | ❌ 无 |
| **生效方式** | 事件发生时触发一次 | 获得后无条件持续 |
| **示例** | 废物利用机 `[使用帮助卡时] 恢复2点血量` | 铁盾 `伤害减免+1` |

> 两类都是效果——共享相同的容器模型和类型标签，只是触发方式不同。

## 效果与属性的区别

> 以下讨论见 [[属性]]。

**效果改规则，属性改数值。** 效果改变的是游戏的行为逻辑（减伤规则、敌方数值削弱、互动规则、倍率等），属性改变的是玩家/怪物自身的数值面板。

| | 属性 | 效果（含事件触发和常驻） |
|:--|:--|:--|
| **改什么** | 改数值面板 | 改行为规则 |
| **示例** | 木剑 `攻击+1` 、活力护符 `血量上限+6` | 铁盾 `伤害减免+1`、龙鳞甲 `所有怪物卡攻击-1` |
| **格式** | `属性：攻击+1` | `效果【类型XXX】：[时机] 动作` 或 `效果【类型XXX】：动作` |

> 遗物可以同时拥有属性和效果（如活力护符：`属性：血量上限+6`，`效果【类型遗物】：[每关卡结束时] 恢复6点血量`）。两者互不隶属。

---

## 效果描述约定

详见 [[技能系统#效果格式]]。所有效果遵循统一格式：

- **位置前缀**：`[场上]` `[道具牌格]` `[登场]`——限定效果生效的位置
- **事件前缀**：`[使用时]` `[战斗时]` `[击杀怪物时]` `[受到伤害时]` 等——描述触发事件
- **时机关键词**：`处于格X时` `移动到格X时` `每移动N次`——描述触发条件

无任何前缀时，效果持续生效或满足内文条件时生效。
