# RUL_战斗

> 纯机制定义。所有虚构名映射见 `[[虚构对照表#二、规则层（RUL）]]`。

---

## RUL_006：交互范围

化身只能与**正交相邻**槽位上的敌方单位或辅助道具进行网格互动。

### 网格互动类型（累计 interactionCount）

| 操作 | 效果 | 触发旋转 |
|:--|:--|:--|
| 点击敌方单位 | 进入战斗结算 | 击杀后旋转 |
| 点击辅助道具 | 拾取到道具槽 | ✅ 旋转 |
| 点击正交相邻空槽 | 触发旋转 | ✅ 旋转 |

- 战斗**未**导致敌方移除 → **不旋转**

### 道具使用

- 从道具槽点击使用，**不受正交相邻限制**，可瞄准网格任意敌方
- 道具使用**不**触发网格旋转，**不**累计 interactionCount

## RUL_005：伤害计算

### 结算流程（按顺序）

```
1. 原始伤害 = max(0, 攻击力 - 伤害减免)
2. 若为无视护甲伤害 → 血量损失 = 原始伤害
3. 否则：
   护甲损失 = min(当前护甲, 原始伤害)
   血量损失 = 原始伤害 - 护甲损失
4. 当前护甲 -= 护甲损失
   当前血量 -= 血量损失
5. 实际扣血最低为 0
```

### 有效属性

每次需要属性值时从头重算（详见 `[[RES_属性管线]]`）：
- **化身**：基础值 → 持久修正 → 条件修正 → 临时修正
- **敌方**：基础值 → 持久修正 → 条件修正

## RUL_004：先手判定

| 情境 | 先手方 |
|:--|:--|
| 双方均无先手技能 | **化身**先 |
| 双方均有先手技能 | **化身**先 |
| 仅一方有先手技能 | **持有方**先 |

先手方优先造成伤害。若先手伤害足以击杀对方，对方无法反击。

化身本身不会拥有先手技能。

## RUL_008~010：事件触发链

### 事件顺序

```
玩家动作
  ↓
执行直接效果
  ↓
伤害/回复/护甲变化结算
  ↓
死亡与移除结算（killMonster → removeCard）
  ↓
触发事件：onKill / onRemove / onUse / onDamageTaken
  ↓
判断旋转条件：
  ├── 击杀敌方 / 拾取道具 / 点击空槽 → 批量补牌 → 旋转
  └── 战斗未击杀 → 不旋转，直接补牌
  ↓
位置/移动触发结算（onMove、移动到槽X等）
  ↓
再次处理死亡与移除（若有）
  ↓
最终批量补牌
  ↓
通关检查
  ↓
解锁输入
```

### killMonster 事件

- 敌方单位因战斗/伤害血量 ≤0 时触发
- 触发后立即触发 removeCard
- 货币发放、`[击杀敌方时]` 被动装备效果在此阶段结算

### removeCard 事件

- 任意单位离开网格时触发（含敌方被击杀、道具被拾取/使用、技能直接移除）
- `[被移除时]` 敌方技能效果在此阶段结算

### 完整触发顺序

```
[受到致命伤害时] → killMonster → [击杀敌方时] → removeCard → [被移除时]
```

## RUL_010：战斗输入锁定

以下状态激活时，禁止发起新战斗交互：
- 战斗结算进行中
- 补牌执行中
- 覆盖层/弹窗显示中

---

## 通关判定

```
运行时抽牌堆为空 且 网格无敌方单位 → 弹出道具三选一 → 房间类型二选一 → 下一节点
```

房间按钮出现后，化身仍可：
- 拾取网格上的道具到道具槽
- 从道具槽使用道具
- 无法再与敌方战斗（已无敌方）

点击房间按钮后：所有未使用道具回到化身侧卡池，每张 +10 货币。
