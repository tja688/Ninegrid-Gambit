# RUL_移动

> 纯机制定义。所有虚构名映射见 `[[虚构对照表#二、规则层（RUL）]]`。

---

## RUL_003：顺时针旋转

### 规则

除槽5 外，网格上其余槽位的所有单位按固定路径**顺时针移动 1 格**。

```
旋转路径：槽1 → 槽2 → 槽3 → 槽6 → 槽9 → 槽8 → 槽7 → 槽4 → 槽1
```

### 触发条件

| 玩家动作 | 是否旋转 |
|:--|:--|
| 战斗导致敌方移除 | ✅ 先补牌 → 再旋转 |
| 战斗未导致敌方移除 | ❌ 不旋转，直接补牌 |
| 拾取道具 | ✅ 先补牌 → 再旋转 |
| 点击正交相邻空槽 | ✅ 先补牌 → 再旋转 |
| 道具槽使用道具 | ❌ 不旋转 |

### 技能触发的特殊位移

`EVT_SKILL_016`：每移动 3 次，与随机敌方单位**交换位置**。

`EVT_SKILL_034`：[登场] 时旋转一次。

`EVT_SKILL_051`：与化身战斗后旋转一次。

`EVT_SKILL_xx`（竖向拉杆）：
- 移动到槽7 时：槽1→槽7，槽4→槽1，槽7→槽4
- 移动到槽3 时：槽3→槽6，槽6→槽9，槽9→槽3

`EVT_SKILL_xx`（决斗）：与化身战斗后，所有单位不再移动直到本卡被移除。

## 道具在网格上的移动触发

部分道具在网格上移动时自动触发效果：

| 道具 | 触发条件 | 效果 |
|:--|:--|:--|
| `EVT_ITEM_007` | 移动到槽3 且槽6 为非精英非Boss 敌方 | 移除槽6 敌方，之后自移除 |
| `EVT_ITEM_018` | 移动到化身相邻时 | 化身恢复 2 血量 |
| `EVT_ITEM_023` | 移动到槽1/3/7/9 时 | 对随机敌方造成 3 伤害，触发 4 次后移除 |
| `EVT_ITEM_024` | 处于槽1 时 | 对敌方使用的道具触发 2 次 |
| `EVT_ITEM_027` | 移动到化身相邻时 | 对化身造成 2 伤害 |
