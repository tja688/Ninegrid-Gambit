# FLOW_关卡循环

> 纯机制定义。所有虚构名映射见 `[[虚构对照表#三、流程层（FLOW）]]`。

---

## FLOW_001~003：整体结构

### 三层九节点架构

```
大阶段 ×3（FLOW_001）
  └── 每阶段 9 个作战节点（FLOW_002）
       ├── 节点 1-3：弱精英配置池（FLOW_003）
       ├── 节点 4-6：强精英配置池
       └── 节点 7-9：Boss 配置池
```

总计 3 × 9 = 27 个节点。击破第 3 阶段 Boss 后游戏通关。

---

## FLOW_004：节点结算状态机

每个节点固定按以下阶段顺序执行，前一阶段未完成不得进入下一阶段：

```
1. 构建敌方卡池
2. 重置节点状态（化身固定在槽5）
3. 开局发牌（见 RUL_发牌）
4. 玩家互动循环（战斗/拾取/旋转）
5. 通关检查（抽牌堆空 + 网格无敌方）
6. 道具三选一（可跳过 +10 货币）
7. 房间类型二选一
8. 执行房间事件
9. 提交结果 → 下一节点
```

> 敌方卡池不跨节点继承，道具使用后默认永久移除。

---

## FLOW_005：通关条件

```
运行时抽牌堆为空 AND 网格无敌方单位 → 通关
```

通关后流程：
1. 弹出道具三选一覆盖层
2. 选择结束 → 弹出二选一房间按钮
3. 点击房间按钮前，化身仍可拾取网格道具和使用道具槽道具
4. 点击房间按钮 → 结算未使用道具（回化身侧卡池 + 每张 +10 货币）
5. 进入所选房间 → 执行房间事件 → 下一节点

---

## FLOW_006：房间类型

通关后从两种房间类型中二选一：

| 房间 ID | 效果 |
|:--|:--|
| `ROOM_SHOP` | 展示 6 张道具供购买（加入化身侧卡池）；可出售道具（每张 +10 货币） |
| `ROOM_GOLD` | 获得 50 货币 |
| `ROOM_CHEST` | 三选一被动装备（白 65% / 蓝 30% / 金 5%） |
| `ROOM_SPRING` | 血量上限 +4，血量回满 |
| `ROOM_TAVERN` | 四个可选动作各限一次：①恢复 10 血量（-20 货币）、②基础护甲+1（-30 货币）、③随机获得 1 道具（-50 货币）、④离开 |

## 精英/Boss 击杀奖励

| 单位类型 | 击杀后洗入抽牌堆的道具 |
|:--|:--|
| 精英 | 1×蓝色宝箱 `EVT_ITEM_022` + 1×货币道具 `EVT_ITEM_015` + 1×属性提升 `EVT_ITEM_025` |
| Boss | 1×金色宝箱 `EVT_ITEM_026` + 2×货币道具 `EVT_ITEM_015` + 1×属性提升 `EVT_ITEM_025` |
