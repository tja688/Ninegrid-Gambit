# FLOW_交互流程

> 纯机制定义。所有虚构名映射见 `[[虚构对照表#三、流程层（FLOW）]]`。

---

## 玩家操作状态机

```
[等待输入]
  ├── 点击正交相邻敌方 → 战斗结算
  ├── 点击正交相邻道具 → 拾取到道具槽
  ├── 点击正交相邻空槽 → 触发旋转
  ├── 点击道具槽道具 → 使用道具（不触发旋转）
  └── 点击房间按钮 → 进入下一节点
```

---

## 道具交互流程（FLOW_007）

### 道具槽规则

- 上限 5 格
- 道具放入后不受交互距离限制，可瞄准网格任意敌方

### 道具使用流程

```
点击网格道具 → 放入道具槽 → 从道具槽点击使用 → 永久移除（默认）
```

- 标注"使用后复原"的道具：关卡结束后回到化身侧卡池
- 关卡结束时未使用道具：全部回到化身侧卡池 + 每张 +10 货币

## 界面覆盖层跳转（FLOW_UI）

| 触发条件 | 弹出面板 | 操作 |
|:--|:--|:--|
| 通关 | 道具三选一 | 选一张或跳过（+10 货币） |
| 通关选择后 | 房间二选一 | 选择进入下一节点 |
| 击杀强精英 | 技能三选一（导师） | 永久习得一项技能 |
| 使用宝箱道具 | 被动装备三选一 | 选一件或跳过（+20 货币） |
| 进入商店 | 6 张道具展示 | 购买/出售 |
| 进入酒馆 | 4 个动作选项 | 各限一次 |
| 被动装备满 12 格 | 满格提示 | 需先丢弃再选择 |

---

## 输入锁定条件

以下状态激活时，玩家输入被锁定：
- 战斗结算中
- 补牌执行中
- 任何覆盖层/弹窗显示中
