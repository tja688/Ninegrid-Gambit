## PRO_001：被动装备基础规则

### 装备栏

- 上限 **12** 件
- 右键丢弃返还 20 货币
- 同类被动装备不重复出现（宝箱自动排除已有）

### 获取途径

宝箱道具打开后三选一：
- 底部提供跳过按钮（+20 货币）
- 装备栏满 12 格时，弹出"满格"提示，需先丢弃

## PRO_010：套装系统

同时持有特定组合的三件被动装备时触发额外加成：

| 组件 A | 组件 B | 组件 C | 套装效果 |
|:--|:--|:--|:--|
| `EVT_RELIC_002` | `EVT_RELIC_003` | `EVT_RELIC_004` | A 基础护甲 +2、B 攻击 +2、C 血量上限 +8 |

## 被动装备效果分类

### 按触发时机

| 触发时机 | 示例 |
|:--|:--|
| 常驻（无前缀） | `EVT_RELIC_031`：伤害减免+1 |
| `[使用道具时]` | `EVT_RELIC_001`：恢复 2 血量 |
| `[击杀敌方时]` | `EVT_RELIC_010`：对随机敌方造成 4 伤害 |
| `[战斗时]` | `EVT_RELIC_015`：敌方有护甲时攻击+3 |
| `[受到伤害时]` | `EVT_RELIC_021`：每受 5 伤害获 1 血量上限 |
| `[受到致命伤害时]` | `EVT_RELIC_052`：恢复 50% 血量并移除 |
| `[每关卡开始时]` | `EVT_RELIC_006`：加入 2 张特定道具 |
| `[每关卡结束时]` | `EVT_RELIC_035`：恢复 6 血量 |
| `[旋转时]` | `EVT_RELIC_028`：多旋转 1 次 |
| `[互动时]` | `EVT_RELIC_045`：下次补牌敌方受伤 |
| `[获得时]` | `EVT_RELIC_050`：加入 2 张宝箱道具（仅 1 次） |

### 按定位标签

| 主标签 | 含义 |
|:--|:--|
| 道具 | 围绕道具使用触发 |
| 护甲 | 围绕护甲属性 |
| 属性 | 纯数值加成 |
| 杀怪 | 击杀敌方后触发 |
| 经济 | 影响货币 |
| 血量 | 围绕血量属性 |
| 位移 | 影响网格位置/旋转 |
| 恢复 | 提供血量恢复 |
| 纯属性 | 纯数值无触发 |
| 条件爆发 | 满足条件大幅加成 |
| 成长 | 数值随条件逐步增长 |
