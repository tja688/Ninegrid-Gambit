# 帮助卡数据

全帮助卡效果、品质、价格一览。具体使用规则见 [[游戏开发项目/九宫牌局/02-卡牌/帮助卡系统]]。

## 数据结构说明（AI 解析用）

以下字段映射表用于将下方人类可读的效果文本转换为代码数据结构：

| 代码字段 | 对应的人类描述 | 说明 |
|:--|:--|:--|
| trigger | "使用时"/"被移除时"/"移动到格X时"等前缀 | 触发时机 |
| zone | "场上"/"道具牌格"等位置前缀 | 效果所在区域 |
| condition | 描述中的"若…""当…时"条件句 | 触发条件 |
| effect | 描述中的实际效果动作 | 如扣血、加攻、移除等 |
| duration | "本关卡永久"/"战斗一次后复原"等 | 效果持续时间 |
| targetFilter | "目标怪物卡"/"所有怪物卡"/"非玩家卡" | 目标过滤 |

> 例如：滚石 — [场上] 移动到格3时，若格6为普通怪物卡，移除格6怪物卡、移除本卡
> → {trigger:'onMoveToSlot', condition:'slot==3 && slot6.isMonster && !slot6.isElite && !slot6.isBoss', effects:['remove(slot6)','remove(self)']}
