# 音效打点探查文档

> 生成日期：2026-07-05  
> 范围：Ninegrid Gambit 全项目代码深度探查  
> 现状：**项目零音频实现**，但架构事件驱动完备，QFramework AudioKit 已安装未接入

---

## 0. 现有音频基础设施

| 设施 | 状态 | 说明 |
|------|------|------|
| QFramework AudioKit | 已安装，未调用 | `Assets/QFramework/Toolkits/AudioKit/` — 提供 `PlayMusic()`、`PlaySound()`、`PlayVoice()`、音量控制、同音防叠 |
| Unity Audio Module | 已启用 | `com.unity.modules.audio` 在 manifest.json 中 |
| AudioListener | 1个 | MainScene.unity 主相机上 |
| 游戏音频脚本 | 无 | 全项目无任何 Audio/Sound/SFX/Music 相关代码 |
| 游戏音频资产 | 无 | 无 .wav/.mp3/.ogg 文件（仅第三方插件 demo 音频） |
| Feel 插件 | 已安装 | 含 MMFeedbacks 反馈系统，可在 Inspector 中绑定音效触发 |
| TextAnimator | 已安装 | 含打字机音效样本（3个 .ogg），支持 TextAnimatorTag 触发 |

**最佳接入方式**：构建一个 `AudioManager` 单例订阅各系统的 C# 事件，或直接在已有 UnityEvent 钩子上挂 AudioKit 调用。

## 10. 接入架构建议

### 10.1 推荐方案：事件订阅式 AudioManager

```
GameFlowController.StateChanged ──┐
BattleController.BattleFinished ──┤
BattleController.EnterCompleted ──┤
HydraulicSceneController.* ───────┤──→ AudioManager（单例）──→ AudioKit.PlaySound()
DialogueSystem.* ─────────────────┤                           AudioKit.PlayMusic()
WinchCrankController.Clicked ─────┤
AnchorRammingController.UnityEvent──→ Inspector 直挂 AudioKit 调用
```

### 10.2 零代码改动可接线的 6 个 UnityEvent

`AnchorRammingController` 上的 `onRamBegin`、`onCrankBegin`、`onPreImpact`、`onImpact`、`onBounce`、`onRamEnd` 可在 Inspector 中直接添加 AudioKit PlaySound 回调，**无需修改任何代码**。

### 10.3 需要注意的技术细节

- **TimeScale**：战斗系统大量使用 `Time.timeScale = 0`（顿帧）和 `0.22x`（慢动作），音效需设 `AudioSource.ignoreListenerPause = true` 或使用 unscaled 模式播放
- **音高/音量动态调制**：绞盘连打 (#21) 的 `Intensity01` 应映射到音高 (0.8→1.5) 和音量 (0.3→1.0)
- **冲击力缩放**：撞击 BOOM (#18) 的音量应按 `AnchorRammingController` 的实际冲击力值缩放
- **同音防叠**：AudioKit 已内置同音防叠机制，适合绞盘连打等高频触发场景
- **TextAnimator 打字音效**：TextAnimator 插件已原生支持打字机音效 tag，可直接在对话文本中嵌入 `<sound=typewriter>` 标签

### 10.4 分阶段落地建议

**第一阶段（核心体感，22 个 S 级）**：场景过渡 + 战斗起止 + 撞击全流程 + 锻造冲压 + 序章演出 + 战斗 BGM  
**第二阶段（完善体验，38 个 A 级）**：锚链物理 + 绞盘连打 + 锻造进出 + 对话系统 + UI 面板 + 环境音  
**第三阶段（精细打磨，24 个 B 级）**：HP 消耗 + 钻头部署 + 通知弹出 + 岛屿/路线 UI  
**第四阶段（锦上添花，14 个 C 级）**：悬停微反馈 + 衰减音 + 背景底噪
