# Systems — 系统一览

源码根：`Systems/`。全部实现 `QFramework.ISystem`，在 `NineGridArchitecture.Init` 注册。

## 0. 调用关系总图

```text
IPhaseSystem ──enqueue──► IActionPipelineSystem ──Dispatch──► ITriggerSystem
     │                           │                              │
     │                           │ Apply GameAction             ├─► IEffectSystem (反应)
     │                           ▼                              ├─► IEconomySystem (OnRemove)
     ├─► IBoardSystem (邻接)     EventLog                       └─► IRewardSystem (OnKill)
     ├─► IDeckSystem (清场)
     ├─► IStatSystem (攻防规则)
     ├─► IContentSystem / IRewardSystem / IEconomySystem
     └─► IPresentationSyncSystem (LegalCommands 输入锁)

IContentSystem ──Activate──► IEffectSystem ──Register──► ITriggerSystem
IBattleScopeSystem ──ClearModifiers──► IStatSystem (+ 全卡 StatBlock)
IBoardSystem / IDeckSystem / IEconomySystem / IRewardSystem
     └──► IActionPipelineSystem.Execute / RunToCompletion
```

## 1. ActionPipelineSystem

| 相对路径 | 类型名 | 职责 |
| --- | --- | --- |
| `Systems/ActionPipelineSystem.cs` | `IActionPipelineSystem` / `ActionPipelineSystem` | Action 队列 + 反应栈；写 `EventLog`；驱动 Trigger |
| 同上 | `Evt_ActionRejected` | 拒收时 `SendEvent` 的载荷 |

**公开方法：** `Enqueue`, `PushReaction`, `Execute`, `RunToCompletion`, `RejectCommand`, `Clear`；属性 `EventLog`, `IsRunning`, `PendingCount`。

**读写 Model：** 不直接改 Model；通过 `GameAction.Apply` 间接写。

**执行语义：**

1. 反应栈优先于队列  
2. 单次 `ResolveAction`：`ActionStarted` → Pre triggers → `Apply` → 追加事件 → Post triggers → FollowUp 反应 → `ActionFinished`  
3. 反应链深度上限 64  
4. `RejectCommand` 写 `ActionRejected` 事件并触发 `OnActionRejected`

**依赖：** `ITriggerSystem`。

## 2. PhaseSystem

| 相对路径 | 类型名 | 职责 |
| --- | --- | --- |
| `Systems/PhaseSystem.cs` | `IPhaseSystem` / `PhaseSystem` | 相位门禁 + 全部玩家/导演命令编排 |

**公开方法（接口）：**  
`CurrentPhase`, `LegalCommands`, `CanExecute`,  
`StartNode`, `Attack`, `ResolvePlayerAttackTargetUid`,  
`ApplyCombatHit`, `ResolvePostKillBoard/Fill/Rotate`, `ResolveFusionRefill`, `ResolveDrainRefill`,  
`PickupItem`, `ApplyPickupItem`, `ApplyUseItem`, `ClickEmpty`,  
`UseItem`（重载）, `SelectReward`, `SkipHelpChoice`, `SelectRoom`, `EnterRoom`。

**读写 Model：** `RunModel.Phase`, `BoardModel`, `CardRegistry`, `DeckModel`, `PlayerModel`, `PendingChoiceModel`。

**关键调用：**

| 方法 | 管线动作要点 |
| --- | --- |
| `StartNode` | ClearPending → 相位链 → SetupNodeDeck → OpeningDeal → Fill → ResetArmor → NodeStarted → InteractionLoop |
| `Attack` | 邻接/嘲讽校验 → BeginEngagement → 先攻互殴 → EndBattleScope；击杀则整拍旋转补牌 |
| `ApplyCombatHit` | 无相位门禁；单段伤害；可选 engagement |
| `ResolvePostKillFill/Rotate` | 导演分拍：Fill 与 Rotate+清场分离 |
| `CompleteNodeIfCleared`（私有） | 清场 → NodeCompleted → `SettleUnusedHelpCards` → OfferReward `help.choice`×3 |

**LegalCommands：** 受 `IPresentationSyncSystem.IsInputLocked` 影响；锁定期仅 `PresentationFinished` + 待选奖励/房间命令。

**未完成痕迹：** 注释写明 `InteractionRange` 未接入邻接判定。

## 3. BoardSystem

| 类型 | 职责 |
| --- | --- |
| `IBoardSystem` / `BoardSystem` | 邻接（含 VirtualAdjacency 规则）、空槽、旋转/交换/补牌入口 |

**公开：** `ClockwisePath`, `AreAdjacent`（3 重载）, `IsSlotAvailable`, `RotateClockwise`, `Swap`, `FillEmptySlots`。

**读写：** 读 `BoardModel`/`CardRegistry`；写经 `IActionPipelineSystem`。

**依赖：** `IStatSystem.EvaluateRule(RuleId.VirtualAdjacency)`（怪↔怪）。

---

## 4. DeckSystem

| 类型 | 职责 |
| --- | --- |
| `IDeckSystem` / `DeckSystem` | 节点牌组 setup 封装；敌军存在性；清场判定 |

**公开：** `SetupNode`, `HasEnemyOnBoard`, `HasEnemyInDrawPile`, `HasPendingEnemyCards`, `IsNodeCleared`。

**清场条件：** `DrawPile` 空 && `EnemyCardPool` 空 && 盘上无 Monster。

**读写：** 读 `DeckModel`/`BoardModel`/`CardRegistry`；写经管线。

---

## 5. ContentSystem

| 类型 | 职责 |
| --- | --- |
| `IContentSystem` / `ContentSystem` | Catalog 加载、校验、Draft、激活卡/技能/遗物效果 |
| `ContentValidationReport` | Issues / Implemented / Pending 列表 |

**公开：** `Catalog`, `HasCatalog`, `Load`, `TryReloadFromConfig`, `ValidateCatalog`, `CreateDraft`, `ApplyContentToCard`, `ActivateCardEffects`, `ActivatePlayerSkill`, `ActivateRelic`, `DeactivateRuntimeEffectsByOwner`, `ClearRuntimeEffects`。

**读写：** 无直接 Model 写；经 `IEffectSystem` 激活；跟踪 `mRuntimeEffectInstanceIds`。

**依赖：** `IConfigUtility`（键 `ContentConfigKeys.DefaultCatalog`）、`IEffectSystem`。仅 `Implemented` 状态效果会激活。

---

## 6. EconomySystem

| 类型 | 职责 |
| --- | --- |
| `IEconomySystem` / `EconomySystem` | 跳过奖励金币、未用帮助卡结算、删卡卖金、怪物移除金 |

**公开：** `AwardSkipHelpChoice`, `AwardSkipRelicChoice`, `SettleUnusedHelpCards`, `DeleteHelpCard`, `RebindSystemTriggers`。

**Trigger：** `OnRemove` Post → 非 `GoldReward` 计数的 Monster 发 `MonsterRemovedGold`。

**读写：** `PlayerModel`（帮助卡回库）、`CardRegistry`/`BoardModel`/`DeckModel`；金币经 `ModifyGoldAction`。

**注意：** `InitialGameFactory` Clear Trigger 后必须 `RebindSystemTriggers`。

---

## 7. RewardSystem

| 类型 | 职责 |
| --- | --- |
| `IRewardSystem` / `RewardSystem` | 奖励池抽取、房间选项、节点 `NodeDeckOptions` 构建、房间结算 |

**公开：** `RollPool`, `RollRoomChoices`, `BuildNodeDeckOptions`, `ResolveRoom`, `RebindSystemTriggers`。

**Trigger：** `OnKill` Post → Elite/Boss 池 `kill.elite` / `kill.boss` → `ShuffleIntoDrawPileAction`。

**读写：** 读 `PlayerModel`/`RunModel`/`BoardModel`；写经管线。部分池 ID 硬编码稀有度权重（`help.choice`、`shop.helpCards`、箱子池等）。

---

## 8. StatSystem

| 类型 | 职责 |
| --- | --- |
| `IStatSystem` / `StatSystem` | 有效属性、卡上 Modifier、全局 `RuleModifierRegistry` |

**公开：** `RuleModifiers`, `CreateContext`, `GetEffectiveValue`/`GetEffectiveInt`, `Add/RemoveModifier*`, `ClearModifiersByScope`, `EvaluateRule`。

**读写：** 改 `CardInstance.Stats`；规则改 `RuleModifiers`；上下文读 Registry/Board/Player。

---

## 9. TriggerSystem

| 类型 | 职责 |
| --- | --- |
| `ITriggerSystem` / `TriggerSystem` | 按 `(TriggerTiming, TriggerPoint)` 注册/分发反应 |
| `TriggerContext` | 触发上下文；`TryReserveFragmentMerge` 批次去重 |
| `ITriggerReaction` / `DelegateTriggerReaction` | 反应接口与委托实现 |

**公开：** `Register`→`IUnRegister`, `Unregister`, `Dispatch`, `Clear`。

**Dispatch：** 快照列表 → 各 `React` → 合并 `GameAction` 列表（由管线 PushReaction）。

---

## 10. BattleScopeSystem

| 类型 | 职责 |
| --- | --- |
| `IBattleScopeSystem` / `BattleScopeSystem` | 交战敌人 UID；清理 `UntilEnemyChanges` / `UntilBattleEnds` 修饰 |

**公开：** `EngagedEnemyUid`, `BeginPlayerMonsterEngagement`, `EndCurrentBattle`, `ClearScopedModifiers`。

**读写：** `BattleContextModel`；清 `IStatSystem.RuleModifiers` + 全卡 `ClearModifiersByScope`。
