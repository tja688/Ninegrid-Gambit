# Commands & Queries — 命令与查询

源码：`Commands/CoreCommands.cs`、`Queries/EffectiveStatQuery.cs`；结果类型在 `Domain/Commands/CoreCommandResult.cs`。

全部命令为 `AbstractCommand<CoreCommandResult>`，经 `IArchitecture.SendCommand` 或 `CoreCommandDispatcher.Send` 执行；本体委托 `IPhaseSystem` 或 `IPresentationSyncSystem`。

## 1. 契约：`CoreCommandResult`

| 字段 | 含义 |
| --- | --- |
| `Accepted` | 是否接受 |
| `Reason` | 拒收原因（接受时为空） |
| `ResolvedActions` | 管线本轮解析的 Action 数（拒收为 0） |

工厂：`Accept(int resolvedActions)` / `Reject(string reason)`。

## 2. 命令一览

| 相对路径 | 类型名 | 一句话职责 | 委托 |
| --- | --- | --- | --- |
| `Commands/CoreCommands.cs` | `StartNodeCommand` | 开始节点；构造参数 `NodeDeckOptions` | `IPhaseSystem.StartNode` |
| 同上 | `AttackCommand` | 攻击槽位；含相位/邻接/嘲讽门禁 | `Attack` |
| 同上 | `CombatHitCommand` | 表现可信单段伤害；无交互门禁 | `ApplyCombatHit` |
| 同上 | `ResolvePostKillBoardCommand` | 击杀后整拍：计数+补牌+旋转+清场 | `ResolvePostKillBoard` |
| 同上 | `ResolvePostKillFillCommand` | 击杀后分拍：计数+补牌 | `ResolvePostKillFill` |
| 同上 | `ResolvePostKillRotateCommand` | 击杀后分拍：旋转+清场 | `ResolvePostKillRotate` |
| 同上 | `ResolveFusionRefillCommand` | 融合补牌分拍；`skipFill` 可开空批 | `ResolveFusionRefill` |
| 同上 | `ResolveDrainRefillCommand` | drain 补牌分拍；`skipFill` 可开空批 | `ResolveDrainRefill` |
| 同上 | `PickupItemCommand` | 拾取（相位门禁） | `PickupItem` |
| 同上 | `ClickEmptyCommand` | 点空槽 | `ClickEmpty` |
| 同上 | `UseItemCommand` | 使用道具/帮助卡（相位门禁）；可选 selectedUids/option | `UseItem` |
| 同上 | `ApplyUseItemCommand` | 可信用牌（无相位门禁） | `ApplyUseItem` |
| 同上 | `SelectRewardCommand` | 选奖励选项索引 | `SelectReward` |
| 同上 | `SkipHelpChoiceCommand` | 跳过帮助卡选择 | `SkipHelpChoice` |
| 同上 | `SelectRoomCommand` | 选房间选项索引 | `SelectRoom` |
| 同上 | `EnterRoomCommand` | 进入已选房间 | `EnterRoom` |
| 同上 | `PresentationFinishedCommand` | 表现批次 Ack；参数 `batchId` | `IPresentationSyncSystem.FinishBatch` |

### 命令分组（按用途）

| 组 | 命令 | 备注 |
| --- | --- | --- |
| 玩家交互（门禁） | StartNode, Attack, PickupItem, ClickEmpty, UseItem, Select*, Skip*, EnterRoom | 受 `LegalCommands` / 相位约束 |
| 导演可信 | CombatHit, ApplyUseItem | 注释标明跳过部分门禁 |
| 导演分拍 | ResolvePostKillFill/Rotate, ResolveFusion/DrainRefill | 与整拍 `ResolvePostKillBoard` 并存 |
| 表现同步 | PresentationFinished | Dispatcher 对此不开新批 |

`GameCommandKind` 枚举与上表对应（含 `ApplyPickupItem` 等 Phase API；**无**独立 `ApplyPickupItemCommand` 类——拾取可信入口目前只有 Phase 方法 `ApplyPickupItem`，命令层仅有 `PickupItemCommand`）。

## 3. 查询

| 相对路径 | 类型名 | 一句话职责 | 关键依赖 |
| --- | --- | --- | --- |
| `Queries/EffectiveStatQuery.cs` | `EffectiveStatQuery` | `AbstractQuery<int>`：按 cardUid + StatId 取有效整型属性 | `CardRegistry`, `IStatSystem` |

用法：`architecture.SendQuery(new EffectiveStatQuery(uid, StatId.Attack))`。

目录内仅此一个 Query 文件。

## 4. 与 Dispatcher 的关系

`CoreCommandDispatcher.Send` 包装任意 `ICommand<CoreCommandResult>`：执行命令、从 EventLog 切片建批、条件性 `OpenBatch`。详见 [内核表现桥](../Presentation/内核表现桥.md)。

## 5. 公开 / 内部

| 类别 | 内容 |
| --- | --- |
| 公开 | 全部 Command 类、`EffectiveStatQuery`、`CoreCommandResult` |
| 内部 | 各 Command 私有字段；无额外内部类型 |
