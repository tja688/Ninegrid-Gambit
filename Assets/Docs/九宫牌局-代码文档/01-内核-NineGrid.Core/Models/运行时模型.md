# Models — 运行时模型

源码根：`Models/`。均为 QFramework `AbstractModel`（`CardInstance`/`HelpCardStackEntry`/`CounterBag` 除外），在 `NineGridArchitecture.Init` 中 `RegisterModel`。状态变更普遍通过 `BindableProperty` + `Version` 递增通知。

## 1. 生命周期总览

```text
Architecture.Init
  → 各 Model.OnInit：惰性创建 BindableProperty

InitialGameFactory.Create
  → Clear 效果/触发/管线/表现锁
  → registry.Clear / board.Reset / deck.Clear / player.Reset
  → run.Reset(seed) / pendingChoice.Clear / battleContext.Reset
  → 创建 Avatar → board.SetAvatar(Board5) → 职业技能与帮助卡堆

StartNode / 节点内 Actions
  → SetupNodeDeck：清盘上牌与非 Avatar 实例；重建暂存池
  → OpeningDeal / Fill / Rotate / Remove / Kill …
  → PendingChoice Offer/Clear
  → RunModel 相位与 AdvanceNode（可 Victory）

节点结束 / 失败重开
  → InitialGameFactory 再次全量重置（含效果与 Trigger Rebind）
```

`CardInstance` 生命周期：`CardRegistry.Create` → 进入 Zone/Slot → `Remove`/`Kill` 改 Zone → 节点重置时非 Avatar `registry.Remove`。

## 2. 文件与字段

### CardInstance / CounterBag

| 相对路径 | 类型名 | 一句话职责 | 关键依赖 |
| --- | --- | --- | --- |
| `Models/CardInstance.cs` | `CardInstance` | 单卡运行时：Uid/DefId/Kind/Stats/Counters/Zone/Slot/EffectIds | Registry, Actions |
| 同上 | `CounterBag` | 字符串→int 计数器 | `CoreCounterKeys` |

字段：`Uid`, `DefId`, `Kind`, `StatBlock Stats`, `CounterBag Counters`, `BindableProperty<ZoneId> Zone`, `BindableProperty<SlotId> Slot`, `EffectIds`（列表）。

### CardRegistry

| 类型 | 职责 |
| --- | --- |
| `CardRegistry` | UID 分配与卡字典 |

字段/API：`Version`, `Cards`, `Create`, `Get`/`TryGet`, `MoveCard`, `Remove`, `Clear`（`mNextUid=1`）。

### BoardModel

| 类型 | 职责 |
| --- | --- |
| `BoardModel` | 1..9 槽 UID 映射、Avatar、Blessed 标记 |

字段：`Version`, `AvatarUid`, `AvatarSlot`；内部 `mCardUidsBySlot[10]`, `mBlessedSlots[10]`。

API：`GetCardUid`, `IsEmpty`, `BoardCardUids`, `SetAvatar`, `PlaceCard`, `ClearSlot`, `RemoveCard`, `IsBlessed`/`SetBlessed`, `IsMarked`/`SetMark`/`CountMarkedSlots`, `ClearBoardCards`, `Reset`。

Avatar `Zone=Avatar`，盘上牌 `Zone=Board`。

### DeckModel

| 类型 | 职责 |
| --- | --- |
| `DeckModel` | 抽牌堆 + 节点暂存池 + 道具槽 |

列表：`DrawPileUids`, `PlayerCardPoolUids`, `EnemyCardPoolUids`（注释：仅节点 setup 暂存，OpeningDeal 排空）, `ItemSlotUids`；`Version`。

API：`AddToDrawPile`/`PlayerCardPool`/`EnemyCardPool`/`ItemSlots`, `RemoveCard`/`RemoveUid`, `TryPeekDrawPile`, `ReorderDrawPile`, `Clear`。

### PlayerModel

| 类型 | 职责 |
| --- | --- |
| `PlayerModel` | 金币、交互计数、职业、遗物/技能/帮助卡堆、玩家侧 StatBlock |

字段：`Stats`, `Coins`, `InteractionCount`, `ProfessionId`, `Version`, `RelicDefIds`, `SkillDefIds`, `HelpCardStacks`。

API：`SetProfession`, `AddCoins`, `AddInteractionCount`, `Add/RemoveRelic`, `Add/RemoveSkill`, `AddHelpCard`, `TryRemoveHelpCard`, `CountHelpCardsByDefId`, `TotalHelpCardCount`, `ConsumeHelpCardStacksForNode`（节点开始清空并返回快照）, `Reset`。

### HelpCardStackEntry

| 类型 | 职责 |
| --- | --- |
| `HelpCardStackEntry` | `(DefId, Count)` 不可变条目 |

### RunModel

| 类型 | 职责 |
| --- | --- |
| `RunModel` | 楼层/节点/种子/房间/相位 |

常量：`NodesPerFloor=9`, `FinalFloor=3`。  
字段：`Floor`, `NodeIndex`, `Seed`, `Room`, `Phase`, `Version`。  
API：`Reset(seed)`（Phase→BuildEnemyPool, Room→Battle）, `SetPhase`, `AdvanceNode`（跨层；完成第 3 层返回 true）。

### BattleContextModel

| 类型 | 职责 |
| --- | --- |
| `BattleContextModel` | `EngagedEnemyUid` 供 UntilEnemyChanges 清理 |

API：`Reset`, `SetEngagedEnemy`。

### PendingChoiceModel

| 类型 | 职责 |
| --- | --- |
| `PendingChoiceModel` | 奖励三选一 / 房间二选一 待选状态 |

字段：`Kind`, `PoolId`, `SelectedRoom`, `Version`, `RewardOptions`, `RoomOptions`。  
API：`OfferRewards`, `ClearRewardChoices`, `OfferRooms`, `SelectRoom`, `Clear`。

## 3. Model ↔ System 读写矩阵（摘要）

| Model | 主要写入方 | 主要读取方 |
| --- | --- | --- |
| CardRegistry | CardDraft.Create, Setup/Spawn/Kill Actions | 几乎全部 |
| BoardModel | Place/Remove/Rotate/Swap/SetAvatar/Mark | Board/Phase/Effects |
| DeckModel | Setup/Opening/Fill/Pickup/Shuffle… | Deck/Phase/Economy |
| PlayerModel | Gold/Help/Relic/Skill/Profession Actions | Economy/Reward/Phase |
| RunModel | ChangePhase, AdvanceNode, Reset | PhaseSystem |
| BattleContextModel | BattleScopeSystem | BattleScope |
| PendingChoiceModel | Offer*/Clear*/SelectRoom Actions | PhaseSystem |

## 4. 公开 / 内部

| 类别 | 内容 |
| --- | --- |
| 公开 | 全部 Model 类型与上表 API；`CardInstance`/`CounterBag`/`HelpCardStackEntry` |
| 内部 | 各 Model 私有数组/列表；`Touch()` |

无空目录；无占位空 Model。
