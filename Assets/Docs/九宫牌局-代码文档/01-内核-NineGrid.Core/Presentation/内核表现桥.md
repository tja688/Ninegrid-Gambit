# Presentation — 内核表现桥

源码根：`Presentation/`。内核不播放动画；把 `EventLog` 切片映射为 `PresentationBatch`，并用 `IPresentationSyncSystem` 管理输入锁与批次 Ack。

## 1. 对外契约（推荐路径）

```text
var dispatcher = new CoreCommandDispatcher(architecture);
var result = dispatcher.Send(new AttackCommand(slot));
// result.Accepted && result.BatchOpened
//   → 表现层消费 result.Batch.Instructions + Batch.Snapshot
//   → 播放结束后：
dispatcher.Send(new PresentationFinishedCommand(result.Batch.BatchId));
```

也可直接：

- `architecture.SendCommand(...)` 后自行 `PresentationBatchFactory.FromEventLog`
- `IPresentationSyncSystem.OpenBatch` / `FinishBatch`
- 订阅 `Evt_PresentationBatchOpened` / `Cleared` / `FinishRejected`

**契约要点（代码事实）：**

1. 仅当命令 **Accepted**、发送前 **未锁输入**、且命令不是 `PresentationFinishedCommand` 时，Dispatcher 才 `OpenBatch`。  
2. 拒收命令不打开批次（避免导演门卡死）。  
3. `RequiresAcknowledgement` = 批次内任一条目 `LocksInput==true`；无阻塞指令仍须 `FinishBatch` 关闭（注释：导演锁步）。  
4. `PhaseSystem.LegalCommands` 在 `IsInputLocked` 时主要只放行 `PresentationFinished` + 待选命令。

## 3. PresentationSyncSystem API

| 成员 | 行为 |
| --- | --- |
| `IsInputLocked` | Open 时若 `batch.RequiresAcknowledgement` 则为 true |
| `ActiveBatchId` / `ActiveBatch` | 当前打开批次 |
| `OpenBatch` | 设置状态；非 null 时发 Opened |
| `FinishBatch(batchId)` | 校验 ActiveBatchId；匹配则 Clear(acknowledged:true)；否则 Reject + FinishRejected 事件 |
| `Clear()` | 无 Ack 清除（工厂重置用） |

## 4. CoreCommandDispatcher

构造：`CoreCommandDispatcher(IArchitecture, firstBatchId=1)`。  
`Send(ICommand<CoreCommandResult>)`：

1. 记录 EventLog `startIndex` 与是否已锁  
2. `architecture.SendCommand(command)`  
3. `PresentationBatchFactory.FromEventLog(..., mNextBatchId++, Capture)`  
4. 条件满足则 `OpenBatch`  
5. 返回 `CoreCommandDispatchResult`

## 5. 事件映射策略（摘要）

`PresentationEventMap` 为每个 `CoreEventType` 指定：

- `RequiresPlayback`：是否进入批次指令列表  
- `LocksInput`：是否使批次阻塞输入  

示例（非全表）：

| CoreEventType | Instruction | Playback | Lock |
| --- | --- | --- | --- |
| ActionStarted/Finished | Mark* | false | false |
| ActionRejected | ShowRejectedIntent | true | true |
| DamageDealt / HpChanged / ArmorChanged | ShowDamage / Update* | true | true |
| CardKilled / CardMoved / BoardRotated | Kill/Move/Rotate | true | true |
| SlotsFilled / InteractionChanged | Fill/UpdateInteraction | true | false |
| RewardOffered / RoomChoicesOffered | Offer* | true | true |
| ContentLoaded | LoadContent | true | false |

无映射的事件类型：`Get` 抛 `InvalidOperationException`。

## 6. CoreViewSnapshot

`CoreViewSnapshotFactory.Capture` 聚合：

- 全卡 `CardView`（含 base/effective 属性）  
- `BoardView`（槽 + Avatar）  
- `DeckView`（各堆 UID）  
- `RunView` / `PlayerView` / `ChoiceView`  

供表现层在批次边界对齐权威状态。
