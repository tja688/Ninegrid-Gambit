# Domain — 领域模型

源码根：`Domain/`。存放纯领域类型：枚举、值对象、草稿、事件日志、属性管线、以及全部 `GameAction` 子类。无 QFramework System 注册。

### `CoreConstants.cs` — `CoreCounterKeys`

`goldReward`, `elite`, `boss`, `level`, `effect.` 前缀, `playerSideDeck`（玩家侧 run 卡组标记）。

## 2. 值对象与草稿

| 相对路径 | 类型名 | 一句话职责 | 关键依赖 |

| 类型 | ActionName | 职责摘要 |
| --- | --- | --- |

## 6. Stats/

| 相对路径 | 类型名 | 一句话职责 | 关键依赖 |
| --- | --- | --- | --- |
| `Domain/Stats/StatBlock.cs` | `StatBlock` | 基础值字典 + Modifier 列表 | `CardInstance`/`PlayerModel` |
| `Domain/Stats/StatModifier.cs` | `StatModifier` / `RuleModifier` | 属性/规则修饰描述 | `StatPipeline`/`RuleModifierRegistry` |
| `Domain/Stats/StatPipeline.cs` | `StatPipeline` | 按 Layer 顺序 ApplyOp | `StatSystem` |
| `Domain/Stats/RuleModifierRegistry.cs` | `RuleModifierRegistry` | 全局规则修饰：Evaluate/Consume/ClearByScope | `StatSystem`、伤害 Once |
| `Domain/Stats/StatArmorUtility.cs` | `StatArmorUtility` | Armor / EffectiveArmor / CurrentArmor 三层语义 | 伤害与重置护甲 |
| `Domain/Stats/StatConditions.cs` | `IStatCondition` + 多个条件类 | 条件修饰是否生效 | Modifier、效果条件桥接 |
| 同上 | `StatEvaluationContext` | Owner/Registry/Board/Player + ActionSource/Target/Actor | `IStatSystem.CreateContext` |

`StatConditions.cs` 条件类型：`AlwaysStatCondition`, `AtSlotCondition`, `HpBelowPctCondition`, `AdjacentCondition`, `AdjacentToUidCondition`, `SourceAdjacentToUidCondition`, `TargetUidCondition`, `TargetUidOrZeroCondition`, `ActorUidCondition`, `CardKindCondition`, `ZoneCondition`, `ActionSourceCondition`, `ExcludeSourcePrefixCondition`。

管线层序：`Persistent → Conditional → Temporary`；运算：`Add` / `Multiply` / `Override`。
