# Setup — 初始化工厂

源码根：`Setup/`。负责一局开始时的确定性重置与 Avatar/职业装配；不负责 `StartNode`（由命令/`IPhaseSystem` 驱动）。

## 1. 流程：`InitialGameFactory.Create`

```text
Create(architecture, options?)
  1. IContentSystem.ClearRuntimeEffects
  2. IEffectSystem.Clear
  3. ITriggerSystem.Clear
  4. IEconomySystem.RebindSystemTriggers   // Clear 后必须
  5. IRewardSystem.RebindSystemTriggers
  6. IActionPipelineSystem.Clear
  7. IPresentationSyncSystem.Clear          // 避免 IsInputLocked 粘连
  8. IRngUtility.SetSeed(options.Seed)
  9. CardRegistry.Clear
 10. BoardModel.Reset
 11. DeckModel.Clear
 12. PlayerModel.Reset
 13. RunModel.Reset(seed)                   // Floor=1, Node=0, Phase=BuildEnemyPool
 14. PendingChoiceModel.Clear
 15. BattleContextModel.Reset
 16. CreateAvatar（Catalog draft 或手写属性）
 17. avatar.InteractionRange base = 1
 18. board.SetAvatar(avatar, SlotId.Board(5))
 19. ApplyProfession（属性覆盖、SeedPlayerSideDeck、ActivatePlayerSkill）
 20. 返回 InitialGameSnapshot + BuildReport
```

注释事实：registry Clear 后 UID 重用；若不先清效果，旧 Trigger 会叠到新卡（如 OnBattle 叠乘）。

## 3. `InitialGameOptions` 默认值

| 字段 | 默认 |
| --- | --- |
| `Seed` | `1UL` |
| `ProfessionId` | `ProfessionCatalog.Jester` (`profession.jester`) |
| `AvatarDefId` | `"avatar.default"` |
| `AvatarMaxHp/Attack/Armor/Recovery` | `ProfessionCatalog.Default` 对应值（10/3/1/1） |

## 4. Avatar 创建逻辑

1. `IContentSystem.CreateDraft(AvatarDefId)`  
2. 若 `draft.Kind != Unknown`：`draft.Create` + `ApplyContentToCard`  
3. 否则：`registry.Create(..., CardKind.Avatar)` + 用 Options 写 MaxHp/Hp/Attack/Armor/CurrentArmor/Recovery  

随后 `ApplyProfession` 再次用 Options 覆盖四维（`ApplyAvatarStats`），并：

- `player.SetProfession`  
- `ProfessionCatalog.SeedPlayerSideDeck` → `player.AddHelpCard`  
- 若有 `InitialSkillDefId`：`player.AddSkill` + `ActivatePlayerSkill`

## 5. `ProfessionCatalog` 代码事实

常量：`Jester = "profession.jester"`。

小丑定义：

| 项 | 值 |
| --- | --- |
| MaxHp / Attack / Armor / Recovery | 10 / 3 / 1 / 1 |
| InitialSkillDefId | `skill.easy_road` |
| InitialCards | healing_potion×3, common_chest_card×1, throwing_knife×3, stat_boost_card×1 |

API：

- `Default` / `Get` / `TryGet`（未知 ID 回落小丑）  
- `SeedPlayerSideDeck(player, professionId)` — 开局写帮助卡堆  
- `AppendInitialPlayerCards(content, catalog, options, professionId)` — 直接往 `NodeDeckOptions` 加 draft（供外部组牌；`RewardSystem.BuildNodeDeckOptions` 实际走 `ConsumeHelpCardStacksForNode`）

注释：`首版唯一职业（小丑）`。

## 6. `BuildReport`

纯文本快照：Seed、Avatar 位置、Board 是否有牌、各堆数量。用于调试/日志，不改状态。
