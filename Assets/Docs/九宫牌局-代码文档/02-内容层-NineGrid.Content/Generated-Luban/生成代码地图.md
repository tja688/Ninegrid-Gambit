# Generated/Luban — 生成代码地图

> 覆盖 `NineGrid.Content/Generated/Luban/**`。全部文件带 `<auto-generated>` 头，**禁止手改**；改表定义后由 `gen_table_nine` 再生。

## 1. 总览

| 项 | 事实 |
|----|------|
| 命名空间 | `cfg`（`Tables`）、`cfg.tablenine`（Tb* / *Row） |
| 依赖 | `Luban`、`Luban.SimpleJSON`（来自 `Luban.Runtime`） |
| 加载契约 | `Tables(Func<string, JSONNode> loader)`；loader 参数为逻辑表名（无 `.json`） |
| JSON 文件名 | `{loader名}.json`，由 Factory 拼到数据目录 |

## 2. `cfg.Tables` 聚合

| 路径 | 类型 | 职责 | 关键依赖 |
|------|------|------|----------|
| `Generated/Luban/Tables.cs` | `cfg.Tables` | 构造全部表；末尾 `ResolveRef()` | 各 `Tb*` |

## 3. 表容器共性（全部 `Tb*`）

统一形态（以 `TbEffect` 为代表）：

- 构造：遍历 JSON 数组 → 反序列化 Row → `_dataList` + `_dataMap`
- API：`DataMap` / `DataList` / `Get` / `GetOrDefault` / 索引器 / `ResolveRef`
- **主键字段因表而异**（见下表）

| 路径 | 类型 | 主键 | 职责 | 关键依赖 |
|------|------|------|------|----------|
| `tablenine/TbEffect.cs` | `TbEffect` | `Id` (string) | 效果表 | `EffectRow` |
| `tablenine/TbCard.cs` | `TbCard` | `DefId` | 卡牌表 | `CardRow` |
| `tablenine/TbSkill.cs` | `TbSkill` | `DefId` | 技能表 | `SkillRow` |
| `tablenine/TbRelic.cs` | `TbRelic` | `DefId` | 遗物表 | `RelicRow` |
| `tablenine/TbRewardPool.cs` | `TbRewardPool` | `Id` | 奖励池 | `RewardPoolRow` |
| `tablenine/TbRewardEntry.cs` | `TbRewardEntry` | `Id` | 奖励条目 | `RewardEntryRow` |
| `tablenine/TbMonsterDeck.cs` | `TbMonsterDeck` | `Id` | 怪物牌组 | `MonsterDeckRow` |
| `tablenine/TbNodeDeckRule.cs` | `TbNodeDeckRule` | `NodeIndex` (int) | 节点组牌规则 | `NodeDeckRuleRow` |

## 4. 行类型分组与字段（从类名/字段推断用途）

### 4.1 玩法效果组

| 路径 | 类型 | 字段 | 推断用途 | Catalog 引用 |
|------|------|------|----------|--------------|
| `EffectRow.cs` | `EffectRow` | Id, ContainerType, State, Json, DesignText | 效果 DSL JSON + 实现状态 + 设计文案 | → `ContentEffectDefinition` |

### 4.2 实体定义组（卡/技/遗物）

| 路径 | 类型 | 字段 | 推断用途 | Catalog 引用 |
|------|------|------|----------|--------------|
| `CardRow.cs` | `CardRow` | DefId, DisplayName, Kind, Rarity, Price, Level, IsElite, IsBoss, IsReserve, DeckId, MaxHp, Attack, Armor, Recovery, Tags, EffectIds, SkillIds | 帮助卡与怪物卡统一行；列表字段为分隔字符串 | → `CardContentDefinition` |
| `SkillRow.cs` | `SkillRow` | DefId, DisplayName, ContainerType, DesignText, EffectIds | 玩家/怪物技能 | → `SkillContentDefinition` |
| `RelicRow.cs` | `RelicRow` | DefId, DisplayName, Rarity, DesignText, Tags, EffectIds | 遗物 | → `RelicContentDefinition` |

### 4.3 奖励与进度组

| 路径 | 类型 | 字段 | 推断用途 | Catalog 引用 |
|------|------|------|----------|--------------|
| `RewardPoolRow.cs` | `RewardPoolRow` | Id, PickCount | 奖励池头（抽几张） | → `RewardPoolDefinition` |
| `RewardEntryRow.cs` | `RewardEntryRow` | Id, PoolId, DefId, Kind, Weight, Count | 池内条目 | → `pool.Add` |
| `MonsterDeckRow.cs` | `MonsterDeckRow` | Id, DisplayName, Kind, MonsterDefIds | 怪物牌组 | → `MonsterDeckDefinition` |
| `NodeDeckRuleRow.cs` | `NodeDeckRuleRow` | NodeIndex, TotalMonsterCount, Level1–3 Min/Max, EliteCount, BossCount, DeckKind | 节点组牌约束 | → `NodeDeckRule` |
| `RoomRow.cs` | `RoomRow` | Kind, DisplayName, Weight, GoldDelta, MaxHpDelta, HealToFull, RewardPoolId, ShopOfferCount | 地图房间 | → `RoomDefinition` |
| `EconomyRow.cs` | `EconomyRow` | Id, MonsterRemovedGold, UnusedHelpCardGold, SkipHelpChoiceGold, SkipRelicChoiceGold, DiscardRelicGold, ShopDeleteHelpCardGold | 全局金币规则（默认行 id=`default`） | → `EconomyConfig` |

### 4.4 表现组

| 路径 | 类型 | 字段 | 推断用途 | Catalog 引用 |
|------|------|------|----------|--------------|
| `ContentVisualRow.cs` | `ContentVisualRow` | ContentId, ContentKind, Description | 内容文案与种类（**不含** Sprite） | → `ContentVisualDefinition` |
| `CardFrameStyleRow.cs` | `CardFrameStyleRow` | StyleId, ColorR/G/B/A | 卡框颜色 | → `CardFrameStyleDefinition` |
