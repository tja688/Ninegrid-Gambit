# Content.Editor — 内容编辑器工具

> 覆盖 `NineGrid.Content.Editor/**` 全部手写 Editor 工具。程序集仅 Editor 平台。  
> 引用：`NineGrid.Core` / `NineGrid.Content` / `NineGrid.Cards` / `NineGrid.Cards.Editor` / `Luban.Runtime`。

## 1. 职责总览

| 工具簇 | 职责 |
|--------|------|
| Luban 数据导出 / 再生成 | 硬编码 Catalog → Datas JSON；运行 `gen_table_nine.ps1` |
| Content Visual 配图窗口 | 编辑 Sprite Catalog SO + description xlsx + 卡框色；**内嵌高保真卡面预览** |
| Xlsx I/O | 经 Python 读写/补丁 `content_visual.xlsx` / `card_frame_style.xlsx` |
| 迁移 | legacy Sprite 键 → Catalog SO；创建 Arts 下 SO 资产 |
| UI 皮肤 | 暖棕控制台风格 UI Toolkit 控件 |

**菜单入口（Unity Menu）：**

| 菜单路径 | 入口类型 |
|----------|----------|
| `TableNine/Content/Export Hardcoded Catalog To Luban Datas` | `TableNineLubanDataExporter` |
| `TableNine/Content/Content Visual Editor` | `ContentVisualLubanMenu.OpenEditor` |
| `TableNine/Content/Regenerate Luban` | `ContentVisualLubanMenu.RegenerateLuban` |
| `TableNine/Content/Migrate Visual Assets Into Catalog SOs` | `ContentVisualSpriteCatalogMigrationMenu` |

## 2. Luban 导出与再生成

### 2.1 `TableNineLubanDataExporter`

| 路径 | 类型 | 职责 | 关键依赖 |
|------|------|------|----------|
| `TableNineLubanDataExporter.cs` | `TableNineLubanDataExporter` | 将 `GameContentCatalog` 写出 Datas JSON | `TableNineContentCatalog`, Core.Content |

- 输出目录：`Assets/Tools/Luban/Datas`
- 菜单调用：`CreateDefault()` → `Export` → `AssetDatabase.Refresh`
- 写出文件：`effects.json`, `cards.json`, `skills.json`, `relics.json`, `reward_pools.json`, `reward_entries.json`, `monster_decks.json`, `node_deck_rules.json`, `rooms.json`, `economy.json`
- **不导出**视觉 xlsx（content_visual / card_frame_style）
- 多值列表用 `|` 拼接；奖励条目 Id 形如 `{poolId}.{index:00}.{defId_with_dots_as_underscores}`
- Economy 固定写 `id: "default"`

### 2.2 `ContentVisualLubanMenu`

| 路径 | 类型 | 职责 | 关键依赖 |
|------|------|------|----------|
| `ContentVisualLubanMenu.cs` | `ContentVisualLubanMenu` | 打开配图窗；执行 gen 脚本 | Process, AssetDatabase |

- `TryRunGenScript`：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File Assets/Tools/Luban/gen_table_nine.ps1`
- 工作目录为脚本所在目录；成功后 `AssetDatabase.Refresh`

## 3. Content Visual 编辑器

### 3.1 Window / Session / Preview / UI

| 路径 | 类型 | 职责 | 关键依赖 |
|------|------|------|----------|
| `ContentVisualEditorWindow.cs` | `ContentVisualEditorWindow` | 主窗口：双 Tab、筛选、保存、Regenerate、**高保真预览**、描述编辑与 SlotCode 插入 | Session, WarmConsoleUi, `CardFacePreviewHost` |
| `ContentVisualEditorSession.cs` | `ContentVisualKeySlot` | Icon / Face / BackBorder / BackShirt / BackLogo | — |
| 同上 | `ContentVisualEditorRowState` | 单行编辑态（直暴露五项 + `DraftDescription` dirty） | XlsxRow |
| 同上 | `CardFrameStyleEditorRowState` | 框色编辑态 | FrameXlsxRow |
| 同上 | `ContentVisualEditorSession` | 加载 xlsx+SO、筛选、保存（含 description patch）、Resolve | Factories, Resolver, XlsxIO |
| `Ui/ContentVisualWarmConsoleUi.cs` | `ContentVisualWarmConsoleUi` | Theme、Header、Toolbar、Nav、StatCard 等 | UIElements |

**Session 关键路径：**

- 内容列表 + **可编辑 description**：`ContentVisualXlsxIO` ← `Assets/Tools/Luban/Datas/content_visual.xlsx`（保存时 `PatchDescriptions`）
- 框色权威：`CardFrameStyleXlsxIO` ← `card_frame_style.xlsx`（保存时 `PatchColors`）
- 直暴露装配项：`Assets/Arts/ContentVisual` 下各 VisualCatalog SO（`SetDirectSlots`：Main_Icon / Face_Background / Back_*；无全局卡背源）
- **权威卡面预览（本窗内嵌）**：`CardFacePreviewHost` → `CardFacePreviewBuilder`（底盘 + L4 + `ApplyPresentation`；含未保存 Sprite / 描述草稿）
- 调试薄壳（非权威）：`NineGrid/Cards/Face Final Preview`（同一 Builder）

**窗口能力摘要：**

- 按 Kind 导航、搜索 content_id/display_name/description
- 过滤：缺 icon / 缺 face / 仅 dirty
- 单选编辑直接暴露五项；多选批量赋 Icon/Face；Kind 默认 DefaultFace / FallbackIcon
- **静态基础描述**可编辑；一键插入 `[SlotCode]`（可插入描述槽）并复制剪贴板；卡面即时预览图标文案
- Tab「Card Frame 配色」编辑各 style 颜色（样本预览同走高保真 Host；框色首波以卡面模板为准）
- 「导出卡图关联」→ `Assets/Notes/CardSprite`（窗口常量）
- 保存 description 后须 **Regenerate Luban** 才进 Play；预览读会话草稿不依赖已 gen JSON

### 3.2 Xlsx I/O

| 路径 | 类型 | 职责 | 关键依赖 |
|------|------|------|----------|
| `ContentVisualXlsxIO.cs` | `ContentVisualXlsxRow` | content_id / content_kind / description / sheet_row_index | — |
| 同上 | `ContentVisualXlsxIO` | `content_visual_xlsx_io.py`：read / headers / **patch_descriptions**；`CanWrite` | Process, SimpleJSON |
| `CardFrameStyleXlsxIO.cs` | `CardFrameStyleXlsxRow` | style_id + RGBA + sheet_row_index | — |
| 同上 | `CardFrameStyleXlsxIO` | 经 `card_frame_style_xlsx_io.py` read/patch | Process, SimpleJSON |

两 IO 类均：`ResolveAbsolutePath` = `CurrentDirectory` + Relative 路径；Python 可执行探测在各自实现内。

| 路径 | 类型 | 职责 | 关键依赖 |

## 5. 工具数据流

```
硬编码 Catalog
  → Export Hardcoded → Datas/*.json
  → gen_table_nine.ps1 → StreamingAssets JSON + Generated C#
  → Runtime Factories

content_visual.xlsx (description，可 PATCH)
  + Arts/...VisualCatalog SO (sprites)
  + card_frame_style.xlsx (colors)
  → Content Visual Editor 编辑
  → 内嵌 CardFacePreviewHost（会话草稿所见即所得）
  → Regenerate Luban（刷新 JSON/代码进 Play）
  → ContentVisualResolver / 投影 Commit 运行时
```

## 7. 与 Runtime Content 的边界

| Editor 可做 | Runtime Content 做 |
|-------------|-------------------|
| 改 Datas / xlsx / Arts SO | 只读 JSON + Resources Bootstrap SO |
| 调用 gen 再生 Generated | 消费已生成的 `cfg.*` |
| 用 Session 草稿 + CardFacePreviewHost 预览未保存改动 | 正式 Bootstrap/Factory + 投影 Commit |
| 导出硬编码为表源 | `CreateDefault` 作为 Auto 回退 |
