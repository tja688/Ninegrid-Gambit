# Slots / 装配槽注册表

> 覆盖 `Assets/Scripts/Cards/Slots/`。  
> 对齐 ADR-0002 / #14 / #16：项目级槽表 + 纯数据解析 + 通层 order 校验；描述 `[SlotCode]` 插入见 Presentation。

---

## 1. 职责

登记卡面装配槽代号与角色；按内容覆盖 / 模板兜底解析图标；扫描通层重复 `sortingOrder`；节点名候选供 Binder / 预览解析。  
描述运行时插入由 `CardFaceDescriptionComposer`（Presentation）消费本表的 `InsertableInDescription` 角色。数值 Commit 见 [Presentation/投影Commit.md](../Presentation/投影Commit.md)。

---

## 2. 类型

| 类型 | 作用 |
|------|------|
| `CardFaceSlotCodes` | 稳定代号常量（`Main_Icon`、`Face_Background`、`Back_*`、`Action_Icon`、`Basic_Description` 等） |
| `CardFaceSlotRole` | Flags：DirectExpose / Collapsed / InsertableInDescription / Numeric / Icon |
| `CardFaceSlotDefinition` | 单槽：代号、中文注释、角色 |
| `CardFaceSlotRegistrySO` | 项目级注册表；`TryGet` / `ApplyDefaultCatalog` |
| `CardFaceSlotResolver` | 旁路纯数据：图标内容优先、缺省回退模板；数值缺省 0 |
| `CardFaceSlotNodeMap` | 槽代号 ↔ 卡面节点名候选；含 `Action_Icon`→行动图标、`Basic_Description`→描述/介绍区域；模板默认抽取 / 灌图 |
| `CardFaceSortingOrderValidator` | 同 SortingGroup + SortingLayer 内重复 order 检测 |

**资产路径：** `Assets/Arts/Cards/CardFaceSlotRegistry.asset`（菜单 `NineGrid/Cards/Ensure Card Face Slot Registry Asset`）。

**内容字段映射：** Catalog `icon`↔`Main_Icon`，`face`↔`Face_Background`，`backBorder/Shirt/Logo`↔`Back_*`；无全局卡背源。  
`Action_Icon` 首波主要来自卡面模板默认 Sprite（Collapsed + InsertableInDescription）。
