# Managers / 管理器与视图

> 覆盖 `Assets/Scripts/Cards/` 根目录全部类型（不含 Battle、Convergence、Effects、Editor、Tests）。  
> 源码事实；SerializeField 装配点来自字段 Tooltip/注释。

---

## 1. 关系总览

```
CardManagerSingleton ──Spawn──► ManagedCard.View = StandardCardView
        │                              │
        │ SetDisplayMode               ├─ CardVisualDriver
        │                              ├─ CardEffectManager
        │                              └─ CardTransformTower (Convergence)
        │
        ├── CardDeckManagerSingleton ──Deal──► GroundFieldManagerSingleton
        │         │                              │
        │         └── DealCardToHand ──► CardHandManagerSingleton
        │                                      │
        │                              PullFromGround / Drag
        │
        └── FieldBattleManagerSingleton ◄── TryHandleBattleClick
                      │
                      └── CardAttackBasicAdapter / DirectionRig
```

**净土域（IHandoffEndpoint）**：Deck、Hand、FieldBattle —— 域内布局黑盒，C 阶段只暴露 `Evict`/`Admit`（速度恒 0）。  
**复杂域**：GroundField —— 持有 PresentationClock / BeatGrid / LeaseArbiter / SlotDealFlightService，格位位移走 L2 收敛。

## 2. CardManagerSingleton + ManagedCard

**文件：** `CardManagerSingleton.cs`  
**类型：** `CardDisplayMode` · `ManagedCard` · `CardManagerSingleton`

### 职责

- 以 Uid 为键的**表现视图注册表**。
- Spawn / Release / DisplayMode；死后离锚点暂存。
- `DontDestroyOnLoad` 单例。

### CardDisplayMode

| 值 | 用途 |
|----|------|
| `CardDeckMode` | 牌组 |
| `HandCardMode` | 手牌 |
| `GroundCardMode` | 场地 |
| `RemovedMode` | 移除 |
| `DragCardMode` | 拖拽中 |

### ManagedCard（句柄，非 MonoBehaviour）

| 成员 | 说明 |
|------|------|
| `Uid` | 与 Core CardInstance.Uid 相同（正）或纯表现负 Uid |
| `DefId` | 选预制体；逻辑数据以 Core 为准 |
| `View` | `StandardCardView` |
| `DisplayMode` | 当前显示模式 |
| `IsFieldDead` | 交战即死后标记 |
| `CoreKind` | Flow 写入的 `CardPresentationKind` |

### 公开 API（摘要）

| API | 作用 |
|-----|------|
| `Instance` / `TryGetInstance()` | 单例；销毁期用 Try |
| `RegisterPrefab(defId, prefab)` | 注册 Def 预制体 |
| `SpawnView(uid, defId, …)` | Core 已分配 Uid 时创建视图 |
| `Spawn` / `SpawnMany` | 本地分配正 Uid（无 Core 兜底） |
| `SpawnPresentationOnly` | 负 Uid 纯表现卡 |
| `EnsureComplexDomainStack` | 确保复杂域栈组件 |
| `TryGet` / `Get` / `TryGetTracked` | 查找 |
| `EnumerateCards` / `TryResolveUid` | 枚举 / Transform→Uid |
| `Release` / `ReleaseAll` | 销毁视图 |
| `SetDisplayMode` / `RefreshDisplayMode` | 切换模式 |
| `MarkFieldDead` / `StageFieldDeadCorpseOffAnchor` | 死亡表现离锚 |

### SerializeField

| 字段 | 装配 |
|------|------|
| `cardRoot` | 卡牌实例父节点 |
| `standardCardPrefab` | Standard Card 预制体（可 Bootstrap 加载） |

### 互相调用

- 被 Deck/Hand/Ground/Battle 全面依赖。
- `SetDisplayMode` 驱动 `CardVisualDriver` / HitProxy 启用。

## 3. CardDeckManagerSingleton

**文件：** `CardDeckManagerSingleton.cs` · 依赖 `CardDeckSlotContainer` · `CardDeckLayoutSettings` · `CardDeckMode` · `CardDeckTween`

### 职责

编排卡组 **Standby → Entry → InGame**，向 Ground 发牌，向 Hand 发牌，场地回库。实现 `IHandoffEndpoint`。

### 公开 API（摘要）

| API | 作用 |
|-----|------|
| `InjectDeck` | Standby 注入已 Spawn 的卡列表 |
| `BeginEntryAsync` | Entry 展开 |
| `DealCard` / `DealFirstCard` / `DealCardByUid` | 同步发牌到场地格 |
| `DealCardByUidAsync` / `DealCardByUidWithFlightAsync` | 异步发牌 + 飞牌句柄 |
| `DealCards` / `DealOpeningRing` | 批量 / 开局环 |
| `DealCardToHandAsync` | 发到手牌 |
| `AddCardAtAsync` / `AddCardAtFromOriginAsync` | 入组 |
| `TryWithdrawFirstCard` / `TryReturnCardToDeckFront` | 抽离 / 回前 |
| `LaunchReturnFieldCardToDeck` | 场地卡回库飞行 |
| `ClearGround` / `ResetToStandby` | 清理 |
| `IsReturnInFlight` | 回库途中门禁 |
| `Evict`/`Admit`/`EvictCard`/`AdmitCard` | 交接 |

### 发牌链路（源码）

1. 从 `_slotContainer` 取出卡。
2. `GroundFieldManagerSingleton.RequestPlaceCard(groundSlot, card)`。
3. 场地侧启动 `SlotDealFlightService` Drain/Explore；Deck 侧可拿 `DealFlightHandle`。

### SerializeField

| 字段 | 装配 |
|------|------|
| `deckAnchorsRoot` | `Anchors/CardDeckAnchors`；空则按名查找 |
| `addAnchorsRoot` | `CardDeckAddAnchors`；空则子节点查找 |
| `entryPreparationSlot` | `DeckEntryPreparationSlot` |
| `groundAnchorsRoot` | `Anchors/GroundAnchors` |
| `layoutSettings` | `CardDeckLayoutSettings` |

## 4. CardHandManagerSingleton

**文件：** `CardHandManagerSingleton.cs` · `CardHandSlotContainer` · `CardHandLayoutSettings`

### 职责

最多 `maxSlots`（默认 5）手牌：布局、hover、拖拽、ApplyZone 释放、从场地抓取。`IHandoffEndpoint`。

### 公开 API（摘要）

| API | 作用 |
|-----|------|
| `ClearHand` / `ContainsUid` / `TryRemoveFromHand` | 槽操作 |
| `PullFromGroundAsync` | 从场地拉到手牌 |
| `TryBeginDragFromHand` / `TryPickupFromGround` | 拖拽开始 |
| `NotifyCardReleased` / `TryCompleteDragApply` | 释放 / 确认 Apply |
| `CancelDragAndReturnToHand` | 取消 |
| `VanishParkedBoardSelectItemAsync` | 棋盘选择停靠卡消失 |
| `DragApplyValidator` | 事件：待 Core 校验释放 |
| `CanAcceptCard` / `IsSelfBusy` / `IsDragging` | 门禁 |

`IsBusy` 聚合：自身忙 + CombatHitSink 门禁 + GroundField.IsBusy。

### SerializeField

| 字段 | 装配 |
|------|------|
| `handAnchorsRoot` | `Anchors/CardHandAnchors` |
| `applyZoneCollider` | `HandcardApplyZone` Collider |
| `layoutSettings` | `CardHandLayoutSettings` |

## 5. GroundFieldManagerSingleton

**文件：** `GroundFieldManagerSingleton.cs` · 拓扑 `GroundSlotTopology` · 快照 `GroundFieldSnapshot`

### 职责

- 9 格**几何占用**权威（`_uidBySlot` / `_slotByUid`）；注释声明非逻辑占格权威。
- 放置、搬移、外圈旋转、空槽点击、Avatar 揭示、骷髅合体委托。
- 拥有 `SlotDealFlightService`、`PresentationClock`、`BeatGrid`、`LeaseArbiter`。
- 交战编排已抽至 `FieldBattleManagerSingleton`。

### 公开 API（摘要）

| API | 作用 |
|-----|------|
| `RequestPlaceCard` / `RequestPlaceCardAtAnchor` | 登记占用 + 可选飞牌 |
| `RequestRelocateOccupancy` / `RequestMoveCard` | 搬占用 / 动画移动 |
| `ApplyBoardMovesAndHopAsync` | 批量 hop（commitment） |
| `RotateOuterRingClockwiseAsync` / `RotateOuterRingWhileBusyAsync` | 外圈旋转 |
| `TryTakeCardFromField` / `RequestRemoveFromField` / `ClearField` | 离场 |
| `IsDealInFlight` / `WaitAllActiveDealFlightsAsync` | 飞牌等待 |
| `PresentSkeletonFusionAsync` | 骷髅合体 |
| `RequestRevealAvatarAsync` | Avatar 揭示 |
| `IsAvatarOrthogonalBattleSlot` | 可交战正交槽 |
| `EmptySlotClicked` / `FieldMaybeClearSignal` | 事件（无 Core 引用） |
| `GetSnapshot` / `TryGetCardAt` / `TryGetSlotOf` | 查询 |

`IsBusy` = 场地忙 ∨ FieldBattle 忙 ∨ CombatHitSink 门禁。  
`IsFieldBusy` = 仅场地自身（供交战判断可否开打）。

### SerializeField

| 字段 | 装配 |
|------|------|
| `groundAnchorsRoot` | `Anchors/GroundAnchors` |
| `layoutSettings` | `GroundFieldLayoutSettings`（含 `dealFlight`） |
| `skeletonDeckPresentation` | `SkeletonDeckPresentationManager`；空则场景查找 |

## 7. StandardCardView + 视觉附属

### StandardCardView

像素卡面：攻/血数字、护甲块或护甲数值（>7）、主图标、卡底、边框。`RequireComponent(SortingGroup)`。

| API | 作用 |
|-----|------|
| `SetAttack`/`SetHealth`/`SetArmor`/`Add*` | 数值 |
| `SetMainIcon`/`SetCardFace`/`SetFrameColor` | 外观 |

**SerializeField：** `spriteLibrary`、各 Anchor、各 SpriteRenderer、间距/排序/默认攻血甲。留空时 `Awake` 按子节点名自动查找（Attack/Life/ArmorBlocks 等）。

### CardVisualDriver

按 `CardDisplayMode` / `CardVisualTarget` 驱动缩放、sorting、hover/selected 反馈。`Bind(ManagedCard)`。

### PixelDigitDisplay / ArmorBlockDisplay

内部数字与护甲块渲染；由 View 构建。

### PixelCardPackSpriteLibrary

ScriptableObject：0–9 数字 Sprite + armorBlockSprite。

## 11. Sink / Probe / 选择模式

### CombatHitSink（核心桥）

静态门禁：`ChoiceOverlayActive`、`BoardSelectModeActive`、`OpeningPresentationActive`、`DirectorMainlineBusy`、PresentationLock。

委托请求（由 Flow 接线）：

- `RequestCombatHit` / `RequestPostKillBoard` / `RequestEstimateWillKill`
- `RequestPickupItem` / `RequestUseItem` / `RequestExploreIntent` / `RequestAttackIntent`
- `RequestSyncCard` / `RequestDamageNumber` / `RequestDrainPostKillBoard`
- `NotifyBattleEnded` / `RequestNodeSettlement`

结果结构体：`CombatHitPresentationResult`、`PostKillBoardPresentationResult`、`BoardPresentationStep`、`PickupItemPresentationResult`、`UseItemPresentationResult` 等。

### 其他 Sink

| Sink | 作用 |
|------|------|
| `CardZoneOwnershipSink` | Core ItemSlots/DrawPile 查询 |
| `ChoreoTraceSink` | 编排 Begin/End/Explore/Anomaly |
| `FlowFieldTraceSink` | 场地 hop/batch 追踪 |
| `PerfTraceSink` | CloseBeat 等 |
| `RegistryTraceSink` | 用户交互通知 |
| `DescriptionHoverSink` | 描述 Show/Clear |

### CardPresentationProbe

静态诊断：Motion/Spawn/Vacate/Lease/Handoff/BattleBind 等埋点。

### BoardCardSelectModeController

静态：`Begin`/`End`/`TryToggleSelection`/`IsEligibleTarget`；与 Hand 停靠卡协同。

### BoardMotionStepScheduler

`ExecuteMotionStepAsync`：按 Step.Kind 调 Field.Rotate / ApplyBoardMovesAndHop。

### BoardPresentationMerge

`MergeLethalHitAndPostKill`：合并致死与击杀后盘面。
