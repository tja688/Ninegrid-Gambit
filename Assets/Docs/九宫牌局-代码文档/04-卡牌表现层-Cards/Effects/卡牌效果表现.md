# Effects / 卡牌效果表现

> 覆盖 `Assets/Scripts/Cards/Effects/` 与 `Effects/Implementations/`。  
> 命名空间均为 `NineGrid.Cards`（无独立 Effects 命名空间）。

---

## 1. 体系结构

```
调用方（FieldBattle / Hand / Timeline Callback）
        │
        ▼
CardEffectManager（挂在 Standard Card 上）
        │ Resolve CardEffectBinding(kind, direction)
        ▼
CardEffectSO 子类（ScriptableObject）
        │ PlayAsync(CardEffectPlayContext)
        ▼
DOTween / Material 闪白 / L3 EffectFrame 位移（部分实现）
```

- **表现反馈**，非 Core 效果 DSL。
- `CardEffectManager`：`RequireComponent(typeof(StandardCardView))`。
- EffectTrigger 为内置脉冲，可不装配 SO。

---

## 2. 核心运行时

### CardEffectManager.cs

| API | 作用 |
|-----|------|
| `PlayAsync(invoke)` | 通用入口 |
| `PlayAttackAsync` / `PlayHitAsync` / `PlayDeathAsync` / `PlayUseAsync` / `PlayHitFlashAsync` | 分类快捷 |
| `PlayEffectTriggerPulse` | 非阻塞缩放脉冲 |
| `Callback(int/string)` / `CallbackPlayHitFlash*` | Timeline 回调入口 |
| `StopCurrent` / `TryConsumeHoverSuppression` | 停止 / hover 抑制 |

**SerializeField：**

| 字段 | 说明 |
|------|------|
| `bindings` | `List<CardEffectBinding>`（Attack/Hit/Death/Use/HitFlash） |
| `effectTriggerScale` / `*Duration` | EffectTrigger 脉冲参数 |
| debug*（Odin） | 调试方向/槽位/幅度 |

### CardEffectManagerExtensions.cs

`ManagedCard.TryGetEffectManager` / `PlayEffectTriggerPulse`。

### CardEffectBinding.cs

| 类型 | 说明 |
|------|------|
| `CardEffectBinding` | kind + defaultEffect + directionalOverrides |
| `CardDirectionalEffectOverride` | 方向 → 覆盖 SO |
| `Resolve(selfDirection)` | 选 SO |

### CardEffectInvokeContext.cs

工厂：`ForAttack` / `ForHit` / `ForDeath` / `ForUse` / `ForHitFlash` / `ForEffectTrigger`。

### CardEffectPlayContext.cs

播放时传给 SO 的运行时上下文（Transform、方向、幅度等）。

### CardEffectSO.cs（抽象基类）

| 属性 | 说明 |
|------|------|
| `EffectId` / `DisplayName` / `Description` | 元数据 |
| `Kind` | 须与 Manager 装配一致 |
| `EstimatedDuration` | 预估时长 |
| `SupportsDirectionVariants` | 是否按方向变体 |
| `OrchestrationDelay` / `UsesBasicAttackComboDelay` | 与基础攻击编排配合 |

子类实现 `PlayAsync`。

### CardEffectKind.cs

`Attack` · `Hit` · `Death` · `Use` · `HitFlash` · `EffectTrigger`。

### CardEffectCallbackAction.cs

Timeline 回调动作枚举 + 解析工具；可映射到 `CardEffectKind`。

### CardEffectOrchestrationUtility.cs

基础攻击命中延迟：`TryGetBasicAttackHitDelay` / `ShouldUseBasicAttackComboDelay`。

## 3. 方向与攻击呈现

### CardBoardDirection.cs

棋盘相对方向枚举（含 None / 正交与对角等；由 Utility 使用）。

### CardBoardDirectionUtility.cs

| API | 作用 |
|-----|------|
| `ComputeSelfDirection(observerSlot, focusSlot)` | 槽位→方向 |
| `GetOrthogonalOpposite` | 正交反方向 |
| `ToLocalOffset` | 方向→局部位移 |

### CardDOTweenDirectionUtility.cs

Right/Left 水平符号翻转（配合烘焙 clip）。

### CardAttackPresentationKind.cs

攻击呈现种类枚举（与 Battle Rig 族配合的元数据）。

### CardTweenClip / CardTweenClipType

数据化 Tween 片段：delay、duration、ease、type（如 LocalMove）、endValue、isRelative。  
供 `CardDOTweenSequenceEffectSO` 使用。

### CardSpriteHitFlashExecutor.cs

运行时组件：对 Sprite 材质做 HitFlash；`GetOrCreate(root)`。

## 4. Implementations/

| SO | 行为 |
|----|------|
| `CardDOTweenSequenceEffectSO` | 按 `List<CardTweenClip>` Insert(0) 并行播序列 |
| `CardSpriteHitFlashEffectSO` | 材质闪白（模板 Material、色、阈值） |
| `CardTweenDirectionalLungeEffectSO` | 沿方向前冲再回（可走 EffectFrame） |
| `CardTweenDirectionalPunchEffectSO` | 方向加权 PunchScale |
| `CardTweenScaleOutEffectSO` | 缩小消失（Death/Use 常用） |

各 SO 的关键 SerializeField 见源码 Tooltip（距离、时长、vibrato、闪白 Material 路径等）。

---

## 5. 与战斗 / 场地的关系

| 调用方 | 典型 Kind |
|--------|-----------|
| `CardAttackBasicDirectionRig` Timeline 回调 | HitFlash / Hit / Death |
| `FieldBattleView` | 致死/移除时 Death |
| `CardHandManagerSingleton` Apply 消失 | Use / ScaleOut |
| 场地效果触发 | EffectTrigger 脉冲 |

Lunge 等实现可经 `EffectFrameConvergence` 写 L3，避免污染格位 L2。
