# Convergence / 汇合与编排

> 覆盖 `Assets/Scripts/Cards/Convergence/` 全部类型。  
> 「汇合 / Convergence」含义**仅从源码推断**（见 §1）。

---

## 1. 「汇合」含义（源码推断）

本目录不是玩法「卡牌汇合」，而是**表现运动学编排**：

1. **曲线汇合（Converge）**  
   卡牌某变换层（主要是 L2 `SlotFrame`、L3 `EffectFrame`）的 local 位姿，沿五次多项式 `ConvergenceCurve` 从当前状态**汇合到目标**（就位 / Redirect / 回家），不靠每帧写 world position 做动画。

2. **变换塔分层**  
   `CardTransformTower` 固定五层（L0–L4）。格位位移只驱动 L2；特效位移驱动 L3；视觉叶在 L4。就位约定：L0 停在格锚、L2.local = 0。

3. **节拍与屏障（Beat + Barrier）**  
   多卡同拍启动；`BeatGrid` 放屏障，等所有注册槽完成或到期，实现齐步落地。

4. **租约仲裁（Lease）**  
   Sync 必达独占写通道；Async 后发先至。冲突时 Commandeer / Alarm。

5. **域交接（Handoff）**  
   `IHandoffEndpoint.Evict/Admit`：跨净土域/复杂域边界时交出局部位姿（速度常强制 0）。

一句话：**Convergence = 分层 Transform 曲线收敛 + 节拍屏障 + 写通道租约 + 域交接。**

## 2. 变换塔

### TowerLayer.cs

```
CardRoot(0) → BoardFrame(1) → SlotFrame(2) → EffectFrame(3) → CardVisual(4)
```

编译期定死，不可事后插层。

### CardTransformTower.cs

MonoBehaviour；`EnsureTower()` 在 Awake 按固定名创建/绑定子节点。

| 属性 | 层 |
|------|-----|
| `CardRoot` | L0 = transform |
| `BoardFrame` | L1 |
| `SlotFrame` | L2 |
| `EffectFrame` | L3 |
| `CardVisual` | L4 |

**SerializeField：** 各层 Transform；Tooltip 标明留空时 EnsureTower 自动装配。

## 3. 曲线与驱动

### ConvergenceCurve1D / ConvergenceCurve

- 1D：位置/速度/加速度；`Redirect` 中途改终点。
- 3D：由三条 1D 合成；`EvaluatePosition/Velocity/Acceleration`。

「五次收敛」指源码中对起止位姿与速度约束的多项式汇合（见 Curve 工厂方法），非贝塞尔飞牌（飞牌数学在根目录 `DealFlightMath`）。

### LayerConvergenceDriver.cs

挂在卡根上的 MonoBehaviour，驱动指定 `TowerLayer`：

| API | 作用 |
|-----|------|
| `ConfigureDrivenLayer` / `Ensure` / `TryGet` | 配置 |
| `ConvergeTo` / `Redirect` / `Stop` / `Tick` | 运动 |
| `Evict` / `Admit` | 实现 `IHandoffEndpoint` |
| `SampleVelocity` | 采样速度 |

### SlotFrameConvergence.cs（静态门面）

复杂域格位约定：

- `BeginDealFromLaunch` / `ConvergeVisualToWorld` / `RedirectVisualToWorld`
- `SnapHome` / `SanitizeForSanctuary` / `Park` 类离散落锚
- `TryEnsureInfrastructure`：无塔时补齐 L2/L3 driver

**规则（类注释）：** 换格/补牌只改 L2 目标重收敛，零 SetParent；L0 收敛过程中不写 world position。

### EffectFrameConvergence.cs（静态门面）

L3 特效层：`ConvergeVisualToWorld` / `ConvergeHome` / `SnapHome` / `ParkRootAtWorld`。

## 4. 时钟 / 节拍 / 租约

### PresentationClock.cs

表现时钟：`Now` / `Advance` / `Seek` / `Reset`。与真实 Time 解耦，供 Beat 对齐。

### BeatGrid.cs

| API | 作用 |
|-----|------|
| `OpenBeat(sharedSourceTime)` | 开拍 |
| `Register` → `BeatConvergenceSlot` | 注册驱动槽 |
| `PlaceBarrier` / `TryValidateBarrier` / `IsBarrierSatisfied` | 屏障 |
| `TickBeat` / `AreAllComplete` | 推进 |

### LeaseTypes.cs + LeaseArbiter.cs

| 概念 | 说明 |
|------|------|
| `LeaseKey` | CardId + TowerLayer |
| `LeaseRequest` | Async / Sync 工厂 |
| `LeaseVerdict` | Accepted / Rejected / Commandeered / SyncConflict / PreemptAlarm |
| `CommitmentKind` | Async=后发先至；Sync=必达+租约 |
| `LeaseArbiter.TryAcquire/Release/MarkFulfilled` | 仲裁 |

`GroundFieldManagerSingleton` 构造时 `new LeaseArbiter(OnDisciplineBAlarm)`。

### CommitmentKind.cs

贴在每次表演请求上的承诺标签（亦出现在 `BoardPresentationStep.Commitment`）。

## 5. 交接协议

### HandoffState.cs

局部位姿 + 速度快照；`AtRest(localPosition)` 速度为 0。

### IHandoffEndpoint.cs

```csharp
HandoffState Evict();
void Admit(in HandoffState state);
```

实现者：Deck / Hand / FieldBattle / LayerConvergenceDriver；净土域实现常忽略速度。

### ICornerReshapePolicy.cs

拐角速度重塑；默认 `SprintCornerReshapePolicy`。

### IDependencyDag.cs

节拍依赖 DAG 接口；`NullDependencyDag` 空实现。

## 6. 飞牌服务与排序通道

### SlotDealFlightService.cs（internal）

GroundField 持有。类注释：

> Drain / Explore 均走 L2 五次收敛；换格 = Redirect，无替身、无握手。  
> Deal→Rotate 时起飞即瞄准预解最终格（逻辑占格仍 birth）。

| API | 作用 |
|-----|------|
| `StartExplore(birthSlot)` | 探索补牌飞行 |
| `LaunchDrainFlight(card, birthSlot, launchPos, context)` | Drain 批量飞行 |
| `TryRedirectFlightToSlot` | 环移/hop 接管 |
| `OnRingShifted` | 外圈旋转时平移探针 |
| `WaitAllSettledAsync` | 聚合句柄 |
| `CancelAll` / `IsInFlight` | 取消 / 查询 |

与根目录 `DealFlightHandle` / `DealFlightContext` / `DealSettleBudget` 协作。

### FlightSortingChannel.cs

飞牌期间抬高 SortingGroup order：`ArmForSlotConvergence` / `Raise` / `Restore` / `Disarm`。

## 8. 与 GroundField / DealFlight 的协作

```
GroundFieldManagerSingleton
  ├─ PresentationClock
  ├─ BeatGrid
  ├─ LeaseArbiter
  └─ SlotDealFlightService
         │ BeginDeal / Redirect
         ▼
      SlotFrameConvergence → LayerConvergenceDriver(L2)
         │
         ▼
      CardTransformTower.SlotFrame 位姿汇合到目标格
```

Deck `DealCard*` → Field `RequestPlaceCard` → `LaunchDrainFlight` / `StartExplore`。  
环旋转 → `OnRingShifted` + `TryRedirectFlightToSlot`。
