# Battle / 战斗表现

> 覆盖 `Assets/Scripts/Cards/Battle/` 全部类型。  
> 运行时调用方：`FieldBattleView`（根目录）经本目录的 Intent / Catalog / BindParams / Guard 完成交战绑参与路由。

---

## 1. 编排链路（源码推断）

```
点击场上卡 / 导演请求
        │
        ▼
FieldBattleView
        │ 构造 BattleIntent（Attack / Lethal / Counter…）
        ▼
BattlePresentationRouter.Resolve(catalog, intent, playerDefId, monsterDefId)
        │
        ▼
BattleEncounterProfileSO.ToBindParams() → BattleBindParams
        │
        ▼
CardAttackBasicAdapter → CardAttackBasicDirectionRig.BindParticipants(…, bind)
        │ Timeline / Tween
        │ 命中帧 → CombatHitSink.RequestCombatHit
        │ 致死 → BattleFinalStateGuard / 死亡回调
        ▼
表现结束；盘面 Drain 由 CombatHitSink / GroundField 缓释
```

## 2. 类型详解

### BattleIntent.cs

| 类型 | 说明 |
|------|------|
| `BattleIntent` | `Attack` · `AttackLethal` · `CounterAttack` · `CounterAttackLethal` |
| `BattleIntentUtility` | `IsLethal` / `IsCounter` / `FromFlags(counter, lethal)` |

由 FieldBattleManager 构造，经 Catalog 路由到 Encounter Profile。

### BattleParticipantIds.cs

参战双方 DefId 匹配用结构：

- 通配符常量（`Wildcard` / `*`）。
- `Normalize`、`Matches(pattern, actual)`。
- `Any` = 双通配。

### BattleEncounterProfileSO.cs

ScriptableObject：单次遭遇的演出参数。

| 关键字段（SerializeField） | 含义 |
|---------------------------|------|
| `profileId` / `displayName` / `description` | 身份 |
| `intent` | 预期 Intent |
| `playerContentId` / `monsterContentId` | DefId 通配匹配 |
| `rigFamily` | Rig 族（默认 CardAttackBasic） |
| `useRelativeAttackerMotion` / `useRelativeVictimKnockback` | 相对运动 |
| `victimKnockbackCoefficient` | 击退系数（按 Intent 钳制） |
| `bindDeathCallback` | 是否绑死亡回调 |
| `hitFlashTimingPolicy` | Heuristic / Explicit |
| `hitFlashCallbackDelay` / `deathCallbackDelay` | 显式延迟 |
| `restoreAttackerToSlot` / `restoreVictimToSlot` | 是否回锚 |
| `requireFinalStateGuard` | 是否强制 FinalStateGuard |

**API：** `ToBindParams()` · `ClampLockedFields()` · `ApplyIntentDefaults` · Editor setters。

### BattleEncounterCatalogSO.cs

ScriptableObject：路由表。

| 成员 | 说明 |
|------|------|
| `Entry` | intent + player/monster DefId + profile |
| `entries` | 按优先级：精确 > 单通配 > 双通配 |
| `Resolve` / `TryResolve` | 查表 |
| `EditorSet*` | 编辑器写入 |

### BattlePresentationRouter.cs

静态路由：

| API | 作用 |
|-----|------|
| `Resolve` / `TryResolve` | Catalog → Profile |
| `ResolveBindParams` | Profile → BindParams（失败走 SafeFallback） |
| `MatchKind` | 匹配精度枚举 |

### BattleBindParams.cs

值类型绑参（供 Rig.BindParticipants）：

- 从 Profile 投影的运动/回调/回锚标志。
- `IsLethal` / `IsCounter` 属性。
- `CreateSafeFallback(intent)`：Catalog 缺失时的安全默认。

### BattleHitFlashTimingPolicy.cs

枚举：受击闪白时机策略（Heuristic vs Explicit）。

### BattleFinalStateGuard.cs

静态工具：战斗结束时强制最终位姿。

| API | 作用 |
|-----|------|
| `Capture` | 拍 ParticipantSnapshot |
| `SnapImmediate` | Kill tween + 硬落锚 |

用于 `requireFinalStateGuard` 为 true 的遭遇。

## 3. 完整文件路由

| 文件 | 一句话 |
|------|--------|
| `BattleBindParams.cs` | Rig 绑参 DTO + SafeFallback |
| `BattleEncounterCatalogSO.cs` | Intent×参战方 → Profile 目录 |
| `BattleEncounterProfileSO.cs` | 单遭遇演出参数 SO |
| `BattleFinalStateGuard.cs` | 结束态硬对齐 |
| `BattleHitFlashTimingPolicy.cs` | 闪白时机策略枚举 |
| `BattleIntent.cs` | 攻击/反击/致死意图 |
| `BattleParticipantIds.cs` | DefId 通配匹配 |
| `BattlePresentationRouter.cs` | Catalog 静态解析器 |

## 4. 与根目录交战组件的分工

| 组件 | 层 | 职责 |
|------|-----|------|
| `FieldBattleView` | 根 | 流程编排、忙闲、点击入口 |
| `CardAttackBasicAdapter` | 根 | 选方向 Rig、播攻击 |
| `CardAttackBasicDirectionRig` | 根 | Timeline + 回调 |
| `Battle/*` | 本目录 | 数据驱动的 Intent/Profile/Bind |
| `CombatHitSink` | 根 | 命中写 Core 的桥（非本目录） |
