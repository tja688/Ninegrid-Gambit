## InBattleManagerSingleton

**路径**：`Assets/Scripts/Flow/InBattleManagerSingleton.cs`  
**职责**：局内 Core 桥 + Present 薄适配；**表演编排唯一出口**为 `PresentationDirector`（类注释 #11）。

### 公开入口（节选）

| API | 作用 |
|-----|------|
| `Instance` / `IsBusy` | 单例与局内忙标记 |
| `OnNodeSettlementReady` | 节点可结算时事件 |
| `StartBattleNodeAsync(...)` | 开战斗节点：清面、同步 UI、开 Trace session、装配导演 |
| `ClearPresentationSurface` / `ClearCardPresentationSurface` | 清表现面 |
| `RefreshPersistentInBattleUi` | 刷新遗物/HUD |
| `TryEnterNodeSettlement` | 尝试进入节点结算 |
| `NotifyPresentationBoardMayBeClear` | 盘面可能清空通知 |
| `PresentRewardChoiceFromCoreAsync` | 读 `PendingChoiceModel` 开 Bounce 奖励 |
| `PresentUnusedHelpCardSettlementFromEventLogAsync` | 未用帮助卡结算表演 |
| `PresentEffectTriggersFromEventLog` / `PresentGoldGainsFromEventLog` | EventLog → FX/金币 |
| `TryCheatSetAvatarHp` / `TryCheatSetAvatarAttack` / `TryCheatForceNodeVictory` | Debug 作弊 |

静态意图入口（Cards 侧调用）：`TrySubmitExploreIntentFromCards` / `TrySubmitAttackIntentFromCards` / `TrySubmitUseItemIntentFromCards`（private static，经 CombatHitSink 注册暴露）。

### Inspector 依赖

| 字段 | Tooltip 要点 |
|------|----------------|
| `cardManager` | 运行时自动 `CardManagerSingleton.Instance` |
| `deckManager` | 运行时自动 `CardDeckManagerSingleton.Instance` |
| `fieldManager` | 运行时自动 `GroundFieldManagerSingleton.Instance` |
| `relicManager` | 运行时自动 `RelicManagerSingleton.Instance` |
| `panelRouter` | 留空则同物体/场景查找 `UiPanelRouter` |

### 调用 Core 的方式

- `NineGridArchitecture.Current.GetModel/GetSystem`：`BoardModel`, `CardRegistry`, `DeckModel`, `PlayerModel`, `PendingChoiceModel`, `RunModel`, `IPhaseSystem`, `IActionPipelineSystem`, `IDeckSystem`, `IBoardSystem`, `IStatSystem`, `IEconomySystem`, `IPresentationSyncSystem`, `IContentSystem`
- `CoreCommandDispatcher`：由 `EnsurePresentationDirector` 构造，供 Intent 工厂发 `ClickEmpty` / `CombatHit` / `ApplyUseItem` / `ResolvePostKill*` 等
- 批次门：`PresentationSyncBatchGate.FromSync(IPresentationSyncSystem, resolve)`

### 生命周期

| 钩子 | 行为 |
|------|------|
| `Awake` | 单例、`ResolveManagers`、订阅场地信号、`RegisterCombatHitSink` |
| `Update` | `_presentationDirector.Tick`；同步 `CombatHitSink.DirectorMainlineBusy` |
| `OnDestroy` | 取消 Present CTS、退订、卸 Sink；Editor 下 `BattleTraceRecorder.ExportOnPlayExit` |
| `EnsurePresentationDirector` | 懒装配通道 + 三工厂 + Routing + TriggerPulseHub |
| `TeardownPresentationDirector` | HardClear、卸 Hold 钩子、Reset Pulse、清空通道 |

### 导演装配（代码事实）

```
QueuedBoardPresentChannel ×3 (explore / attackBoard / useItemBoard) → DrainPostKillBoardAsync
CombatAttackPresentChannel → PlayDirectorAttackHitPresentAsync
CombatCounterPresentChannel → PlayDirectorCounterPresentAsync
UseItemPresentChannel → PlayDirectorUseItemPresentAsync
Explore / Attack / UseItem IntentScriptFactory
RoutingIntentScriptFactory → PresentationDirector
TriggerPulseHub.Configure(CardEffectTriggerPulseSink, Debouncing(Audio))
CombatHitSink.Begin/End/ForceEndDirectorExternalHold ↔ TryBeginExternalHold / End / ForceEnd
```

投影回调 `On*BatchProjected`：补 `DamagePopups`、`Enqueue` 到对应通道、金币/效果脉冲/洗回扫描。

## MainGameLoopManagerSingleton

**路径**：`MainGameLoopManagerSingleton.cs`  
**职责**：主菜单 → 局内 → 通关奖励 → 房间二选一 → 房间事件 → 下一节点；关卡牌组由 `IRewardSystem` 按节点 DeckKind 随机。

### LoopState

`MainMenu` | `BattleStub` | `RewardChoice` | `RoomChoice` | `RoomEvent` | `VictoryNotice` | `DefeatNotice`

### 公开入口

| API | 作用 |
|-----|------|
| `BeginRun` / `BeginQuickTestRun` | 开跑 / 快速测试 |
| `TryBeginQuickTestFromPickerCode` | DevTest 选关码 |
| `ReturnToMainMenu` | 回主菜单 |
| `NotifyBattleVictory` / `NotifyBattleDefeat` | 局内通知胜负 |
| QuickTest / Debug 文案与 TimeScale | `Show*Notice`, `Build*MenuText`, `ApplyInBattleDebugQuickModeTimeScaleX*` |
| `CanAcceptQuickTestEntry` / `CanAcceptInBattleDebugQuickMode` | 门禁 |

常量：`QuickTestTimeScale`, `QuickTestAvatarHp`, `QuickTestAvatarAttack`。

### Inspector

`panelRouter`, `selectorManager`, `inBattleManager`, `startRunHit`, `quitGameHit`, `noticeText`, `worldCamera`；时序：`roomEventStubSeconds`, `victory/defeatNoticeSeconds`, `victory/defeatMessage`。均支持运行时查找兜底。

### Core

`IPhaseSystem`, `PendingChoiceModel`, `IRewardSystem`, `IContentSystem.Catalog`, `IActionPipelineSystem`；胜负后驱动 Trace 导出路径（经 Diagnostics API）。

### 生命周期

`Awake`：单例、绑定、订阅结算、进主菜单。`Update`：主菜单点选 Start/Quit。`OnDestroy`：退订、取消 CTS。

## SelectorManagerSingleton

**职责**：选择会话门面。

### Inspector

- `bouncePresenter`：Bounce；运行时可 Get/AddComponent
- `roomChoicePresenter`：房间二选一；可在 RoomChoisePanel 上 AddComponent
- `placeholderDefId`：默认占位卡 DefId

### API

`BeginBounceChoice(...)`（重载）、`BeginRoomChoice(...)`、`HideChoice`、`IsChoiceActive`。

不直接改 Core；由 InBattle/MainLoop 在 PendingChoice 时调用。

---

## DescriptionManagerSingleton

**职责**：遗留悬停 / Notice TMP；路由优先级 Hover / Drag / BoardSelect。  
**非权威**：卡面基础描述权威在 Cards Presentation Commit（`Basic_Description`）。Hover/Drag 对 ContentVisual 卡面文案不再写入 Card Info Text（防双写真相）；选择项 / BoardSelect / Notice / Avatar HUD 追加仍可写。

### Inspector

- `cardInfoText`：InGameInfoText 下 Card Info Text
- `noticeText`：Overlay Notice Text

### API

`Show(defId, route)`, `ShowText`, `ShowOnNotice`, `Clear*` / `ClearRoute`；返回 generation。

### Core

`IContentSystem` 解析描述；可读 `BoardModel`/`CardRegistry`/`IStatSystem`/`PlayerModel` 做动态替换。经 Sink 与 Cards hover 解耦。
