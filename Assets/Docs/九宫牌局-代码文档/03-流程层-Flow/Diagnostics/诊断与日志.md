# 诊断与日志（Diagnostics）

> 覆盖 `Assets/Scripts/Flow/Diagnostics/**`。落盘路径由代码 `DiagTraceShared.ResolveNotesDir` 推断（Editor → `Assets/Notes/...`）。

---

## 四轨总览

| 轨 | Track 枚举 | Recorder | JSON | 落盘目录（Editor） | 用途（从代码推断） |
|----|------------|----------|------|-------------------|-------------------|
| Battle | `DiagTraceTrack.Battle` | `BattleTraceRecorder` | `BattleTraceJson` | `Logs/OtherLog/BattleLog` | 战斗操作序列：op、相位、EventLog 切片、卡快照、Present 摘要、裁决提示 |
| Core / Flow | `Core` | `FlowTraceRecorder` | `FlowTraceJson` | `Logs/CoreLog` | 全流程事件时间线（schema v3 + beatId）：开跑/胜负/房间/导演旁路等 |
| Perf | `Perf` | `PerfTraceRecorder` | `PerfTraceJson` | `Logs/PerfLog` | 卡位姿/运动/异常；含 Director 剧本层打点（经 DirectorTrace） |
| Registry | `Registry` | `RegistryTraceRecorder` | `RegistryTraceJson` | `Logs/OtherLog/RegistryLog` | CardManager 注册表：Release/Audit/空位视觉差；缺卡类 bug |

统一会话身份：`DiagTraceShared` 的 `sessionId` / `seed` / `runTag`。  
自动导出总控：`DiagTraceExportPreferences`（EditorPrefs）；Play 退出经 `BattleTracePlayModeExporter`（Editor 程序集）与 `InBattle.OnDestroy` 双保险。

手动/胜负/重开：`BattleTraceRecorder.ExportBothNow` / `ExportTrackNow` 可导出四轨。

## 导出触发（代码事实）

1. **Play Mode 退出**：Editor `BattleTracePlayModeExporter` → `BattleTraceRecorder.ExportOnPlayExit`（内部可连带 Core/Perf）；`BattleSessionController.OnDestroy` 再调一次。
2. **偏好门控**：`AutoExportEnabled` + 分轨 `AutoExport*`；手动导出 `automatic: false` 不受限。
3. **录制开关**：`Enabled` setter 在 Editor 写回 Preferences；静态构造读 Preferences。
4. **非 Editor**：`ResolveNotesDir` 落到 `Application.persistentDataPath`。

---

## DirectorTrace ↔ Presentation

Presentation 不引用具体 Recorder 文件名以外：`using NineGrid.Flow.Diagnostics`，调用 `DirectorTrace.*`。  
`BattleTimeline` 经 `ITimelineDiagnosticSink` 写入 Step 进出；生产 sink 即 `DirectorTrace.TimelineSink`，事件落入 **PerfLog** 同轨。
