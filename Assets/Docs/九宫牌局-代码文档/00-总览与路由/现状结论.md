# 代码现状结论（跨层综合）

> 由各层权威文档归纳；仍只陈述源码事实，供重构前对齐。

---

## 分层真相

| 层 | 一句话 |
|----|--------|
| **Core** | 无引擎 QFramework 核：命令 → Phase → ActionPipeline → EventLog → PresentationBatch（需 Ack） |
| **Content** | Luban/硬编码 → `GameContentCatalog` + 视觉目录；不跑战斗 |
| **Flow** | Core↔Cards 编排壳：`PresentationDirector` 时间线 + Present 通道 + FinishBatch |
| **Cards** | Uid 注册表驱动手牌/牌库/九宫/飞牌；**程序集不引 Core** |
| **LivingUI / VisualLook** | 大盘载体转场 / URP 像素与文字相机；与玩法无 asmdef 耦合 |
| **DevTest** | TestKey 级联栈分发小键盘；末层优先 |

## 重构时最硬的事实

1. **依赖单向**：Cards ↛ Core；Content → Core；Flow 同时握 Core+Content+Cards。  
2. **场景宿主壳**：`BattleSessionController` / `GroundFieldView` / `FieldBattleView` / `GameFlowController` 仅保留场景绑定与生命周期；权威在 `PresentationCompositionRoot` + 各 QF System。  
3. **数据边界**：`Generated/Luban` 禁止手改；经 Tools/Luban + Content.Editor。  
4. **可删候选**：`NineGrid.TemporaryTest`（UITest 形态选择验收）。  
5. **验证面**：Core 契约/回归 + Presentation EditMode（含宿主合同结构测试）+ Cards 汇合/飞行数学。
