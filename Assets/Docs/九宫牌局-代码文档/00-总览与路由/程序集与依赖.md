## 结构性结论（从 asmdef 直接推出）

1. **Core 是纯逻辑核**：无 UnityEngine 引用；仅 QFramework。适合 EditMode 无场景测试。  
2. **Cards 不依赖 Core**：卡牌视图层与规则核在程序集级解耦；由 **Flow** 做桥。  
3. **Flow 是集成层**：同时引用 Core / Content / Cards / QFramework / 表现第三方。  
4. **LivingUI / VisualLook 不进主玩法程序集依赖**：与 Flow/Cards 的耦合若存在，只能是场景装配或反射/同场景 MonoBehaviour，而非 asmdef 硬依赖（LivingUI references 为空）。  
5. **DevTest 挂在最上层**：可直接摸 Flow/Cards/Core，属于开发期叠加层。
