# 命名空间与目录对照

以源码 `namespace` / `rootNamespace` 与文件夹为准。

---

## 主命名空间

| 命名空间前缀 | 典型目录 | 程序集 |
|--------------|----------|--------|
| `NineGrid.Core` | `NineGrid.Foundation/NineGrid.Core/**` | NineGrid.Core |
| `NineGrid.Core.Systems` | `.../Systems` | 同上 |
| `NineGrid.Core.Effects` | `.../Effects` | 同上 |
| `NineGrid.Core.Stats` | `.../Domain/Stats` | 同上 |
| `NineGrid.Core.Commands` | `.../Commands` + Domain/Commands | 同上 |
| `NineGrid.Core.Content` | Core 内 Content 契约 + Content 程序集协作 | Core / Content |
| `NineGrid.Content` | `NineGrid.Foundation/NineGrid.Content/**` | NineGrid.Content |
| `NineGrid.Flow` | `Scripts/Flow/**`（根） | NineGrid.Flow |
| `NineGrid.Flow.Presentation` | `Flow/Presentation/**` | 同上 |
| `NineGrid.Flow.Diagnostics` | `Flow/Diagnostics/**` | 同上 |
| `NineGrid.Cards` | `Scripts/Cards/**`（根） | NineGrid.Cards |
| `NineGrid.Cards.Convergence` | `Cards/Convergence/**` | 同上 |
| `NineGrid.Cards.Battle` | `Cards/Battle/**`（以实际 namespace为准） | 同上 |
| `NineGrid.LivingUI` | `UI/LivingUI/**` | NineGrid.LivingUI |
| `NineGrid.VisualLook` | `UI/VisualLook/**` | NineGrid.VisualLook |
| `NineGrid.DevTest` | `NineGrid.Foundation/NineGrid.DevTest/**` | NineGrid.DevTest |

Luban 生成代码命名空间以 `Generated/Luban` 下实际 `namespace` 为准（常见为 `cfg` / `tablenine` 相关），详见 [02 Generated-Luban](../02-内容层-NineGrid.Content/Generated-Luban/生成代码地图.md)。

## Core 内目录 → 职责标签

| 目录 | 标签 |
|------|------|
| `Architecture/` | `NineGridArchitecture` 注册入口 |
| `Models/` | QFramework Model：牌注册表、棋盘、牌库、玩家、Run、战斗上下文、待选 |
| `Systems/` | 棋盘/牌库/阶段/经济/奖励/属性/触发/内容/战斗作用域/行动管线 |
| `Effects/` | 效果系统与原子执行 |
| `Domain/` | 枚举、常量、Action、Event、Stat、SlotId 等纯领域 |
| `Presentation/` | 内核侧表现同步与命令分发桥 |
| `Commands/` / `Queries/` | 对外命令壳与查询 |
| `Setup/` | `InitialGameFactory` 等初始化 |
| `Utilities/` | RNG / Log / Config Utility |
| `Content/` | Core 侧内容接口/契约（与 Content 程序集对接） |

## Flow 根类型角色标签（按文件名）

| 后缀/模式 | 含义（从命名惯例） |
|-----------|-------------------|
| `BattleSessionController` / `GameFlowController` | 场景生命周期壳（非权威） |
| `*ManagerSingleton` | 仍保留的场景宿主（手牌/牌库/遗物等） |
| `*Presenter` | UI/选择呈现 |
| `*Scanner` | 扫描 Core/表现请求并转交 |
| `Presentation/*Channel` | 表现通道 |
| `Presentation/*Lockstep` | 与表现锁步 |
| `Presentation/*Step` | 时间线步骤 |
| `Diagnostics/*` | 追踪/导出 |

完整表见各层文档。

---

## Cards 根类型角色标签

| 模式 | 含义 |
|------|------|
| `GroundFieldView` / `FieldBattleView` | 场地/交战场景 View（几何与交战权威在 System） |
| `Card*ManagerSingleton` | 仍保留的区域宿主 |
| `*HitProxy` | 点击/射线代理 |
| `DealFlight*` | 发牌飞行数学与句柄 |
| `StandardCardView` / `CardVisualDriver` | 单卡视图 |
| `Convergence/*` | 表现汇合/编排子系统 |

## 快速跳转

- 内核注册表：`NineGridArchitecture.Init` → 见 Core Architecture 文档  
- 内容入口：`TableNineContentCatalog` → Content Catalog 文档  
- 战斗流程壳：`BattleSessionController` / `GameFlowController` → Flow Runtime-Managers（权威在 System）  
- 场地表现：`GroundFieldView` + `GroundFieldGeometrySystem` → Cards Managers
