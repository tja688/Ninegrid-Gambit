# 测试键栈与模块

> 键位与行为以各 `*DevKeys.ConfigureBindings` 源码为准；SO `declaredBindings` 仅为 Editor 目录元数据。

## 1. 核心类型

### 1.1 `TestKeyModuleBehaviour`

- 抽象 `ModuleId`；可选序列化 `layerProfile`。
- `LayerId`：有 Profile 用 `profile.LayerId`，否则 `ModuleId`。
- `OnEnable`：`ConfigureBindings` → `TestKeyManager.AttachLayer`。
- `OnDisable`：`DetachLayer(LayerId)`。
- 优先级**不**由模块决定，只由 `TestKeyStackConfigSO` 决定。

### 1.2 `TestKeyRegistrationBuilder`

```text
Bind(KeyCode, label, Action)  // 同键后写覆盖前写
Bind(KeyCode, Action)         // label = key.ToString()
Build()                       // 绑定数须 > 0，否则抛异常
```

### 1.3 `TestKeyLayerProfileSO`

| 字段 | 含义 |
|---|---|
| `layerId` | 与运行时挂载 ID 对应 |
| `displayName` | 监视器 / Runner 显示名 |
| `declaredBindings` | 键 + 标签元数据；**回调由 DevKeys 提供** |

CreateAssetMenu：`NineGrid/DevTest/Test Key Layer`。

### 1.4 `TestKeyStackConfigSO`

| API | 行为 |
|---|---|
| `Layers` | 只读列表；末项最高优先级 |
| `PromoteLayer(profile)` | 不在列表则追加；已在则移到末尾 |
| `PromoteLayerById(id)` | 按 layerId 移到末尾 |
| `RegisterLayerAsHighestPriority` | = `PromoteLayer` |

CreateAssetMenu：`NineGrid/DevTest/Test Key Stack`。

### 1.5 `TestKeyManager`（单例）

| API | 行为 |
|---|---|
| `SetStack(config)` | 载入 SO 顺序；`RebuildCascade` |
| `AttachLayer` | 挂载回调；未声明层 Insert(0) |
| `DetachLayer` | 卸回调；动态层移出栈 |
| `PromoteLayerToTop` | Editor only：写 SO 末项并重载 |
| `Register` / `UnregisterModule` | 旧 API 别名 |
| `PollInput` | 对 `ActiveBindings` 快照后 `GetKeyDown` |
| `TryInvokeRegisteredAction` | 按层+键直接 Invoke（无视级联） |
| `GetOverflowKeysForLayer` | 本层声明但被他层占用的键 |
| `Reset` / `ResetSingletonForTests` | 清空 / 测专用 |

### 1.6 宿主与轮询

| 类型 | ExecutionOrder | 行为 |
|---|---:|---|
| `TestKeyInputPoller` | -10000 | BeforeSceneLoad 载栈；AfterSceneLoad 建常驻 GO；Update 轮询 |
| `TestKeyStackHost` | -9999 | Awake：序列化 SO，空则 `Resources.Load("DevTest/TestKeyStack")` |

## 5. 非 TestKey 模块（同程序集 Flow）

| | |
|---|---|
| 目标 | `GameFlowController` |
| 门控 | `CanAcceptQuickTestEntry` |

## 6. 单元测试覆盖点（`TestKeyManagerTests`）

| 测试 | 断言要点 |
|---|---|
| `Cascade_BottomLayerWins_OnOverlappingKeys` | 末层赢同键；溢出键列表正确 |
| `PromoteLayerToTop_WritesStackAssetAndReloads` | 置顶后归属与 `StackOrder[^1]` |
| `AttachLayer_RespectsStackConfigOrder_ForConfigLayers` | SO 序不被挂载顺序打乱 |
| `AttachLayer_UndeclaredLayer_GetsLowestPriority` | 动态层在索引 0 |
| `DetachLayer_ReleasesKeysToLowerLayer` | 卸高层后键归还 |
| `GetAllRegisteredActions_IncludesOverflowBindings` | 溢出项 `IsKeypadActive=false` |
| `TryInvokeRegisteredAction_InvokesOverflowBinding` | 旁路可触发溢出层回调 |
