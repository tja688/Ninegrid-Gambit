## 2. 主场景装配（`Assets/Scenes/MainScene.unity`）

场景入口链（已核对 `Setup/PresentationSceneRoot.cs` 实现）：

```
PresentationSceneRoot（QF PresentationController，DefaultExecutionOrder -100）
  ├─ 序列化持有 10 个场景 Host：
  │    BattleSessionController / GameFlowController / RelicManagerSingleton /
  │    SelectorManagerSingleton / DamageNumberManagerSingleton /
  │    CardManagerSingleton / CardHandManagerSingleton / CardDeckManagerSingleton /
  │    GroundFieldView / FieldBattleView
  ├─ OnBind → WireHosts()：主菜单阶段即完成——
  │    PlayerAudioSettingsSystem / LanguageSettingsSystem / MusicSystem /
  │      VfxSystem .EnsureRegistered()（语言系统注册即装载翻译表，ADR-0046）
  │    BattleSessionController.BindSceneHosts(...)（依赖注入，源码禁 Find）
  │    静态 Hook 接线（CardEntityLifecycle / GroundFieldGeometry / Explore /
  │      BoardWalk / AvatarBoardFacing / FieldBattlePresentation / Attack /
  │      UseItem / Pickup / RecycleItem / GameFlowShell / RoomChoiceCore /
  │      RewardChoiceCore / RelicHud 各 Hook.RequestWire）
  │    输出 Controller EnsureInstalled（DamageNumber / TriggerPulse(三通道生产装配) /
  │      Diagnostic / GoldGainPresentationBinder）
  ├─ EnsureInstalled()（局内战斗开始时，由 BattleSessionController 经
  │    BindRuntimeLifecycle 回调触发，幂等）：
  │    mComposition(PresentationCompositionRoot).Install(PresentationSceneBindings)
  │      → PresentationRuntimeSystem → PresentationDirector → BattleTimeline
  │      → BattleBeatScheduler 注册处理器链（PlayerInfoHud → DamageFloater →
  │        CardFaceStat → CardFaceFlip → FX/金币装饰）
  ├─ Update：Tick IPresentationRuntimeSystem（战斗运行时）与 IVfxSystem（应用会话）
  └─ ShutdownRuntime(reason)：TeardownPresentationDirectorRequested 事件或 OnUnbind 收口
```

要点（对齐 code-map「MainScene 装配卫生」#141，已抽查）：

- **生产装配入口唯一**：MainScene 恰好一个 `PresentationSceneRoot`；`PresentationCompositionRoot.Install(bindings)` 是唯一生产装配入口；`PresentationSceneBindings` 只是场景 Host 引用包。
- **两段生命周期**：音频/音乐/VFX/玩家音量系统安装在**主菜单生命周期**（WireHosts，跨主菜单到跑图结束的应用会话）；战斗表演 Runtime（导演/时间线）只在**局内**经 `EnsureInstalled` 安装、战斗结束 Shutdown。`TriggerPulseHub` 局内关闭时只重置旧 FX 通道，audio/VFX 通道保持应用会话。
- **流程壳 View** 由 `GameFlowController.Awake` 自绑定 `GameFlowShellSystem`（单入口，SceneRoot 不重复 Bind）。
- 依赖一律经 `BindSceneHosts` 注入；生产源码禁 `FindObjectOfType` / `GameObject.Find`。
- 主线 busy 真相：`PresentationDirector.IsMainlineBusy`（经 `IPresentationRuntimeSystem` / InputState 只读投影）。
