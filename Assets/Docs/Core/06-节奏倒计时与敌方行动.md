# 06 卡级节奏、倒计时与敌方行动阶段

> 本篇覆盖：`Domain/AttackPattern.cs`、`Domain/ActionCountdown.cs`、`Domain/CardRhythm.cs`、`Domain/CardRhythmMoveTicks.cs`。敌方行动阶段的执行代码位于 `Systems/PhaseSystem.cs`（文件归属见第 7 篇），本篇讲清其流程。文件基准路径：`Assets/Scripts/NineGrid.Foundation/NineGrid.Core/`。

## 职责综述

怪物"多久打一次、从哪打得到"的完整规则：

- **攻击模式（AttackPattern）**：纯几何，四取值（无 / 普通近战=正交 / 斜角近战=对角 / 全向近战=八向）；出生属性，不进效果 DSL，不可运行时改写（ADR-0011）。
- **卡级节奏（CardRhythm，ADR-0038）**：每张有节奏需求的卡二选一绑定**行动计数**（九宫格互动推进）或**移动计数**（本卡盘面换格推进）通道，配置周期 X；攻击模式开火与技能同步触发共用同一个"还差几次"倒计时（`attackPattern.countdown` 计数器）。
- **倒计时数学（ActionCountdown，ADR-0013）**："每 N 次"统一为倒计时语义，支持大 delta 跨多阈值多次触发并保留余量。
- **敌方行动阶段（ADR-0012）**：报名 → 逐条结算 → 收尾的齐射，阶段内盘面冻结。

## 关键类型表

| 类型 | 文件 | 一句话职责 |
|---|---|---|
| `AttackPattern` / `AttackPatternRules` | `Domain/AttackPattern.cs` | 四取值枚举 + 中文 token 解析 + `ParticipatesInEnemyAction` + `MeetsPositionRequirement` 几何裁决；`Frequency` 已废止恒返 0 |

| `CardRhythmMoveTicks` | `Domain/CardRhythmMoveTicks.cs` | 移动通道推进：从动作结果的 CardMoved（盘面→盘面）事件对移动源正面卡 −1 共享倒计时并追加 ActionCountdownChanged |

## 核心流程与数据流

### 共享倒计时的生命周期

```
出生（CardDraft.Create）：NeedsRhythm ∧ 源合法 ∧ X>0 → Counters[attackPattern.countdown] = X
推进（两条通道，二选一）：
  行动源：敌方行动报名链（PhaseSystem.RegisterEnemyActionPhaseInternal）每次九宫格互动 −1
  移动源：本卡盘面换格（RotateBoard/Swap/MoveCard 的 CardMoved 事件 → CardRhythmMoveTicks）每次换格 −1；
          已在 0（开火窗）时保持 0 等报名收走
归零 = 开火窗口（一次性）：
  资格通过 → 单向打击（若模式≠无）+ OpenCardRhythmFireWindow（若有同步技能）→ 重置为 X
  资格不通过（位置不符/ActionBanned）→ 本窗作废，直接重置为 X（不保留蓄力）
效果加减速：ModifyActionCountdown 原子 → SetAttackPatternCountdownAction（背面目标跳过）
背面（ADR-0016）：冻结——报名跳过背面卡，移动 Tick 也要求 FaceUp
```

### 敌方行动阶段三段（代码在 PhaseSystem，命令分拍见第 1 篇）

**报名（RegisterEnemyActionPhaseInternal）**
- 遍历场上正面怪（Trap 不参与——只收 `Kind==Monster`）且 `HasActiveRhythm`。
- 移动源：只收已归零者入名单（推进发生在换格路径，报名不 −1）。
- 行动源：剩余 >0 则 −1（经 `SetAttackPatternCountdownAction` 落事件）；减后 ≤0 或本来已 ≤0 入名单。
- 名单按 **uid 升序**冻结（进场先后）；随后对全场背面卡跑 `FaceDownTickCounters.TickFaceDownBoard`。

**逐条结算（ResolveNextEnemyActionInternal，每调用一条）**
- 终端相位或玩家已死 → 剩余名单作废。
- 复核：怪仍在场存活、仍正面（背面则不开火**且不重置**，保持冻结）。
- 模式参与开火时复核 `ActionBanned` 与 `MeetsPositionRequirement`；不过 → 整窗作废重置为 X（同步技能也不触发）。
- 通过：模式≠无 → `DealDamageAction(怪→玩家, 有效攻+EnemyAttackDelta)` 单向打击（**不开交战作用域**，玩家不反击）；有同步技能 → `OpenCardRhythmFireWindowAction`（发 `CardRhythmFireOpened` 事件，Post 派发 `OnCardRhythmFire`，订阅的技能同拍触发）。
- 收尾重置倒计时为 X；打死玩家则名单立即作废。

**收尾（ResolveEnemyActionFinaleInternal）**
- 清名单 + `CompleteNodeIfCleared`；**不补牌不旋转**（补位交给统一稳定化边界）。

### 几何速查

| 模式 | 位置条件（怪 vs Avatar 格） |
|---|---|
| 无 | 不开火（可有同步技能，仅走 OpenCardRhythmFireWindow 路径） |
| 普通近战 | `IsAdjacentTo`（行列差绝对值和 = 1） |
| 斜角近战 | `IsDiagonallyAdjacentTo`（行列差均 = 1） |
| 全向近战 | 上两者并集（八向） |

`Unspecified` 是装配错误（`ContentSystem.ValidateCatalog` 报 issue），不得静默当"无"。

### ActionCountdown 数学

`TickCount(counters, key, period, delta)`：未初始化（≤0）先置为 period；`after = remaining - delta`；`after > 0` 存回返回 0；否则触发次数 = `(-after)/period + 1`，余量 `after + fireCount*period` 存回。`period ≤ 1` 时任意正 delta 直接返回 delta 且不碰计数器。DSL 的 `OnInteract every` / `OnSelfMove every` / `OnCumulative threshold` 全走此原语（与卡级共享倒计时是**不同的计数器键**，互不偷值）。

## 对外通信面

- `ActionCountdownChanged` 事件（ResultValue=剩余）→ 表现层 `UpdateActionCount` 指令（Settled 提交，卡面「行动计数」槽）。
- `CardRhythmFireOpened` 事件不进表现批次（映射表 RequiresPlayback=false），仅驱动 OnCardRhythmFire 触发点。
- 导演分拍命令：`RegisterEnemyActionPhase` / `ResolveNextEnemyAction`（每怪一拍）/ `ResolveEnemyActionFinale`；`PendingEnemyActionUids` 供表现层读名单余量。

## 关联 ADR

- ADR-0038（双通道 + 共享倒计时 + 同拍触发；废止模式表频率）
- ADR-0011（几何四取值、必填、不可运行时改写）
- ADR-0013（倒计时语义、一次性窗口、可加减速）
- ADR-0012（报名/逐条/收尾、盘面冻结、uid 升序名单、玩家死亡中断）
- ADR-0016（背面不报名、不推进、结算时背面不重置）

## 不变量与坑

- **窗口一次性**：错过位置就重置为 X，不停留在 0 等下拍（唯一例外：移动源已归零等待报名收走时保持 0）。
- **名单冻结、资格复核**：中途进场/被加速的怪不插队；被推远的怪打不到（逐条时实时复核位置）。
- **模式与技能同拍**：位置不符作废的是**整窗**——同步技能也不触发（`patternFires && 不合格 → return`，代码顺序保证）。
- 攻击伤害取**有效攻**再加 `EnemyAttackDelta` 规则；与交战同一 `GetAttackDamage`。
- `AttackPatternRules.Frequency` 是废止兼容桩（恒 0），别再当频率表用。
- 名单期间累计的死亡统一在批间由稳定化处理；阶段自身绝不触发旋转。
