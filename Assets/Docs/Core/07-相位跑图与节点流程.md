# 07 相位门禁、跑图进程与节点流程

> 本篇覆盖：`Systems/PhaseSystem.cs`（约 2000 行，Core 最大流程枢纽）、`Domain/Actions/PhaseActions.cs`、`Domain/MapNodeProgression.cs`。文件基准路径：`Assets/Scripts/NineGrid.Foundation/NineGrid.Core/`。

## 职责综述

`PhaseSystem` 是全部玩家命令的**门禁与编排层**：维护合法命令矩阵（LegalCommands）、把每条命令展开为动作序列、驱动节点生命周期（开局管线 → 交互循环 → 清关 → 选房 → 进房 → 推进节点）与敌方行动阶段（流程见第 6 篇）。`MapNodeProgression` 是 8 节点/层的编排只读表（ADR-0021）。`PhaseActions` 提供相位切换、节点事件、选择容器操作等轻量动作。

## 核心流程与数据流

### 相位机（GamePhase）

```
None/BuildEnemyPool/NodeCompleted ─StartNode→ 战斗节点:
  ClearPendingChoices → ReactivateMissingRelicEffects（遗物效果自愈，须在 NodeStarted 前）
  → BuildEnemyPool → SetupNodeDeck → (Avatar归位格5) → ResetNode → DealOpeningCards
  → OpeningDeal → ResetCurrentArmor → FillEmptySlots → NodeStarted → InteractionLoop
非战斗节点(4/7)：ClearPendingChoices → ReactivateMissingRelicEffects → ResetNode
  → ResetCurrentArmor → NodeStarted → RoomChoice（放导航/层主房图标）
InteractionLoop ─击破离开机关→ ClearCheck → NodeCompleted → RoomChoice（放选项族）
RoomChoice ─SelectRoom→ RoomEvent ─EnterRoom→
  消费/特殊房 → RewardItemChoice（房内会话）→ 离开 → AdvanceNode → NodeCompleted
  战斗房 → AdvanceNode → NodeCompleted →（壳层再 StartNode 下一节点）
第 3 层节点 8 清关后踩下楼 → AdvanceNode 返回通关 → Victory
Avatar HP≤0（任意时点）→ Defeat（终端粘性）
```

### 合法命令矩阵（RefreshLegalCommands）

- **Presentation 锁定期**（批次未 ack）：仅 `PresentationFinished` + 待决选择命令（宝箱 Bounce 期间必须仍能 Select/Skip，防孤儿 PendingChoice 卡死）。
- **InteractionLoop**：有奖励待决 → 仅 SelectReward/Skip/DiscardRelic/RecycleItemSlot；Avatar 活着 → Attack/Pickup/ClickEmpty/UseItem/RevealFace/DiscardRelic/RecycleItemSlot；Avatar 判死（ADR-0039）→ 仅栏位管理。
- **RewardItemChoice**：选择/跳过 + 回收丢弃 + UseItem（ADR-0032 卡级裁决在 UseItem 内）+ 商店刷新 + 消费房场地板 MoveAvatar。
- **RoomChoice**：SelectRoom/Pickup/UseItem/MoveAvatar/回收丢弃；宝箱卡开出遗物三选一时放行 Select/Skip。
- **RoomEvent**：EnterRoom/MoveAvatar/回收丢弃。

### 玩家交互命令（门禁细节）

- `Attack`：格有卡、可交战桶、正交邻接（含虚拟邻接）、无嘲讽限制、目标正面 → 交战编排（第 5 篇）→ 互动 +1 → 稳定化 →（击杀则旋转+再稳定化）→ 敌方行动整拍。导演分拍路径改用 `CombatHit` + 各分拍命令自行编排。
- `PickupItem` / `ApplyPickupItem`：邻接 + 非交战对象；帮助卡（无 GoldReward）满格拒入；InteractionLoop 下走整拍 `ResolveInteractiveRotation`（计数+稳定化+旋转+敌方行动）。
- `ClickEmpty`：邻接空格发事件；旋转补牌留给导演分拍。
- `RevealFace`：邻接背面卡单向翻开（消耗互动由表现剧本分拍推进）。
- `MoveAvatar`：仅非战斗相位合法；正交单步；RoomChoice/RoomEvent/RewardItemChoice 允许踩软占格。
- `UseItem`：ItemSlots 内 + 种类可用 + 相位裁决（InteractionLoop 恒放行；RoomChoice/RewardItemChoice 看卡级 `usableOutsideBattle`，ADR-0032）；遗物栏满时拒开宝箱类卡；用毕 `ConsumeUsedItemIfStillInItemSlots` 移除；主管线跑完后为 ADR-0044 道具链收尾锚点——ForceBattle 类道具交战窗内挂起的位移在此落地。
- `RecycleItemSlot` / `DiscardRelic`：移除 + EconomySystem 兑金（+10 / +20）。

### 消费房会话（SelectReward 分派）

按 `PendingChoiceModel` 池 id 分派：属性三选二（已废止路径）→ 卡店固定二级确认 → 卡店三服务（扣费、下架本货架、留店）→ 商店道具牌格升级（50 金 +1 格，满 5 下架）→ 商店购买（按 Catalog Price 扣金，货架拿走留店）→ 普通奖励（含遗物三选一：满栏拒选、记未选中降权、嵌套时恢复挂起货架）。`RefreshShop`：扣本次刷新价并翻倍、重建货架/服务。`SkipHelpChoice`：按池区分——消费房离开不发金、遗物三选一跳过发 SkipRelicChoiceGold、通关帮助三选一跳过发 SkipHelpChoiceGold。

### 清关收场（CompleteNodeIfCleared）

InteractionLoop ∧ `IsNodeCleared`（离开机关已破）时：ClearCheck → NodeCompleted → NodeCompletedAction → ResetBattleScopedCountdowns → ClearNodeTransientModifiers（清四档临时修正，「对战残留不出局」）→ ResetCurrentArmor（当前甲回落到有效甲）→（EconomySystem）`SettleUnusedHelpCards`（开局真怪全灭才兑金场上残留道具）+ `ClearResidualTraps`（清残留怪与机关不兑金）→ RoomChoice + 按节点表放出选项/导航。临时修正清理放在 NodeCompleted 之后，保证 OnNodeEnd 类效果（如结算回血）先在原数值语境下结算。

- `LegalCommands` / `CanExecute` 供表现层 IntentIntake 预判。

## 不变量与坑

- **StartNode 不变量（开发断言）**：全链结束后 HP≤0 ⇒ phase==Defeat；Avatar zone 非法（在册 HP>0 但 Zone≠Avatar）在 StartNode 强制归位格 5 自愈。
- **互动计数无条件推进**：交战无论击杀与否都 +1（`AdvanceInteractionCountInternal` 甚至在已 Defeat 时仍计一次）；其开头是 ADR-0044 的交战收尾锚点——先落地挂起位移再 +1 计数。
- **挂起位移排水（FlushDeferredBoardMotionsInternal）**：三处锚点（互动计数推进 / 敌方行动收尾 / 道具链收尾）共用的循环排水——落地引发的连锁若再开窗口再挂起（如 OnMoveToSlot→ForceBattle），循环继续，迭代上限 8 护栏；终局相位直接丢弃队列；窗口仍打开（嵌套未闭合）时留给下一锚点。
- **未清关才旋转**：`ResolvePostKillRotateInternal` 在已清关时跳过旋转直接收场——击破离开机关那一拍不再补牌/旋转（防表现层发牌飞行卡死主线）。
- `mInRoomRewardContext`：进消费/特殊房置位；房内会话结束（选完/跳过）据此 AdvanceNode 离房——中途被遗物三选一覆盖再恢复不丢该位。
- 命令门禁与"Apply* 可信通道"并存：改门禁时两条路径都要看（如 ApplyUseItem 不查相位但仍查 ItemSlots 注册）。
- `SelectReward` 中商店/特殊房分支不清 PendingChoice（留店）；普通奖励清掉后按"未清关回 InteractionLoop / 已清关放选项"续流程（`ResolvePostRewardChoiceFlow`）。
