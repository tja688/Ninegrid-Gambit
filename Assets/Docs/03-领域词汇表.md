## 跑图与房间

| 词条 | 含义 | 代码体现 |
|------|------|----------|
| 跑图（Run） | 从选角到通关/死亡的一整趟；3 层 × 每层 8 节点；进度真相在 Core | `C/Models/RunModel.cs`（Floor/NodeIndex/Seed） |
| 层（Floor） | 跑图大段落，8 节点，末节点为层主房；每层开局绑一套未用过的主题怪物卡组 | `RunModel` + `RewardSystem.FindMonsterDeck` |
| 地图节点（MapNode） | 层内落脚点 1–8；节点自身无内容，序号决定清关后放哪类房间选项；4/7 非战斗 | `C/Domain/MapNodeProgression.cs` |
| 房间 | 节点的具体化：战斗房/消费房/特殊房三族 | `RoomKind` 枚举、`RoomDefinition`（Catalog 投影） |
| 清关 | 完成战斗节点、放出后续图标的规则事件；唯一手段=击破离开机关卡 | `PhaseSystem.IsNodeCleared`=`IsLeaveTrapBroken`（ADR-0026） |
| 离开机关卡 | 打通对局的关键机关卡，持「门」「魔免」「离开」三技能 | 内容 `trap.leave`；模板 `tpl.trap.door/magic_immunity/leave` |
| 门（机关技能） | 持有者只承受交战中玩家出手的伤害，其余伤害/移除无效 | Core 伤害与移除管线的 Rule 分支（ADR-0026） |
| 魔免（机关技能） | 不受任何外来「效果」影响；可被选中但效果管线剔除目标 | 效果管线目标剔除（ADR-0026） |
| 场地图标 | 落在九宫格上、走上去驻留触发的非卡牌实体（房间图标/导航图标）；导航不进玩法 Catalog | `P/Flow/RoomIcons/`（Spawn/占格/驻留） |
| 驻留提交 | 踩上图标停留满 1 秒自动提交；跳走取消；计时器在表现侧 | `RoomIconDwellSession` → IntentIntake |
| 就地选项卡 | 房内落格、任意距离点击生效的选项实体（卡店服务等）；不算九宫格互动 | `P/Flow/TavernBoard/`、`ShopBoard/`；kind=`ChoiceOption` |
| 简要解释 | 悬停当前格认领者时的一句话说明（兼胜负 Notice） | `P/Flow/BoardBriefTip/` → 场景 `Panels/简要解释文字框` |
| 主题怪物卡组 | 一套 5 张、序列 1–5 的怪物集合；按层难度档随机绑定 | `monster_decks.json`、`CT/Catalog/ThemeDeckStableMapping.cs`/`ThemeDeckFloorTierMapping.cs` |
| 序列（sequence） | 怪物在其主题卡组内的梯队位次 1–5；序列 5=层主 | 怪物 JSON `sequence`/`level`；`NodeDeckRule` 按序列抽卡 |
| 怪物层数数值叠加 | 相对第 1 层基准每升一层攻 +1、血 +2 | `C/Content/MonsterFloorStatScaling.cs`（`ContentSystem.CreateDraft` 注入） |

## 玩家持有与经济

| 词条 | 含义 | 代码体现 |
|------|------|----------|
| 道具卡格 | 已入手道具的唯一持有域；跑图内持续持有，不因清关被清；口语「手牌」 | Core `PlayerModel.ItemSlots`（ADR-0025） |
| 道具卡格容量 | 道具卡格格位数：初始 3、上限 5；商店 50 金升 1 级 | `PlayerModel.ItemSlotsCapacity`、商店 `ExpandItemSlots` |
| 玩家侧卡组 | 每个战斗节点开局按规则重生成、发进场地的道具卡集合（固定卡+来源池随机+房间注入） | `RewardSystem.BuildNodeDeckOptions`（ADR-0022） |
| 玩家侧卡组容量 | 每战斗重生成张数上限（默认 6，卡店扩容） | `PlayerModel.ItemDeckCapacity` |
| 来源池 | 玩家侧随机装填的候选 defId 池，只含常规（White）道具卡 | `ItemSourcePoolDefIds`、`ProfessionCatalog.SeedItemGenerationRules`（ADR-0033） |
| 常规 / 特殊（稀有度投放） | White=常规可进随机池；蓝/金/红=特殊只走定向渠道 | `HelpCardDecks.RegularRarity`（ADR-0033） |
| 道具卡回收 | 拖入回收区离手，每张固定 +10 金 | Core `RecycleItemSlot`；表现 `HandcardRecycleZone`/`CardRecycleNotice` |
| 遗物丢弃 | 遗物图标拖入同一回收区，每件 +20 金；右键只详述 | Core `DiscardRelic`；`RelicManagerSingleton`（ADR-0027） |
| 携带卡包（已退役） | 旧中转容器；现购入/奖励一律直写道具卡格，满则拒 | 无代码（禁复活，ADR-0025） |
| 非战斗可用 | 道具卡卡级声明 `usableOutsideBattle`；RoomChoice/RewardItemChoice 可拖用 | `C/Content/ItemUseEligibility.cs`（ADR-0032） |
| 功能角色（ContentRole） | 帮助卡/遗物投放粗轴（攻/防/功能）；「防御」仅指投放桶，非战斗属性 | 卡 JSON `role`；投放均衡规则 |
| 细标签（tags） | 可增长的多值检索标签，不承担投放均衡 | 卡 JSON `tags` |
| 卡组（deckId） | 卡的视觉归属（卡背）兼怪物遭遇分组；内部渠道代号 | 卡 JSON `deckId`；`deck.trap`/`deck.help`/`deck.relic` 等 |
| 主题 ID 不透明 | `deck.dragon`、`SkeletonFusion*` 等主题词是历史虚构命名，按不透明主键处理 | 全仓约定（ADR-0014）；玩家称呼走 `displayName` |
| 归档卡组 | 显示名含「归档」的组及成员不属正式接线（保留 JSON、不进奖池/遭遇） | `deck.relic_archive`/`deck.help_archive`/`deck.transition`、怪物 `isReserve`；`CardPresentationPrimaryCardRules` |
| 主要内容卡牌 | 批量描述导出语境的四类：Monster/Relic/HelpCard/Trap（排除归档） | `CT/CardPresentation/CardPresentationPrimaryCardRules.cs` |

## 战斗规则

| 词条 | 含义 | 代码体现 |
|------|------|----------|
| 九宫格互动 | 玩家对棋盘的一次操作（交战/拾取/点空格）；推进行动计数通道；道具使用不算 | `IPhaseSystem.AdvanceInteractionCount` |
| 行动计数 / 移动计数 | 内核双节奏通道：前者由九宫格互动推进，后者由本卡盘面换格推进 | `C/Domain/CardRhythm.cs`（ADR-0038） |
| 卡级节奏源 / 节奏周期 | 卡出生时二选一绑定的通道 + 正整数周期 X | 怪 JSON `rhythmSource`/`rhythmPeriod` |
| 卡级共享倒计时 | 「还差几次」剩余值；攻击模式与技能同步触发共用；卡面行动计数槽显示它 | Core 计数器（`AttackPatternCountdown` 系）；上屏经 `ActionCountdownChanged` Settled |
| 开火窗口 | 倒计时归零那一拍；一次性——位置不合格即作废并重置为 X | `PhaseSystem` 敌方行动裁决（ADR-0013/0038） |
| 技能同步触发 | 绑定卡级节奏、与攻击模式同拍触发的技能（不自带 every） | `OnCardRhythmFire` 触发点 |
| 攻击模式 | 怪物必填内生几何属性：普通近战/斜角近战/全向近战/无；只管「打得到吗」不管频率 | 怪 JSON `attackPattern`（ADR-0011） |
| 敌方行动阶段 | 报名→逐条结算→收尾的齐射；阶段内盘面冻结 | `PhaseSystem` 分拍入口 + `EnemyActionPhaseScheduler`（ADR-0012） |
| 行动名单 | 报名时冻结的本拍开火序列（uid 升序），不再增删 | 同上 |
| 盘面冻结 | 齐射报名与结算期间不补牌不旋转；死亡收尾统一处理 | 同上 |
| 交战 | 玩家发起的与正交相邻怪物互相伤害结算；`OnBattle` 仅交战作用域 | `IBattleScopeSystem`（Begin…End） |
| 单向打击 | 怪物按攻击模式主动打玩家一次，玩家不反击；不是交战 | 敌方行动阶段结算路径 |
| 先手还击 | 交战内出手顺序裁决；仅交换入队顺序不产生额外攻击 | `RuleId.FirstStrike`、`CombatEngagementOrder`、`MonsterStrikesFirstQuery` |
| 牌面朝向 | 卡的明/暗逻辑状态，权威在 Core；背面双向惰性 | `CardInstance.FaceUp`、`FlipCardAction`/`RevealFace`（ADR-0016） |
| 背面 Tick | 需要「背面仍计回合」的效果的独立计数（`faceDownTick.*`） | `C/Domain/FaceDownTickCounters.cs` |
| 机关卡（Trap） | 可交战可受伤的非怪物卡；不计真怪、无赏金、静默禁反击 | `CardKind.Trap`、`C/Domain/CardCombatRules.cs`（ADR-0017） |
| 可交战桶 / 真怪物桶 | `IsBoardCombatTarget`=Monster\|Trap；`IsTrueMonster`=仅 Monster（赏金/清关分母） | `CardCombatRules` 双桶 helper |
| 基础/有效/当前护甲 | 静态成长层 / 经 Modifier 后 / 本关可消耗缓冲（受伤先扣） | `StatId.Armor`、`GetEffectiveInt`、`StatId.CurrentArmor`（ADR-0028） |
| 伤害减免 | 受击方累加减伤属性，公式在甲吸收前减去；不上卡面/HUD | `RuleId.DamageReduction` |
| 无视护甲 | 单次伤害实例标记：跳过甲与金甲全额打血 | `DealDamageAction.IgnoreArmor`、DSL `ignoreArmor` |
| 金甲 | 金币盔甲吸收：每 5 金抵 1 点「拟甲伤」，不救溢出血伤 | `GoldArmorAbsorb`（Core 伤害公式内） |
| 盘面稳定化 | 「有非 Avatar 空格且牌堆有牌就欠补位」的稳定边界，Core 权威逐切片裁决 | `C/Systems/BoardStabilizationSystem.cs` + `BoardStabilizationScheduler`（ADR-0034） |
| 占格权威 vs 几何注册 | 逻辑占格真相唯一在 Core `BoardModel`；表现只持「格位→认领者」几何注册 | `BoardModel` / `SlotClaimRegistry` |

## 表演编排与输入

| 词条 | 含义 | 代码体现 |
|------|------|----------|
| 表演导演（PresentationDirector） | 战斗表演时间线唯一所有者与出口 | `P/Flow/Presentation/PresentationDirector.cs` |
| 编排时间线（BattleTimeline） | 唯一串行主线；输入互斥只认它是否在跑 | `P/Flow/Presentation/BattleTimeline.cs` |
| 编排步骤（Step） | 时间线原子单元：解算下一批/播表演/Delay/触发脉冲 | `ITimelineStep`/`PresentStep` |
| 解算批次（Batch） | 一拍被 ack 驱动的 Core 解算，配 OpenBatch/FinishBatch | `C/Presentation/PresentationSyncSystem.cs` |
| 就位回执（ack） | 一批表演播完、通知时间线可前进的信号 | `PresentStep.TryAcknowledge` |
| 输入意图（InputIntent） | 输入转成的、经 IntentIntake 裁决的请求；不直改状态 | `InputIntentKinds`（Explore/Attack/Pickup/UseItem/BoardWalk/RevealFace/RecycleItem…） |
| 意图收口（IntentIntake） | 输入进入编排的唯一入口；门禁/合法性/互斥一处裁决 | `P/Systems/IntentIntakeSystem.cs`（ADR-0004） |
| 时序互斥（Mainline busy） | 门禁第一轴：唯一以主线是否在跑为准；忙时棋盘动作 Reject 不缓冲 | `PresentationDirector.IsMainlineBusy` |
| 输入所有权 | 门禁第二轴：当前拥有输入的表面（受保护场地/场地覆层/棋盘选择） | `PresentationInputStateSystem.CurrentOwner` |
| 冲动轻点（impatience tap） | 忙时额外点击发给（当前 no-op）加速通道的独立脉冲 | `IAccelerationSink` |
| 触发脉冲（Trigger） | 特效/音效一次性脉冲，发即完成、可降级、不占主线 | `TriggerPulseHub`（FX/audio/VFX 三通道） |
| 旁路装饰道 | 纯装饰表演的并行道，不占输入互斥锁 | 飘字/FX/金币等 BeatHandler |
| 表演锚点（Beat） | 结算指令的表演消费时刻：Impact/Settled/None | `NineGrid.Core.PresentationBeat` + `PresentationEventMap` |
| 结算指令 | 一批解算产出的事实条目（数值为绝对值） | `PresentationBatch.Instructions` |
| 投影提交（Commit） | 可见值推到卡面消费端的动作；数值只经排期器触发 | `BattleBeatScheduler` → `CardFaceStatHandler` → `ManagedCard.CommitPresentation` |
| 权威值 vs 卡面显示值 | 内核此刻真相 vs 玩家看到的数字（有意滞后） | ADR-0005 分层 |
| 触发可见因果 | 后果上屏前触发条件必须已可见 | `FlushImpactExcept` / Drain 冲刷时机（ADR-0018） |
| 战斗锚点排期器 | 一批指令唯一分发出口，多处理器第一认领者消费 | `BattleBeatScheduler` + `IBattleBeatHandler`（ADR-0007） |
| 表面 / 场地面 | 指针命中仲裁最小单位；九宫格整体是单一表面 | `PointerHitRouter`/`PointerHitSurfacePriorities`/`GroundFieldHitSurface` |
| 格位命中框 | 格位锚点上世界尺寸恒定的命中区；棋盘几何、全局常开 | 场景 `GroundAnchors/slotN` 的 `BoxCollider2D`（ADR-0023） |
| 认领者 | 某格此刻静止的可点击实体；一格一认领者；Avatar/飞行中永不认领 | `SlotClaimRegistry` |
| 命中恒成功 | 棋盘内点击永远命中某格；「不生效」必须是显式拒绝 | IntentIntake 拒绝记录 |
| 卡牌底盘 / 卡面模板 | 运行时卡实体（塔/排序/命中/挂点）/ 按 Kind 的可见构型 | `StandardCardView`（底盘宿主）+ 五套卡面 prefab（`CardChassisPaths`） |
| ChainId / ChoreoSeqId | 诊断两级关联键：连锁根 / 动作内展开 | `PresentationDirector` 分配 + `ChoreoTraceContext`（ADR-0003） |
