## 战斗关卡循环流程

战斗关卡流程固定为以下阶段，前一阶段未完成不得进入下一阶段：

1. 生成玩家侧卡组（若房间类型额外增加道具卡，则在玩家侧卡组生成后加入）
2. 生成怪物侧卡组（若房间类型额外增加怪物卡，则在怪物侧卡组生成后加入）
3. 确认 [[玩家卡]] 位置在格5，重置节点状态
4. 按 [[发牌机制]] 进行开局发牌
5. 玩家互动循环，每次互动后触发空格补牌。
6. 击破带「离开」技能的离开机关卡即清关（**唯一清关条件**）；真怪物清零不再自动清关。击破当拍场上残留（未拾取道具 / 剩余怪 / 其它机关）一并清场且**不兑金**；[[道具卡格]] 内容跨节点保留。
7. 清关后按节点放出选项（玩家自行选择时机触发）：
   - 节点1 / 2 / 5 → 两个**战斗**房间选项（节点5起含困难房）
   - 节点3 → 两个**消费**房间选项（商店 / 卡店）
   - 节点6 → 两个**特殊**房间选项（宝箱奖励房 / 道具奖励房）
   - 节点8 → 进入下层选项（第三层则游戏通关）
   - 节点4 / 节点7 为**非战斗缓冲**：节点4 放 1 个**离开**导航图标推进至节点5；节点7 放 1 个**层主房**图标（战前缓冲），走格进入后推进至节点8 开战
8. 玩家选定选项后前往下一地图节点；清关残留不兑金，金币仅来自**主动回收**（拖入回收区，每张 +10）

## 关卡间状态继承

| 状态 | 关卡结束后 |
|------|-----------|
| 玩家基础属性（攻击/血量/护甲） | 本局永久保留 |
| 当前护甲 | 重置为有效护甲 |
| 技能描述中"本关卡永久获得"的属性 | 清除 |
| 遗物 | 本局永久保留（除非丢弃） |
| 道具卡格内的道具卡 | 跨关卡保留，使用后移除 |
| 道具卡格外的未使用道具卡 | 清关清场时移除，不兑金（主动回收才 +10 金币） |
