## 关卡循环
1. 按 [[游戏开发项目/九宫格登神/03-敌人侧卡牌/敌人侧卡组生成]]生成敌人侧卡组
2. 确认 [[玩家卡]] 位置在格5，重置节点状态
3. 按 [[机制汇总]] 开局发牌
4. 玩家互动循环（战斗/拾取/旋转），每次互动后触发空格补牌。详见[[机制汇总]]
5. 击破带「离开」技能的离开机关卡即清关（**唯一清关条件**，ADR-0026）；真怪物清零不再自动清关
6. 清关当拍场上残留（未拾取道具 / 剩余怪 / 其它机关）一并清场且**不兑金**；[[道具卡格]] 内容跨节点保留
7. 清关后按节点放出场地图标（见[[层级流程]]）：节点3 → 消费房（商店 / 卡店）、节点6 → 特殊房（宝箱 / 道具奖励房）、节点8 → 下楼；节点4 / 7 为**非战斗缓冲**（离开图标 / 层主房图标）
8. 玩家走格 / 驻留选择图标进入下一节点
9. 前往下一节点

## 每层循环

1. 开始游戏
2. 进行地图节点1（随机战斗房）
3. 进行地图节点2（前一选定战斗房）
4. 进行地图节点3（战斗房，清关后放两个消费房选项）
5. 进行地图节点4（**非战斗导航缓冲**：1 个离开图标，推进至节点5）
6. 进行地图节点5（随机战斗房，清关后放两个战斗房选项）
7. 进行地图节点6（战斗房，清关后放两个特殊房选项）
8. 进行地图节点7（**非战斗层主缓冲**：1 个层主房图标，进房后推进至节点8开战）
9. 进行地图节点8（层主房）
10. 进入下一层；第3层通关
