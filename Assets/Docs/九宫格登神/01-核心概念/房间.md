## 定义
房间是地图节点的具体化

## 战斗房间类型
| 战斗房间类型  | 说明                                                                                  | 可选时机         |
| :------ | :---------------------------------------------------------------------------------- | ------------ |
| **属性房** | 关卡开始时，从3张属性相关道具卡中选择2张（可重复）加入玩家侧卡组（血量卡 40%，加甲卡 40%，加攻卡 20%）                          | 所有           |
| **金币房** | 关卡开始时，将1张金币卡加入玩家侧卡组                                                                 | 所有           |
| **宝箱房** | 关卡开始时，将1张宝箱卡加入玩家侧卡组                                                                 | 所有           |
| **恢复房** | 关卡开始时，将1张食品卡加入玩家侧卡组                                                                 | 所有           |
| **困难房** | 关卡开始时，从金币卡，宝箱卡，食品卡，3张属性相关道具卡中随机选择2张加入玩家侧卡组（不可重复），将当前选择怪物卡组的1张序列为3和1张序列为4的怪物卡加入怪物侧卡组 | 节点5及之后的战斗房间选项中才可能出现（见[[层级流程]]） |
| **层主房** | 无                                                                                   | 固定为地图节点8     |
## 消费房间类型
| 消费房间类型 | 说明                                |
| :----- | :-------------------------------- |
| **卡店** | 提供**道具卡数值强化**，**道具卡固定**，**道具卡扩容** |
| **商店** | 出售1张宝箱卡，1张随机属性相关道具卡，1张恢复药水和1张食品卡  |

**道具卡数值强化**：花费50金币，提升所有道具卡数值3点（无视没有数值的道具卡）
**道具卡固定**：花费50金币，本局永久。此后每次玩家侧卡组生成时，固定包含一张选定的道具卡
**道具卡扩容**：花费50金币，本局永久提高1点玩家侧卡组容量（初始容量为6，详见[[卡组生成流程]]）

所有消费房间初始可以花费10金币刷新货物（替换全部现有货物并补入新货），每使用一次价格增加一倍，无刷新次数上限。

## 特殊房间类型
| 特殊房间类型    | 说明                                           |
| :-------- | :------------------------------------------- |
| **宝箱奖励房** | 提供1张宝箱卡，3张随机道具卡                              |
| **道具奖励房** | 提供2张属性相关道具卡（血量卡 40%，加甲卡 40%，加攻卡 20%），3张随机道具卡 |
