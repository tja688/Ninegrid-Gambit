
## 定义

[[玩家卡]] ，[[怪物卡]]和[[机关卡]] 拥有的基础数值，在战斗中发挥不同作用

## 详细作用

| 属性名称 | 作用                                                |
| :--- | :------------------------------------------------ |
| 攻击   | 决定造成伤害的数值                                         |
| 血量   | 能承受的伤害总量                                          |
| 基础护甲 | 角色的静态护甲属性值 |
| 有效护甲 | 基础护甲 + 遗物加成 + 套装加成 + 技能永久加成，用于关卡开始时初始化当前护甲 |
| 当前护甲 | 本关当前护甲资源。关卡开始时 当前护甲 = 有效护甲。受伤时优先扣除当前护甲，归零后伤害扣除血量 |
| 伤害减免 | 减少受到的伤害数值。多来源累加（如[[铁盾]]）。当前无来源时 = 0 |
属性最低均为0，不可为负数
获得血量上限时立刻获得等量的血量
