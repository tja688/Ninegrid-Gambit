## 显示规则

**玩家面板**：显示的攻/甲/血为 **已结算属性**，非裸值，即时结算。

**怪物卡**：显示的攻/甲/血包含技能加成，实时反映实际战斗数值。

**机关卡**：显示的攻/甲/血包含技能加成，实时反映实际战斗数值。

**牌组区下一张预览**：[[战斗卡组]] 有牌时显示牌面信息（怪物：名称/攻/甲/血；帮助卡：名称/品质/效果），无牌时显示"牌组已空"。

## 有效属性计算

属性计算统一采用以下重算管线，每次需要属性值时从头重算，不存中间值：

### 玩家属性管线
1. **基础值**：职业初始属性 + 属性提升卡永久加成
2. **持久修正**：遗物加成 + 套装加成 + 技能永久加成
3. **条件修正**：满足条件时生效的修正（如处于特定格、血量低于阈值等）
4. **临时修正**：限次/限时效果（如暴力卡翻倍、庇佑等）

**玩家攻击** = 基础攻击 → 持久修正 → 条件修正 → 临时修正
**玩家有效护甲** = 基础护甲 → 持久修正 → 条件修正 → 临时修正
**玩家血量上限** = 基础血量 → 持久修正 → 条件修正 → 临时修正

### 怪物属性管线
1. **基础值**：怪物卡数据中的原始属性
2. **持久修正**：光环技能、自身技能永久成长
3. **条件修正**：处于特定格、正交相邻等条件触发的修正

**怪物攻击** = 基础攻击 → 持久修正 → 条件修正
**怪物护甲** = 基础护甲 → 持久修正 → 条件修正

### 机关属性管线
1. **基础值**：机关卡数据中的原始属性
2. **持久修正**：光环技能、自身技能永久成长
3. **条件修正**：处于特定格、正交相邻等条件触发的修正

**机关攻击** = 基础攻击 → 持久修正 → 条件修正
**机关护甲** = 基础护甲 → 持久修正 → 条件修正
