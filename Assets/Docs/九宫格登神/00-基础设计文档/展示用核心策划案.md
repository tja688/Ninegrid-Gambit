# 九宫地下城

> 玩家是一个深入地下的冒险者。在独具特色的地下城九宫格战场中迎战从四周聚拢的敌怪、找到求生的出口、搜刮宝藏和装备，去最深邃的地底迎接属于玩家自己的荣耀。

**品类**：策略、探索、卡牌战斗、轻度 Rogue、卡牌游戏
**单局时长**：约 40 分钟  
**灵感参照**：魔塔、星陨传说（Meteorfall）、迷失之径、寻剑迷途

---

## 快速介绍

整场战斗挤在 **3×3 九宫格** 里：玩家站中心，只能摸到上下左右；每清掉一块空位，棋盘就顺时针转一格——敌人、道具、机关一起挪位。需要根据变动的阵型选择合适的战术，并推演后续的变化。

---

## 特色总结

多数卡牌 Roguelike 的决策在「手牌」；本作的决策在「格子」。

- **距离即资源**：只能攻击/拾取正交相邻格。远一点的高威胁怪，要么等它转过来，要么用道具隔空处理。
- **杀怪会改盘面**：击杀或拾取后空格补牌，再整体顺时针旋转。一次正确的击杀，可能把下一只威胁推到眼前——也可能把治疗图腾转开。
- **顺序决定难度**：同一组怪，处理顺序不同，压力差一截。这和魔塔「先打谁」的直觉一脉相承，但盘面在动。

## 一局怎么走

![[mermaid-diagram-1785855099735.png]]

- **结构**：共 3 层，每层 8 个节点，收尾是层主。打穿第 3 层层主即通关；血量归零则失败。
- **节点节奏**：战斗为主，中途插入消费房（强化/购物）和特殊奖励房。多数节点结束时给两个去向，玩家自己选路线「属性 / 金币 / 宝箱 / 恢复」or「复合型困难战斗」。
- **局内成长**：属性永久抬升（攻 / 血 / 甲）、遗物被动堆叠、道具卡库存与金币经济。

## 战场上有什么

| 东西      | 玩家怎么用它                                  |
| ------- | --------------------------------------- |
| **玩家卡** | 固定从中心开局；血量归零即败。不走格子，靠点击相邻卡互动。           |
| **怪物卡** | 点击相邻怪开战：玩家先手，打不死它就挨反击。清光场上与牌堆里的怪即本节点通关。 |
| **道具卡** | 先拾进道具栏，再用；用道具不转盘，可瞄准全场，是「破局钥匙」。         |
| **机关卡** | 图腾、陷阱、滚石等，占格、改规则、帮玩家或帮怪。要当地形读，不当纯杂兵。    |
| **遗物**  | 局内装备，被动改玩法（杀怪回甲、用道具掉血反伤等）。上限 12，可丢弃换金币。 |

属性：**攻、血、甲**。伤害先啃甲再掉血。深度不在公式，在「攻击打完，盘面会变成什么样」。

## 差异化与潜力

**和常见卡牌 Roguelike 的差别**

|        | 类杀戮尖塔      | 本作              |
| ------ | ---------- | --------------- |
| 决策主场   | 手牌、能量、牌库构筑 | 九宫格位置、击杀顺序、旋转后果 |
| 单局信息密度 | 牌墙、关键词堆叠   | 盘面始终只有九格，威胁可见   |
| 空间感    | 弱（抽象牌桌）    | 强（距离、邻接、转动）     |
