# 详细数据

## 序列说明

序列是怪物卡组内的难度分级，1为最低、5为最高。序列5固定为该卡组的层主（BOSS）。序列决定了怪物在卡组生成时的出场优先级和数量分配，详见[[卡组生成流程]]。

每提升一层，所有怪物卡攻击+1血量+2
