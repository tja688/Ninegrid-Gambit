
## 定义

[[机关卡]] 或 [[怪物卡]] 拥有的特殊能力。机关卡和怪物卡都只能获得自身类型允许的技能。

## 技能叠加规则

技能效果默认 **可叠加**，除非另有说明

## 技能基本规则

- **怪物技能**：均为 **被动常驻**，怪物卡出现在九宫格时生效，怪物卡被移除时全部消失，不跨关卡
- **机关技能**：均为 **被动常驻**，机关卡出现在九宫格时生效，机关卡被移除时全部消失，不跨关卡
- 技能 **可以被移除**。移除形式包括但不限于：因离开触发格而失去条件性获得的技能、被其他技能效果移除、被遗物效果移除等
- 当技能强调处于特定格子生效时，离开特定格子后效果消失
- 当技能强调移动到特定格子生效时，移动到特定格子上时效果触发

## 技能描述约定

### 术语
- 「本卡」泛指持有该技能的卡牌自身（怪物卡、机关卡、道具卡均适用）。以「本卡」为主语的效果均作用于该卡自己，不涉及其他卡牌。
- 属性增减未注明"临时"或条件限制的，默认为本关卡永久获得。

### 效果格式

> 本章定义的前缀与格式是**所有效果类型的通用描述规范**（适用于遗物效果、怪物技能效果、机关技能效果、道具卡效果。因技能系统文档最早建立，格式规范以此处为权威源，其他文档引用此处。

所有效果描述统一使用 `[前缀]` + 条件/时机 + 效果内容 的格式。前缀分为两类：

**位置前缀**（限定效果生效的所在位置）：

| 前缀       | 含义             |
| :------- | :------------- |
| `[场上]`   | 在九宫格战场上        |
| `[道具卡格]` | 在道具卡格中         |
| `[登场]`   | 从战斗卡组打出放到场上的瞬间 |

不写位置前缀表示任意位置都生效。

**事件前缀**（描述触发效果的时机/事件，通用）：

| 前缀           | 含义                                                       |
| :----------- | :------------------------------------------------------- |
| `[使用时]`      | 玩家主动点击使用该卡                                               |
| `[使用道具卡时]`   | 玩家使用任意道具卡                                                |
| `[战斗时]`      | 与玩家战斗结算时触发                                               |
| `[击杀怪物时]`    | **仅**在怪物因战斗/伤害血量≤0 被移除时触发。道具卡被移除、技能效果直接移除怪物**不触发**本前缀。   |
| `[怪物被移除时]`   | 怪物卡离开九宫格时触发。无论移除原因（击杀/技能/道具卡效果）均触发。                      |
| `[受到伤害时]`    | 受到伤害时触发                                                  |
| `[受到致命伤害时]`  | 受到足以致死的伤害时触发                                             |
| `[每关卡开始时]`   | 每个关卡开始阶段触发                                               |
| `[每关卡结束时]`   | 每个关卡结束阶段触发                                               |
| `[旋转时]`      | 棋盘旋转发生时触发                                                |
| `[互动时]`      | 玩家每次棋盘互动时触发。                                             |
| `[击杀精英/层主时]` | 击杀精英或层主怪物时触发                                             |
| `[获得本遗物时]`   | 遗物被拾取到装备栏时触发                                             |
| `[被移除时]`     | 卡牌离开当前区域时触发。适用于所有卡牌类型。若怪物因击杀被移除，本前缀在 `[击杀怪物时]` **之后**触发。 |
| `[战斗后]`      | 与玩家战斗结算完后触发                                              |
| `[翻面后]` | 翻面后触发。详见[[翻面机制]] |

事件前缀不限定位置。位置前缀和事件前缀可同时使用，如 `[场上] [被移除时]`。

**时机关键词**（描述在格子上的持续/触发条件）：

| 关键词      | 含义                 |
| :------- | :----------------- |
| `处于格X时`  | 持续条件，满足时生效，离开后效果消失 |
| `移动到格X时` | 每次到达该格触发一次         |
| `每移动N次`  | 以本卡自身移动次数计数        |
| `每战斗N次`  | 以本卡自身战斗次数计数        |
| `每互动N次`  | 以玩家卡互动次数计数         |

无任何前缀和关键词时，表示效果持续生效或满足内文条件时生效。

### 计数规则

- **每互动N次**：以玩家卡互动次数为全局计数器。每次玩家执行九宫格互动（战斗、拾取道具卡、点击相邻空格）完成后 +1。道具使用不增加此计数。
- **每移动N次**：以本卡自身移动次数计数。因九宫格旋转导致的移动计入，因卡牌效果导致的位移（如交换卡、逃避）也计入。本卡登场不视为移动。
- **每战斗N次**：以本卡自身被玩家点击触发战斗的次数计数。反击和被道具卡攻击不计入。
