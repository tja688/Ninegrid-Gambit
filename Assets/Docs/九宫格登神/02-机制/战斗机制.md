# 战斗机制

## 伤害结算

**伤害定义**：攻击或技能效果造成的数值，优先由护甲吸收，最低为0

结算流程（按顺序执行）：
1. 原始伤害 = max(0, 攻击力 - 伤害减免)
2. 若为无视护甲伤害：血量损失 = 原始伤害
3. 否则：护甲损失 = min(当前护甲, 原始伤害)；血量损失 = 原始伤害 - 护甲损失
4. 当前护甲 -= 护甲损失；当前血量 -= 血量损失
5. 实际扣血最低为0，不可为负数。

> 伤害减免来自遗物,技能等来源（如铁盾），多来源累加。当前无来源时，伤害减免 = 0。

**反伤效果**：在受到伤害时同步对攻击方造成的回弹伤害。与反击不同——反击是怪物存活后发起的独立攻击结算；反伤在伤害结算阶段同步生效，即使攻击方在反伤中死亡，反伤伤害仍会结算。

**标准结算流程**：玩家先对目标造成伤害；若目标未死亡，则目标进行反击造成伤害。目标死亡则不进行反击


## 战斗结算详细流程

战斗结算按以下事件队列严格执行，同一阶段内的事件按注册顺序触发：

### 阶段一：直接伤害
1. 点击怪物卡 → 检查战斗状态→ 通过则进入战斗
2. 计算有效属性
3. 玩家先手造成伤害

### 阶段二：死亡/移除结算
4. 检测怪物血量 ≤ 0：
   - 是 → 触发 `[击杀怪物时]` 效果，移除该怪物卡，触发`[被移除时]`效果
   - 否→则进入下一步
5. 怪物存活 → 怪物反击（计算有效攻击），反伤效果同步生效（双方伤害同步结算）
6. 免死效果触发（触发时机：`[受到致命伤害时]`）
7. 血量损失累计效果触发


## 通关判定

战斗房以击破带「离开」技能的**离开机关卡**为**唯一**清关条件（真怪物清零不再自动清关）。击破当拍场上残留（未拾取道具 / 剩余怪 / 其它机关）一并清场且**不兑金**；[[道具卡格]] 内容保留。击破前玩家可一直留在场地交互（拾取更替、回收丢弃、击杀赚钱）——这不是另开的拣选相位。

清关后按所处地图节点放出 [[房间]] 选项或导航图标（见 [[层级流程]]）。
