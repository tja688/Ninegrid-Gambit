# 翻面机制

## 基础规则

- 所有卡牌默认**正面朝上**打出到九宫格（除非效果另有说明，如[[刺客领袖]]）
- 翻面：将卡牌从正面朝上变为正面朝下，或从正面朝下变为正面朝上
- 背面默认**双向惰性**：背面卡不可被伤害、不推进/不开火，被动与常规技能默认**不生效**；只有显式声明豁免（`ActiveWhileFaceDown`）的效果才可在背面生效（ADR-0016）。「背面技能照常生效」的旧说法已废止

## 相关效果前缀

| 前缀 | 含义 |
|------|------|
| `[翻面]` | **效果关键词**：执行翻面动作（正面↔背面切换） |
| `[翻面后]` | **事件前缀**：翻面动作完成后触发 |
