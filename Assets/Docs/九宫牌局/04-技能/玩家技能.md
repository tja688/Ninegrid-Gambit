# 玩家技能

[[玩家卡]] 可通过击杀 [[强精英]] 后出现的 [[导师卡]] 习得的永久 [[游戏开发项目/九宫牌局/04-技能/技能系统]]。同类技能不可叠加，获得相同技能时取效果更强者或覆盖。详见 [[游戏开发项目/九宫牌局/04-技能/技能系统#技能叠加规则]]。

## 可选技能（导师卡三选一）

### 刺皮
效果【类型玩家技能】：[战斗时] 对怪物卡造成等同于该怪物卡攻击的 [[伤害]]。

### 硬皮
效果【类型玩家技能】：获得本技能时血量上限+10。[每关卡结束时] 恢复10点 [[血量]]。

### 历战
效果【类型玩家技能】：[战斗时] 攻击+2（仅对当前敌人有效，换敌人时复原）。跨关卡时保留上一敌人的加成，直到与新关卡的新敌人战斗时才复原基础值。复原仅重置历战自身加成，不重置 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|属性提升卡]]、[[游戏开发项目/九宫牌局/03-遗物/遗物系统]] 等其他来源的属性。

### 军械库
效果【类型玩家技能】：[每关卡结束时] 选择 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|飞刀]]、[[游戏开发项目/九宫牌局/07-数据/帮助卡数据|爆弹]]、[[游戏开发项目/九宫牌局/07-数据/帮助卡数据|破击锤]] 的其中一张加入玩家侧卡组。

### 偶数仇恨
效果【类型玩家技能】：[战斗时] 若目标怪物卡的等级奇偶性为偶数，造成双倍伤害。

### 塔之子
效果【类型玩家技能】：[每关卡开始时] 将一张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|倍增塔]] 放入 [[道具牌格]]。
