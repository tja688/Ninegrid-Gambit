# 技能系统

## 定义

[[玩家卡]] 或 [[怪物卡]] 拥有的特殊能力。玩家卡和怪物卡都只能获得自身类型允许的技能。

## 技能叠加规则

- **怪物卡**：技能效果默认 **可叠加**，除非另有说明
- **玩家**：通过 [[游戏开发项目/九宫牌局/03-遗物/遗物系统]] / [[导师卡]] 获得的同类技能 **不可叠加**，获得相同技能时取效果更强者或覆盖

## 技能获取途径

- **玩家技能**：击杀 [[强精英]] 怪物后出现 [[导师卡]]，从三个技能中选择一个永久习得
- **怪物技能**：怪物有固定的技能对应表，每个怪物类型绑定特定技能

## 技能基本规则

- **玩家技能**：均为 **被动常驻**，从导师卡习得后永久生效，跨关卡保留（除非被其他效果移除）
- **怪物技能**：均为 **被动常驻**，怪物卡出现在九宫格时生效，怪物卡被移除时全部消失，不跨关卡
- 技能 **可以被移除**。移除形式包括但不限于：因离开触发格而失去条件性获得的技能、被其他技能效果移除、被遗物效果移除等
- 玩家可持有技能数量 **无上限**
- 当技能强调处于特定格子生效时，离开特定格子后效果消失
- 当技能强调移动到特定格子生效时，移动到特定格子上时效果触发

## 技能描述约定

### 术语
- 「本卡」泛指持有该技能的卡牌自身（怪物卡、玩家卡、帮助卡均适用）。以「本卡」为主语的效果均作用于该卡自己，不涉及其他卡牌。
- 属性增减未注明"临时"或条件限制的，默认为本关卡永久获得。

### 效果格式

> 本章定义的前缀与格式是**所有效果类型的通用描述规范**（详见 [[效果类型隔离规范]]），适用于遗物效果、怪物技能效果、玩家技能效果、帮助卡效果。因技能系统文档最早建立，格式规范以此处为权威源，其他文档引用此处。

所有效果描述统一使用 `[前缀]` + 条件/时机 + 效果内容 的格式。前缀分为两类：

**位置前缀**（限定效果生效的所在位置）：

| 前缀 | 含义 |
|:--|:--|
| `[场上]` | 在九宫格战场上 |
| `[道具牌格]` | 在道具牌格中 |
| `[登场]` | 从战斗卡组打出放到场上的瞬间 |

不写位置前缀表示任意位置都生效。

**事件前缀**（描述触发效果的时机/事件，通用）：

| 前缀 | 含义 | 适用文档 |
|:--|:--|:--|
| `[使用时]` | 玩家主动点击使用该卡 | 帮助卡 |
| `[使用帮助卡时]` | 玩家使用任意帮助卡 | 遗物 |
| `[战斗时]` | 与玩家战斗结算时触发 | 怪物技能、遗物 |
| `[击杀怪物时]` | **仅**在怪物因战斗/伤害血量≤0 被移除时触发（`killMonster` 事件）。帮助卡被移除、技能效果直接移除怪物**不触发**本前缀。 | 遗物 |
| `[怪物被移除时]` | 怪物卡离开九宫格时触发（`removeCard` 事件）。无论移除原因（击杀/技能/帮助卡效果）均触发。 | 遗物、怪物技能 |
| `[受到伤害时]` | 玩家受到伤害时触发 | 遗物 |
| `[受到致命伤害时]` | 受到足以致死的伤害时触发（先于 `killMonster`） | 遗物 |
| `[每关卡开始时]` | 每个关卡开始阶段触发 | 遗物 |
| `[每关卡结束时]` | 每个关卡结束阶段触发 | 遗物、帮助卡 |
| `[旋转时]` | 棋盘旋转发生时触发 | 遗物 |
| `[互动时]` | 玩家每次棋盘互动时触发（详见互动定义：点击怪物/帮助卡/相邻空格）。道具牌格使用帮助卡**不计入**本触发。 | 遗物 |
| `[击杀精英/层主时]` | 击杀精英或层主怪物时触发 | 遗物 |
| `[获得本遗物时]` | 遗物被拾取到装备栏时触发 | 遗物 |
| `[被移除时]` | 卡牌离开当前区域时触发（`removeCard` 事件）。适用于所有卡牌类型。若怪物因击杀被移除，本前缀在 `[击杀怪物时]` **之后**触发。 | 怪物技能、帮助卡 |

> **事件触发顺序**：`[受到致命伤害时]` → `killMonster` → `[击杀怪物时]` → `removeCard` → `[怪物被移除时]` / `[被移除时]`

事件前缀不限定位置。位置前缀和事件前缀可同时使用，如 `[场上] [被移除时]`。

**时机关键词**（描述在格子上的持续/触发条件）：

| 关键词 | 含义 |
|:--|:--|
| `处于格X时` | 持续条件，满足时生效，离开后效果消失 |
| `移动到格X时` | 每次到达该格触发一次 |
| `每移动N次` | 以本卡自身移动次数计数 |
| `每战斗N次` | 以本卡自身战斗次数计数 |

无任何前缀和关键词时，表示效果持续生效或满足内文条件时生效。
