# 伤害公式

## 基础公式

结算流程（按顺序执行）：
1. 原始伤害 = max(0, 攻击力 - 伤害减免)
2. 若为无视护甲伤害：血量损失 = 原始伤害
3. 否则：护甲损失 = min(当前护甲, 原始伤害)；血量损失 = 原始伤害 - 护甲损失
4. 当前护甲 -= 护甲损失；当前血量 -= 血量损失
5. 实际扣血最低为0，不可为负数。

> 伤害减免来自遗物,技能等来源（如铁盾），多来源累加。当前无来源时，伤害减免 = 0。


## 有效属性计算

属性计算统一采用以下重算管线，每次需要属性值时从头重算，不存中间值：

### 玩家属性管线
1. **基础值**：职业初始属性 + 属性提升卡永久加成
2. **持久修正**：遗物加成 + 套装加成 + 技能永久加成
3. **条件修正**：满足条件时生效的修正（如处于特定格、血量低于阈值等）
4. **临时修正**：限次/限时效果（如暴力卡翻倍、庇佑等）

**玩家攻击** = 基础攻击 → 持久修正 → 条件修正 → 临时修正
**玩家有效护甲** = 基础护甲 → 持久修正 → 条件修正 → 临时修正
**玩家血量上限** = 基础血量 → 持久修正 → 条件修正 → 临时修正

### 怪物属性管线
1. **基础值**：怪物卡数据中的原始属性
2. **持久修正**：光环技能（attackAura）、复仇累计、自身永久成长
3. **条件修正**：处于特定格、正交相邻等条件触发的修正

**怪物攻击** = 基础攻击 → 持久修正 → 条件修正
**怪物护甲** = 基础护甲 → 持久修正 → 条件修正

> 各阶段修正均为可选。管线保证新增遗物/技能/帮助卡时只需注册修正到对应阶段，无需逐条 hardcode。

## 显示规则

玩家面板和卡牌上显示的攻/甲/血为 **有效总值**（基础 + 遗物 + 套装 + 技能），非裸值，即时结算。怪物卡牌显示的攻甲数值包含技能加成（光环 + 复仇累计），实时反映实际战斗数值。
