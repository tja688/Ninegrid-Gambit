# 战斗机制

## 交互范围

[[玩家卡]] 固定出生在格5，可被效果移动，但没有自行移动手段。玩家交互分为两类：**九宫格互动** 和 **道具使用**。

### 九宫格互动（Board Interaction）
以下三种操作属于九宫格互动，会累计 `interactionCount`：
- **clickMonster**：点击 [[怪物卡]]，与目标怪物进行战斗（结算伤害）
- **clickHelpCard**：点击 [[帮助卡]]，拾取到 [[道具牌格]]，详见 [[游戏开发项目/九宫牌局/02-卡牌/帮助卡系统]]
- **clickAdjacentEmptySlot**：点击相邻空格，仅在空格与玩家正交相邻时可用
- 玩家只能与玩家卡 **正交相邻** 格子上的卡牌进行九宫格互动

**九宫格旋转规则**：
- 战斗导致怪物卡被移除时 → 先补牌填充空格，再触发九宫格顺时针旋转1格
- 战斗未导致怪物卡被移除时 → **不旋转**
- 拾取帮助卡或点击相邻空格 → 先补牌填充空格，再触发九宫格顺时针旋转1格

### 道具使用（Item Use）
- 点击道具牌格中的帮助卡使用其效果，**不受正交相邻距离限制**，可瞄准九宫格任意怪物
- 道具使用**不属于**九宫格互动：
  - 不触发九宫格旋转
  - 不累计 `interactionCount`
  - 不触发 `[互动时]` 遗物效果

## 伤害结算

详细计算公式见 [[游戏开发项目/九宫牌局/01-机制规则/伤害公式]]。

**标准结算流程**：无 [[游戏开发项目/九宫牌局/01-机制规则/先攻]] 时，玩家先对目标造成伤害；若目标未死亡，则目标进行反击造成伤害。拥有先攻的一方优先造成伤害。

**优先级规则**：先攻技能 > 玩家默认优先。

| 情境     | 结算顺序                                                                    |
| :----- | :---------------------------------------------------------------------- |
| 双方均无先攻 | **玩家先** 造成伤害                                                            |
| 双方均有先攻 | **玩家先** 造成伤害                                                            |
| 一方有先攻  | **先攻方** 先造成伤害(怪物先攻时，怪物先造成伤害，玩家后反击；先攻方击杀对方则对方无法反击)                       |
| 伤害致死   | 死亡的一方 **无法造成伤害**；若双方同时受到致命伤害，则双方同时死亡（如果玩家卡互动先造成足以击杀怪物卡的伤害，则这次怪物卡不会造成伤害） |

## 战斗结算详细流程

战斗结算按以下事件队列严格执行，同一阶段内的事件按注册顺序触发：

### 阶段一：直接伤害
1. 点击怪物卡 → 检查战斗状态（isCombatResolving / isBoardRefilling / isOverlayOpen）→ 通过则进入战斗
2. 计算有效属性（详见 [[游戏开发项目/九宫牌局/01-机制规则/伤害公式]]）
3. 玩家先手造成伤害（[[游戏开发项目/九宫牌局/01-机制规则/先攻]] 技能确保优先权）

### 阶段二：死亡/移除结算
4. 检测怪物血量 ≤ 0：
   - 是 → 触发 `killMonster` 事件（仅对本次战斗击杀的怪物触发一次）
   - `killMonster` 触发后，立即触发 `removeCard` 事件（将该怪物从场上移除）
   - 金币发放、遗物 `[击杀怪物时]` 效果在 `killMonster` 阶段结算
   - 怪物技能 `[被移除时]` 效果在 `removeCard` 阶段结算
5. 怪物存活 → 怪物反击（计算有效攻击），反伤效果同步生效（双方伤害同步结算）
6. 庇佑效果可免疫单次反击伤害（如庇佑魔法卡）
7. 免死效果触发（触发时机：`[受到致命伤害时]`，在 `killMonster` 之前）
8. 血量损失累计效果触发

### 阶段三：事件触发（详见统一结算链）
9. 依次触发：`onKill` → `onRemove` → `onUse` → `onDamageTaken` 等已注册事件

## 统一结算链

每次玩家动作按以下固定顺序执行，前一阶段未完成不得进入下一阶段：

```
玩家动作
  ↓
执行直接效果（伤害/拾取/空格旋转）
  ↓
结算伤害/回血/护甲变化
  ↓
死亡与移除结算（killMonster → removeCard）
  ↓
触发事件：onKill / onRemove / onUse / onDamageTaken
  ↓
判断九宫格互动类型：
  ├── 战斗移除怪物 / 拾取帮助卡 / 点击空格 → 先批量补牌 → 再旋转
  └── 战斗未移除怪物 → 不旋转，直接补牌
  ↓
结算位置/移动触发（onMove、移动到格X等）
  ↓
再次处理死亡与移除（若有）
  ↓
批量补牌（若有新空格）
  ↓
通关检查（战斗卡组为空且场上无怪物卡）
  ↓
解锁输入
```

> 此结算链同时兼容战斗、移动、被动触发、批量补牌、防抖和通关检查，与[[游戏开发项目/九宫牌局/05-职业与层级/层级系统#关卡流程示意图|关卡流程示意图]]一致。

## 战斗输入锁定

以下任一状态激活时，禁止玩家发起新的战斗互动：
- 战斗结算进行中（isCombatResolving）
- 棋盘补牌执行中（boardRefillRunning）
- 覆盖层/弹窗显示中（帮助卡选择、商店、导师卡、宝箱选择等）

输入锁定防止战斗动画/补牌过程中的重复点击导致的状态异常。

## 通关判定

当 [[战斗卡组]] 与九宫格上没有任何 [[怪物卡]] 时，立即弹出帮助卡三选一覆盖层。选择结束后出现两个 [[房间卡]] 按钮。玩家可自行选择何时点击房间卡按钮决定下一个房间的类型。

 [[房间卡]] 按钮出现后，玩家仍可：
- 点击九宫格上的帮助卡 → 拾取到 [[道具牌格]]
- 点击道具牌格中的帮助卡 → 正常使用效果
- 无法再与怪物卡战斗（已无怪物）

点击通关按钮后，结算所有未使用帮助卡（道具牌格 + 玩家侧卡组 + 九宫格上未拾取帮助卡）：全部回到玩家侧卡组，每张 +10 [[游戏开发项目/九宫牌局/00-核心概念/金币]]。结算完毕后进入所选房间卡，结束房间卡事件后进入下一地图节点。详见 [[游戏开发项目/九宫牌局/05-职业与层级/层级系统#关卡循环流程]]。
