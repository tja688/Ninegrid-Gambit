# 先攻

## 定义

 [[怪物卡]] 拥有的特殊 [[游戏开发项目/九宫牌局/04-技能/技能系统\|技能]]，决定 [[游戏开发项目/九宫牌局/01-机制规则/战斗机制|战斗]] 中谁先造成伤害。（导师卡中不会出现先攻选项）

## 优先级

| 情境 | 先手方 |
|:-----|:-------|
| 双方均无先攻 | 玩家先 |
| 双方均有先攻 | 玩家先 |
| 仅一方有先攻 | 先攻方先 |

拥有先攻的一方优先造成伤害。如果先攻方的伤害足以击杀对方，对方无法造成伤害。
玩家卡不会拥有先攻技能，表格仅为举例
## 持有者

先攻文档只定义规则，不维护持有者列表。是否持有先攻，由怪物卡数据（monsterData）或技能数据（skillData）的 tags 或 conditionalEffects 字段决定。持有者包括但不限于：卡面固定持有先攻技能的怪物卡、通过技能条件触发获得先攻的怪物卡（如流浪幼崽在格6时获得先攻）。
