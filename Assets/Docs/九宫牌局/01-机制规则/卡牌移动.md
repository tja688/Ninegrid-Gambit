# 卡牌移动

## 基本移动规则

**旋转**：除格5上的卡牌外，九宫格上其余格子的卡牌按固定路径 **顺时针移动一格** 的行为。

移动顺序（顺时针）：格1 → 格2 → 格3 → 格6 → 格9 → 格8 → 格7 → 格4 → 格1

**旋转触发条件**详见 [[游戏开发项目/九宫牌局/01-机制规则/战斗机制#交互范围]]：
- 战斗导致怪物卡被移除 → 先补牌填充空格，再旋转
- 战斗未导致怪物卡被移除 → 不旋转
- 拾取帮助卡或点击相邻空格 → 先补牌填充空格，再旋转
- 道具牌格使用帮助卡 → 不旋转

## 点击空格旋转

玩家可以通过点击正交相邻的空格子，触发棋盘顺时针旋转一格。

## 特殊移动效果

部分 [[游戏开发项目/九宫牌局/04-技能/怪物技能]] 会触发特殊位移：
- [[竖向拉杆]]：移动到格7时，格1→格7、格4→格1、格7→格4；移动到格3时，格3→格6、格6→格9、格9→格3
- [[决斗]]：与玩家战斗后，所有卡牌不再移动直到本卡移除
- [[不休追击]]：每次移动到玩家正交相邻格时，自动与玩家战斗一次

## 帮助卡的位置效果

部分 [[帮助卡]] 在九宫格上移动时会触发被动效果：
- [[治疗泉]]：移动到玩家卡正交相邻格时，恢复2点血量
- [[滚石]]：移动到格3时，可能击杀格6的怪物
- [[瞭望塔]]：移动到格1/格3/格7/格9时，对任意怪物造成3点伤害（触发4次后移除）
- [[倍增塔]]：处于格1时，对怪物使用的帮助卡触发两次
