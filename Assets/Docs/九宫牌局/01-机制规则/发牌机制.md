# 发牌机制

## 开局发牌

关卡开始时按以下顺序发牌：
1. 从玩家侧卡组（[[通用牌组]] + 职业牌组）中抽3张卡，随机摆放在空格子上（若卡组为空则跳过）
2. 从怪物侧卡组中抽3张卡，随机摆放在空格子上，如果怪物侧卡组存在弱精英怪物卡，强精英怪物卡或层主怪物卡，则必定抽出（也就是怪物侧卡组抽出的三张卡里，有一张为弱精英怪物卡，强精英怪物卡或层主怪物卡以及其他两张任意怪物卡）
3. 将玩家侧卡组与怪物侧卡组洗在一起，形成 [[战斗卡组]]
4. 从战斗卡组中抽卡，摆放在空格子上，直到场上没有空格子

开局场上共8张卡 + [[玩家卡]] = 9格全满。

## 空格补牌

每当九宫格上出现空格子（如怪物被击杀、帮助卡被拾取），自动从 [[战斗卡组]] 顶部顺序抽一张牌打出到空格子上。战斗卡组为洗混后的固定顺序牌堆，不随机抽取。在[[战斗卡组]]仍有卡牌的情况下，九宫格上不应出现因为未补牌而产生的空格

**批量补牌**：若同时存在多个空格子，连续抽取直到填满或卡组耗尽，补牌间隔约0.5秒。

**补牌延迟**：击杀怪物后延迟约500ms补牌，拾取帮助卡后延迟约450ms补牌，给玩家视觉缓冲。

**补牌防抖**：短时间内连续多个补牌请求合并为一次批量处理，防止并发吞卡。同一时间段内只执行一次补牌操作。

补牌完成后自动检查通关条件。

## 战斗卡组耗尽

当 [[战斗卡组]] 为空时，停止抽牌。九宫格上可能留有永久空格。
