# 职业

## 定义

[[游戏开发项目/九宫牌局/05-职业与层级/职业]] 决定 [[玩家卡]] 的初始属性、初始 [[游戏开发项目/九宫牌局/04-技能/技能系统|技能]]，以及绑定的 [[牌组系统|牌组]]。

每个职业绑定**通用牌组 + 职业牌组**，开局选定后整局固定使用。详见 [[牌组系统]]。
