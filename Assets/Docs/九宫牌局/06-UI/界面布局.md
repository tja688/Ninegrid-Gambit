# 界面布局

![[游戏开发项目/九宫牌局/资源/九宫格战场.png]]

## 区域划分

| 区域         | 位置     | 内容                                                     |
| :--------- | :----- | :----------------------------------------------------- |
| **玩家信息面板** | 屏幕左上方  | 头像、血量（当前/上限）、攻击、护甲、状态、[[游戏开发项目/九宫牌局/00-核心概念/金币]] 数量 |
| **装备栏**    | 屏幕左下方  | 存放已装备 [[游戏开发项目/九宫牌局/03-遗物/遗物系统]]，上限12件（右键点击可丢弃遗物）                          |
| **作战场地**   | 屏幕正中上方 | [[游戏开发项目/九宫牌局/01-机制规则/九宫格战场]]（格1~格9）                   |
| **道具牌格**   | 屏幕正中下方 | 存放已获取的 [[帮助卡]]，上限5格。满时拾取失败，原卡保留在棋盘原格，弹出"道具牌格已满"提示 |
| **技能栏**    | 屏幕右下方  | 玩家拥有的 [[游戏开发项目/九宫牌局/04-技能/技能系统]] 及其描述                                      |
| **牌组区**    | 屏幕右上方  | [[战斗卡组]] 存放处，正面朝上显示下一张会放到空格子上的卡牌                       |
| **介绍区**    | 屏幕右中间  | 鼠标悬停在 [[怪物卡]] 上时，显示怪物技能详细描述                            |

## 显示规则

**玩家面板**：显示的攻/甲/血为 **已结算属性**（基础 + [[游戏开发项目/九宫牌局/03-遗物/遗物系统]] + [[游戏开发项目/九宫牌局/04-技能/技能系统]] + [[游戏开发项目/九宫牌局/03-遗物/套装]] 加成），非裸值，即时结算。详见 [[游戏开发项目/九宫牌局/01-机制规则/伤害公式#显示规则]]。

**怪物卡牌**：显示的攻/甲/血包含技能加成（怪物攻击光环技能 + [[复仇]] 累计），实时反映实际战斗数值。

**牌组区下一张预览**：[[战斗卡组]] 有牌时显示牌面信息（怪物：名称/攻/甲/血；帮助卡：名称/品质/效果），无牌时显示"牌组已空"。

## 覆盖层系统

覆盖层分两类：

- **selectionOverlay（选择覆盖层）**：[[帮助卡]] 选择、[[游戏开发项目/九宫牌局/05-职业与层级/商店]]、[[导师卡]]、[[游戏开发项目/九宫牌局/07-数据/帮助卡数据|宝箱]] 选择。使用半透明黑色背景覆盖层，阻止下层点击。只能通过"选项/跳过/关闭按钮"退出，点击遮罩不关闭。
- **infoPopup（提示弹窗）**：购买上限、遗物满格等提示。使用居中弹窗，可点击任意空白位置关闭。

## 右键交互

装备栏中已装备的 [[游戏开发项目/九宫牌局/03-遗物/遗物系统]] 支持 **右键点击丢弃**，丢弃后获得20 [[游戏开发项目/九宫牌局/00-核心概念/金币]]。游戏启动时禁用浏览器默认右键菜单。
