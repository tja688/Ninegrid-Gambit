# 牌组系统

> 牌组是卡牌体系的**顶层分类概念**。每张卡牌都归属于一个牌组，牌组决定了卡牌的主题、归属和使用范围。

## 牌组总览

| 牌组        | 阵营  | 包含卡牌                                    | 详见        |
| :-------- | :-- | :-------------------------------------- | :-------- |
| **通用牌组**  | 玩家  | 所有职业共享的 [[帮助卡]] 与 [[导师卡]]               | [[通用牌组]]  |
| **小丑牌组**  | 玩家  | [[小丑]] 职业专属的 [[帮助卡]]            | [[小丑牌组]]  |
| **弱精英牌组** | 怪物  | 每层一~三的地图节点使用的牌组，包含普通[[怪物卡]]与一张精英[[怪物卡]] | [[弱精英牌组]] |
| **强精英牌组** | 怪物  | 每层四~六的地图节点使用的牌组，包含普通[[怪物卡]]与一张精英[[怪物卡]] | [[强精英牌组]] |
| **层主牌组**  | 怪物  | 每层七~九的地图节点使用的牌组，包含普通[[怪物卡]]与一张层主[[怪物卡]] | [[层主牌组]]  |

## 牌组与职业

每个 [[游戏开发项目/九宫牌局/05-职业与层级/职业]] 绑定一个**职业牌组**和**通用牌组**。玩家在选择职业后，整局游戏中卡牌选择和商店购买只会出现这两个牌组中的卡牌。

当前唯一的职业为 [[小丑]]，其职业专属帮助卡（如 [[飞刀]]）归入小丑牌组。其余帮助卡和全部导师卡归属通用牌组，所有职业共享。

## 牌组与运行时

### 玩家侧

玩家选职业后，该局的玩家侧卡牌来源为：**通用牌组 + 职业牌组**。

- 商店中可购买的帮助卡来自通用牌组和当前职业牌组
- 通关后的帮助卡三选一来自通用牌组和当前职业牌组
- [[游戏开发项目/九宫牌局/05-职业与层级/职业]] 由职业牌组决定

### 怪物侧

每个 [[地图节点]] 的怪物侧卡组按 [[游戏开发项目/九宫牌局/05-职业与层级/层级系统#怪物侧卡组构成]] 规则生成。

### 战斗卡组

关卡开始时，玩家侧卡组（通用 + 职业）与怪物侧卡组混合洗成 [[战斗卡组]]。详见 [[游戏开发项目/九宫牌局/01-机制规则/发牌机制]]。

## 扩展方向

牌组体系具备良好的扩展性：

- **新增职业牌组**：新职业自带对应的职业牌组（如"法师牌组"），与通用牌组搭配使用
- **新增怪物牌组**：新建独立牌组（如"游戏王牌组"、"哥布林牌组"、"龙牌组"），不同层或地图节点可指定不同怪物牌组
- **牌组内子分类**：大型牌组内部可按主题或强度进一步划分子牌组
