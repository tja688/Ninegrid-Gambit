# 帮助卡系统

## 使用规则

- 点击九宫格上的 [[帮助卡]] 后，将其放入 [[道具牌格]]
- 点击道具牌格里的帮助卡使用，帮助卡不受玩家互动距离影响，可以对整个 [[游戏开发项目/九宫牌局/01-机制规则/九宫格战场]] 使用
- 使用帮助卡后该卡**永久移除**（默认规则，无需在卡面重复标注）
- 若卡面标注"**使用后复原**"，则该卡在关卡结束后回到玩家侧卡组（[[通用牌组]] 或职业牌组）
- 对局结束（通关判定成立）时**立即结算**所有未使用的帮助卡（含道具牌格、玩家侧卡组/手牌、九宫格上未拾取的帮助卡）：均回到玩家侧卡组，每张 +10 [[游戏开发项目/九宫牌局/00-核心概念/金币]]；结算与通关后续流程（帮助卡三选一、房间选择）并行进行，不阻塞，通关后三选一新获得的帮助卡不参与本次结算
  > 若帮助卡卡面标注了关卡结束时的特殊处理（如 [[烈焰]] 的 `[每关卡结束时] 若未使用本卡，则永久移除本卡`），以**卡面效果优先**，覆盖上述默认规则。

## 帮助卡选择环节

通关后从三张帮助卡中选择一张加入玩家侧卡组（可跳过直接 +10 金币）。底部提供 **「跳过 → +10💰」** 按钮。可选卡牌来自 [[通用牌组]] 和当前职业牌组。

## 帮助卡唯一标识

每张帮助卡拥有唯一 uid（自增整数），用于精确追踪使用/未使用状态。[[游戏开发项目/九宫牌局/00-核心概念/金币]] 结算时按 uid 逐一匹配，同名多张卡各自独立计算。

## 帮助卡出现概率

| 品质  | 概率                                      |
| :-- | :-------------------------------------- |
| 白色  | 65%                                     |
| 蓝色  | 30%                                     |
| 金色  | 5%                                      |
| 红色  | 0%（只会被 [[游戏开发项目/九宫牌局/03-遗物/遗物系统]] 效果加入） |

## 宝箱卡补充

宝箱卡（普通/蓝色/金色）打开后三选一 [[游戏开发项目/九宫牌局/03-遗物/遗物系统|遗物]]，底部提供 **「跳过 → +20💰」** 按钮。已拥有的遗物不会在宝箱中重复出现。遗物装备栏满12格时，点击选择遗物弹出「遗物格子已满」提示。

## 商店中的帮助卡

在 [[游戏开发项目/九宫牌局/05-职业与层级/商店]] 中可以从玩家侧卡组中删除任意数量的帮助卡，每删除一张获得 10 [[游戏开发项目/九宫牌局/00-核心概念/金币]]。
