# 通用牌组

通用牌组是所有 [[游戏开发项目/九宫牌局/05-职业与层级/职业]] 共享的牌组，包含绝大部分 [[帮助卡]] 和所有 [[导师卡]]。无论玩家选择哪个职业，通用牌组中的卡牌都可用。

## 定位

通用牌组提供游戏的基础卡牌池。职业牌组（如 [[小丑牌组]]）在此基础上提供职业专属卡牌，两者搭配构成玩家完整的卡牌来源。

## 包含的导师卡

[[导师卡]] 池也归属通用牌组。击杀 [[强精英]] 后出现的三选一 [[游戏开发项目/九宫牌局/04-技能/玩家技能]] 选项来自通用牌组的导师卡池。当前所有职业共享同一导师卡池。

## 出现概率

从通用牌组中抽取帮助卡时，各品质的出现概率：

| 品质 | 概率 |
|:-----|:-----|
| 白色 | 65% |
| 蓝色 | 30% |
| 金色 | 5% |
| 红色 | 0%（仅遗物效果加入） |
