# 卡组管理

玩家的卡牌来源由 [[通用牌组]] 和职业牌组（如 [[小丑牌组]]）构成。怪物的卡牌来源按节点决定：节点1-3使用 [[弱精英牌组]]，节点4-6使用 [[强精英牌组]]，节点7-9使用 [[层主牌组]]。怪物类型表只定义卡牌数据，不负责决定在哪个节点出现。

## 玩家侧卡组

玩家选职业后，整局游戏中的卡牌来源为：**通用牌组 + 职业牌组**（开局选定，固定使用）。

### 复原规则

帮助卡在关卡中被使用后**永久移除**（默认规则）。若卡面标注"使用后复原"，则该卡在关卡结束后回到玩家侧卡组。牌组不设跨关卡的消耗。

### 节点快照

每节点开始时对玩家侧卡组做快照保存。节点结束时，已永久移除的卡不恢复，节点内未使用的卡从快照恢复。新增卡牌（选牌/商店购买/掉落）在恢复后加入。

### 卡组上限

同一种帮助卡允许堆叠（如"恢复药水×3"）。同一名称的帮助卡最多持有 **3张**，达到3张后无法再获得同名卡。同名卡也计入卡组上限（如牌组内有"恢复药水×3"，则在第1层还剩下9张帮助卡可加入）。在关卡内靠着遗物/技能效果获得的帮助卡即使到达上限也能加入，但若是关卡结束依然超过上限则强制移除最后加入的帮助卡。

按层扩容：

| 层数  | 上限  |
| :-- | :-- |
| 第1层 | 12张 |
| 第2层 | 18张 |
| 第3层 | 24张 |

达到卡组上限或同名3张上限时，弹出提示窗口告知玩家。

## 怪物侧卡组

怪物侧卡组按当前[[地图节点]]从对应牌组中自动构成：节点1-3使用[[弱精英牌组]]，节点4-6使用[[强精英牌组]]，节点7-9使用[[层主牌组]]。详见[[游戏开发项目/九宫牌局/05-职业与层级/层级系统#怪物侧卡组构成]]。每个关卡结束后怪物侧卡组 **不继承** 到下一关卡，每个关卡的怪物侧卡组独立生成。

## 战斗卡组

关卡开始时，从玩家侧卡组（通用 + 职业）与怪物侧卡组中各抽3张卡（若一侧不足3张则全抽），然后将两个来源剩余卡牌合并洗牌形成战斗卡组，再从战斗卡组持续补牌直到非玩家格填满或战斗卡组为空。详见 [[游戏开发项目/九宫牌局/01-机制规则/发牌机制]]。

当战斗卡组为空时停止抽牌。
