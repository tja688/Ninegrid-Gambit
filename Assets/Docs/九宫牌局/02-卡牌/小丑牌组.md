# 小丑牌组

小丑牌组是 [[小丑]] 职业的专属牌组，包含小丑职业独有的 [[帮助卡]]。选择小丑职业后，小丑牌组与 [[通用牌组]] 搭配，构成玩家整局游戏的完整卡牌来源。

## 定位

小丑牌组强调小丑职业的主题和玩法风格。卡牌偏向快速、灵活的战斗方式，与小丑职业的天赋 [[轻车熟路]] 形成配合。

## 扩展方向

随着小丑职业的玩法深化，小丑牌组可新增更多职业专属卡牌。新卡牌应围绕小丑的主题风格设计（快速、灵活、低费高互动）。
