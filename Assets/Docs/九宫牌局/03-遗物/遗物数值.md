# 遗物数值

## 品质与价值基准

遗物的数值以 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|属性提升卡]] 三选一的综合价值为参照基准。达成遗物效果可根据实现难度灵活给予数值，可超过品质上限。

| 品质  | 基准价值       | 成长性             |
| :-- | :--------- | :-------------- |
| 白色  | 相当于2张属性提升卡 | 可达到蓝色数值，但成长速度慢  |
| 蓝色  | 相当于3张属性提升卡 | 可达到金色数值，但成长速度较慢 |
| 金色  | 相当于4张属性提升卡 | 可无上限，成长速度快      |

## 品质出现概率

### 普通宝箱卡（蓝色品质）
- 白色遗物 65%，蓝色遗物 30%，金色遗物 5%

### 蓝色宝箱卡（金色品质）
- 白色遗物 40%，蓝色遗物 50%，金色遗物 10%

### 金色宝箱卡（红色品质）
- 白色遗物 0%，蓝色遗物 50%，金色遗物 50%

## 遗物定位分类

每件遗物标注定位标签，格式为 `主标签，副标签`（如 `杀怪，直伤`、`护甲，经济`）。单维度遗物只写一个标签（如 `属性`、`经济`）。

### 主标签

| 标签 | 含义 | 示例遗物 |
|:--|:--|:--|
| **道具** | 围绕帮助卡使用触发效果 | 废物利用机、飞刀袋 |
| **护甲** | 围绕护甲属性提供加成/效果 | 木盾、重盔甲 |
| **属性** | 直接提供攻击/血量上限等数值加成 | 木剑、木甲 |
| **杀怪** | 击杀怪物后触发效果 | 弹弓、打盾刀 |
| **经济** | 影响金币获取或消耗 | 幸运硬币、金血 |
| **血量** | 围绕血量属性提供加成/效果 | 血魔、身体潜力 |
| **位移** | 影响棋盘位置/旋转 | 交换按钮、旋转技巧 |
| **恢复** | 提供血量恢复能力 | 活力护符 |

### 特殊标签（独立使用）

| 标签 | 含义 | 示例遗物 |
|:--|:--|:--|
| **纯属性** | 纯数值加成，无触发效果 | 龙鳞甲 |
| **条件爆发** | 满足特定条件时获得大幅加成 | 狂战士斧 |
| **成长** | 数值随条件触发逐步增长 | 锻造器具、锐利长剑 |

> 完整清单见 [[游戏开发项目/九宫牌局/07-数据/遗物数据]]。
