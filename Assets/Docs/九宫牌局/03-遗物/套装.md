# 套装

## 定义

当 [[玩家卡]] 同时装备指定的多件 [[游戏开发项目/九宫牌局/03-遗物/遗物系统]] 时，各组件获得额外属性加成。

## 木制套装

组件：[[游戏开发项目/九宫牌局/07-数据/遗物数据#木盾]] + [[游戏开发项目/九宫牌局/07-数据/遗物数据#木剑]] + [[游戏开发项目/九宫牌局/07-数据/遗物数据#木甲]]

同时拥有三件时触发额外效果：
- 木盾：护甲额外 +2（总计 +3）
- 木剑：攻击额外 +2（总计 +3）
- 木甲：血量额外 +8（总计 +10）

三件合计：攻击+3、护甲+3、血量+10，约等于5张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据#属性提升卡]] 的综合价值，符合白色遗物成长性可达蓝色数值的设计预期（参见 [[游戏开发项目/九宫牌局/03-遗物/遗物数值]]）。
