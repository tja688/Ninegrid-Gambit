# 遗物系统

## 基础规则

[[游戏开发项目/九宫牌局/03-遗物/遗物系统]] 是可装备的被动道具，为 [[玩家卡]] 提供常驻属性加成或特殊效果。

- 遗物最多可以拥有 **12个**，存放在 [[游戏开发项目/九宫牌局/06-UI/界面布局|装备栏]]
- 右键点击已装备的遗物可以 **丢弃** 并获得 20 [[游戏开发项目/九宫牌局/00-核心概念/金币]]
- 宝箱卡生成遗物选项时自动排除已拥有的遗物，不会开出重复遗物
- 装备栏满12格后，选择新遗物弹出"遗物格子已满"提示窗口，需先丢弃旧遗物

## 获取途径

- [[游戏开发项目/九宫牌局/07-数据/帮助卡数据#普通宝箱卡|宝箱卡]]：打开后三选一遗物，不同品质宝箱对应不同品质概率
- 遗物丢弃后可获 20 [[游戏开发项目/九宫牌局/00-核心概念/金币]]

## 属性叠加

所有 [[游戏开发项目/九宫牌局/03-遗物/遗物系统]] 属性与玩家基础属性、[[游戏开发项目/九宫牌局/04-技能/技能系统]] 加成累加。玩家面板上显示的攻/甲/血为有效总值（基础 + 遗物 + [[游戏开发项目/九宫牌局/03-遗物/套装]] + 技能）。
