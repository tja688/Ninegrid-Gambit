# 九宫牌局

> **一句话定义**：本作是 3×3 九宫格卡牌 Roguelike。[[玩家卡]] 初始位于格5，通过点击相邻 [[怪物卡]] 战斗、点击 [[帮助卡]] 拾取到道具区。每次有效互动后，除格5外的卡牌按固定路径顺时针旋转1格。当 [[战斗卡组]] 为空且场上无 [[怪物卡]] 时，关卡结束。

**核心灵感**：迷失之径，魔塔 × 星陨传说（Meteorfall）
