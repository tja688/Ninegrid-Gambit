### 金币盔甲
- 属性：基础护甲+1
- 效果【类型遗物】：[受到伤害时] 每5金币抵消1点当前护甲伤害，金币数不足时再扣除当前护甲（对血量造成伤害时不生效）
- 品质：白色
- 定位：护甲，经济
- **实现注**：金币抵消在伤害公式中最先执行（原始伤害 → 金币抵消 → 剩余走护甲吸收 → 血量损失）

### 泡沫盔甲

- 效果【类型遗物】：[受到伤害时] 每关卡第一次当前护甲归零时，下一次受到伤害时该次伤害变为0（仅免疫单次伤害，对多段伤害只免疫第一段）
- 品质：白色
- 定位：护甲

### 锻造工具

### 金色宝箱
- 属性：无
- 效果【类型遗物】：[获得本遗物时] 将两张 [[游戏开发项目/九宫牌局/07-数据/帮助卡数据|金色宝箱卡]] 加入玩家侧卡组（仅生效一次）

- 定位：经济

### 狂战士斧

### 废物老虎机
- 属性：无
- 效果【类型遗物】：[使用帮助卡时] 从以下效果中随机触发一个（按括号内概率）：

  3. 对随机一张怪物卡造成2点伤害（21%）
  4. 获得1点血量上限（10%）
  5. 玩家基础护甲+1（5%）
  6. 玩家攻击+1（5%）
  7. 获得20金币（10%）
  8. 随机洗入一张帮助卡到战斗卡组（5%）
  9. 洗入一张蓝色宝箱卡到战斗卡组（1%）
- 品质：金色
- 定位：道具
