# 编辑器工作台体系（NineGrid.Content.Editor · localhost HTTP+WS 工作台）

> 覆盖范围：`EditorWorkbench/` 全部 5 文件、`CardPresentationWorkbench/` 全部 5 文件、`AudioWorkbenchServer/Launcher/EditorState`、`VfxWorkbenchServer/Launcher/Host/EditorState`、`VfxBindingEditorWorkbenchSession`。
> Web 前端（非 .cs，不计入 149）：`CardPresentationWorkbenchWeb/`（index.html + styles.css + app.js）、`AudioWorkbenchWeb/`、`VfxWorkbenchWeb/`——每个工作台目录一套三件静态页。

## 职责综述

三个「系统浏览器 localhost 工作台」共用一套通用传输层：Unity Editor 内起 loopback HTTP 服务，浏览器页面经 Bearer token 鉴权后通过 WebSocket（或长轮询回退）收 revision 快照、发命令补丁。域逻辑（音频调音 / VFX 绑定调试 / 卡面表现配置）各自实现 `IEditorWorkbenchHost` 宿主接口，传输层完全不感知业务语义。这是 ADR-0036「完整作者 UI 为系统浏览器鉴权 localhost HTML 工作台，Unity Editor 仅保留启动器、loopback 服务与作者态编排」及 ADR-0040 复用条款的落点。

| 工作台 | 菜单 | 端口区间 | 宿主状态 | 前端目录 |
|---|---|---|---|---|
| 声音绑定调音 | `NineGrid/音频/声音绑定调音工作台` | 7910–7939 | `AudioWorkbenchEditorState` | `AudioWorkbenchWeb/` |
| VFX 绑定调试 | `NineGrid/视觉特效/VFX 绑定调试工作台` | 7950–7979 | `VfxWorkbenchEditorState` | `VfxWorkbenchWeb/` |

## 核心流程与数据流

### 传输协议

```
浏览器打开 http://127.0.0.1:<port>/#token=<base64url 32B>
  静态页（index/styles/app）带 CSP：default-src 'self'; img-src 'self' blob: data:
  ├─ WebSocket /stream：hello{token} → snapshot 信封 → 之后 command/commandResult 双向 + 推送
  └─ 回退长轮询 GET /api/events?afterRevision=N（≤25s）
命令：POST /api/command {requestId, command, payload}（Bearer 头）
  → transport 把执行封送到 Editor 主线程（RunOnMainThread，30s 超时）
  → host.TryDispatchCommand → 域状态变更 → BumpRevision
  → transport 泵检测 revision 变化 → 推 delta/snapshot 信封给全部 WS 客户端
资产：GET /api/asset?kind=…（仅 CardPresentation 台，Bearer 鉴权，PNG）
```

安全边界：仅 loopback 远端、Host/Origin 白名单（127.0.0.1/localhost:端口）、Bearer token（SessionState 存续一个 Editor 会话）、路径穿越拒绝、载荷 1 MiB 上限。快照/命令全在主线程执行，浏览器永远看不到半更新状态。

### 作者态三大纪律（Audio/VFX 台）

1. **工作副本 vs 磁盘快照**：浏览器只发「约定命令补丁」（replace*Binding 带整行 DTO），不直接改 JSON 文本；脏行以 Clone+JSON 相等性判定。
2. **瞬态恢复与冲突门禁**：程序集重载前把「基线 JSON + 工作副本 JSON + 焦点」写 SessionState；重载后基线与磁盘一致 → 静默恢复工作副本；不一致 → `DiskChanged` 冲突态，**阻塞一切写命令**，只留「恢复临时版（下次保存覆盖磁盘，需确认位）」与「丢弃临时版」两个显式出口——无静默合并（ADR-0036）。
3. **保存即正式**：Save 直接写随包发布的正式 JSON 并升格 `humanConfirmed`；无第三层本机覆盖。Play Mode 下 SFX/VFX 脏改在每次变更后热应用到运行时（`ApplyWorkbenchCatalog`，严格解析失败不替换旧 catalog），未保存禁用表现为「临时静音/抑制」。

CardPresentation 台没有冲突门禁/瞬态恢复（其真源是逐卡 JSON 文件而非单一 catalog，编辑粒度小、且与 UI Toolkit 窗口共享 Session）；其特有能力是 `/api/asset` 离屏渲染（卡面/模板/词条样例 PNG）与 `animFrames`/`vfxFrames` 逐帧引用（前端 JS 定时器换图实现动画与特效试播、CSS 3D 实现翻面）。

### Web 前端（非 .cs）

每台一套 `index.html + styles.css + app.js` 纯静态三件（无构建步骤、无外部依赖，CSP 只放行 self）。CardPresentationWorkbenchWeb 是最大的一套：五区导航（卡面/词条/效果池/特效库/卡组·卡背）对齐 UI Toolkit 窗口 IA，精灵选择器走 `listSprites` + `/api/asset?kind=sprite` 缩略图，pins/filters/列宽等纯视图偏好只存浏览器 localStorage（不进作者态）。

## 对外通信面

- **入**：浏览器 HTTP/WS；Unity 菜单；程序集重载/退出事件。
- **出**：与 05 篇同一批磁盘真源（cards/tables JSON、audio/vfx 绑定 JSON、词条 SO）；Play Mode 下经 `IAudioSystem` / `IMusicSystem` / `IVfxSystem`（`NineGrid.Presentation`）观测与热应用。
- 三台相互独立（端口/token/状态分离），可同时开。

## 关联 ADR

ADR-0036（作者态编排、瞬态冲突门禁、热应用与临时静音、三模式权威 UI）、ADR-0040（VFX 台复用传输、Pulse 只观察、State 可清槽、停用只抑制后续）、ADR-0008/0035（CardPresentation 台的数据真源与描述纪律）。

## 不变量与坑

- **传输层不得引用域语义类型**——新开工作台时实现 `IEditorWorkbenchHost`（可选 `IEditorWorkbenchAssetHost`）即可，不改 transport。
- `RunOnMainThread` 在 Editor 编译中（`isCompiling`）也会走队列封送——命令在编译窗口期可能等满 30s 超时，属预期防护而非死锁。
- 长轮询超时也返回**完整快照**（非 304 空响应），前端逻辑依赖这一点做兜底刷新。
- delta 信封与 snapshot 信封 payload 目前**相同**（全量快照），区别只是类型标记——前端不应假设 delta 是增量补丁。
- Audio/VFX 台的 `pendingRecoverOverwriteConfirm` 是一次性确认位：恢复临时版后**下一次保存**清位并覆盖磁盘；中途 reload 即放弃。
- CardPresentation 台 `AutoRestartSessionKey` 只在 LaunchUrl/EnsureStarted 被置位——从未打开过工作台的会话里域重载不会莫名起 HTTP 服务。
- `/api/asset` 的 PNG 编码走 `RenderTexture` Blit（绕过纹理不可读限制），预览渲染与编辑器窗口共用 `CardFacePreviewHost`——两处画面不一致时先查词条覆盖注入（`EnsureDescriptionIconPipeline`）是否两侧都执行。
- token 存 SessionState：Editor 重启后 URL 里的旧 token 失效，须从菜单重新打开（重载不换 token，页面可自动重连）。
