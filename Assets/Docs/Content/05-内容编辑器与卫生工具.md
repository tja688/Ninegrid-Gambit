# 内容编辑器与卫生工具（NineGrid.Content.Editor · 窗口 / 会话 / 校验 / 迁移）

> 覆盖范围：`NineGrid.Content.Editor` 中除 Workbench 体系（`EditorWorkbench/`、`CardPresentationWorkbench/`、`*WorkbenchServer/State/Host/Launcher`、`VfxBindingEditorWorkbenchSession`——见 [06](./06-编辑器工作台体系.md)）之外的全部文件。
> 本程序集全部代码 Editor-only（`#if UNITY_EDITOR` 或 Editor asmdef），不进 Player。

## 职责综述

内容编辑器层给内容作者提供三代工具的叠合：

1. **卡牌表现编辑器**（`NineGrid/表现层配置` UI Toolkit 窗口）——一卡一文件 JSON 的主编辑入口：卡面/词条/效果池/特效库/卡组·卡背五区 + 高保真卡面预览。
2. **旧 ContentVisual 编辑器**（`NineGrid/归档/Content Visual Editor`）——Luban/xlsx 时代的配图窗口，已降级为归档兜底（有 JSON 的条目本窗只读描述）。
3. **卫生校验与迁移工具**——断链扫描、内容卫生汇总、怪物遭遇配置校验、音频素材迁移与卫生、Cue/VFX 声明扫描、绑定 Catalog 卫生、AI 初始绑定、描述批量导出导入。

## 核心流程与数据流

### 卡牌表现编辑器保存链

```
UI 改动 → 直接写 entry.Dto 字段（IsDirty = 序列化指纹 ≠ SavedJson）
保存（单条 / 全部）：
  Face：TryExpandSkillIdsIntoAssemblies（skillIds → 装配并清空）
        → NormalizeLogicMounts（无装配时清 effectIds）
        → CardPresentationJsonIO.SaveAuthoring（双写 Arts + Streaming + ImportAsset）
  Deck：直接 SaveAuthoring
  效果模板 / 特效库：EffectTemplateEditorIO / VisualEffectCatalogEditorIO.TrySaveAll（双写 + Invalidate 运行时缓存）
  词条表 / 内联图标样式：SetDirty + SaveAssets（SO 资产，表现层 CardChassisPaths 下）
  末尾 CardPresentationConfigCatalog.Invalidate()
```

自动描述机制：未「锁定自定义」时描述框跟随装配增删自动重写为各装配参数化 design_text 的「；」拼接；同键跨装配异值时把 `{key}` 升格为 `{装配id.key}`（与 ADR-0035 契约一致）；手改后与自动文案不等即锁定，清空描述框解锁。每个装配行提供「发送自身变量」按钮，把标准 `{装配id.键}` 令牌追加进描述（装配无稳定 id 时按 #154 直接不显示，不兜底 templateId）。

预览链：`CardFacePreviewHost`（表现层 Editor 工具，本程序集消费）按 `CardFacePreviewRequest` 实例化「底盘 + L4 卡面模板」离屏渲染；描述经 `CardFaceDescriptionProjector.Project(Instance模式)` 投影（与运行时同一渲染层）；卡背按「所属卡组背槽覆盖自有槽」规则合成（与运行时 `ApplyDeckBackSprites` 对齐）；Trap 的 ActionCount/ShowActionCount 经 `CoreCardPresentationMapper.BuildVisualSnapshotFromDefId` 取运行时同源快照。词条编辑页通过 `CardFacePresentationBinder.Set*Override` 把未保存的词条表/内联样式草稿注入渲染管线实现所见即所得。

### 音频绑定作者链（Editor 侧）

```
[AudioCue] 声明（Presentation 程序集） ──扫描──┐
audio_manifest.json（素材键表） ──ClipOptions──┤
audio_bindings.json（磁盘快照） ──────────────┴→ AudioBindingEditorSession
                                                  （声明∪绑定 成行；未绑定行可 CreateDraft）
浏览器工作台补丁（06 篇）→ TryReplaceWorkingDto（键冲突拒绝）
保存 → 卫生关键项拦截 → humanConfirmed → 写正式 JSON（无第三层本机覆盖，ADR-0036）
```

`AudioAiInitialBinder` 是这条链的批量起点：一次性为全部声明生成 aiDraft 绑定（硬编码「cueId → 中文素材名」精确表 + 打分启发式），此后人工在工作台逐条确认。

### 音频素材迁移链（#167，已执行的一次性工程）

preflight 审计（哈希/引用核对，任何 finding 即中止）→ 移动正式素材入 `Resources/audio/SFX`（校验 GUID 不变）→ 隔离素材出 Resources → 删除重复根 → 规范导入设置 → 写 manifest → 终审计报告。此后 `AudioAssetHygieneValidator` 常态守护六类卫生。

## 不变量与坑

- **描述权威分流**：contentId 有 CardPresentation JSON → 描述归 JSON（旧窗口只读、不写 xlsx）；无 JSON → 才允许旧窗口写 xlsx。别在旧窗口里找不到描述编辑框就以为坏了。
- **模板分类是 id 前缀启发式**（`tpl.help/relic/skill/trap.` + 名称含词兜底），不是 schema 字段——新模板起名不带前缀会掉进「其他效果」桶且不被任何卡种默认多载。
- 编辑器「同类多载」只是 UI 门禁：跨类遗留挂载仍显示（标注真实分类）且运行时 JSON 同构合法（ADR-0009）。
- `TryExpandSkillIdsIntoAssemblies` 在**打开卡面时**就会执行并标脏——只是浏览怪物卡也可能产生「未保存改动」，这是设计（编辑器内收敛单一装配源），保存后 JSON 中 skillIds 清空、装配落地。技能 JSON 全找不到时保留 skillIds 不静默丢挂载。
- 保存链的三处 Invalidate（ConfigCatalog / EffectTemplateCatalog / VisualEffectCatalog）是运行时缓存一致性的保证；绕过编辑器手改 JSON 后要么重开 Play、要么手动触发重载。
- 音频/VFX 绑定保存即 `humanConfirmed`——AI 重绑（非强制）不会再碰它；想让 AI 重新接管一条绑定需手工把 authoringStatus 改回 aiDraft 或走强制重绑。
- `AudioBindingCatalogHygieneValidator.ToCueIdSet` 的注释是真实教训：cueId 不能走 `NormalizeKey`（`Path.GetExtension` 会把 `ui.action.press` 裁成 `ui.action`）。
- 旧 xlsx 桥依赖 `Assets/Tools/Luban/*.py` 与 venv Python——脚本已随 Luban 退休删除时读表静默空列表，这是兼容行为不是 bug；不要为“xlsx 读不出”修桥。
- `MonsterLoadoutPresentationValidator` 的同步技能节奏检测是**从简启发式**（模板 id 含 `delivery.move`/`gear_delivery`），与投影层 `DetectSyncRhythmSkills`（扫 body `OnCardRhythmFire`）口径不同，前者只用于配置校验提示。
