# 音频系统（SFX / BGM / 玩家音量 / 诊断）

> 覆盖范围：`Systems/` 下音频十件套。
> 结构总纲见 ADR-0036：**Cue（语义）→ Binding（决策）→ Adapter（播放）** 三层，MMSoundManager 只允许出现在 Adapter 内。

## 职责综述

- `AudioSystem`：唯一 SFX 策略模块。输入稳定 `AudioCueRequest`，从 `AudioBindingCatalog`（`Resources/audio/audio_bindings.json`）解析最终绑定，处理冷却/变体池/延迟排期，输出结构化 `AudioCueResult`。
- `MusicSystem`：唯一期望音乐状态模块。流程层提交 `DesiredMusicState` + 稳定 source，模块管切歌代数、淡出收口、幽灵 BGM 审计。
- `MMSoundManagerAudioPlaybackAdapter`：项目唯一播放 Adapter，SFX/Music 双轨 + Editor/Dev 诊断能力。
- `PlayerAudioSettingsSystem`：Master/BGM/SFX 三路玩家偏好唯一读写口（PlayerPrefs 持久化，与作者调音分离）。
- 诊断四件（`AudioDiagnostics*` / `MusicDiagnostics*`）：Editor/Development 专属的轨道巡检与异常快照。
- `MMSoundManagerBootstrap`（文件内类型名 `MMSoundManagerRuntimeHost`）：运行时兜底创建 MMSoundManager 宿主。

## 核心流程与数据流

### SFX 请求管线（`AudioSystem.RequestCue`）

```
记 Requested（History + PerfTrace AudioCueRequest）
→ Catalog.TryResolve(request)（内容覆盖优先级 cardDefId+skillId → skillId → cardDefId → 基础 Cue）
   失败 → Unbound（"cue ID 为空" / "声音绑定不存在"）
→ !binding.Enabled → Suppressed（"workbench binding disabled"，#186 工作台临时停用可观察）
→ ResolveVariant：有效变体池加权随机，>1 个变体时默认排除上一次选中（避免立即重复）；
   池空回退绑定单素材；仍无 → Unbound（"缺少有效素材"）
→ 最短间隔（按最终 AudioBinding 实例 + UnscaledTime）→ Cooldown("minimum interval")
→ Adapter.Play(AudioPlaybackRequest{clipKey, volume=dB→linear(binding+variantTrim),
   startOffset(素材内起播点), bindingDelay(InitialDelay)})
   异常/失败 → BackendFailure
→ 记 Played、更新 LastPlayedAt/LastVariantId、TrackBurstIfNeeded
   （1 秒窗口 ≥4 次同 cue → PerfTrace AudioCueBurstAnomaly，2 秒报告冷却）
```

- **排期**：`ScheduleCue(request, delay)` 经 `IAudioCueScheduler`（默认 DDOL 协程 `UnityAudioCueScheduler`，`WaitForSeconds`——scaled 时钟）延迟后重新走 `RequestCue`；`CancelScheduledCue` 显式撤销（蓄力/预备类，History 记 `Cancelled/"explicit cancel"`）。**普通绑定延迟走 Adapter `InitialDelay` 必播，不因宿主死亡取消**——两者语义严格分开（ADR-0036）。
- **PerfTrace**：所有 outcome 都打 `PerfTraceKinds.AudioCue*`，payload 带 cueId/clipKey/bindingKey/reason/scheduleKey/内容上下文/`sinceLastPlayMs`/Director busy 字段/batchId/sessionId；打点失败静默（不干扰玩法）。运行时 UID 只进诊断字段，**不参与绑定解析主键**。
- **Editor/Dev 工作台缝**（#186）：`GetWorkbenchSnapshot`（History 深拷贝 + PlayingSources（标记 workbenchPreview）+ SceneOrphans + PersistAnomalies + 按 BindingKey/CueId 聚合 `AudioCueAggregate`）、`ApplyWorkbenchCatalog`（严格 `TryFromJson`，失败**不替换旧 catalog**；成功清冷却/变体记忆、revision++）、`PreviewWorkbenchBinding`（忽略 enabled、不写冷却/普通历史，sourceId 记入 preview 集合）、`StopSfxSource` / `StopAllSfxSources`（经诊断 Adapter）。

### Adapter（`MMSoundManagerAudioPlaybackAdapter`）

- **SFX Play**：`AudioAssetManifestLoader.NormalizeKey` → 必须是 manifest 登记的正式键（否则 Failure）→ `Resources.Load<AudioClip>` → MMSoundManager Sfx 轨（Volume clamp 0..2、PlaybackTime=起播点、InitialDelay=绑定延迟）。成功后 `RegisterSfxSource(owned:true)` 登记 `sfx-source:<instanceId>`。
- **Music Play**：只认 manifest 中 `kind=="BGM"` 的键；Persistent + DoNotAutoRecycle；FadeIn 走 MM 原生 Fade。返回 `MusicPlaybackHandle`（clipKey + AudioSource + sourceId）。
- **淡出**：`MusicFadeRunner`（挂在 MMSoundManager 宿主上的协程组件）按 unscaled 时间线性降音量，支持 `TryPause/TryResume`（Editor 试听暂停恢复用）；`FadeOutPlayingForCue`（`IAudioSfxTailAdapter`）按 cueId 找已登记 SFX 源批量淡出（`battle.attack.charge` 取消类）。
- **诊断实现**（Editor/Dev）：`GetPlayingSfxSources`（对未经 Adapter 起播的"逃逸源"标 `Claimed=false`，登记但不升格 owned）、`StopSfxSource`（未登记源最后从实时轨反查，保证未认领源也停得掉）、`GetSceneAudioOrphans`（场景中在播且不在 MM 双轨池内的 AudioSource，**只报不停**）、`GetPlayingMusicSources` / `StopMusicTrackSource` / `PlayPreview` / `Pause` / `Resume`。
- `ResetPlaySession`：只清跨 Play 会话的登记簿，不停在播源。

### BGM 状态机（`MusicSystem.RequestState`）

- 必带稳定 source（空 → `InvalidSource`）；Catalog 解析失败/禁用/缺素材 → `Unbound`。
- **同曲 no-op**：当前绑定 clipKey 相同且当前源确实在播（`IsCurrentPlaybackAlive` 实测 AudioSource）→ `NoOp`，只更新 State/StableSource 标签，不重启音乐。
- 切歌流程：先 `ReleaseRetiringSource`（**至多一个淡出源**——新切歌先硬停更老的淡出源，记 `RetiredSourceReleased`）→ 当前源转 retiring 并 `BeginFadeOut`（完成回调里 `ReferenceEquals` 校验，旧代数回调记 `StaleCallback` 忽略）→ `generation=++mNextGeneration` → Adapter.Play → 成功记 `Started`，失败 `BackendFailure`。
- `StopAll(source)`：停 current+retiring+Preview，清 DesiredState。
- **审计**（Editor/Dev）：`AuditMusicTrack(trigger)` 把实际在播源与 current/retiring/preview 三个认领者比对，未知源生成 `MusicOverlapAnomaly`（带 desiredState/requestSource/scene/chainId/batchId），只报不停；`StopUnknownMusic` 人工触发才停；`MusicDiagnosticsTicker` 每秒巡检 + sceneLoaded 触发。`BeginPreview/EndPreview`：试听前 Pause 挂起 current/retiring（记位置），结束 Resume 恢复原位置。
- Play 会话重置：`RuntimeInitializeOnLoad(SubsystemRegistration)` 调 `ResetPlaySessionState`（DisableDomainReload 兼容）。

### 玩家音量（#171）

`PlayerAudioSettingsSystem`：作者默认从随包 `MMSoundManagerSettings` SO 捕获（构造时一次），玩家偏好独立存 PlayerPrefs 键 `NineGrid.PlayerAudioSettings.v1`（JSON DTO）；`SetVolume/SetMuted` 即时经 `MMSoundManagerAudioBusApplier` 写 AudioMixer 三参数（linear→dB，0 音量压 −80dB；静音=EffectiveVolume 为 0 但原音量保留）；`ResetToAuthorDefaults` 删键恢复。`Changed` 事件供 UI 双向绑定（`PlayerAudioSettingsPanel`）。`EnsureRegistered` 已注册时会重新 `ApplyToAudioBus`（场景重载后 Mixer 重挂）。**不写回作者 JSON / 不碰调音工作台工作副本。**

### SFX 持续异常检测（`AudioDiagnosticsService`）

由 `AudioSystem.EnsureRegistered` 在 Adapter 支持诊断时安装。每秒 `AuditSfxTrack`：记 `AudioSfxTrackSnapshot`（前 8 源明细）；对每个 sourceId 维护 `PersistTracker`——同 clip 连续 ≥3 次巡检仍在播，且（导演空闲 或 loop）→ 记 `AudioSfxPersistAnomaly`（PerfTrace + 环形 32 条快照供工作台"正在播放"页展示）。

## 对外通信面

- **发射入口**：业务一律经 `TriggerPulseHub.PulseAudio(AudioCueRequest)`（audio 通道 = `DebouncingTriggerPulseSink(AudioTriggerPulseSink, 0.05s)`，由 `TriggerPulseOutputController` 装配）或各权威发射者直调 `InteractionAudioCues.Pulse` 等声明门面（Flow 侧）。
- **BGM 提交口**：仅 `GameFlowShellSystem.SubmitMusicForShellState / SubmitMusicForState`（见《03》）。
- **工作台**：`NineGrid.Content.Editor` 的 `AudioWorkbenchServer/Host/EditorState` 经上述 Editor/Dev 接口读写（不在本区块范围）。
- **测试缝**：构造注入 catalog/playback/clock/scheduler/randomValue；`NullAudioPlaybackAdapter` / `NullMusicPlaybackAdapter` 缺省失败实现。

## 不变量与坑

- **业务/表现代码禁止直调 AudioKit / MMSoundManager**——只有 Adapter 内允许（`AudioStructureGuardTests` 源码扫描护栏**仍在生效**，违规会挂 EditMode 测试，见《10》）。
- **禁动态 cue**：`sfx.effect.<CardUid>` 之类运行时拼接不得成为正式绑定键。
- 随机变体只用 Unity 表现 RNG（`UnityEngine.Random.value`），**不消费 Core RNG**。
- 音频时钟统一 `Time.realtimeSinceStartup`（`RealtimeAudioClock`）；但 `UnityAudioCueScheduler` 用 `WaitForSeconds`（**scaled**）——排期在 timeScale≠1 时会拉伸，与冷却时钟不同源（现状事实，改动前先确认预期）。
- 冷却键是 `AudioBinding` 实例引用——`ApplyWorkbenchCatalog` 换 catalog 后旧冷却自动失效（刻意行为）。
- `Suppressed` ≠ `Unbound`：工作台停用是可观察状态，别当断链修。
- History/聚合/在播源/孤儿源全部 `#if UNITY_EDITOR || DEVELOPMENT_BUILD`；Release 只有 PerfTrace 少量字段。排查线上问题主要靠 PerfTrace。
- 玩家偏好（PlayerPrefs）与工作台工作副本（内存 catalog）与作者 JSON（磁盘）三者互不覆盖——音量不对先分清是哪一层。
- `MMSoundManagerSettings.AutoLoad` 已关闭：历史 `mmsound.settings` 存档不得覆盖包体作者默认。
