# 05 · 变换塔、收敛体系与盘面运动执行

> 权威代码事实文档 · 生成于 2026-08-12 · 覆盖 `Cards/Convergence/` 全部 18 个 .cs 与盘面运动执行三件（`Ground/GroundMotionExecutor`、`BoardMotionStepScheduler`、`BoardPresentationMerge`）及盘面表现契约 `CombatPresentationContracts`，共 22 个 .cs。

## 职责综述

这是 Cards 区的运动内核。每张卡挂一座**编译期定死的 L0–L4 变换塔**（`CardTransformTower`：CardRoot → BoardFrame → SlotFrame → EffectFrame → CardVisual/FacePivot），世界位置 = 各层 local 叠加、**永不换父**（ADR-0024 不 SetParent 到格锚）。运动被拆成三种正交写入：L2 SlotFrame 承载格位收敛（发牌/换格/旋转），L3 EffectFrame 承载特效位移（击退/冲刺，末态回零），L4 CardVisual 只做缩放质感（hop 起跳/落地脉冲）。收敛数学是**五次 Hermite / 最小 jerk 曲线**（`ConvergenceCurve1D`：给定 p0/v0/p1、末速末加速为零，T 秒精确命中；Redirect 以当前位姿+速度重解，C1 连续），由 `LayerConvergenceDriver` 逐帧推进。同步表演经 `LeaseArbiter` 按（卡,层,时间窗）租约独占，`BeatGrid` 提供同拍共享 sourceTime 与就位栅栏。`GroundMotionExecutor` 是场地运动执行器（旋转/hop/换位/移除/Avatar 入场/空格点击分流），消费 Flow 投影出的 `BoardPresentationStep` 保序步骤流。

## 核心流程与数据流

### 1. 收敛数学与驱动

1. `ConvergenceCurve1D.Create(p0, v0, p1, T)`：闭式解归一化五次多项式（v0=0 时退化为经典最小 jerk 10s³−15s⁴+6s⁵）；`EvaluatePosition/Velocity/Acceleration` 端点硬返回边界条件；`IsComplete` 只认解析时刻 t≥T 不靠位置 epsilon。
2. `LayerConvergenceDriver`：挂在卡根（RequireComponent Tower），按 `DrivenLayer` 驱动 L2 或 L3 的 localPosition；`ConvergeTo` 从当前位姿+速度重解（收敛中重入即 Redirect，C1 连续）；`Tick(Time.deltaTime)` 逐帧求值，完成时精确落 target、清速度、发 `Completed` 事件；`Evict` 吐真实速度（B 阶段复杂域），`Admit` 直接落位姿+速度。

### 2. L2 门面（`SlotFrameConvergence`）——格位收敛约定

- 约定：**就位时 L0 停在格锚、L2.local = 0**；换格/补牌只改 L2 目标重收敛，零 SetParent；收敛过程中不写 L0 world position。
- `BeginDealFromLaunch(card, launchWorld, slotAnchorWorld, T)`：L0 先落**目标格锚**，L2 = 起飞点相对 local，再收敛回 0——所以飞行中「L0 在终点、视觉在空中」，读位置必须用 `GetVisualWorldPosition`（CardVisual 优先）。同时 `FlightSortingChannel.ArmForSlotConvergence` 抬飞行序。
- `ConvergeVisualToWorld / RedirectVisualToWorld`：保持 L0 不动，把 L2 收敛到目标世界点对应 local；`ConvergeVisualToWorldAsync` 完成后默认 `SnapHome`（L0 落锚、L2 归零）。
- `SnapHome`：离散落锚（Kill tween、L4 缩放归一、driver Admit AtRest、L0=锚点、L2=0、`FlightSortingChannel.Restore`）；`SlotFrame.HopComplete` 原因下不重置 L4 缩放（hop 脉冲自己收束）。
- `SanitizeForSanctuary`：进手牌/卡组前清塔——保持视觉世界位不变、L2/L3 归零、杀 hover punch、L0 移到视觉位；残差 >0.01 打 `TowerResidueOnSanctuary` 异常。
- 全程 Motion 探针：StartConvergenceDiag/EndMotionDiag 按 driver 配对 MotionBegin/End（redirected/complete/snap/cancel/sanitize），关联 choreoSeqId。

### 3. L3 门面（`EffectFrameConvergence`）——特效位移

- 写 L3.localPosition、末态回零，与 L2 物理隔离；`ParkRootAtWorld` 把视觉位固化到 L0 并清 L3（融合撞点后用）；`TryPlayOutAndBackAsync` 冲刺往返（交战 lunge SO 的塔路径）；`ConvergeVisualToWorldAsync` 带「视图销毁即退出」保护（driver 永不完成时防 Present 挂死）。

### 4. 租约与栅栏

- `LeaseArbiter.TryAcquire`：Sync 请求撞在窗内的 Sync 租约 → `SyncConflict` + 纪律 B 报警；Sync 征用 Async → `Commandeered` 附带 `sampleHandoff()` 采样的位姿速度（driver Admit 后无缝续走）；Async 后发先至，但抢占**未兑现的 committed** Async 也报纪律 B。`MarkFulfilled`/`Release` 配对。
- `GroundMotionExecutor.IssueSyncL2Lease/ReleaseSyncL2Lease`：hop/换位以 Sync commitment 播时按（uid, SlotFrame, now..now+T）取租约，完成 `CommitmentArrive + MarkFulfilled + Release`；报警回调 `OnDisciplineBAlarm` 解析 uid 后打 `ConvergenceDiagProbe.DisciplineB`。
- `BeatGrid`：`OpenBeat(sharedSourceTime)` → 各卡 `Register(beatId, committed, driver)` → `PlaceBarrier(墙钟)`；`IsBarrierSatisfied` = 时间到（容忍 5ms）+ Tick 全员 IsComplete（绑 driver 的还要 driver.Completed）。旋转用它保证「整环同曲线进度、到点全员就位」；不满足打 `BarrierUnsatisfied` 异常（regs=0 单独标 skipEmpty）。

### 5. 盘面运动执行（`GroundMotionExecutor`）

1. **Busy 两义**：`IsFieldBusy`（本地 `_isBusy`，场地自身运动重入保护）与 `IsBusy`（聚合 ChoiceOverlay/MainlineBusy/交战 busy）——输入门禁只认 MainlineBusy（IntentIntake），聚合值只用于运动 API 的调用保护。非 skipBusyGuard 的旋转/hop/换位会 `PresentationMainlineHold.TryAcquire("FieldMotion")` 短租主线。
2. **旋转** `RotateOuterRingInternalAsync`：外圈快照 → 批量置换事务 `TryCommitPermutation` → `_deal.OnRingShifted`（在途飞牌跟环）→ 全员卸认领 → BeatGrid 开拍/放栅栏 → 逐卡 `AnimateCardHopToSlotAsync`（注册进 beat）→ WhenAll → 栅栏判定 → 落地全员 `SyncGroundCardClaim` → `AuditRegistryIntegrity`。空环时只 Delay `emptyRotateDuration`。全程 RingShift 探针（plan/registered/animate/commit_fail 分相）+ choreo 包裹。
3. **hop** `AnimateCardHopToSlotAsync`：发牌在途卡只 `TryRedirectFlightToSlot` 并等同一 driver（禁止 hop 与飞牌互抢）；否则 Sync 租约 + L4 `PlayHopScalePulseAsync`（起跳放大→落地略缩→回基准）与 L2 `ConvergeVisualToWorldAsync` 并行；完成 RefreshDisplayMode。
4. **换位** `ApplyCrossSwapMovesInternalAsync`：识别 A↔B 互换对（`TryGetCrossSwapPair`）→ 批量置换 → 双卡卸认领 → 双 Sync 租约 → 双 L2 收敛 WhenAll → 回认领。`ApplyBoardMovesAndHopAsync` 入口按 moves 形态分流：互换对 → 换位；整环同向 → 旋转（`TryClassifyOuterRingRotation` 严格校验方向一致、占格匹配、无环外卡）；否则通用批量 hop（前置校验视图与占格齐全，任一缺失整批放弃「占格不变」）。
5. **移除/取走**：`RequestRemoveFromField` / `TryTakeCardFromField` / `VacateSlotForExplore`——先 `CancelDealFlightForUid`（同批 Deal→Remove 防 WaitAll 挂死）、卸认领、Unregister、可选 `StartExplore(slot)` 补位探求；`VacateUidMismatch`（占格 uid 与期望不符）显式拒绝。视图缺失时记 RegistryMiss 并 heal-vacate 占格。
6. **Avatar 入场** `RequestRevealAvatarAsync`：只门禁场地自身 busy（覆盖层/主线锁不挡开局）；登记格 5 → SnapHome → scale 0→ScaleAppear。
7. **空格点击** `TryHandleEmptySlotClick`：轴二快拒（ChoiceOverlay/Opening/BoardSelect）后按 `BoardWalkInputHook.IsEnabled` 分流 BoardWalk / Explore 提交（轴一互斥交 IntentIntake，不轮询 FieldBusy）。
8. **清场** `ClearField(force)`：force 路径取消交战工作+全部动画+清 busy；非 force 逐格 Vacate→Release（与 RequestRemoveFromField 契约一致防幽灵占格）。

### 6. 步骤流契约与合并

- `BoardPresentationStep`（Kind=Rotate/Swap/Move/Deal/Remove + Commitment + MultiHopStrategy + CoreSequence/ActionId）由 Flow 自 EventLog 投影，保序步骤流非空时优先于扁平 Moves/Deals/RemovedUids。
- `BoardMotionStepScheduler.ExecuteMotionStepAsync`：位移类 Step 的执行层入口——先发 `CardLifecycleAudioCues.PulseMotion`，优先经 `GroundPresentation`（System 已 Bind），否则回退 `GroundFieldView` 转发。
- `BoardPresentationMerge`：`ForHitPresentDrain` 从命中批剥离交战主目标 Remove（尸体走 Vacate/FinalizeLethal 路径，见 06 篇）；主目标已死（`stripVictimMotion`）时同时剥离尸体的 Move/Swap 位移——Core 在击杀落地前的 OnBattle 旋转/换位会真实移动尸体，表现侧尸体已先行 Vacate，不得重放其位移；`MergeLethalHitAndPostKill` 合并致死命中与击杀后剧本为单一有序 Drain 批（RemovedUids 去重 + 排除 victim + 剥离 victim 位移）。

## 不变量与坑

- **塔五层职责铁律**：L0 离散落锚、L1 整盘运动（预留）、L2 格位收敛、L3 特效位移（末态回零）、L4 纯缩放视觉；跨层混写（如把击退写进 L2）会破坏 Redirect 与 Sanitize 的全部假设。
- **读位置必须用视觉位**：`GetVisualWorldPosition`（CardVisual→SlotFrame→Root 逐级回退）；BeginDeal 期间 L0 已在终点，直读 `Transform.position` 是经典错误源。
- **占格事务先行**：一切动画前先 `TryCommitPermutation`/`TryRegister` 落几何表；事务失败整批跳过动画（决不让视觉与登记分叉）。
- **在途飞牌只能 Redirect**：hop/换位对 `IsDealInFlight` 的卡禁止另起收敛，必须走协调器 Redirect 并等同一 driver。
- **租约纪律 B**：Sync 撞 Sync、抢占未兑现 committed 都是结构错误，报警不静默；征用必须带速度交接（视觉 C1 连续）。
- **`IsBusy` getter 有未使用变量**：`var battle = FieldBattlePresentationHook.BattleOrNull();` 为残留死代码（不影响行为，见 README 可疑问题）。
- **栅栏是诊断性收口**：`IsBarrierSatisfied` 失败只打异常不回滚——就位承诺的兜底在 SnapHome 与 FinalStateGuard，不在栅栏。
