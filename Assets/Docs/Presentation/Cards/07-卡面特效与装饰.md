# 07 · 卡面特效 SO 与程序化装饰

> 权威代码事实文档 · 生成于 2026-08-12 · 覆盖 `Cards/Effects/`（含 `Implementations/`）全部 22 个 .cs 与 `Cards/Vfx/` 3 个 .cs。

## 职责综述

`Effects/` 是**单卡表现反馈**体系：每张卡的底盘挂一个 `CardEffectManager`，按 `CardEffectKind`（Attack/Hit/Death/Use/HitFlash/EffectTrigger）装配 `CardEffectSO` 资产（可按八向覆盖变体），由场地/手牌/战斗编排层被动驱动——攻击冲刺、受击闪白、死亡退场（默认 Burning 精灵表脱卡 FX）、使用缩小退场、效果触发脉冲（ADR-0018 基础触发表现 v1 缩放）。Timeline/DOTween/AnimationEvent 统一走整型/字符串 `Callback` 入口。`Vfx/` 是三个**轻量程序化装饰**（静态门面 + 运行时 Runner 单例，不进 VfxBindingCatalog）：`CardEdgeDustFx` 落地喷发/飞牌双尾迹尘雾（算法移植自 LostForSwords），`BoardRangeGlowFx` 悬停范围荧光——怪物威胁范围（暖橙）、机关影响范围（冷青）、玩家可攻击范围（暖橙，悬停 Avatar 格触发），`BoardCardLifeFx` 场地卡生命层——独占 L1 做悬浮飘动 + 冲击波 + 落位沉降（ADR-0051）。

## 核心流程与数据流

### 1. 主通道播放（`CardEffectManager.PlayInternalAsync`）

1. `ResolveEffect(kind, direction)`：查 bindings（方向覆盖优先，回退 default）；未装配告警跳过。
2. **HitFlash 与 EffectTrigger 走旁路**：不 StopCurrent、不置 IsPlaying——受击闪白/触发脉冲不得掐断进行中的 Attack/Death 主通道（ADR-0018 的「脉冲发即完成」）。
3. 其余种类：`StopCurrent`（取消旧播放 + 停闪白）→ 置 `_isPlaying/_suppressHover` → `PrepareMotion`（Kill 根 tween + 打断 hover 反馈）→ 组 `CardEffectPlayContext`（Self 世界位规则：活卡用**视觉位**含 L3 击退；RemovedMode 尸体 + SelfSlot 用格锚——`ResolveSelfWorldPosition` 纯函数）→ `effect.PlayAsync`；取消走 `effect.Stop`；finally 清态并（非 Death/Use）RefreshDisplayMode。
4. `PlayDeathAsync/PlayUseAsync` 在播放前先发声音 cue（Death 可换 cueId 区分碎裂/退场）与 VFX cue（`CardLifecycleVfxCues.PulseDeathOrExit/PulseItemUse`，携带世界位快照）。战斗死亡**不发爆发 VFX**（2026-08-13 删除原 `vfx.combat.death` 骷髅烟雾，只保留卡面碎裂退场帧动画）；非战斗退场仍发 `vfx.card.exit` 轻烟。

### 2. 统一回调入口

`Callback(int)` / `Callback(int, direction)` / `Callback(string)`：Play 段数值与 Kind 一致（0–5），Stop 段 100（StopCurrent）/101（StopHitFlash）；字符串支持枚举名与中英文别名（"闪白"、"死亡"等）。Timeline 死亡回调即 `Callback(2)`、闪白即 `CallbackPlayHitFlash()`（06 篇 rig 重挂的目标）。未传方向用 `LastResolvedDirection`。

### 3. 效果触发脉冲（ADR-0018 基础触发表现）

`PlayEffectTriggerPulse`：装配了 EffectTrigger SO 则走 SO 旁路；否则内置 DOTween 脉冲——记录基准缩放 → 快速放大 1.1x（0.08s）→ 较慢回落（0.22s）；重入先 Kill 并还原基准；OnDisable 兜底还原。由 Flow `EffectTriggerPulseBeatHandler` 在 Impact 对在场持有者调用。**机关卡（Trap）不演缩放脉冲**——`CardEffectTriggerPulseSink` 按 CoreKind 拦下（光环类机关每步触发太吵），提示改由悬停影响范围荧光承担；触发时刻的类型化 VFX / 音效通道不受影响。

### 4. 死亡退场（默认 `CardSpriteSheetBurnExitEffectSO`）

1. 取 `context.SelfWorldPosition`（视觉位，含 L3 击退——碎亡留在击退终点，不回格锚）与卡面世界包围盒（藏卡前量测，无 Renderer 回退模板尺寸 3.31×4.69）。
2. 立刻把卡根 scale 置 0（藏卡），脱卡生成 `CardBurnExitFx` GameObject：SpriteRenderer + `SpriteSheetLoopPlayer` 播 Burning 帧（24fps 不循环），uniformScale 按短边贴齐卡面；Sorting 继承卡牌层（默认 Main、order 5000——Default 层会沉到 BG 之下不可见）。
3. `PlayAsync` 即返回（发射后不管）；FX 按帧数寿命自毁，**不挂**播放取消令牌（卡 Release 后 FX 仍播完）。

### 5. 受击闪白

`CardSpriteHitFlashEffectSO` → `CardSpriteHitFlashExecutor.GetOrCreate(root).PlayAsync`：首次初始化把全部子 SpriteRenderer 换成 HitFlash 材质实例（同步 sprite 贴图与颜色），DOTween 序列驱动 `_HitFlashAmount` 0→峰值→0 循环 N 次；重播前同步材质贴图（sprite 可能已换帧）；`Stop` 归零；OnDestroy 销毁材质实例。

### 6. 悬停范围荧光（`BoardRangeGlowFx`）

1. `GroundCardHitProxy.HoverEnterClaim` → `ShowThreatRange(requester, card)`：读 `card.CommittedPresentation`（**只认已提交投影**，背面卡 FaceUp=false 直接不显示，ADR-0016 双向惰性）。怪物：AttackPattern → 邻格过滤器（正交/斜角/全向），暖橙威胁色；机关：任一效果模板 Body 含邻接原子（`TrapHasAdjacentInfluence`，与 Mapper `DetectSyncRhythmFromDto` 同款模板扫描）才点正交邻格，冷青影响色（与怪物区分）；无邻接影响的机关（回响铃/沙漏/离开机关等）不显示。
2. 玩家本体：`GroundFieldHitSurface` 悬停到无认领者格位且该格为 Avatar 槽时 → `ShowAvatarInteractionRange(requester, hoveredSlot)`，按互动范围（Avatar 槽四向正交，与 Core `AreAdjacent` 同源）点亮，颜色与怪物威胁一致；重复悬停同格幂等。
3. 每个目标格在锚点底板包围盒上铺一块程序化 9-slice 光环贴片（96px 贴图、内缘 alpha 先升后指数衰减、中央拉伸区归零防整格填光），`TableNine/SlotGlowAdditive` 加色材质（缺 shader 回退 Sprite-Unlit 半透明并只告警一次）；Avatar 所在威胁/影响格权重 1.45 加亮。
4. `Update` 双职责：`ValidateActiveRequest` 兜底（请求者失活 / 源卡换格或死亡 / Avatar 模式下 Avatar 槽变更 / `MainlineBusy` 开跑任一命中即清目标）+ `TickCellVisuals` 缓入缓出（0.16s/0.28s）+ 呼吸（0.45Hz、深度 0.18）。
5. `Hide(requester)` 只在当前显示属于该请求者时清除（防他卡 hover 误灭）。

### 7. 边沿尘雾（`CardEdgeDustFx`）

1. **Place**（`SlotFrameConvergence.SnapHome` 落格 / `PlaceAtAnchor` 处调用）：沿卡面四边等距+抖动布点，法向扇形（±45°再加 ±20° 随机）喷出双层叠色粒子（暗底 1.25x + 亮面），TTL 0.6–1s，速度随 TTL 五次幂衰减。
2. **Trail**（飞牌 `BeginTrail/EndTrail` 成对）：按位移累计距离 `trailEmitDistance` 分段回推喷点，只在速度反方向的两个尾角洒粒（双路径），靠后粒子 TTL 略长形成「先飞出先淡」。
3. **预算保护**：`TryReserveSlot` 两模式——Trail 只能回收 Move 粒子、绝不强杀 Place（拖尾让路落地烟）；Place 优先回收 Move、必要时短时软超限（`PlaceHardCap`）也不回收其它 Place。压力打 `DustBudgetPressure` 异常（拖尾侧 0.25s 节流）。
4. 全局开关 `fxEnabled` **默认 false**（SO 未开启时 Play/Trail 全 no-op）；粒子池预热 128 对。

### 8. 场地卡生命层（`BoardCardLifeFx`，ADR-0051）

0. **起点**：`[RuntimeInitializeOnLoadMethod(AfterSceneLoad)]` 主动建 Runner（飘动是常驻表现，不能等第一次冲击才起；场上无卡时每帧只做一次空成员同步），`SubsystemRegistration` 复位静态门面（Runner 引用与三个旋钮）。
1. **成员集合**：每帧至多一次 `SyncMembership` 扫格 1–9 取 `GroundFieldGeometryHook.FieldOrNull()` 的占格卡（表现权威），拿不到塔或 BoardFrame 的跳过；离场卡先 `WriteHome` 归零 L1 再摘除。相位/频率由 `uid * 2654435761` 派生——同一张卡轨迹稳定、卡与卡之间错频，整盘不会像一块板在呼吸。
2. **飘动**：两组不整倍频率（w 与 1.618w / 0.83w 与 1.37w）叠加出「无规律又无缝循环」的位移，幅度 X 0.075 / Y 0.105 世界单位（32 PPU ≈ 2.4/3.4 像素），微旋 0.4°；悬停中的卡幅度 ×1.45。权重按 `IsBoardCalm`（`MainlineBusy` 空闲 且 `IsFieldBusy` 为假）淡入 0.9s / 淡出 0.28s——**主线一开跑整盘停止呼吸**。
3. **让位（`IsEngaged`）**：非 GroundCardMode、L2/L3 local 非零、L2/L3 driver 在跑、L0 离锚超 0.05，任一命中即**当帧硬归零**（不缓动）——L1 是 L2 的父级，`WorldToSlotLocal` 会把 L1 偏移算进收敛目标，缓动让位会污染格位收敛。
4. **冲击**：`Impulse`/`Roll` 各一路欠阻尼弹簧（k=85/c=11.5，roll k=120/c=13.5）；`PlayRadialShock` 按到爆心距离算衰减（半径 6、指数 0.7）与波前延迟（距离÷26），`PlayJolt` 给随机偏下的方向，`PlayImpulse` 给定向。总偏移钳 0.65、总微旋钳 6°。
5. **落位沉降**：卡从「被搬动 ≥0.12s」回到闲置的那一帧补一次向下小冲击（0.09）——发牌、hop、旋转、换位通吃，不需要各运动路径分别接线。
6. 幅度按世界单位定义（写 L1 时除以父级 lossyScale），`Enabled` / `DriftScale` / `ImpulseScale` 三个全局旋钮，关闭即全盘归零；`OnDisable` 兜底 `ResetImmediate`。

## 对外通信面

- **驱动方**：交战 rig 回调（闪白/死亡）、`FieldBattlePresentationExecutor`（PlayDeathAsync/PresentRemoved）、手牌（PlayUseAsync/回收碎裂）、`GroundMotionExecutor`（RemoveCardAnimated）、Flow `EffectTriggerPulseBeatHandler`（触发脉冲）、`SkeletonDeckPresentationManager`（合体闪白）。
- **发声/发 VFX**：Death/Use 前发 `CardLifecycleAudioCues` 与 `CardLifecycleVfxCues`（声明在 Flow 侧；本层只携带 defId 与位置快照）。
- **hover 抑制**：`TryConsumeHoverSuppression` 供 `CardVisualDriver` 在效果播放中压掉 hover 动效（注意：方法名带 Consume 但实现只读不清位，清位在播放 finally）。
- **Vfx 三件为静态门面**：不进 `VfxBindingCatalog`/`TriggerPulseHub` 三通道，是独立的程序化装饰（code-map presentation.md 已登记）。
- **`BoardCardLifeFx` 的调用方在 Flow 侧**：`DamageFloaterBeatHandler`（受击一颤）与 `EffectTriggerPulseBeatHandler`（签名冲击波）；本层不反向读 Flow。

## 关联 ADR

ADR-0016（背面不显示威胁荧光）、ADR-0018（脉冲不占主通道、基础触发表现 v1 缩放、Lethal 碎亡留在击退终点）、ADR-0023（荧光/尘雾不进命中路由）、ADR-0011/0038（威胁范围按攻击模式几何）、ADR-0051（L1 装饰运动层：飘动/冲击波/落位沉降与让位纪律）。

## 不变量与坑

- **HitFlash/EffectTrigger 永不 StopCurrent**：旁路语义是「受击闪白不得掐断死亡/攻击主通道」；反向地，`FieldBattlePresentationExecutor.TryBeginLethalVictimPresentation` 靠 `PlayInternal` 的 StopCurrent 顶掉未完成 Hit 保证 Death 必播。
- **死亡 FX 脱卡且不随卡取消**：Burn FX 不挂播放令牌，卡 Release 后仍播完自毁；落点必须用 `SelfWorldPosition`（视觉位），直读 Root.position 会落回格锚（击退在 L3）。
- **Burn FX Sorting 必须落 Main 层**：Default 层沉在 BG 下不可见（SO 注释明确）。
- **威胁荧光只读已提交投影**：`CommittedPresentation.AttackPattern/FaceUp`——不直读 Core（与卡面显示值同一纪律）；主线一开跑立即淡出，不残留过期提示。
- **尘雾默认关**：`fxEnabled=false` 是有意的发布保守值；调参经 Resources SO 或 `CardEdgeDustFx.SetIntensity`。
- **L1 只能有一个写者**：`BoardCardLifeFx` 独占 `_L1_BoardFrame`；再挂第二个写 L1 的系统会互相覆盖，且让位纪律失效（收敛目标带上残余偏移）。手牌拖拽倾斜同样写 L1，但手牌卡不在本层成员集合内（只收占格卡），两者不重叠。
- **方向变体按 Right 基准制作**：Left 系播放时 `CardDOTweenDirectionUtility` 对 X 取反（`CardTweenClip.endValue` 注释约定）。
- **`CardDOTweenSequenceEffectSO` 结束还原 localPosition**：片段全部 Insert(0) 并行、finally 回起点——它假定操作对象是可还原的根，不适合叠加在 L2 收敛上（冲刺类请用 L3 的 Lunge SO）。
