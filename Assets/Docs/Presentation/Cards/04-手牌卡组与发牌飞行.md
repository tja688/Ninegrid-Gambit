# 04 · 手牌、卡组与发牌飞行

> 权威代码事实文档 · 生成于 2026-08-12 · 覆盖手牌/卡组两大净土域管理器、发牌飞牌（贝塞尔预算 + L2 收敛）、炸牌入组、骷髅合体等 24 个 .cs。

## 职责综述

手牌（道具卡格的表现侧，ADR-0025）与卡组（抽牌堆的表现侧）是两个**净土域**：内部布局黑盒、外界只经显式 API 出入卡，域边界交接实现 `IHandoffEndpoint`（C 阶段速度恒 0）。`CardHandManagerSingleton` 管 hover 槽位带、拖拽（ApplyZone 打出 / RecycleZone 回收 / 回手）、场地拾取入手与跨节点持续持有重建；`CardDeckManagerSingleton` 管 Standby→Entry→InGame 三模式、向场地发牌、洗入/回库与「视觉槽序 = Core DrawPileUids」的对账断言。发牌的空中段由 `DealFlightCoordinator` 以 **L2 五次收敛**驱动（`SlotFrameConvergence.BeginDealFromLaunch`）：预算制时长（`DealSettleBudget`）、旋转期间 Redirect 改目标、起飞即瞄准预解最终格（`DealVisualTargetResolver`）。附属表演：炸牌散点入组（`CardBurstScatterIntoDeckPresenter`）与骷髅军团合体（`SkeletonDeckPresentationManager`）。

## 核心流程与数据流

### 1. 手牌 hover 槽位带（不依赖 collider）

`CardHandManagerSingleton`（`DefaultExecutionOrder(-50)`，先于 PointerHitRouter）每帧 `TickHandHover`：

1. 指针屏幕点 → 手牌锚点平面世界点；按 `handHitBoxSize` AABB 收集候选（以**槽位布局坐标**为心，不随 hover 抬升动效移动）。
2. 多候选按槽位带二分（相邻槽中点为界）+ `hoverSwitchHysteresis` 滞回抑制边界抖动。
3. 换 hover：旧卡回 Base + 恢复槽位序；新卡 `CardVisualTarget.Hover`（上浮+放大+摇摆）、sorting 抬升 `hoverSortingBoost`、其余手牌半透明（`CardOpacityUtility.SetAlpha(nonHoveredAlpha)`）。
4. `TryBeginDragFromHoveredCard`：Router 主键按下时优先调用（半黑屏/详述打开时拒绝）；`TryPeekHoveredCardForInspect` 供右键详述取当前 hover 手牌。

### 2. 拖拽：打出 / 回收 / 回手

1. `TryBeginDragFromHand`：从槽容器移除（余卡 ripple 补位）、记录 DragSession（原槽位、was hovering）、激活回收 UI（`SetRecycleUiActive(true)` 同时让卡组 `SetRecycleBackgroundSuppressed(true)` 下沉 BG 层）、进入 `RunDragLoopAsync`。
2. 拖拽循环：每帧卡跟指针（同平面 ScreenToWorld）、`UpdateRecycleValueHover`（悬停回收区显示 `+N` 金）、盖住场地卡时半透明（`dragAlphaWhenOverGround`）。
3. **拖拽手感（ADR-0051）**：拾起瞬间 `PlayDragPickupSquash` 在 L1 打一次 `DOPunchScale(-0.05, +0.07)` 挤压；循环内按横向速度算惯性倾斜（速度平滑 16、0.3°/单位速度、上限 9°、跟随 18）写 L1 `localRotation`。**写 L1 而非 L0** 是为了不与 hover 在 L0 的 punch 旋转互踩；正常退出与 `finally` 双路 `ResetDragTilt` 归零，避免卡带着倾角回槽或入场。手牌卡不在 `BoardCardLifeFx` 成员集合内（该层只收占格卡），两个 L1 写者不重叠。
4. 松手判定：先回收区（`recycleZoneCollider.bounds`）后 ApplyZone；都不在 → `FinishDragWithReturnAsync` 回原槽。
5. 回收：`RecycleItemInputHook.TrySubmitRecycleItem(uid)`（Controller 内 IntentIntake→Core `RecycleItemSlot`）成功后走 `ShatterCardAfterRecycleAsync`——Death 碎裂通道（`PlayDeathAsync(audioCueId: Shatter)`），与使用的缩小退场区分；busy 缓冲路径由 `OnRecycleItemIntentFlushed`（Director flush 后回调）补做离手+碎裂。
6. 打出：`DragApplyValidator`（Flow 注入，含目标格解析 `TryResolveGroundSlotUnderPoint` → 场地面 `TryResolveSlotAtWorld` 交棒，ADR-0023）通过后——BoardSelect 模式挂起则 `ParkCardForBoardSelectAsync`（卡飞到格 5 驻留、武装 `BoardSelectParkedCardHitProxy` 供点击反悔）；否则 `VanishCardAfterApplyAsync`（`PlayUseAsync` 缩小退场 + Release；Choice 路径已把 scale 置 0 时只补音效不再弹回）。

### 3. 拾取入手（场地 → 手牌）

1. `GroundCardHitProxy` 点击 → `TryPickupFromGround`：本地门禁（拖拽中/满格/自 busy/Choice/BoardSelect/开局表演/非正交）逐项打 `PickupGate` 旁路 → `PickupInputHook.TryApplyPickup(slot)`（Controller 内 IntentIntake→ExternalHold→Core Apply）。
2. 返回三态：`buffered`（主线忙已缓冲，等 flush）/ `lockFail`（放弃）/ Accepted。Accepted 且 idle 时本方法只播表现：`BeginPresentAcceptedPickup` → `TryTakeCardFromField`（卸占格不销毁）→ `PullFromGroundAsync`（插槽 + ripple 飞入）→ **`PresentPickupSliceWithStrikesAsync`（ADR-0050 补记 c/d「先开批后 Drain」）：经 `BattleBeatFlush.PresentEventLogSliceWithStrikesAsync` 先 OpenBatch（打击计划构建/暂扣），再执行 Drain 委托（`DrainPostKillBoardAsync` 播补位/旋转批，其中移除呈现在退场前消费打击组——滚石经拾取转盘破坏卡片先撞击再碎裂）→ 触发脉冲 → 串行剩余打击（倒刺等机关经拾取转盘打人在此可见）→ 其余 Impact/Settled**（补记 c 此前 Drain 先于开批，纯移除打击组必然静默降级）→ 占格冲突标志只告警。
3. 缓冲路径：Director flush 后 `OnPickupIntentFlushed` 取 ExternalHold 再走同一 Present；`RemovedWithoutHand`（拾取即消耗类）走场地移除 + 同一「先开批后 Drain」切片编排。拾取失败（未到切片编排）以 `PresentPickupSliceFallback` 按旧旁路立即冲刷兜底；切片编排内部取消/异常由其 finally 收批（FlushBeats + FinishBatch），节拍不丢失、调用方不得重放同一切片。
4. `TryPlaceInHandImmediate`：跨节点持续持有重建（ADR-0025 `ApplyOpeningHandRestores`）无飞入动画直接贴槽。

### 4. 卡组三模式与发牌

1. `InjectDeck`（仅 Standby）：卡按序堆到 `DeckEntryPreparationSlot` 待命堆。
2. `BeginEntryAsync`：逐张滑入卡组锚点（`entryDealInterval` 间隔；`CardLifecycleAudioCues.BeginDeckEntryAudio` 洗牌音会话按滑入拍 `PulseSlideBeat`、末张启动即 `Complete`）→ `SetCardsDense` 入槽 → ripple 切动态布局 → InGame。
3. 发牌主路径 `DealCardByUidWithFlightAsync`：回库在途先 `WaitReturnSettledAsync`（防空堆同 UID 抢跑）；卡不在组内时用 `ensureCard` 经 AddAnchors 入组再发；已在场地则同格 no-op / 错位 `RequestRelocateOccupancy` 迁格。核心 `TryDealCard`：占格 `RequestPlaceCard` 成功后 `LaunchDrainDealFlight` 启动 L2 收敛飞牌（无协调器时回退 `SlotFrameConvergence.BeginDealFromLaunch` 直飞）；每步失败都有回滚入组 + `DealResult` 旁路（nullView/noAnchor/placeDenied 等 reason）。
4. 洗入/赠牌：`AddCardAtFromOriginAsync`——originAnchor 非空（遗物/技能开局赠牌）从锚点缩放飞入；空则经 `CardDeckAddAnchors` 镜像槽入组（局内洗入如离开机关必须走此路径）。入组索引 `ResolveDeckInsertIndex`：随机时非空排除 slot 0，显式 0 允许置顶（对应 Core `Top=true`）。
5. 回库：`LaunchReturnFieldCardToDeck`（发射后不管）——`TryClaimCardForDeck` 拒收手牌持有/Core ItemSlots 的卡（防卡组吸走道具卡格视图）→ 清占格 → `BeginReturnInFlight` 登记 → `CardDeckTween.LaunchFieldExitThenDeckInsert` 垂直上飞离画（`fieldExitYThreshold`）→ OnComplete/OnKill 双保险回调 `CompleteFieldReturnDeckInsert` → AddAnchor 落点 + `InsertViaAddAnchorAsync` ripple 归位 → `EndReturnInFlight` 唤醒 waiter。
6. 视觉序对账：`SyncVisualOrderFromDrawPile(orderedUids, pendingDealUids)`（busy/回库在途拒绝）→ `TryReorderToUids` 重排 + 贴布局 + 重排序。`pendingDealUids` 是本批 Core 发牌序：Core 已抽出但还没飞出的牌按该序排队首——批内洗过牌时旧视觉相对序不等于 Core 抽出序，不按发牌序排就会「顶牌不是下一张飞出的牌」。贴布局（`SnapDeckCardsToLayoutPositions`）逐卡先 `CardDeckTween.KillMotion` 再直写位置，`BuildRippleMoves` 也不再跳过「已在目标位但仍在飞」的卡：发牌 ripple 是 Forget 起飞，旧落点缓动跑完会把牌拖回改序前的槽位。Dev 下 `AssertTopMatchesDrawPile` 断言 slot0 == 期望顶牌（有发牌序取其中还在组内的第一张，否则张数一致时比 Core 顶牌），失配 LogError 打 core/visual/pendingDeals 三份 uid 列表（表现只读对账不改抽牌堆，ADR-0034）。

### 5. 飞牌协调器（`DealFlightCoordinator`）

1. 两类探针：`StartExplore(birthSlot)`（空位探求：节流 `exploreDealInterval` 后从卡组 `TryWithdrawFirstCard` 取牌）与 `LaunchDrainFlight(card, birthSlot, launchPos, context)`（结算批补牌）。
2. 起飞：`DealSettleBudget.Compute` 按距离幂 + busy/并发/待播旋转步松弛算预算（0.18–0.65s 夹紧）；`SlotFrameConvergence.BeginDealFromLaunch`（L0 先落目标锚、L2 置起飞相对位再收敛回零，见 05 篇）；`CardEdgeDustFx.BeginTrail` 洒尾迹；`ChoreoTraceSink` 开 `dealFlight` choreo。
3. 途中：`OnRingShifted(clockwise)` 让在途探针 TrackedSlot 随外圈环移更新并 `RedirectProbeToSlot`（L2 C1 连续换目标）；大盘 hop 接管经 `TryRedirectFlightToSlot`；`WaitProbeConvergenceAsync` 轮询 driver 完成并逐帧扣预算。
4. 落地：`ResolveSettleSlot`（Tracked 已跟上环移用 Tracked，否则保留预解视觉瞄准防 Snap 回 birth）→ `SnapHome` + `PlayPlace` 尘雾 → **先卸 in-flight 再登记**（Explore 走 `PlaceForExplore` 占格+认领；Drain 走 `NotifyDealFlightLanded` 只回登记认领）→ `Handle.Complete(true)` + `deal.settled` 配对诊断。
5. 取消：`CancelFlightForUid`（Vacate/Remove 前必须调，否则 WaitAll 挂死、choreo 泄漏）同步卸表 + EndChoreo；Explore 取消回滚 `RollbackCard`（回库或 Release）。

### 6. 炸牌入组与骷髅合体

- `CardBurstScatterIntoDeckPresenter.PresentAsync`：新生洗入卡从死位（origin）抬 `FlightSortingChannel.Raise` → 并行 L3 收敛飞到圆周散点（等角 + 随机相位）→ 停顿 → 逐张 `LaunchReturnFieldCardToDeck` → `WaitReturnsSettledAsync` 等全部落地 → 可选停顿 → `Restore` 排序。中途被 Release 的卡剔除防挂死。
- `SkeletonDeckPresentationManager.PresentFusionAsync`：解析参与卡 → `MarkFieldDead` + 清占格（Vacate 后回调 `onFusionStarted` 触发补牌）→ 抬序 → Kill 残留运动 → L3 共享 sourceTime 撞向视觉中点（`ComputeMergeCenter` 用视觉世界位含 L2/L3，禁只读 L0）→ `HardStickParticipantsAt`（L0 贴合点、L2/L3 归零，>1mm 失配打 `SkeletonHardStickMisalign`）→ 闪白 → 隐藏参与卡 → 结果卡 Spawn/复用后同点弹出 + 闪白 → `LaunchReturnFieldCardToDeck` 离场入组 → Release 参与卡。全程 choreo 包裹并 `ForceCloseOpenChoreos` 兜底。

- **意图 Hook（入 Core 的唯一路）**：`UseItemInputHook` / `PickupInputHook` / `RecycleItemInputHook`（拖放/点击提交）；`PickupIntentFlushHook` / `RecycleItemIntentFlushHook`（Flow 侧 Director flush 回调，本域承接缓冲表演）。

## 不变量与坑

- **手牌容量与 Core 对齐**：`maxSlots=5` 为道具卡格上限表现值；满格拒入在 Core 已裁决，表现侧再挡一层。
- **回库 in-flight 纪律**：`IsReturnInFlight` 期间禁止发同 uid 牌、禁止 Sync 征用；`LaunchFieldExitThenDeckInsert` 必须挂 OnKill 兜底（KillMotion 不触发 OnComplete，漏挂会让 ReturnInFlight 永久粘住、后续同 uid Deal 挂死主线）。
- **先切模式再入槽**：`PullFromGroundAsync` 必须在 `TryInsertAt` 之前 `SetDisplayMode(HandCardMode)`——反序会瞬间贴位，ripple 飞入失效。
- **卡组容器不查重**：`AddCardAt*` 前必须 `ContainsUid` 自查（#180 幽灵占槽教训）。
- **入槽排序双保险**：`ApplySortingOrder` 每次都 `PropagateSortingLayerFromGroup`（不只在层名变化时）——否则回收 BG 下沉后子节点逃出、始终压最上。
- **发牌回滚完整性**：`TryDealCard` 的 nullView/noAnchor/placeDenied 三处回滚都要么回插卡组要么 Release，绝不留半悬空句柄。
- **炸开原点用视觉位**：合体/炸牌的中点、落点计算一律 `GetVisualWorldPosition`（含 L2/L3），只读 L0 会偏。
- **拖尾必须 finally 收**：`BeginTrail`/`EndTrail` 成对（协调器 try/finally），否则粒子跟随已销毁卡。
- **拖拽倾斜必须归零**：`ResetDragTilt` 在正常退出与 `finally` 双路调用；漏归零会让 L1 的旋转/缩放残留跟着卡进场地或回槽（L1 是 L2 的父级，残留还会污染后续格位收敛目标）。
- **已知小问题**：`CardDeckTween.cs` 内两处中文注释为乱码（编码事故，语义可从上下文恢复：类注释=「牌组相关 DOTween 缓动工具」、`LaunchFieldExitThenDeckInsert` 注释=「场地卡垂直上飞离画后回调入组」）。
