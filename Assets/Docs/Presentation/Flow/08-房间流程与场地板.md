# 房间流程与场地板 —— 选房图标 · 商店/卡店/奖励房 · 简要解释 · Bounce 三选一

> 权威代码：`Flow/RoomIcons/`（5）、`Flow/ShopBoard/`（3）、`Flow/TavernBoard/`（3）、`Flow/RewardBoard/`（3）、`Flow/AttributeBoard/`（4，遗留废止）、`Flow/InRoomBoard/`（5）、`Flow/BoardBriefTip/`（5），及根下 `RoomChoiceCoreHook` / `RewardChoiceCoreHook` / `BounceFanChoicePresenter` / `SelectorManagerSingleton` / `BoardSlotWorldPlacement`，共 33 个文件。
> 关联 ADR：ADR-0020（选房与房内交互走场地面）、ADR-0023（命中面身份仲裁）、ADR-0024（落格不 parent 锚点）、ADR-0025（购领接手牌）、ADR-0031（属性房废止）

## 职责综述

清关后的「选房 → 进房 → 房内消费 → 离房」全部走**场地面九宫格**交互（ADR-0020，旧浮层已退役）：房间图标/货架是落在格位上的对象，玩家 BoardWalk 走过去驻留提交或任意距离点击。本区分四层：

- **选房层**：`RoomIconBoardPresenter` 刷图标、登记软占、驻留提交 SelectRoom+EnterRoom、进房硬切。
- **房内会话层**：Shop / Tavern / Reward（/ 废止的 Attribute）四套 Presenter 同构——`TrySpawnFromPending` 刷货架真卡、HitProxy 认领格位点击、离开格驻留 → SkipHelpChoice。
- **共享基建**：`InRoomBoard/`（落格规划/货架动画/购领接手牌/扣金 HUD）、`RoomIconOccupancy`（表现侧软占）、`BoardSlotWorldPlacement`（ADR-0024 只对齐世界坐标）、两个 CoreHook（写 Core 的唯一门面）。
- **并行体系**：战斗内/浮层三选一（宝箱遗物、清关奖励）走 `SelectorManagerSingleton` + `BounceFanChoicePresenter`，与场地货架体系分离。

文案层 `BoardBriefTip/` 驱动场景「简要解释文字框」（悬停 + Notice 两路）与「楼层提示」。

## 核心流程

### 1. 选房 → 进房（RoomIconBoardPresenter）

1. `TrySpawnFromPending`：读 `PendingChoiceModel`（Room 双选或 Navigation）→ `RoomIconBoardSlotResolver` 落格（JSON boardSlot 优先，撞格 fallback）→ `RoomIconOccupancy` 登记 `WalkDestination` → 图标挂 `BoardBriefTipHitProxy`（悬停文案 + BoardWalk 提交）。无 prefab 仍登记占格（无美术可测）。
2. `WatchAvatarLoop`：Avatar 踩上图标格 → `RoomIconDwellSession.Begin` 驻留 1s → 到期 `TryConsumeArmed` → `PresentationInputGates.SetChoiceOverlay(true)` 包裹提交 → `RoomChoiceCoreHook.SelectRoom(index)` + `EnterRoom()`（经 IntentIntake）。跳走 `Cancel`；提交失败可重武装。
3. 可选过场：消费/特殊房 `BeginCoverAsync` 盖住 → 房内板刷完 `CompleteRevealAsync` 揭开（[主编排篇](01-GameFlow主编排与流程壳.md) §8）。
4. `HardCutAfterEnter`：清全部图标 + `MoveAvatarAction` 把 Avatar 硬切到格 5。

### 2. 房内会话同构模式（Shop / Tavern / Reward）

四步共性：

1. **刷板**：`TrySpawnFromPending` 按 `PendingChoiceKind.Reward` + PoolId（`IsShopPool` / `IsTavernPool` / `IsSpecialRewardPool`）分派；货架真卡 `SpawnPresentationOnly` + `ApplyVisualsByDefId`，`InRoomOfferSlotPlanner.Plan` 动态落格（预留离开 8 / 刷新 2，保证 Avatar→Leave 的 PreferEmpty 通路，用 `AvatarWalkPathfinder` 验证）；`BoardSlotWorldPlacement.TryAlignToSlot` 对齐世界位置；`RoomIconOccupancy` 登记货架 `SoftBlockOnly` + 离开 `WalkDestination`；禁用真卡 `GroundCardHitProxy` 防抢点。
2. **点击**：各 `*HitProxy.Configure` → `GroundFieldGeometryHook` 认领格位（`SlotClaimant(owner, tip, callback)`，tip 与悬停同源）→ 回调 Presenter → `RewardChoiceCoreHook.SelectReward/RefreshShop`。
3. **购后表演**：`InRoomGoldPresentation.PresentGoldChangesSince`（扣金 HUD）；道具/帮助卡 `InRoomItemAcquirePresentation.TryAcquireShelfHelpCardToHand`（ADR-0025：Release 货架纯表现卡 → SpawnView → PullIntoHand，失败 `TryPlaceInHandImmediate` 兜底，**禁止只碎裂导致逻辑有牌手牌看不见**）；其余碎裂 `InRoomShelfAnimation.PlayConsumeDeath`；`ResyncShelfAsync` diff 补位（`TryMatchOldIndex` 容忍单点移除，跳格/落下动画而非整板瞬移）。
4. **离开**：踩离开格 8 驻留（复用 `RoomIconDwellSession`）→ `SkipHelpChoice` → 过场离房。失败（如二级面未收）须重开 dwell 计时。

**卡店特有**：三服务粘性家格（购后留洞不换格）；「道具卡固定」服务进**二级候选面**（`IsTavernFixItemPool`——隐藏主面，货架换手牌道具卡候选，离开格语义变「取消选择」走 SkipHelpChoice 回主面，无过场）；多种 Core 拒绝 reason 映射 Notice 文案。
**商店特有**：刷新格 2（`RefreshShop`，重刷后 `mReplanShelfSlots`）；金币不足专用 Notice + 拒绝音效。
**奖励房特有**：房内开宝箱会挂起 consumer session——`ResyncFromPending` 检测到挂起时早退不拆板。

### 3. 软占与命中（RoomIconOccupancy + ADR-0020/0023）

两种角色泾渭分明：`WalkDestination`（可作 BoardWalk 终点 + 驻留提交：选房图标、离开图标）vs `SoftBlockOnly`（只挡 PreferEmpty 寻路，**任意距离点击**，禁作跳格终点：货架、候选卡）。走格系统读软占决定路径；变更后 `RoomIconOccupancySlotHits.Refresh` 刷格位命中框。点击不依赖 Collider（各 HitProxy 禁用 `BoxCollider2D`，命中走 `GroundFieldHitSurface` 九格表面 + 格位认领）。

### 4. Bounce 扇形三选一（战斗内/浮层体系）

`SelectorManagerSingleton.BeginBounceChoice(optionDefIds, onPicked)` → `BounceFanChoicePresenter.Begin`：`RemovedMode` 纯表现卡（**负 uid，勿 `Spawn()` 占正号**）扇形入场弹性 → 悬停推挤 → 点选掉落 → `OnPresenterPicked` 转发 → 退场后 `NotifySessionFinished` 回调。命中用容器本地固定 AABB（ADR-0023）；`sessionId` 防 DelayedCall 误伤下一轮；右键可开 `CardInspectOverlayPresenter` 详述。数值经 `BattleBeatFlush.PresentLatestEventOfType(RewardOffered)` 指令排期器，禁止 clearCombatStats 旁路。消费方：清关奖励（`PresentRewardChoiceFromCoreAsync`）、宝箱遗物三选一、卡店二级确认等。

### 5. 简要解释与楼层提示（BoardBriefTip）

- `BoardBriefTipPresenter.EnsureExists` 绑定场景权威面板 `Panels/简要解释文字框`（禁止建无 TMP 孤儿，孤儿 fallback 销毁）；`ShowHover`（代数防脏清）/ `ShowNotice`（盖住 Hover）/ `HardClear`（进战/撤场兜底，防「金币不足」粘连进战斗）。
- 文案全部出自 `BoardBriefTipCopy` 纯逻辑（房间悬停 `ForRoom/ForContentId`、货架价格 `ForOptionOrShelf`、楼层 `FormatFloorLevelHint` 罗马数字）。
- `FloorHintPresenter` 绑场景 `楼层提示` 根节点，`LateUpdate` 轮询 `RunModel.Floor/Room` 变化写 TMP；Attribute/Gold/Fountain/Treasure 房均显示「战斗房间」。

## 对外通信面

- **写 Core（全部经 Hook + IntentIntake）**：`RoomChoiceCoreHook.SelectRoom/EnterRoom`；`RewardChoiceCoreHook.SelectReward/SkipHelpChoice/RefreshShop`。View 禁止直改 Model（ADR-0020）；店内购买以 ProtectedField 而非 ChoiceOverlay 提交（房内板整段持有 ChoiceOverlay 会导致 BoardWalk ownerMismatch）。
- **读 Core**：`PendingChoiceModel`（一切刷板输入）、`BoardModel`（走格拓扑）、`RunModel`（楼层提示）、EventLog（购后金币/新卡）。
- **静态 Hook**：`GroundFieldGeometryHook`（格位认领/锚点）、`CardEntityLifecycleHook`（货架卡 Spawn/Release）、`BoardWalkInputHook`（走格提交）。
- **兄弟模块**：`RunSceneTransitionService`（进离房过场）、`AvatarWalkSystem`（走格）、`CardHandManagerSingleton`（接手牌）、`FlowRoomEconomyAudioCues`（购买/拒绝/离房音效）、`PresentationInputGates`（ChoiceOverlay 包裹提交）。

## 不变量与坑

- **驻留计时不进 IntentIntake**：`RoomIconDwellSession` 是表现侧异步计时，提交那一下才走门禁；过场期间不可绑 dwell CTS。
- **tip 与认领同源**：悬停文案存在 `SlotClaimant` 上，由 `GroundFieldHitSurface` 读取——改文案改 Configure 参数，别另开渠道。
- `mActive` 须先于 `StartAvatarWatch` 置位（Shop/Tavern），否则 watch 循环开跑即早退。
- 货架卡是**纯表现卡**（`SpawnPresentationOnly`）：购领成功接手后调用方勿再 Release；`RoomOptionFaceVisuals` 只服务就地 GO 选项，真卡走 `ApplyVisualsByDefId`。
- 根 hop 脉冲不用 `PlayHopScalePulseAsync`（会 Kill MoveToWorld tween）；Player 构建无 Death 资产时直接藏卡。
- `AttributeBoard/` 四件与 `TavernBoardSlotResolver.ServiceSlotAt` 是废止/Obsolete 遗留——排查 bug 时勿当活路径；正式流程不会进入 `PendingChoiceKind.AttributePick`。
- Bounce 面板祖先 scale=0 会导致 Mask 锚定错位（隐藏用位置/alpha，不用零缩放）。
