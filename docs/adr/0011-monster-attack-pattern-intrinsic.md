# 怪物攻击模式：内生基础属性，不是技能效果

## 决策

每张怪物卡必须显式选择一个**攻击模式**，规定「从哪些格位打得到玩家」。**多久出手一次**改由卡级节奏源与节奏周期决定（见 [ADR-0038](0038-card-rhythm-dual-channel.md)）；本 ADR 不再把频率写进模式表。

1. **权威在 Core，不经效果 DSL。** 攻击模式是卡数据上的一个枚举字段，由 Core 的敌方行动裁决直接消费（见 [ADR-0012](0012-enemy-action-phase-volley.md)）。它**不进** `effectAssemblies`、不生成 `EffectInstance`、不进效果池、不参与词条展开、不可被「移除效果」类效果影响。
2. **不写入卡面描述。** 怪物怎么打人由卡面「攻击模式」图标、「是否有技能同步触发」子图标与「行动计数」数值槽表达，不由描述文本承担。
3. **四个取值（仅几何）。** 位置限制越松、可打范围越大；**频率不在本表**。远程射击不进本枚举，由 `远程武器` 等技能在卡级节奏窗口触发。

   | 模式 | 位置条件 |
   |------|----------|
   | 普通近战 | 与玩家卡正交相邻 |
   | 斜角近战 | 与玩家卡对角相邻 |
   | 全向近战 | 与玩家卡八向相邻（正交 ∪ 对角） |
   | 无 | ——（不开火；可有技能同步触发） |

4. **必填、无默认值。** 字段缺失属**装配错误**（编辑器报错 + 加载期告警），不静默当作「无」。`无` 是必须显式写出的正当取值，服务纯机制怪或「仅技能」预留。
5. **首版不可被运行时改写。** 攻击模式是出生属性，不走 `RuleId` 修正管线。可被效果影响的是卡级共享倒计时（见 [ADR-0013](0013-action-countdown-unified.md)、[ADR-0038](0038-card-rhythm-dual-channel.md)）。
6. **新增一个几何谓词。** `对角相邻`（行列差均为 1）。既有 `SlotId.IsAdjacentTo` / `IBoardSystem.AreAdjacent` 保持正交语义不动；`RuleId.VirtualAdjacency` 仍只服务怪-怪融合，不参与攻击距离。

### 已被 ADR-0038 废止的条款

- 模式表内建频率（近战 3 / 远程 5）及「位置越松、频率越慢」与枚举绑定的表述。
- `stats.action` / 行动计数数值真相源 =「该模式的频率」——改为卡级节奏周期 X；旧 `Action_Icon` 语义迁移为模板节点「攻击模式」。

## 为什么

**「必须具备」和「可以拥有」是两种不同的东西。** 仓库的效果体系（[ADR-0009](0009-parameterized-effect-templates.md) 参数化模板、[ADR-0010](0010-self-declared-effect-responsibility.md) 责任自陈）整套语义都建立在「效果是可装配、可复用、可缺席、可被玩家读到解释」之上。攻击模式恰好四条全反：它不可缺席、不需要复用（五个取值就是全集）、不该被读成「这只怪有一条技能」、而且一旦缺席就是内容错误而非「这只怪没这个能力」。把它塞进效果装配，等于让整个效果体系的默认假设对它全部失效，然后靠约定逐条豁免。

**风险方向也不同。** ADR-0010 的核心教训是「装配成功、校验通过、运行时静默什么都不做」是最坏的失败模式。攻击模式如果是效果，那么忘记装 = 这只怪永远不动，而这个症状和「有意选了`无`」在游戏里完全无法区分——61 只怪里漏一只，你要靠试玩碰运气才能发现。作为必填字段，漏填在加载期就报出来。

**关于「不复用效果管线是否在重复造轮子」**：需要的构件（位置谓词、伤害动作、倒计时原语）确实与效果 DSL 重叠，但重叠的是**底层原语**，不是**实例生命周期**。原语按 ADR-0013 / ADR-0038 抽出来两边共享；`EffectInstance` 的注册/条件层/作用域/移除那一整套，攻击模式一样都不需要。

**关于几何取值的演进**：初版曾设 `普通远程`（无条件几何），与「全向 = 八向相邻」下的 `全向近战` 在语义上易重叠，且远程威胁已由 `远程武器` 技能承载（宿主通常配 `全向近战` + 技能）。**现行废止 `普通远程` 枚举**；JSON 中该取值视为装配错误。`斜角近战` 取真对角语义（见下）。节奏快慢由卡级 X 调节（ADR-0038）。

## 考虑过的替代

- **枚举字段 + 装载期脱糖成 intrinsic 效果实例**：否决——能复用触发/条件/动作管线，但需要给 `EffectInstance` 全线打 `intrinsic` 标记以便效果池、描述展开、词条、`ProbeWhyNotTriggered`、「移除效果」逐一豁免。豁免点比重写原语多，且每个新增的效果侧能力都要重新想一次「intrinsic 要不要跟」。
- **纯 DSL 效果模板 `tpl.monster.attack_pattern.*` + 内容侧必填校验**：否决——必填只能靠外部校验器维持，而 ADR-0010 刚把「靠外部门禁维持效果边界」这条路拆掉；同时怪物怎么打人会出现在效果池与描述展开里，与产品意图相反。
- **首版就让攻击模式可被 `RuleId` 修正覆写**：否决——`AttackTargetRestriction` / `FirstStrike` 提供了先例，技术上可行，但「改写模式」类效果目前一条都没有设计需求；而倒计时可加减速已能表达绝大多数「干扰敌方节奏」的诉求。留到有真实内容需求时再升级，届时字段读取点集中在一处，改造面可控。
- **`斜角近战` 保留「非正交」语义并改名（如「远位攻击」）**：否决——否定式会随玩家位置漂移，梯度不稳定；远程威胁改由技能表达。
- **缺省即 `无`**：否决——见上「风险方向」。

## 后果

- **61 张怪物卡需要迁移。** 先批量写 `无` 保持行为不变（#77），再逐只按设计意图改（#82）。中间态已结束：生产 Catalog 不再全员「无」；攻 0 怪（大石头、火祭司）显式保留「无」，其余按设计赋模（默认普通近战，主题覆盖远程/全向/斜角）。ADR-0038 落地时再为每只怪显式配置节奏源与周期。
- **卡面槽（ADR-0038 更新）。** 模板节点「攻击模式」按模式套图；「行动计数」数值显示卡级共享倒计时剩余；有同步技能时激活「是否有技能同步触发」。旧 `Action_Icon` / `stats.action=模式频率` 真相源已废止。
- **需要三套模式图标 + 同步触发图标。** 接线前可模板兜底；素材与绑定见落地 Spec。
- **攻击力 0 的怪成为规则前提上的空洞。** `monster.big_stone`（0/1/5）与 `monster.fire_priest`（0/12/8）零反击，玩家砍它们时不付血量代价，因而能免费冻结盘面（见 ADR-0012 的盘面节奏与 ADR-0013 的窗口模型）。两者在新体系下只能填 `无`。这属**内容层待议项**，不阻塞规则落地：或调数值、或限制同场投放、或明确定为「玩家可用来买时间的安全沙袋」。
- **旧「先攻」保留但改名。** 它只裁决交战内的出手顺序、不产生额外攻击，与攻击模式正交且能正常工作（`CombatEngagementOrder` + `RuleId.FirstStrike` + 两条模板 + 石头人装配 + 两个测试全部保留）。仅玩家可见名称与词汇表改为**先手还击**，避免玩家把「先攻」读成「会主动先动手」——真正会主动先动手的是攻击模式。代码侧 `RuleId.FirstStrike` 等标识符不动，零回归风险。
