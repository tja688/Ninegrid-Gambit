# 场地即交互面

## 决策

非战斗流程的**全部**玩家选择拍平到九宫格上的实体，浮层退役。

- **选房 / 导航**：房间图标与导航图标（离开 / 下楼 / 上楼）作为**场地图标**落格；玩家经 BoardWalk 跳过去，**踩上后驻留 1 秒**自动提交，驻留期间跳走即取消。双图标固定落格 1 / 格 3，单图标落固定单格。
- **房间内选项 / 货架**：卡店服务为**就地选项卡**，商店货架与奖励房产出为**真卡**；一律**任意距离点击**生效，不受正交相邻限制，不算九宫格互动，不推进互动计数、不补牌、不旋转。
- **唯一嵌套选择（卡店「道具卡固定」）**：点服务卡后，主面服务与刷新退场，**场上剩余空格铺开候选道具卡**供点选（保持「场地即交互面」）；离开图标 tip 改为「取消选择」，驻留提交后回到三项服务面且不扣费。不复用战斗内扇形三选一。
- **悬停简要文案**走场景对象 `Panels/简要解释文字框`；无悬停即空。右键详述面板（`CardInspectOverlayPresenter`）职责不变，仍只服务**战斗内**卡牌检视。胜负 Notice 亦改由简要解释文字框承载。
- **退役**：房间二选一浮层 `RoomChoicePresenter`、旧属性三选一 UI（`Attack` / `Armor` / `Hp` 选项卡）。
- **保留**：扇形三选一 `BounceFanChoicePresenter`，仅服务宝箱卡开遗物——那是**战斗内**行为，不属于流程交互。
- **驻留计时归表现侧**：计时器在表现层跑，到点向 IntentIntake 提交一条 `EnterRoom` 意图。IntentIntake 与两轴门禁内**不得**出现壁钟（`IntentIntakeStructuralTests` 既有护栏）。

## 为什么

九宫格是本作唯一的强识别面。老流程把选房、商店、奖励都做成浮层，玩家在「棋盘」和「菜单」两种心智之间反复切换，九宫格退化成纯战斗小部件。把选择物化成场上可走、可点的卡与图标后，整局只剩一套交互语汇，也让「走位」这个战斗内被禁用的动词在流程段获得意义。

驻留 1 秒而非落地即提交：踩图标是不可逆的导航承诺，需要一个可反悔窗口；而二次点击确认会把「走上去」这个动作的完整性打断。进度条属打磨项，不阻塞语义。（历史注：曾与「提交时结算未使用道具」绑定；道具卡格持续持有与主动回收见 [ADR-0025](0025-item-slots-run-persistent-hold.md)，清关见 [ADR-0026](0026-leave-trap-sole-clear-condition.md)。）

## 后果

- BoardWalk 的**终点**须放宽到图标格（ADR-0019 原限制「途经与终点仅空格」只保留在途经侧）。
- 房间图标不是玩法 Catalog 条目（`Leave` / `GoUp` / `GoDown` 尤其如此），命中与落格走场地几何注册，不进 `CardKind` 五套 Spawn。
- 「任意距离点击购买」与「正交相邻才能互动」并存，两者靠**相位**区分而非靠距离规则本身；非战斗相位下的点击不进 `InteractionLoop` 的互动结算链。
- 浮层退役后，`SelectorManagerSingleton` 只剩 Bounce 一条路由。
- `GoUp`（上一层）图标本轮**不启用**，只做单向向下。
