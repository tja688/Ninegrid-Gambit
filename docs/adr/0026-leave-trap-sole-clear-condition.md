# 离开机关为战斗房唯一清关手段

## 决策

战斗房**不再**以「真怪物清零」为清关条件。唯一打通手段是击破**离开机关卡**。

- **离开机关卡**：机关种（`CardKind.Trap`），持有技能「门」「魔免」与「离开」。击破后**直接**完成本次战斗（清关），无需再点离开图标。
- **插入时机（默认战斗房）**：本节点开局编入的真怪物总数为 N（不含机关）；当击破数达到 **⌈N/2⌉** 时，将离开机关洗入**战斗卡组**随机位置，经正常补牌上场。不设强制上场或软锁特判。
- **插入时机（层主房例外）**：`RoomKind.Boss`（每层最终节点）改为：击破本节点**开局编入的层主**（Boss Counter）后才洗入；过半阈值不生效。局中新生层主不计。
- **门**：只承受**交战**中玩家出手造成的伤害；其它伤害与直接移除/放逐无效。不阻挡洗回卡组、翻面；被翻面后玩家可交互翻回。总原则：不得制造死局。
- **魔免**：不受任何外来「效果」影响（机关卡 / 怪物技能 / 道具效果等）。可被选作目标（不改 targeting 合法性），效果管线在解析目标后剔除本卡，使效果直接失效。不挡玩家交战伤害；不挡持有者自身效果（门 / 离开 / 魔免挂载）。
- **离开**：持有者被击破时触发清关。
- **清关收场**：那一拍清掉场上残留（未拾取道具 / 剩余怪 / 其它机关）且**不兑金**；道具卡格内容按 [ADR-0025](0025-item-slots-run-persistent-hold.md) 保留。击破前玩家可一直留在场地交互（拣选、回收、击杀赚钱）——不是另开拣选相位。击破当拍**禁止**再 `FillEmptySlots` / 敌方行动；补牌会把牌堆卡 Deal 进刚腾出的格，表现层发牌飞行可卡死主线。
- **与双桶关系**：普通机关仍不计真怪物、无击杀赏金（[ADR-0017](0017-trap-card-kind-and-dual-bucket.md)）。`IsNodeCleared` 的旧「无真怪即清关」语义废止，改为「离开机关已被击破 / 等价清关标志」。

## 为什么

策划要的是可恋战的出口，而不是清光怪自动收摊。门只吃交战，是为避免 AOE/道具流在恋战时误拆出口；魔免进一步让传送等「效果」对离开机关直接失效（可选中、不改 targeting），避免出口被洗回卡组卡死主线；清关不兑金把「要不要带走」逼回道具卡格与主动回收。

## 考虑过的替代

- **击破后还要踩离开图标**：否决——增加无意义步骤。
- **插入直接占场**：否决——优先洗入牌堆；软锁靠运气与清格，先不特判。
- **门吃一切玩家侧伤害**：否决——防的就是道具 AOE 误拆。
- **传送等效果在 targeting 层非法**：否决——与机关可被选中的定位冲突；改由魔免在效果管线过滤目标，效果直接失效。
