# 换位离巢：落地后数三次占格变化再归位

专属道具「换位」与正面真怪互换格位后进入离巢。归位倒计时从落地后开始，Avatar 占格每实际变化一次 +1，到 3 与当时中心格占用者互换（空则只把 Avatar 移回中心）。再打出换位即重新落地起算。空间振荡器只在这张道具结算成功时、按换位后玩家格做全向 2 伤，到期归位不引爆。入手与其它道具卡相同：角色来源池编进玩家侧卡组、上场拾取、用掉即消耗、不用就留在道具卡格；本卡稀有度 White。节点开始硬切回中心并清倒计时。

否决了把发动换位那一次算进 3 次之内，也否决了到期归位或被旋转带走时触发遗物。
