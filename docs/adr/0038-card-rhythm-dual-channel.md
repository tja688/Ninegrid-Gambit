# 卡级节奏：双通道 + 共享倒计时

## 决策

游戏中所有依赖「每 N 次互动 / 每 N 次移动」的**节奏触发**，统一收拢到两个内核通道与一张卡级共享倒计时上。

1. **双通道。** **行动计数**由九宫格互动推进；**移动计数**由本卡盘面格→盘面格的任意换位推进（不限旋转；手牌/卡组移动不计）。
2. **卡级二选一。** 每张有节奏需求的卡（首要是怪物，机关等同理）必须显式选择**卡级节奏源**（行动或移动）与**节奏周期** X。同卡不得让攻击模式与技能分绑不同通道。
3. **共享倒计时。** 攻击模式开火与**技能同步触发**共用同一个「还差几次」；归零的那一拍是**开火窗口**，同拍触发单向打击（若模式≠「无」且位置合格）与全部同步技能。这废止 [ADR-0013](0013-action-countdown-unified.md)「攻击模式与效果禁止共用计数值」——该禁令曾服务「模式频率 3、技能 every 2」分轨；现频率已解耦到卡级 X，分轨失去必要。
4. **攻击模式只保留几何。** [ADR-0011](0011-monster-attack-pattern-intrinsic.md) 的五取值与位置条件保留；模式表内建频率（近战 3 / 远程 5）废止，频率只来自节奏周期 X。模式仍不进效果 DSL。
5. **同步技能不写节奏 every。** 订阅卡级开火窗口的技能模板去掉节奏 `every`；快递等「每移动 N 次」类效果改为同步技能，N 由宿主卡的 X 决定。
6. **倒计时数学与一次性窗口保留。** 「还差几次」、错过窗口重置为 X、可被效果加减速——沿用 ADR-0013；卡面「行动计数」数值槽仍只经 Settled Commit（[ADR-0005](0005-card-face-beat-commit.md)）。
7. **卡面图标矩阵。** 攻击模式槽按模式套图；有同步技能时激活子图标「是否有技能同步触发」；仅技能、模式=「无」时把该子图标升格进攻击模式槽。详见 `CONTEXT.md`。
8. **豁免。** 非节奏触发（登场、移除、交战边沿、翻面等）与遗物/道具「用量、击杀累计」等（如 `OnCumulative`）**不**强行并入双通道，各管各的。

## 为什么

**频率散落是内容与规则双债。** 现状攻击模式表写死 3/5，技能模板再写死 `every:5`（如快递），同卡可双轨（近战跟互动、快递跟移动）。作者无法在单卡上调一个 X，玩家也无法从一张卡读出一个节奏。

**解耦三轴。** 攻击几何、技能内容、节奏（源+X）正交配置后，同一套「普通近战 + 快递」可通过选源与 X 变成「互动 4 次同拍近战+快递」，而不再需要两套硬编码阈值。

**共用计数在新模型下是特性不是 bug。** ADR-0013 否决共用，是因为当时模式与技能各有独立 N；共用会互相偷拍。现规定同卡只有一个 N，同拍触发正是产品意图。

**移动必须是任意换格。** 若只计旋转，换位类效果（交换、逃避等）会静默不推进节奏，作者与玩家都无法推理。盘面→盘面已是既有 `OnSelfMove` 边界，收紧为「任意换格都算」即可，不必另开全局场上移动总和。

## 考虑过的替代

- **保留模式表频率，仅让技能改绑卡级 X**：否决——三轴仍有一轴写死，远程/近战梯度继续锁在枚举里。
- **继续禁止模式与技能共用计数**：否决——与「同拍触发」产品意图直接冲突。
- **场上任意卡移动都推进本卡移动计数**：否决——与「本卡自身行为」设计案及现有 `OnSelfMove` 不符，且难解释。
- **强迫遗物用量也走双通道**：否决——语义是「用了几张道具」不是互动/换格；硬并会扭曲通道含义。

## 后果

- **需修订 ADR-0011 / ADR-0013**（部分条款 superseded；几何、倒计时数学、一次性窗口仍有效）。
- **Core / 内容 / 卡面未在本文落地**——以 Spec Issue 承载实现；文档先于代码变更权威。
- **敌方行动阶段**须区分节奏源：行动源在互动报名链扣减；移动源在换格推进归零后走开火路径（几何资格复核仍可复用）。
- **卫生校验**：缺源/缺 X、有节奏需求却周期≤0、同步技能仍带节奏 `every` → 装配错误，禁止静默沿用旧 3/5。
- **机关等**可选用同一模型；全量改配可另票，规则边界以本文为准。
