# 道具卡格为跑图内持续持有域

## 决策

玩家持有的已入手道具，唯一权威容器是**道具卡格**（Core `ItemSlots`；「手牌」仅为表现口语）。

- **持续持有**：卡一旦写入道具卡格，在单趟跑图内不因清关、节点切换或自动结算被清掉；跑图结束（通关/死亡）不跨局 meta 保留。不另设「留存卡」容器。
- **双容量拆开**：**道具卡格容量**初始 3、最高 5；**玩家侧卡组容量**仍管每战斗重生成张数（默认 6，卡店扩容可另存）。二者不得共用一个字段。
- **道具牌格升级**：商店房就地选项，固定 **50** 金将道具卡格容量 +1；购买后即下架本轮货架（与普通商品一致，不自动补货），再购走付费刷新通道（刷新重建货架时未满级重新上架）；满 5 后不再上架（修订 2026-08-13）。
- **写入直达**：商店购买、奖励房领取、场上拾取一律直写道具卡格。**携带卡包退役**（取代 ADR-0022 §4）。
- **满则拒入**：格满时一切写入直接拒绝；本阶段不依赖简要解释提示。
- **回收**：拖入回收区离手，每张固定 +10 金；流程段凡道具卡格可用均可发起；主线 busy 时拒收。
- **清关不兑道具卡格**：清关不再把格内卡兑金清空（取代 ADR-0021「清关即全量结算」中涉及道具卡格的部分）。场上未入手残留的处理见 [ADR-0026](0026-leave-trap-sole-clear-condition.md)。

## 为什么

旧模型把「商店买到」放进一次性携带卡包、清关再兑金，与策划「入手即持续持有、玩家主动回收才离手」冲突。双容量若不拆开，会把「格满不能买」和「这关发几张」绑死。

## 考虑过的替代

- **跨跑图 meta 背包**：否决——本决策明确为单趟跑图内抉择。
- **保留携带卡包作中转**：否决——第二持有真相与「直写道具卡格」打架。
- **忙时拒收回收**：否决——玩家会感到回收时灵时不灵；改为排队。
